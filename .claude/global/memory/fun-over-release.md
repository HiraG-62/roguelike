ゲームの方向性を考えるとき、最優先は「いかに面白くするか」。Steam 発売はしたい気持ちはあるが目的ではない（2026-10-02、ブレストが発売準備〔体験版・トレーラー・ストア・英訳〕に寄りすぎた結果を見て）。

**Why:** 発売を軸にすると「売れる看板」「体験版の範囲」で案が選ばれ、遊びそのものの面白さの議論が薄まる。

**How to apply:** ブレストや優先度づけでは「遊んで面白くなるか」で並べる。発売の段取り・ストア・マーケの話は、ユーザーが求めたときだけ出す。品質の基準（安直な案を出さない）は発売のためではなく面白さのために保つ。関連: [[roguelike-hack-and-slash-vision]]、[[content-volume-policy]]

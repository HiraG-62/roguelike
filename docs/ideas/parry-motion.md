# 受け流しの動き（武器種ごとの受けの構え）

作成日: 2026-10-03
状態: 実装（全 29 武器種）

## 1. 目的（ユーザーの要望）

- 受け流し（全武器共通。`system/parry.ts`）に動きが無く、押したか・決まったかが分かりづらい
- 武器ごとに攻撃を受け止めるような動きを作る。見本は剣（刃を前上へ立てる）・大剣（刃を前下へ斜めに盾のように立てる）・双剣（2 本を交差）

## 2. 決めたこと

- **見た目だけ**。受け流しの窓・硬直・成否のロジックは変えない（`REPLAY_VERSION` も変えない）。描画は state を読むだけ
- 段階（`render/parryMotion.ts`。数値は `feel/PARRY_POSE.json`）
  - **構え**: 押した瞬間から `raiseSec` で受けの構えになり切る（窓 0.2 秒の頭で形が見える）。剣の右 1 段目の構えの受け流しも同じ構え
  - **決まった直後**（`parry` の印〔`parrySucceed` が置く〕の経過）: 受け止めた形のまま手が後ろへ押され・武器の先が押し返され（`pushDots` / `tiltDeg`、`jarSec` で戻る）、体は衝撃のコマ。`settleFrom` の後に待機の構えへ戻す。受けの部分に白い閃きと火の粉（`render/parrySpark.ts`）
  - **外した硬直**: 構えが崩れて手が下がり（`sagDots`）、`slackHold` の後に待機の構えへ戻す（硬直で動けないことが見て分かる）
  - 振り（反撃）・ダッシュが始まったらすぐそちらの動き（決まった直後の余韻より優先）
- 体: 受けのコマ 2 枚（`scripts/actor/rig.mjs` の `PARRY_KEYS`。0 = 足を開いて腰を落とし上体をわずかに引く / 1 = 押されて沈み後ろ足が滑る）。全ジョブ共通
- 腕と武器: 武器の絵の `meta.stance.parry`（`playerRig.ts` の `ParryStance`。武器を足す人が共有の表を触らずに済むよう、構えと同じく武器の絵のファイルが持つ）。照準によらず体の前に構える（受け流しは全方位なので向きは左右だけ）
  - `hand` / `deg` / `mirror`: 主の手と武器の向き
  - `off` / `offDeg` / `offMirror`: 二刀のもう 1 本、それ以外は添える素手（奥の腕なので構えの間は体の後ろに描く。体の前に描くと奥の腕が胴や顔の前を横切る）
  - `grip`: 両手持ちの添え手の柄の上の位置（柄を立てる長柄は尻の側だと後ろの肩から届かない）
  - `contact`: 受け止める所（火花の位置）
  - `barrier`: 武器で受けず体の前に結界を張る（値は色）。ユーザーの判断「魔法系の武器は武器で直接守るよりバリアを出す方がいい」で杖（紫）・書（青）・手鈴（金）。結界は向いている側の弧の帯で縁に光が走り、決まった瞬間は白く光って前へ膨らみ・結界の色の火花、外すと点が抜けて崩れる（`render/parryBarrier.ts`、数値は `PARRY_POSE.barrier`）
- 確認: `ppnpm run menu:shot --only "parry+weapons=sword,greatsword,twinBlades,spear"`（列 = 待機 / 構え / 決まった瞬間 / 押し返され / 解く / 外して崩れる / 左向き）

## 3. 武器種ごとの形（値は各武器の絵のファイル `scripts/actor/sheets/wpn<武器種>.mjs` の `parry`）

- 剣: 刃を前上へ立てる（見本 1）/ 大剣: 柄を頭の高さへ掲げ、刃を前下へ斜め（42°）に立てて盾にする（見本 2。ユーザーの判断「体が隠れてもよいので上に。下へ伸びすぎない」で、切っ先は足元まで）/ 双剣: 手前の刃を縦・奥の刃を斜め前に寝かせて十字（見本 3 の上向きの X は手前の刃が顔を横切る）
- 刀: 両手で前上へ斜めに掲げる / 槍: 柄を斜めに立てる / 棍: 胸の高さで横寄りに寝かせる / 斧・戦鎚・大鎌: 柄を斜めに寝かせ、頭を前上に
- 鉈: 刃の腹を縦に立てる / 鎖鎌: 柄を突き出し鎌を上へ / 鉄扇: 開いた扇をかざす / チェーンアレイ・鞭: 柄を掲げて後ろの手を添える / 投擲: 苦無 3 本を扇に広げる
- チャクラム: 2 枚を重ねて壁 / 爪: 両手の爪を前に立てて重ねる / 拳: 顎の前のガード / 大盾: 前へ突き出し後ろの手を裏に添える / 戦輪: 顔の高さでかざす
- 片手銃: 銃身を縦に立てる / 二丁拳銃: 2 挺を交差 / 長銃・砲・擲弾・仕掛け弓: 胸の前で斜めに抱え、添え手は銃床の側（先台は後ろの肩から届かない）
- 杖・書・手鈴: 結界（上の `barrier`）

## 4. 残り・候補

- 腕の届く距離（`ARM_SPAN` 10.5 ドット）が、大剣の見本どおりの斜め・双剣の上向きの X・長い銃の先台を握る形を妨げている。受けの構えの間だけ届く距離を延ばす案（レーンの要望）。今は見送り

# 受け流しの動き（武器種ごとの受けの構え）

作成日: 2026-10-03
状態: 実装（全 29 武器種）

## 1. 目的（ユーザーの要望）

- 受け流し（全武器共通。`system/parry.ts`）に動きが無く、押したか・決まったかが分かりづらい
- 武器ごとに攻撃を受け止めるような動きを作る。見本は剣（刃を前上へ立てる）・大剣（刃を前下へ斜めに盾のように立てる）・双剣（2 本を交差）

## 2. 決めたこと

- **見た目だけ**。受け流しの窓・硬直・成否のロジックは変えない（`REPLAY_VERSION` も変えない）。描画は state を読むだけ
- 段階（`render/parryMotion.ts`。数値は `feel/PARRY_POSE.json`）
  - **構え**: 押した瞬間から `raiseSec` で受けの構えになり切る（窓 0.2 秒の頭で形が見える）。剣の右 1 段目の構えの受け流しも同じ構え
  - **決まった直後**（`parry` の印〔`parrySucceed` が置く〕の経過）: 受け止めた形のまま手が後ろへ押され・武器の先が押し返され（`pushDots` / `tiltDeg`、`jarSec` で戻る）、体は衝撃のコマ。`settleFrom` の後に待機の構えへ戻す。受けの部分に白い閃きと火の粉（`render/parrySpark.ts`）
  - **外した硬直**: 構えが崩れて手が下がり（`sagDots`）、`slackHold` の後に待機の構えへ戻す（硬直で動けないことが見て分かる）
  - 振り（反撃）・ダッシュが始まったらすぐそちらの動き（決まった直後の余韻より優先）
- 体: 受けのコマ 2 枚（`scripts/actor/rig.mjs` の `PARRY_KEYS`。0 = 足を開いて腰を落とし上体をわずかに引く / 1 = 押されて沈み後ろ足が滑る）。全ジョブ共通
- 腕と武器: 武器の絵の `meta.stance.parry`（`playerRig.ts` の `ParryStance`。武器を足す人が共有の表を触らずに済むよう、構えと同じく武器の絵のファイルが持つ）。照準によらず体の前に構える（受け流しは全方位なので向きは左右だけ）
  - `hand` / `deg` / `mirror`: 主の手と武器の向き
  - `off` / `offDeg` / `offMirror` / `offBehind`: 二刀のもう 1 本、それ以外は添える素手
  - `grip`: 両手持ちの添え手の柄の上の位置（柄を立てる長柄は尻の側だと後ろの肩から届かない）
  - `contact`: 受け止める所（火花の位置）
- 確認: `npm run menu:shot -- --only "parry+weapons=sword,greatsword,twinBlades,spear"`（列 = 待機 / 構え / 決まった瞬間 / 押し返され / 解く / 外して崩れる / 左向き）

## 3. 武器種ごとの形

各武器の絵のファイル（`scripts/actor/sheets/wpn<武器種>.mjs`）の `parry` の上の 1 行コメントを正とする。

## 0. 結論

- 今のビルド要素は「数が多いが、ほとんどが加算の数値か条件付きの数値」。手触りを変えるものは各層で 5〜15% しかなく、層どうしが掛け算にならず、成長の天井（深度 26〜31）が敵より先に来る。**量を減らし、1 つの要素が「行動・変形・循環」のどれかを必ず変えるようにする**
- 骨格は 4 つに作り直す
  1. **数式**: 「増（加算の壺）× 倍（出所ごとの掛け算）」に一本化し、ソフトキャップをやめる。1 軸を盛るより別の倍を探す方が自然に得になり、それが「人それぞれの最強」を数学的に保証する
  2. **武器 = 戦意を持つ器**: 27 武器種を 13 の「型」に束ね（絵とベースは残す）、型ごとに 1 つの戦意（熱・返し・傷・溜め・弾倉…）と、それを放つ行動を持たせる。全ての型が同じ「瞬間」（終撃・充溢・放出・応手…）を出すので、1 枚の祝福が武器ごとに別の体験になる
  3. **流儀（ジョブ）= ダッシュの形と気力の湧き方**: 武器と直交する軸で、指の動きを確実に変える
  4. **祝福 = 系譜ごとの部屋**: 出口の予告で系譜を選び、1 回の提示は 1 系譜の 3 枚。札は「加護（行動の枠に付く）/ 摂理 / 研鑽 / 昇華」の 4 種。平坦な 198 種の砂場をやめる
- 伸び続ける強さは 3 本立て: **地力**（地金・ラン内の遺物が深度に追随）/ **相乗**（倍と「〜につき」の数）/ **研鑽**（ラン中に上限なく育つ）。深み（踏破後）は敵が指数で伸び、研鑽の出来が「どこまで潜れるか」を決める
- 量の目安: 祝福 198 → 約 100、技 322 → 約 60（+ 武器の変形表）、性質 211 → 約 70（数値は地金へ）、名のある遺物 76 → 約 18（全部に固有のコード）、武器種 27 → 13 型（ベース 115 は残す）

### 1-2. 相乗が起きない理由

- 加算の壺が 3 つ（装備の種別 % / 性質フラグ % / 属性の親和 %）に分かれ、乗算のゲートが約 12 層ある。規則が文書化されておらず、同じ「威力 +X%」が壺だったりゲートだったりする
- 統一ルール文法（25 イベント × 39 条件 × 42 効果）は「発火型の追加効果」しか書けない。**常時の倍率・行動の置き換え・内部の数え・「〜につき」の量・効果どうしの参照** が無い。そのため祝福の 84 種がフック直書きで、`BoonRuleState` に 31 フィールドの作業領域がある
- 連鎖は `chainDecay 0.5^深さ`・深さ 3 で打ち切り。暴走防止であって「循環の設計」ではない
- 流れ（旧「語」）の源 / 糧は祝福の抽選の重みと表示にだけ使われ、「強める」はどこにも読まれていない。スキル・刻印符・敵の Rule は型だけで定義 0
- 武器種を参照する要素: 性質 260 key 中 12、祝福 198 中 11、ジョブの得意 13 / 27。**武器を持ち替えてもビルドが変わらない**。拳銃で 3 択の札の 27% が近接前提の説明文

### 1-4. 選択が生まれない理由

- 装備: 死んでも失わない + ラン中に即付け替え → 拾う判断が無く、強さは倉庫 400 個の目利きで決まる。来歴は「着続けるほど強い」ので固定化の圧になる（`run-arc.md` の持ち込み 2 部位はこれを正面から解く）

## 2. 設計の柱

### 柱 1. ビルドは「行動・変形・循環・基礎」の 4 つでできている

| 要素 | 意味 | 例 | 主に持つ層 |
| --- | --- | --- | --- |
| 行動 | 何を押すと何が起きるか | 左の連撃・右の受け流し・ダッシュ・スキル・奥義 | 武器の型・流儀・スキル |
| 変形 | 行動がどう現れるか | 飛ぶ・回る・分かれる・置かれる・遅れて来る・繋がる・分身がなぞる | 刻印符・祝福の「加護」・改鋳・名のある遺物 |
| 循環 | 何が溜まり、何に変わるか。ここで伸びる | 熱・返し・傷・従魔の数・燃焼の重ね・倒した数の累計 | 武器の戦意・祝福の「研鑽」「昇華」・誓約 |
| 基礎 | 土台の数値 | 生命・防御・ステータス・増 % | 地金・流儀の偏り |

**全ての要素は、行動・変形・循環のどれかを変えなければならない**。基礎だけを変えるもの（「威力 +10%」）は地金に集め、性質・祝福・刻印符からは追い出す。

### 柱 2. 1 つの層に 1 つの役割

今は同じ「威力 +%」「X 時に気力」が性質・祝福・ジョブ・色の共鳴・刻印符のどこにでもある。層ごとに担う役割を決め、重複を禁じる。

| 層 | 永続か | 担うもの | 担わないもの |
| --- | --- | --- | --- |
| 武器の型 | 永続（持ち込み） | 左右の行動・戦意・共通の瞬間の出し方 | 数値の盛り |
| 流儀（ジョブ） | ランの開始に選ぶ | ダッシュの形・気力の湧き方・専用の系譜 1 本 | 得意武器の倍率、単一倍率の弱点 |
| スキル | 永続 | 追加の行動（4 枠） | 数値の格 |
| 刻印符 | **ラン内**（推奨） | スキルを変形する演算子 | 定数倍 |
| 祝福 | ラン内 | 行動への付与（加護）・常時のルール（摂理）・循環（研鑽・昇華） | 資源回収だけの札 |
| 改鋳（新） | ラン内 | 武器の型の行動そのものを変える（Hades のダイダロスの槌に相当） | — |
| 遺物の性質 | 永続（持ち込み）/ ラン内（拾い） | 条件付きの増・行動・転じ | 無条件の数値 |
| 遺物の地金 | 同上 | 数値の全部 | 挙動 |
| 名のある遺物 | 同上 | 固有の挙動（1 つずつ手書き） | 既存性質の束 |
| 誓約 | 同上 | 遊び方の大転換（排他グループ） | 条件付き倍率 |
| 共鳴（色の共鳴の後継） | 自動 | 源と糧が揃ったときの倍 | 色の配合パズル |

### 柱 3. 増と倍

与ダメは次の 1 本の式にする（詳細は 3 章）。

```
威力 = 行動の基礎（Scaling）× (1 + Σ 当てはまる増) × Π 当てはまる倍 × 敵側
```

- **増**: 加算の壺。タグ（近接・射撃・スキル・継続・炎・怯み中・対ボス…）ごとに持ち、1 撃が当てはまる増を全部足す。性質・地金・流儀・祝福の摂理が主に出す
- **倍**: 出所ごとの掛け算。誓約・芯・昇華・名のある遺物・戦意の放出・循環（〜につき）だけが出す。1 つ 1 つがビルドの顔になる

なぜ多様性が生まれるか: 予算 100 を「近接の増」に全部入れると ×2.0。50 を増、50 を別の条件の倍（×1.5）に入れると 1.5 × 1.5 = ×2.25。**増は盛るほど 1 点の価値が下がり、別の倍を足す方が常に得**になる。どの倍の条件（怯み中 / 燃えている敵 / 背面 / 戦意が満ちた時…）を選ぶかは遊び方で決まるので、最適は人の数だけある。ソフトキャップのような人工の天井は要らない（攻撃速度と移動速度だけは操作が破綻するので上限を残す）。

### 柱 4. 伸びは 3 本立て

| 種類 | 中身 | 深度との関係 |
| --- | --- | --- |
| 地力 | 地金・ラン内で拾う遺物の期待値・持ち込み遺物の数値（深度に合わせて伸びる。4-5） | 敵の生命と同じ曲線に追随する。止めない |
| 相乗 | 倍の数、「〜につき」の相手、共鳴、改鋳、昇華 | ランの中で 1 → 5〜12 倍へ。これが「ビルドが完成していく」手応え |
| 研鑽 | 倒した数・燃やした数・受け流した数などで、ラン中に上限なく育つ | 深み（踏破後）で唯一、指数の敵に追い付ける経路 |

### 柱 5. 共通の瞬間で武器を越えて効く

全ての武器の型が同じ名前の瞬間を出す（4-1）。祝福・性質・刻印符は武器名ではなく瞬間を参照する。

- 終撃（連撃の締め・放出・起爆・最大溜め攻撃）
- 充溢（戦意が上限に達した）
- 放出（戦意を使った）
- 応手（受け流し・構え・見切り・弾返しの成功）
- 双撃（左右を交互に当てた）
- 先制（交戦の最初の一撃）

「終撃の時、前方に斬撃波」は、連刃なら熱の乱舞の最後に、剣なら返し斬りに、砲なら一斉起爆に、長銃なら最大溜め攻撃に乗る。**札は 1 枚、体験は武器の数だけ**。今の「拳銃で 27% が近接の札」も消える。

### 柱 6. 「〜につき」で層を掛け合わせる

PoE の相乗の最小単位は「A につき B が伸びる」。文法の量の基準に次を足す。

- 持っている系譜の段数につき / 同じ流れの源の数につき
- 敵に重なった状態異常の数につき / 近くの敵の数につき / 繋いだ敵の数につき
- 戦意の量につき / 従魔の数につき / 研鑽の値につき

例: 「灰燼の研鑽: 燃焼で倒した敵 1 体につき燃焼の倍 +1%」。燃やす手段（武器・スキル・祝福・地形）を増やすほど研鑽が速く育ち、研鑽が育つほど燃やす手段の価値が上がる。**環が閉じると循環になる**。

### 柱 7. 指の動きの審査

新しい要素を足す・残すときは、次のどれが変わるかを 1 文で言えなければならない。言えないものは地（地金）へ移すか削る。

| 変わるもの | 例 |
| --- | --- |
| 押すもの | ダッシュが不退になる。右が受け流しから居合になる |
| 押す時 | 敵の予備動作を待つ。熱が満ちるまで手を止めない。弾倉を撃ち切る |
| 立つ場所 | 自分の炎の上で戦う。敵を束ねて密集させる。遠くに離れる |
| 狙う相手 | 印の敵だけを殴る。燃えている敵から倒す。精鋭を先に |
| 見るもの | 戦意のゲージ・敵の傷の数・従魔の位置・研鑽の値 |

例: 「見切りで気力 +25」→ どれも変わらない → 流儀「拳闘士」の気力の湧き方（柱 2）に吸収して祝福からは削る。「専心（1・2 段目が消える）」→ 押す時が変わる → 残す。

### 柱 8. 永続は「行動と来歴」、数値はランの深度に合わせる

`run-arc.md` の決定（持ち込み 2 部位・袋・持ち帰り）を前提にする。持ち込んだ遺物の **地金はランの深度に合わせて伸びる**（発見深度ではなく今の深度の期待値へ寄せる。4-5）。永続の価値は「その遺物が持つ行動・固有の挙動・来歴」になり、倉庫の目利きで数値を選別する作業が無くなる。強さの一極化（装備の有無で到達 1.00 → 2.63）もここで解ける。

### 柱 9. 収束させて、分岐させる

- **収束**: 出口の予告で系譜を選び、提示は 1 系譜の 3 枚。欲しい方向へ自分で寄せられる（今は平坦すぎて寄らない）
- **分岐**: 加護の枠は 1 枠 1 枚で、差し替えると前の札は消える。倍の条件どうしに排他を置く（誓約グループ、一念 / 巡礼の遺物）。章ごとに改鋳・芯の選び直しがある
- 「毎回違う」は抽選の幅ではなく **手札（持ち込み 2 + ラン内の拾い）と、章ごとの選択の分岐** から生む

## 3. 数式の作り直し

### 3-1. 与ダメ

| 段 | 中身 | 今との違い |
| --- | --- | --- |
| 基礎 | 行動の `Scaling`（base + Σ係数 × 実効ステータス） | 同じ。逓減も据え置き |
| 増 | `PlayerStats.increased: Record<DamageTag, number>`。タグ例: `melee` `ranged` `skill` `ultimate` `dot` `area` `placed` `minion` `fire` `cold` `lightning` `poison` `dark` `light` `vsStaggered` `vsBoss` `vsElite` `reaction` `counter` `backstab` `resource` | 装備の種別 %・性質フラグ %・属性の親和 % の 3 壺を 1 つに。ソフトキャップ廃止 |
| 倍 | `PlayerStats.more: MoreMul[]`（`{ source, mul, when?: RuleCondition[] }`） | 条件付き二値のゲートと誓約の直掛けを、出所付きの列にまとめる |
| 会心 | 倍の 1 つ（×1.5）。会心の倍率は増のタグ `critMulti` で伸びる | 会心が軸になれる（今は性質 11 件） |

| 敵側 | 防御・魔防・耐性・弱点・脆弱・砕き・ダウン | 据え置き。ただし弱点を突く報酬を耐性の罰より大きく（弱点率 2% / 耐性率 9.8% の偏りを直す。4-6） |

表示は「増 +X%」「倍 ×Y」の 2 語に統一し、装備画面の計算式の頁に出所ごとに並べる（単一指標は出さない）。

### 3-2. 敵の深度曲線

| 量 | 章 1〜4（深度 1〜20） | 深み（踏破後、深度 22〜） |
| --- | --- | --- |
| 生命 | ×(1 + 0.15(d−1))（今の 0.18 を少し寝かせる） | 深度 21 の値 × 1.12^(d−21) |
| 攻撃 | **倍率** ×(1 + 0.05(d−1))。flat 加算をやめ、敵の個性（スライムとゴーレムの差）を保つ | × 1.04^(d−21) |
| 怯み耐性 | 生命と同じ曲線（今の 0.08 は生命より速く、しかも上限なし） | 生命と同じ |
| 予備動作 | 今と同じ（下限 0.6〜0.75） | 同じ。速さでは難しくしない |
| 数と質 | 敵数・精鋭率は今と同じ | 変異（ランイベントの常時化）を階ごとに積む（今の器を流用） |

- 章 1〜4 は「まとまったビルドなら無理なく、ばらばらなら章 3〜4 で詰まる」を狙う
- 深みは「どこまで潜れるか = ビルドの物差し」（Balatro の無限アンティ）。**プレイヤー側に上限を置かない**。止めるのは敵の指数だけ。性能の歯止め（弾・設置物・従魔の数）は置くが、強さの歯止めは置かない

### 3-3. 怯み

- 怯み値に増のタグ `poise` を通す。誓約・祝福・武器の戦意で倍も付けられる
- 検査を固定: 「深度 d の通常の敵は、同じ深度の地力に見合う装備で、連撃 1 周（右の段込み）で怯む」（`weapons.test.ts` 系）
- 処刑・背面・受け流しに `onExecute` / `onBackstab` / `onParry` のイベントと、伸ばせる閾値（処刑の生命割合・受けの窓・背面の倍）を足す。今はどれも伸ばす手段が 0

### 3-4. 状態異常・反応

- **継続ダメージは付けた一撃の威力に比例**（燃焼 = 一撃 × 係数 / 秒）。ビルドの火力が燃焼に乗る。毒だけは最大生命 %（ボスは低く）を残し、役割を分ける
- on-hit の判定を「敵ごと 0.2 秒に 1 回」から **期待値の保存**（手数が多い武器は 1 ヒットの確率が下がり、合計の期待値は同じ）に。手数の武器には「重ねやすい」利点が残る
- 反応 24 組をコードの分岐からデータ表 `REACTIONS`（消費する状態・相手・効果・効果量の出どころ）へ。反応の効果量は増のタグ `reaction` と反応ごとのタグで伸ばせる。ビルドが「新しい反応の組を足す」こともできる（名のある遺物・昇華）
- 総スタック 15・異常 5 種の上限は撤廃。上限は行動停止系（凍結・麻痺・恐怖）の拘束時間だけに残す。「重ねる」ビルドを構造的に禁じない

### 3-5. 連鎖

- `chainDecay 0.5^深さ` と深さ 3 の打ち切りを、Risk of Rain 2 の proc coefficient に当たる **連鎖係数** に置き換える。Rule の効果ごとに 0〜1 の係数を持ち、その効果から起きた次の Rule の確率に掛かる（爆発 0.5、連鎖雷 0.3、斬撃波 1.0 など）
- 連鎖係数そのものを伸ばす札・遺物を置く（「連鎖の源」ビルド）。無限ループの保険として深さ 8 で打ち切る
- `direct`（連鎖に数えない）の区別は廃止し、全ての効果が連鎖の起点になれる

### 4-1. 武器の型（13）

### 4-2. 流儀（ジョブ 10）

ジョブを「ダッシュの形」と「気力の湧き方」と「専用の系譜 1 本」で作り直す。**武器の型と直交する**ので、同じ剣でも流儀で指の動きが変わる。得意武器の倍率・単一倍率の弱点・条件付き数値の Rule 14 本は削る。ステータスの偏り（合計 0）は残す。

| 流儀 | ダッシュの形 | 気力の湧き方 | 専用の系譜 | 手触り |
| --- | --- | --- | --- | --- |
| 見習い | 標準（無敵の短い駆け） | 通常攻撃の命中 | なし（出口の系譜が 1 つ多く並ぶ） | 素直。何にでもなれる |
| 剣士 | 踏み込み: 短い突進。攻撃の途中から出せ、次の段へ繋がる | 受け・カウンター・終撃 | 連ね | 攻めを途切れさせない |
| 狩人 | 飛び退き: 後ろへ跳び、足元に小さな罠 | 遠い命中ほど多い | 罠と印 | 距離を取り続ける |
| 拳闘士 | 潜り: 短く低い。見切りの窓が広い | コンボ数に比例 | 連打 | 懐で避けて殴る |
| 盾持ち | 不退: ダッシュの代わりに正面を受ける（不退の間に移動入力で滑る） | 受けた攻撃の量 | 城 | 受けてから動く |
| 呪術師 | 霧: 通過した敵に呪い。無敵は短い | 状態異常の継続の刻み | 疫 | 撒いて待つ |
| 槍兵 | 跳躍: 敵を飛び越え、着地で突く | 先端の命中 | 間合い | 敵の頭上を渡る |
| 術士 | 瞬間移動 | **スキルの命中が気力を返す** | 術式 | スキルで回す（スキル主役が成立する） |
| 影 | 影潜り: 長く移動・攻撃不可。出た直後の一撃は背面扱い | 背面・処刑 | 影 | 消えて背を取る |
| 錬金術師 | 瓶投げ: 短い移動 + 足元に薬の地形 | 反応 | 調合 | 場を混ぜる |

- 気力の湧き方を流儀が決めることで、1-4 の「スキル比率が 54% に固定」が解ける（術士はスキル主役、拳闘士は通常攻撃主役）
- 「鉄壁の構え（ダッシュ → ガード）」のような祝福は盾持ちの流儀へ移す（祝福からは削る）
- 起点は 4 つ（放浪者・素手・死神の友・賭博師）に絞る。剣の巡礼者・呪われた者・詠み手は流儀か芯に吸収

### 4-3. スキルと刻印符

**スキル = 行動、符 = 変形の演算子**（PoE のスキルジェムとサポートジェムの関係、Shape of Dreams のスキルとエッセンスの関係）。

| 項目 | 今 | 作り直し |
| --- | --- | --- |

| 刻印符 | 53（形を変えるのは 8） | 約 30: **変形の演算子 20 + 循環の符 10**。数値倍率だけの 11 枚と条件付き倍率 14 枚は循環の符へ統合 |

| 溜め | 長押しで段が上がる。段ごとに形が大きくなる |

### 4-6. 状態異常・反応・地形

3-4 の数式に加え:

- **弱点を突く報酬を大きく**: 弱点の倍を上げ、敵の頭上の弱点の印を「このランで一度当てたら見える」から「近付いたら見える」に。今は耐性で削られる罰（9.8%）の方が弱点（2%）より多く起きている
- 地形は「踏む」から「置く」へ: 武器の放出・流儀のダッシュ（錬金術師）・符の軌跡・地形化で、プレイヤーが地形を作る手段を増やす。地形の面積・持続は増のタグ `terrain` で伸びる
- 反応を起こす人のためのビルドの道: 錬金術師の流儀・継ぎ目の外套・反応の増・反応の研鑽（「起こした反応の種類の数につき倍」）

- 「1 階 1 点」は判断を生まないので削る。地力の伸びは地金と拾う遺物が担う（柱 8）

### 5-3. 守りの伸び

攻撃だけが伸びて守りが有界だと、深みで「2 発で死ぬ」になる（1-3）。守りは次の 3 つで伸ばす。

- **攻めを守りに変える**: 与ダメの % を障壁・吸命にする札と遺物（渇きの杯）。攻めが伸びれば守りも伸びる
- **止めて守る**: 怯み・凍結・恐怖・繋ぎで「攻撃させない」。怯みの曲線を直す（3-3）ことで深層でも成り立つ
- **受けて守る**: 構え・受け流し・受け溜め。被ダメの倍率で減らす（防御の上限 75% とは別の出所の倍）

## 7. ビルドの原型 12

同じ部品の組み替えで、指の動きと伸び方がこれだけ変わる、という見本。どれも「系譜 1〜2 本 + 武器の型 + 流儀」で組める。**弱みがあること** を必ず書く（弱みの無い原型は最強のテンプレになる）。

| 原型 | 武器の型 / 流儀 | 系譜と札 | スキルと符 | 遺物・誓約 | 手触り | 伸び方 | 弱み |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 火車 | 連刃 / 拳闘士 | 灰燼（乱舞に燃焼・ダッシュが燃える）+ 研鑽「灰」 | 旋風に連打・軌跡 | 重ねの首飾り | 燃える輪の中で手を止めず殴る | 燃焼は一撃比例 × 灰の研鑽 | 距離を取る敵・弾幕 |
| 鎖の牧者 | 鎖 / 呪術師 | 月蝕 + 群れ | 呪いの霧に連鎖 | 伝染の誓約 | 敵を束ね、呪いを移して回る | 繋ぎ × 伝染（敵の数につき） | 単体のボス |
| 地雷原 | 砲 / 錬金術師 | 灰燼 + 雷鳴 | 地雷に分裂・設置 | 継ぎ目の外套 | 置いて誘い、反応で吹き飛ばす | 置ける数 × 反応の型の研鑽 | 素早い敵、置く前の被弾 |
| 返しの達人 | 剣 / 剣士 | 刃鳴 + 大地 | パリィに応手連動 | 星読みの眼・鏡の鞘 | 攻撃を待って取る | 印の研鑽（受けた数） | 攻撃してこない敵・群れ |
| 影の群れ | 投具 / 影 | 刃鳴（影の兵）+ 群れ | 飛刃に分身 | 影縫いの針 | 消えては投げ、影が真似る | 影の数 × 撃破 | 生命が少なく、囲まれると脆い |
| 使役者 | 重打 / 盾持ち | 大地 + 群れ（従魔・地投げ） | 引力球に引き寄せ | 群れ呼びの笛 | 怯ませて処刑し、群れを増やす | 群の研鑽 | 怯みにくい敵・ボス戦の序盤 |

| 硝子の狙撃 | 長銃 / 狩人 | 雷鳴 + 霜枷 | 撃ち抜きに貫き | 硝子の砲・遠間の誓い | 止まって 1 発で抜く | 最大溜め攻撃 × 会心 → 連鎖 | 近付かれると終わり |
| 不動の城 | 盾 / 盾持ち | 大地 + 月蝕 | 震脚に遅延 | 逆さ砂時計・渇きの杯 | 受け止め、溜めて返す | 恨の研鑽 | 遠くから撃ってくる敵 |

## 8. 固定のビルドにしない仕組み

| 仕組み | 何を防ぐか |
| --- | --- |
| 増と倍の数式（柱 3） | 1 軸の盛りが自然に損になる。人工の天井なしで最適が割れる |
| 倍の条件の排他（誓約グループ、一念 / 巡礼の排他、近間 / 遠間） | 全部取りの最強 |
| 加護の枠は 1 枠 1 枚 | 同じ行動に全部乗せ。差し替えで乗り換えの判断が生まれる |
| 出口で系譜を選ぶ + 1 提示 1 系譜 | 平坦な砂場（何を持っても同じ）と、逆に「毎回同じ札」の両方 |
| 持ち込み 2 部位 + ラン内の遺物 | 毎回同じ装備。手札が毎回違う |
| 改鋳・芯を章ごとに選ぶ | 最初の選択でランが決まってしまうこと |
| 章ごとのバイオームと敵の性質（弱点の報酬を大きく） | 1 属性の固定。ただし耐性の罰で縛らず、弱点の報酬で誘う |

| 発見（手がかりの枠・図鑑の連携） | 知っている組み合わせだけを繰り返すこと |
| 弱みの明記（7 章） | 弱みの無い原型 = テンプレ |

## 11. 決めてほしいこと（推奨つき）

1. **武器種を 13 の型に束ねる**（推奨）。束ねた武器種はベース・絵・効果音・奥義として残す。「剣と刀が同じ型」のように、手に取った感じが近いものは個性（右の段の 1 つ・リーチ・速さ）で分ける。代案: 27 種のまま全部に資源を付ける（工数が倍で、重複組は残る）
2. **刻印符をランごとに消す**（推奨。HANDOFF の保留）。永続はスキル（行動）、ラン内は符（変形）。持ち込み 2 部位の方針と揃う
3. **持ち込んだ遺物の数値をランの深度に合わせる**（推奨）。倉庫の目利きを無くし、永続の価値を行動と来歴にする
4. **色の共鳴を、源と糧の組み合わせによる「共鳴」に置き換える**（推奨）。色は分類・残響・ステータスの色分けに残す。星座は削る
5. **ステータスの振り分けをやめ、改鋳と錬磨に置き換える**（推奨）
6. **深みで「壊れ」を許す**（推奨）。プレイヤー側に上限を置かず、敵の指数だけで止める
7. **終撃連動・応手連動の符**（武器の終撃 / 応手と同時にスキルが出る）を許すか。気力は払い、発動のきっかけはプレイヤーの操作なので「オート攻撃」ではない、と考えるのが推奨。ただし `docs/ideas/skills.md` で Cast on X を不採用にした経緯があるので確認したい
8. **祝福の加護の枠**（1 つの行動に 1 枚、差し替えで前の札が消える）。推奨。代案: 枠なしで重ねられる（相乗は増えるが、行動ごとの判断が消える）
9. 量の方針: これまでの「出たアイデアは全部入れる」から「柱 7 の審査を通ったものだけ入れる」へ切り替えてよいか（今回の依頼の趣旨から、そう読んだ）

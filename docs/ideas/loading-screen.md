# 読み込み画面「絵巻」（2026-10-05 決定）

階・拠点に入るとき、1 階ぶんの地図を描き終えるまで（`MapChunkCache.prepare`。`docs/ideas/map-visual-impl.md` 1-3 節）の数秒に出す画面。見本は 6 案のうち「二 絵巻」に決めた（見本のページ: https://claude.ai/artifact/138qEexstxLRwjM6Dhee6P）。

## 見せるもの

- 暗い墨染めの地の真ん中に横長の巻物。左の軸は動かず、右の軸が進み具合に合わせて右へ転がり、紙が開いていく
- 紙には行き先の水墨画（山水）。遠山・中景・両脇の崖を淡墨〜濃墨の 6 段とディザで描く。章の様式（`MapStyle`）で中景の建物、階の種類（`FloorKind`）で手前の添え物を描き分ける
  - 様式: 苔 = 松 / 寺院 = 塔 / 城（炎・氷）= 天守 / 深み・最深 = 裂け目 / 拠点 = 鳥居と屋根
  - 階の種類: 洞窟 = 洞の口 / 暗闇 = 空を濃く / 鍛冶場・鉱山 = 煙 / 沼 = 葦と水の線 / 氷河 = 雪（山の頭を白く残す）/ 野原 = 草 / 骨塚 = 枯れ木 / 通常 = なし
- 紙の右端に題箋（行き先の札）。縦書きで「地下 3 階」と階の種類の名（拠点は「拠点」、稽古の間・御堂はその名）
- 巻物の下に Tips ノートから 1 項目（見出し「心得 ・ 語」+ 本文）。選び方は seed と深度のハッシュ（`state.rng` は使わない）。長い項目は外す
- 広げきったら題箋に朱印を押し、クリック（どこでも。決定キー・パッドの決定でも）を待つ。押してから `holdSec` の後に「クリック / 決定キー で進む」を明滅させ、押されたら薄れて階の画面が現れる（2026-10-05 追加。読み込み中に押したクリックは捨てる）
- 朱印は画面の実際の細かさ（論理 1px = 4 ドット。`RENDER_SCALE`）で作り、「淵」を篆刻ふうの白抜きの線で刻む（ドットフォントの 16 ドットでは画数の多い字が潰れるため）

## 時間と進み具合

- 進み具合 = 描き終えたチャンクの数 ÷ 全チャンクの数（拠点は町の層の出来上がりも待つ）。紙の開きは進み具合へ指数的に追いつく（段々の進みでもなめらかに見せる）
- 地図を描き終えたら: 紙を広げきる → 朱印（弾み）→ クリックを待つ → 薄れる。薄れている間は後ろに階の画面を描く。ゲームは薄れ終わるまで止めたまま
- 数値（追いつきの速さ・朱印・受け付けるまでの秒・案内の明滅・薄れる秒）は `src/data/balance/feel/LOADING.json`
- 画像（体・エフェクト）だけを待つとき（装備の付け替え）は出さない（短いので前の画面のまま止める）。起動直後のフォント待ちも出さない（字が描けない）

## 置き場所

- `src/ui/loadingScreen.ts`: 段取り（開く・朱印・クリックを待つ・薄れる）と進み具合の追いつき、行き先の名と Tips の選び方。DOM に触らない純関数
- `src/render/loadingScrollArt.ts`: 巻物の紙と山水の画素列を作る純関数（様式と階の種類で描き分け、決定的）
- `src/render/loadingScreenUi.ts`: 描画（地・巻物の開き・軸・題箋・朱印・Tips）。文字は `drawText`
- `src/main.ts`: 地図を描いている間は読み込み画面を描き、描き終えたら薄れる間だけ階の画面に重ねる。更新は解き放つまで止め、その間の入力はクリック / 決定の受け付けにだけ使う（読み込み中の入力は捨てる）
- 時計は描画側の実時間（ゲームの時刻は止まっているため）。見た目だけでロジックには効かない

# 銃と投擲物の見直し（2026-10-03。方針決定・一部未決・未着手）

拠点の武器掛けの試用は、これまで銃の家系ごとに「一番早く出る器」の弾で固定だった（長銃 = 火縄銃、砲 = 喇叭銃、短銃 = 拳銃、投擲 = 投げ短剣、戦輪 = 返し輪）。そのため各武器種の型（戦意の溜まり方と放出）・右レーン・派生・奥義・改鋳・文が、その代表の弾を前提に作られてしまっている。武器掛けで器を選べるようにした（同日）ので、全組み合わせが見えるようになった。

この文書は、その食い違いの洗い出し（1・2 章）と、ユーザーが決めた方針（0 章）・未決の論点（3 章）を持つ。決定の元はユーザーのメモ `memo/20261003-1.md`（優先）と、この文書の初版へのレビュー `docs/reviews/gun-bases-review.review.md`。動機は「銃が強すぎる（安全圏から一方的に撃てる）」の調整。

## 0. 決定（2026-10-03 ユーザー）

### 0-1. グループ分け

- **銃**: 二丁拳銃・短銃・長銃・砲・擲弾・仕掛け
- **投擲物**: 投擲・戦輪。銃とは別の概念として扱い、それぞれ別の個性を持たせる
- 投擲は **器ごとに別の武器種** にし、武器掛けでは「投擲」にまとめて並べる（最初はクナイと手裏剣。今後も増やす。器ごとに通常攻撃・特色・奥義・戦意が違う）
- **武器掛けの並び**: 最初の段で「近接・銃・投擲物」を選び、開いた段で武器種、銃・戦輪はさらに器を選ぶ（3 段の形）。「投擲物」の段にはクナイ・手裏剣・戦輪を直接並べる
- **消す器の手持ち**: 移行は作らない（開発段階なので旧データの互換を持たない。`docs/AI_WORKFLOW.md`「速く進める原則」）
- 今の投擲の器（投げ短剣・吹き矢・跳ね銃・導きの珠）と戦輪の器（返し輪・円月輪・飛刃）は消す。近接の武器種チャクラム（`ringBlades`）を戦輪へ移して統合し、見た目はチャクラムの物を使う

### 0-2. 資源（銃に限らない）

- **遠距離の攻撃では気力と奥義ゲージが溜まらない**。銃・投擲物の弾だけでなく、杖・書の魔法の弾も含む
- **戦意は何で溜めてもよい**（射撃・炸裂・止まっている秒なども可）
- 代わりに、どの銃にも資源を戻すための近接攻撃を持たせる。射撃が主で、近接はおまけ程度。「近づかなければ気力が戻らない」というリスクを銃の強さに足すため

### 0-3. 銃の共通の仕組み

- **弾倉**: すべての銃に戦意とは別の弾倉を持たせる。リロードで満タンになり、撃つたびに減る（今の短銃・二丁拳銃の「撃つと増えて満ちたら装填」の戦意とは逆）。撃ち切ったらリロードが要る。容量・リロードの秒・リロード中の足の速さは武器と器（弾）ごとに違う。**引き金を引いた回数** で数える（散弾の粒・三点の 3 本は 1 回）。始めの値は 2-8 節
- **近接**: 長銃の銃剣は残す。他の銃は作り直してよい。ただし全部の銃で同じ形にはせず、それぞれの銃の特徴に合った攻撃にする
- **派生の弾（P2）= A 案**: 派生の弾の数を「普段の射撃を何回撃つか」と読む。1 回の射撃の形（1 + 装備の弾数 + 散弾の粒、三点）は捨てない。例: 散弾銃の装填撃ち = 3 粒 ×1 回、拳銃 + 弾数 +1 の三連射 = 2 発 ×3 回、三連銃の三連射 = 三点 ×3 回。散弾・三点の器の派生が強くなるので倍率は引き直す
- **派生の弾と弾倉**: 派生の弾も弾倉を減らす（撃った射撃の回数ぶん）。残りが撃つ回数に足りなければ残りの分だけ撃つ（振りは出る。弾倉は 0 になる）
- **三点（P4）**: 2・3 本目も同じ射撃として扱い、放出と持続の奥義の補正を全部に掛ける。終撃は 1 本目だけ
- **揺れ（P7）**: 放出の弾には揺れを掛けない（短銃の狙い撃ちはやめるので、狙い撃ちの分は不要になった）
- **計測（P10）**: 連打計測の武器種の節を器ごとに測る節に広げる

### 0-4. 銃の武器種ごと

| 武器種 | 決定 |
| --- | --- |
| 長銃（火縄銃・手砲） | 放出は溜め切った（最大段の）発射でだけ使う。撃つ溜めの最中は連撃の入力窓を止める（今の不具合）（P3） |
| 長銃（小銃・電磁砲・弩・三連弩） | 放出は **リロード後の 1 発目**（弾倉の新しい仕組みに載せる）（P5） |
| 長銃の近接 | 銃剣を残す |
| 砲 | artillery から外して **新しい型「装薬」** を作る（P1）。リロードは 1 発ずつ込める形にし、弾倉が満ちた後も込め続けると「詰め」が戦意として溜まる（最大 3 段）。放出は次の 1 発で、詰めた段ぶん散弾の粒と威力が増え、反動で大きく後ろへ飛ぶ。詰めている間は撃てず足も遅い（新しい弾倉を砲の個性にする）。近接は **込め棒（槊杖）の突き**: 込めている最中にも出せて、込めは止まらない（詰めている間に近づいた敵をあしらう）。**詰めの段**: 1 段 約 0.5 秒。1 段 = 粒 +2（5 粒）・各 1.3 倍・反動 40px / 2 段 = +4（7 粒）・1.6 倍・70px / 3 段 = +6（9 粒）・2.0 倍・100px（壁で止まる）。**右レーン**: 込め棒の突き → 突き → 零距離砲（零距離砲も詰めの放出を使え、強い反動で後ろへ跳ぶ。筒殴り・尻叩きは消す）。**改鋳と奥義**: 吸着は仕掛けの改鋳へ移す。連爆は「放出の粒が当たった敵が炸裂する」に作り直す。奥義「全弾発射」は「弾倉の残りを全部詰めて 3 段の 1 発として撃ち出す」に作り直す |
| 擲弾 | 戦意は炸裂させた数。放出は筒払い（右 1 段目）へ移す。戦意は **敵を 1 体以上巻き込んだ炸裂だけ** 数え、6 で満ちて放てる（満ちないと放てない。空撃ちでは溜まらない）。4 秒巻き込まないと 1 秒に 1 つずつ冷める（P8）。近接は **今の筒払い・筒突き・蹴り飛ばし**（至近に落とせないので押し返して間合いを作る。筒払いは放出も兼ねる） |
| 短銃 | 近接は **空いた手の逆手の短刀**（片手銃なので、銃と短刀の二刀）。右 1 段目を短刀の斬りにし、**今の狙い撃ちはやめる**（強い弾の役は早込めの強装填が担う。短銃は「左で撃ち、右で短刀」）。それ以外の技は今のまま。今の戦意（弾倉）は弾倉の仕組みへ移る。新しい戦意は **早込め**: リロード中に出る拍でもう一度押すと早く込め終えて戦意が溜まる（外すと込めが遅れる）。放出は次の弾倉が「強装填」になる（今の強装填の手触りを新しい弾倉へ移す）。**早込めの窓**: リロードの進みの 55〜70% のあたりに 0.15 秒。窓で押せば即込め終わりで戦意 +1（最大 3）、窓の外で押すと込めが 0.5 秒延びる。満ちたら次の弾倉が強装填（全弾 1.5 倍・怯み値 1.5 倍） |
| 二丁拳銃 | 二丁だからこそ: **弾倉を左右 2 本** に分ける（左クリック = 左手、右クリック = 右手で撃ち、片手で撃ちながら片手で込められる）。戦意は **左右を交互に撃つ拍** で溜まる（同じ手が続くと崩れる）。近接は **弾切れの手の銃把打ち**: 弾倉が空で込めている手のクリックは銃把で殴る（込めは止まらない。片手で撃ち、片手で殴りながら込める）。**放出**: 左右を同時に押すと、両手の弾倉の残りを一気に扇へ撃ち尽くす「弾幕」（戦意の段ぶん強い。撃ち終えると両手とも込めに入る。今の右の弾幕をここへ移す）。**技**: 基本の操作が左右交互なので、逆に **同じ手を続けて押すと連撃の技・近接** が出る（左右交互の拍とは別の入り口）。**左の連続** = 蹴り → 回し蹴り（近接の流れ）、**右の連続** = 銃把打ち → 回転撃ち（回りながら右手の弾を全周へ撒く）。同じ手を続けると交互の拍（戦意）はそこで途切れる。弾切れの手の銃把打ちも残す |
| 仕掛け | 型は今のまま（設置弾で溜まる）。近接は **罠へ蹴り込む**: 今の罠蹴りを強め、蹴った敵を一番近い自分の設置弾の方へ飛ばす（無ければまっすぐ）。「置いて、蹴り込んで、起爆」が一連の流れになる |

### 0-5. 投擲物

- **クナイ**: 左で 1 本ずつ投げる。右は近接。標準では貫通しない。単発で重い。連撃の核は **刺して叩き込む**: 投げたクナイは敵に刺さって残り、刺さった敵を右の近接で打つとクナイを叩き込んで大きな傷（「投げて、詰めて、叩き込む」）
- **手裏剣**: 左 1 回で 3 本をまっすぐ、右 1 回で 3 本を扇に投げる。連撃の核は **刺さった数で崩す**: 同じ敵に刺さった手裏剣の数が溜まり、一定数で怯む。連撃は左右を混ぜるほど投げる本数が増え、段の 1 つに大きい手裏剣の多段ヒット。標準では貫通しない。手数・飛ぶ物の数で押す。左右とも遠距離なので、気力は **ダッシュの抜け斬り** で戻す（ダッシュ攻撃が敵をすり抜けながら斬り、斬った敵の数だけ気力が戻る。ゲンジの疾風斬に近い）。着想は Overwatch のゲンジ
- **戦輪**（チャクラムと統合。`memo/pic/チャクラム投擲.png`）
  - 体の上下から 2 枚を投げ、弧を描いてカーソルの位置まで飛んで交差し、また弧を描いて手元へ戻る。最大射程あり
  - 投げている間は次を投げられない（戻ってから投げられる）。投げている間は手ぶらに見せる。飛ぶ輪は手に持っている絵のまま
  - 連撃は近接と投げを織り交ぜる。連撃の中の投げはカーソルへではなく短い固定の射程（見た目の上で投げる動き）。これも戻るまで次の攻撃につなげない
  - 連撃の段の 1 つとして、発生の遅い（長押しではない）強化投げ
  - **器**: チャクラムの器（輪刃・牙輪）を戦輪の器にし、**器ごとに飛び方を変える**。輪刃 = 上下 2 枚の弧（基本）。牙輪 = 当てた最初の敵に食い込み、0.4 秒そこで回って 4 回当たってから戻る（当てると戻りが遅れ、次の投げも遅れる。射程は輪刃より短い）
  - **戦意**: 1 回の投げで **行きと帰りの両方で当てた敵** 1 体につき +1（最大 4）。満ちると連撃の強化投げが大輪になり、貫いて戻る（今の型「投具」の「飛んでいる数」は戻るまで投げられないので使わない）
  - **奥義**: 戦輪とチャクラムの 6 本から 3 本を残す: 断頭輪（巨大な輪をゆっくり投げ、全て貫き戻りでも当たる）・輪舞（全周へ輪を 4 本）・輪の舞（持続。振りが速く広く）。環の陣・乱輪・円環の理は消す

## 2. 食い違いの一覧

実測は vitest の一時テスト（各器を右手に入れた `createGame`）。

### 2-1. 砲: 型がまるごと死んでいる（最優先）

- 型 artillery の戦意は「置いた弾」の数（`data/weaponForms.ts` の artillery、`gain: placedShots`）。数えるのは設置弾と曲射だけ（`system/morale.ts` の `isPlacedShot`）。砲の器はどちらも散弾なので、**戦意は常に 0**（3 秒撃ち続けて 0。仕掛けは 4、擲弾は 3）
- 放出の零距離砲（右）は振りとしては出るが、放出にも起爆にもならない
- 奥義「全弾発射」の起爆の半分、改鋳「吸着」（設置弾だけが対象）と「連爆」（放出の命中が起点）が死ぬ。改鋳の 3 択は装備中の型の改鋳を先に並べるので、砲を持つと死んだ札が先頭に出る
- 文: 砲の desc・特色（`data/weaponFeatures.ts`）・零距離砲の段の文・型の文「弾を置いて広げ、一斉に起爆する」が成り立たない
- 経緯: 砲は元々「散弾・曲射・設置」の 3 系統の器を持っていた（`weapon-redesign.md` 155 行）。曲射と設置を擲弾・仕掛けへ分けたとき、型が据え置かれた

### 2-2. 擲弾: 型の前提が仕掛け寄り

- 曲射は飛んでいる間しか「置いた弾」に数えない（寿命 0.9 秒以下）。放出の蹴り飛ばしは右の 3 段目（筒払い 0.37 秒 → 筒突き 0.41 秒の後）なので、放出の時点で床に残る曲射は 0〜1 個（計算のみ・未実測）
- 改鋳「吸着」は設置弾だけが対象なので死ぬ

### 2-3. 長銃: 死んではいないが、放出が溜め撃ち前提とずれている

| | 火縄銃・手砲（溜め） | 小銃・電磁砲・弩 | 三連弩（三点） |
| --- | --- | --- | --- |
| 放出（満ちた 1 発） | 溜めの段を問わず満ちた後の最初の発射で使う。**タップ（0.6 倍）でも使い切る**。設計メモは「満ちた後の 1 発 = 最大溜め」（`weapon-forms-impl.md` 234 行） | 押しっぱなしの連射の中で自動で出る（止まって 5 秒で 2 回）。「狙った 1 発」ではなく「止まっていると周期的に強い弾」 | **1 本目だけ**が放出。2・3 本目は通常の弾（`updateBurst` が放出を通さない） |
| 派生 | **溜め撃ちで入力列が消える**（撃つ溜めの最中も連撃の窓が減る。`player.ts` の `tickButtonChain` は近接の溜めしか見ない）。31 フレーム以上溜めると「左→右→左」の派生が出ない。派生の弾は溜め無しの 0.6 倍 | 問題なし | 派生の弾が 1 本（三点にならない） |
| 奥義 | 狙撃手の息の「速く撃てる」は射撃間隔にだけ効き、溜めの 1.1 秒には効かない（1 発あたり 1.27 → 1.23 秒でほぼ無効） | 問題なし | 持続の奥義の補正が 2・3 本目に乗らない |
| 改鋳 | 問題なし | 問題なし | 散華は 1 本目の命中でだけ起きる |

- 死にデータ: rifle 型の終撃にある `aimedShot` はどこからも読まれない（長銃に狙い撃ちの段は無い）

### 2-4. 短銃: 弾倉 8 発固定が器に合っていない

| | 拳銃・回転式 | 短機関銃 | 三連銃 |
| --- | --- | --- | --- |
| 弾倉（型） | 問題なし（5 秒で装填が 24%） | 装填が時間の **44%**。5 秒の火力が拳銃を下回る | 1 回の射撃 = 1 発と数えるので 24 本撃てる（装填 12%）。強装填が 3 倍の弾に乗る |
| 右（狙い撃ち） | 問題なし | 揺れが狙い撃ちにも乗る | 1 本で撃つ（三点にならない） |
| 派生・奥義 | 問題なし | 問題なし | 派生の弾が 1 本ずつ。集中の貫通 +1 が 2・3 本目に乗らない |

### 2-5. 投擲・戦輪・二丁拳銃・仕掛け

- 仕掛け・二丁拳銃: 問題なし
- 投擲: 型・手元返し・派生は問題なし。文「刃を投げる」「左で投げる」が吹き矢・導きの珠・跳ね銃に合わない。奥義「早業」の「まっすぐ」は追尾の器では嘘になる。改鋳「双刃」（投げる刃が 1 枚増え）は投擲の右レーンに対象の段が無く効かない（器の差ではなく武器種の問題）
- 戦輪: 問題なし（右の輪投げ・二輪は技が持つ戻る弾）。円月輪では左の弾が戻らないので、応手「戻りの弾での敵弾消し」は輪投げからしか出ない（小）

### 2-6. 武器種をまたぐ問題: 1 回の射撃の形が捨てられる

散弾の粒・三点の続き・溜めの段が、派生の弾・放出・持続の奥義・狙い撃ちで捨てられる。

- 派生の弾は `count: 1` で撃つので、砲の「装填撃ち」（倍率 1.5）が 1 粒・合計 3.5 になり、通常の射撃（3 粒・合計 7.1）の半分
- 三点の続きは放出・持続の奥義を通さない（2-3・2-4）

### 2-7. 計測の代表もずれている

連打計測（`qa/combatProbe.ts`）は表の順の最初の器（長銃 = 小銃、戦輪 = 円月輪、砲 = 散弾銃）で、試用と指南書は一番早く出る器（長銃 = 火縄銃、戦輪 = 返し輪）。狩人の初期武器は弩。

## 2-8. 弾倉の数値（2026-10-03。ユーザーが始めの値として承認）

## 2-9. 投擲物の技の一式（2026-10-03。ユーザーが承認。数値は始めの値）

### クナイ（単発で重い。刺して叩き込む）

| 入力 | 技 |
| --- | --- |
| 左 | 1 本投げる。刺さって残る（1 体に最大 3 本、5 秒で抜ける）。貫通しない |
| 右の連撃 | 逆手斬り → 返し斬り → 叩き込み（刺さっているクナイを全部叩き込み、1 本ごとに大きな傷）。どの段も刺さった敵に当てれば叩き込む |

| ダッシュ攻撃 | 踏み込みの突き |

| 入力 | 技 |
| --- | --- |
| 左 | 3 本をまっすぐ（縦に並ぶ）。小さく速い。貫通しない |

## 4. 実装の段（2026-10-03 夜。設計役の段取りを統合役が採用）

### 4-1. 設計の要（設計役の 4 章）

- **群**: `MovesetDef.group`（melee / gun / throwing）を明示し、述語を 4 つに分ける: `isGun`（群が銃。弾倉・銃の決まり）/ `isThrowingWeapon` / `isRangedWeapon`（群が近接でない。器が弾を持つ・武器掛けの器の段）/ `shootsPrimary`（左の押しっぱなしで器の弾を撃つ）。`baseFamily` は 3 値
- **弾倉**: `Player.magazine`（戦意とは別。手を 2 本持ち、二丁拳銃も同じ型）。`system/magazine.ts` が持つ
- **遠距離の資源**: プレイヤーの弾（Projectile）の命中では気力も奥義ゲージも増やさない（`gainShotMana`・`pr.energy` を撤去）。ジャンル "ranged" では切らない（銃剣などの近接で戻らなくなるため）

- **刺さる弾**: `Enemy.pins`（`system/pins.ts`・`render/pinsUi.ts`）
- **戦輪の弧**: 二次ベジエの位置を毎ステップ置く（`ShotRuntime.arc`）。投げの組は `ShotRuntime.trip`

### 4-3. 設計役の確認点への統合役の決定（ユーザー就寝中。起きたら見直してもらう）

1. **リロードの入力**: キーを 1 つ足す（既定 T。今の T の「床のアイテム情報の表示切替」は Y へ移す。パッドは空いているボタン）。撃ち切ったら自動でも込める。短銃の早込めは込めの最中にリロードか左を押す。砲はリロードを押し続ける間込め続けて詰める。込めの最中に撃てるのは砲だけ（1 発込めた後）
2. **狩人の流儀の「遠い命中で気力」**: 弾の命中では湧かない。狩人の源は近接寄り（ダッシュ攻撃の命中）に作り直す。流儀の「終撃の命中」の源も弾では湧かない
3. **新しい型の改鋳**: この改修では 0 個を許す（テストを「型ごとに 0 か 2」に一時的に緩める）。手元返し・投げ放ち・装填の窓が消えて働かない改鋳（牽引・双刃・疾駆）は消す。新しい改鋳は後で別に作る
4. **派生の数**: 二丁拳銃（交互撃ちと衝突）と手裏剣は派生なし、クナイは 2 本。テストに理由付きの除外を足す
5. **名前の重なり**: クナイの派生「影縫い」→「影留め」、手裏剣の奥義「風車」→「八方手裏剣」、「大風車」→「大車輪」、二丁拳銃の放出「弾幕」→「撃ち尽くし」
6. **二丁拳銃**: 1 クリック 1 発。拍の上限 6、拍が 0 でも撃ち尽くしは撃てて段ぶん強くなる。回転撃ちは右手の残りを全部使う
7. **手裏剣**: 同じ手を続けても段はそのまま。押しっぱなしで投げ続けない。連ね投げは満ちた後の次の投げで始まる。「縦に並ぶ」は進む向きに直交した 3 本の平行
8. **戦輪**: 投げている間は右の輪払いも出せない（手ぶら）。受け流しとダッシュは出せる。牙輪も上下 2 枚・弧で飛ぶ。近投げは 1 枚、強化投げは 2 枚
9. **長銃（溜めでない器）**: 放出には「戦意が満ちている」と「リロード後の 1 発目」の両方が要る
10. **短銃**: 戦意が満ちたその込めの弾倉が強装填。早込めの窓は進みの 55% から 0.15 秒で、器によらない
11. **性質の家系**: 家系が "gun" の性質 4 つ（連射の烙印・杭・転じ 2）は投擲物にも付く
12. **消す器の遺物**: 読み込み時に捨てる（移行は作らない方針）
13. **新しい語（仮。起きたら確認）**: 型と戦意の名 = 二丁拳銃「二丁 / 拍」・装薬「装薬 / 詰め」・擲弾「擲弾 / 炸裂」・クナイ「苦無 / 叩き込み」・手裏剣「手裏剣 / 崩し」・戦輪「戦輪 / 往復」。短銃の右 1 段目「短刀斬り」
14. **クナイの「1 本ごとに大きな傷」**: 追撃のダメージ（刺さったときの威力 × 倍率）
15. **出始めの深さ**: クナイ 2・手裏剣 3

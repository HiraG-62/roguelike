# 銃と投擲物の見直し（2026-10-03。方針決定・一部未決・未着手）

拠点の武器掛けの試用は、これまで銃の家系ごとに「一番早く出る器」の弾で固定だった（長銃 = 火縄銃、砲 = 喇叭銃、短銃 = 拳銃、投擲 = 投げ短剣、戦輪 = 返し輪）。そのため各武器種の型（戦意の溜まり方と放出）・右レーン・派生・奥義・改鋳・文が、その代表の弾を前提に作られてしまっている。武器掛けで器を選べるようにした（同日）ので、全組み合わせが見えるようになった。

この文書は、その食い違いの洗い出し（1・2 章）と、ユーザーが決めた方針（0 章）・未決の論点（3 章）を持つ。決定の元はユーザーのメモ `memo/20261003-1.md`（優先）と、この文書の初版へのレビュー `docs/reviews/gun-bases-review.review.md`。動機は「銃が強すぎる（安全圏から一方的に撃てる）」の調整。

## 0. 決定（2026-10-03 ユーザー）

### 0-1. グループ分け

- **銃**: 二丁拳銃・短銃・長銃・砲・擲弾・仕掛け
- **投擲物**: 投擲・戦輪。銃とは別の概念として扱い、それぞれ別の個性を持たせる
- 投擲は **器ごとに別の武器種** にし、武器掛けでは「投擲」にまとめて並べる（最初はクナイと手裏剣。今後も増やす。器ごとに通常攻撃・特色・奥義・戦意が違う）
- 今の投擲の器（投げ短剣・吹き矢・跳ね銃・導きの珠）と戦輪の器（返し輪・円月輪・飛刃）は消す。近接の武器種チャクラム（`ringBlades`）を戦輪へ移して統合し、見た目はチャクラムの物を使う

### 0-2. 資源（銃に限らない）

- **遠距離の攻撃では気力と奥義ゲージが溜まらない**。銃・投擲物の弾だけでなく、杖・書の魔法の弾も含む
- **戦意は何で溜めてもよい**（射撃・炸裂・止まっている秒なども可）
- 代わりに、どの銃にも資源を戻すための近接攻撃を持たせる。射撃が主で、近接はおまけ程度。「近づかなければ気力が戻らない」というリスクを銃の強さに足すため

### 0-3. 銃の共通の仕組み

- **弾倉**: すべての銃に戦意とは別の弾倉を持たせる。リロードで満タンになり、撃つたびに減る（今の短銃・二丁拳銃の「撃つと増えて満ちたら装填」の戦意とは逆）。撃ち切ったらリロードが要る。容量・リロードの秒・リロード中の足の速さは武器と器（弾）ごとに違う
- **近接**: 長銃の銃剣は残す。他の銃は作り直してよい。ただし全部の銃で同じ形にはせず、それぞれの銃の特徴に合った攻撃にする
- **派生の弾（P2）= A 案**: 派生の弾の数を「普段の射撃を何回撃つか」と読む。1 回の射撃の形（1 + 装備の弾数 + 散弾の粒、三点）は捨てない。例: 散弾銃の装填撃ち = 3 粒 ×1 回、拳銃 + 弾数 +1 の三連射 = 2 発 ×3 回、三連銃の三連射 = 三点 ×3 回。散弾・三点の器の派生が強くなるので倍率は引き直す
- **派生の弾と弾倉**: 派生の弾も弾倉を減らす（撃った射撃の回数ぶん）。残りが撃つ回数に足りなければ残りの分だけ撃つ（振りは出る。弾倉は 0 になる）
- **三点（P4）**: 2・3 本目も同じ射撃として扱い、放出と持続の奥義の補正を全部に掛ける。終撃は 1 本目だけ
- **短機関銃の狙い撃ち（P7）**: 狙い撃ちと放出の弾には揺れを掛けない
- **計測（P10）**: 連打計測の武器種の節を器ごとに測る節に広げる

### 0-4. 銃の武器種ごと

| 武器種 | 決定 |
| --- | --- |
| 長銃（火縄銃・手砲） | 放出は溜め切った（最大段の）発射でだけ使う。撃つ溜めの最中は連撃の入力窓を止める（今の不具合）（P3） |
| 長銃（小銃・電磁砲・弩・三連弩） | 放出は **リロード後の 1 発目**（弾倉の新しい仕組みに載せる）（P5） |
| 長銃の近接 | 銃剣を残す |
| 砲 | artillery から外して **新しい型** を作る。戦意の溜め方は零距離の散弾に限らない（未決）（P1） |
| 擲弾 | 戦意は炸裂させた数。放出は筒払い（右 1 段目）へ移す。溜まりやすいので放出に要る数を上げる（P8） |
| 短銃・二丁拳銃 | 今の戦意（弾倉）は弾倉の仕組みへ移り、新しい戦意のアクションを作る。短銃は今のまま、二丁拳銃は二丁だからこそできるアクションにして差を付ける |
| 仕掛け | 型は今のまま（設置弾で溜まる） |

### 0-5. 投擲物

- **クナイ**: 左で 1 本ずつ投げる。右は近接。連撃は近接と投げを織り交ぜる（要検討）。標準では貫通しない。単発で重い
- **手裏剣**: 左 1 回で 3 本をまっすぐ、右 1 回で 3 本を扇に投げる。連撃は要検討（案の 1 つ: 連撃の段の 1 つで大きい手裏剣を投げ、当たった敵に多段ヒット）。標準では貫通しない。手数・飛ぶ物の数で押す。左右とも遠距離なので、気力を戻す手段を別に入れる。着想は Overwatch のゲンジ
- **戦輪**（チャクラムと統合。`memo/pic/チャクラム投擲.png`）
  - 体の上下から 2 枚を投げ、弧を描いてカーソルの位置まで飛んで交差し、また弧を描いて手元へ戻る。最大射程あり
  - 投げている間は次を投げられない（戻ってから投げられる）。投げている間は手ぶらに見せる。飛ぶ輪は手に持っている絵のまま
  - 連撃は近接と投げを織り交ぜる。連撃の中の投げはカーソルへではなく短い固定の射程（見た目の上で投げる動き）。これも戻るまで次の攻撃につなげない
  - 連撃の段の 1 つとして、発生の遅い（長押しではない）強化投げ

## 2. 食い違いの一覧

実測は vitest の一時テスト（各器を右手に入れた `createGame`）。

### 2-1. 砲: 型がまるごと死んでいる（最優先）

- 型 artillery の戦意は「置いた弾」の数（`data/weaponForms.ts` の artillery、`gain: placedShots`）。数えるのは設置弾と曲射だけ（`system/morale.ts` の `isPlacedShot`）。砲の器はどちらも散弾なので、**戦意は常に 0**（3 秒撃ち続けて 0。仕掛けは 4、擲弾は 3）
- 放出の零距離砲（右）は振りとしては出るが、放出にも起爆にもならない
- 奥義「全弾発射」の起爆の半分、改鋳「吸着」（設置弾だけが対象）と「連爆」（放出の命中が起点）が死ぬ。改鋳の 3 択は装備中の型の改鋳を先に並べるので、砲を持つと死んだ札が先頭に出る
- 文: 砲の desc・特色（`data/weaponFeatures.ts`）・零距離砲の段の文・型の文「弾を置いて広げ、一斉に起爆する」が成り立たない
- 経緯: 砲は元々「散弾・曲射・設置」の 3 系統の器を持っていた（`weapon-redesign.md` 155 行）。曲射と設置を擲弾・仕掛けへ分けたとき、型が据え置かれた

### 2-2. 擲弾: 型の前提が仕掛け寄り

- 曲射は飛んでいる間しか「置いた弾」に数えない（寿命 0.9 秒以下）。放出の蹴り飛ばしは右の 3 段目（筒払い 0.37 秒 → 筒突き 0.41 秒の後）なので、放出の時点で床に残る曲射は 0〜1 個（計算のみ・未実測）
- 改鋳「吸着」は設置弾だけが対象なので死ぬ

### 2-3. 長銃: 死んではいないが、放出が溜め撃ち前提とずれている

| | 火縄銃・手砲（溜め） | 小銃・電磁砲・弩 | 三連弩（三点） |
| --- | --- | --- | --- |
| 放出（満ちた 1 発） | 溜めの段を問わず満ちた後の最初の発射で使う。**タップ（0.6 倍）でも使い切る**。設計メモは「満ちた後の 1 発 = 最大溜め」（`weapon-forms-impl.md` 234 行） | 押しっぱなしの連射の中で自動で出る（止まって 5 秒で 2 回）。「狙った 1 発」ではなく「止まっていると周期的に強い弾」 | **1 本目だけ**が放出。2・3 本目は通常の弾（`updateBurst` が放出を通さない） |
| 派生 | **溜め撃ちで入力列が消える**（撃つ溜めの最中も連撃の窓が減る。`player.ts` の `tickButtonChain` は近接の溜めしか見ない）。31 フレーム以上溜めると「左→右→左」の派生が出ない。派生の弾は溜め無しの 0.6 倍 | 問題なし | 派生の弾が 1 本（三点にならない） |
| 奥義 | 狙撃手の息の「速く撃てる」は射撃間隔にだけ効き、溜めの 1.1 秒には効かない（1 発あたり 1.27 → 1.23 秒でほぼ無効） | 問題なし | 持続の奥義の補正が 2・3 本目に乗らない |
| 改鋳 | 問題なし | 問題なし | 散華は 1 本目の命中でだけ起きる |

- 死にデータ: rifle 型の終撃にある `aimedShot` はどこからも読まれない（長銃に狙い撃ちの段は無い）

### 2-4. 短銃: 弾倉 8 発固定が器に合っていない

| | 拳銃・回転式 | 短機関銃 | 三連銃 |
| --- | --- | --- | --- |
| 弾倉（型） | 問題なし（5 秒で装填が 24%） | 装填が時間の **44%**。5 秒の火力が拳銃を下回る | 1 回の射撃 = 1 発と数えるので 24 本撃てる（装填 12%）。強装填が 3 倍の弾に乗る |
| 右（狙い撃ち） | 問題なし | 揺れが狙い撃ちにも乗る | 1 本で撃つ（三点にならない） |
| 派生・奥義 | 問題なし | 問題なし | 派生の弾が 1 本ずつ。集中の貫通 +1 が 2・3 本目に乗らない |

### 2-5. 投擲・戦輪・二丁拳銃・仕掛け

- 仕掛け・二丁拳銃: 問題なし
- 投擲: 型・手元返し・派生は問題なし。文「刃を投げる」「左で投げる」が吹き矢・導きの珠・跳ね銃に合わない。奥義「早業」の「まっすぐ」は追尾の器では嘘になる。改鋳「双刃」（投げる刃が 1 枚増え）は投擲の右レーンに対象の段が無く効かない（器の差ではなく武器種の問題）
- 戦輪: 問題なし（右の輪投げ・二輪は技が持つ戻る弾）。円月輪では左の弾が戻らないので、応手「戻りの弾での敵弾消し」は輪投げからしか出ない（小）

### 2-6. 武器種をまたぐ問題: 1 回の射撃の形が捨てられる

散弾の粒・三点の続き・溜めの段が、派生の弾・放出・持続の奥義・狙い撃ちで捨てられる。

- 派生の弾は `count: 1` で撃つので、砲の「装填撃ち」（倍率 1.5）が 1 粒・合計 3.5 になり、通常の射撃（3 粒・合計 7.1）の半分
- 三点の続きは放出・持続の奥義を通さない（2-3・2-4）

### 2-7. 計測の代表もずれている

連打計測（`qa/combatProbe.ts`）は表の順の最初の器（長銃 = 小銃、戦輪 = 円月輪、砲 = 散弾銃）で、試用と指南書は一番早く出る器（長銃 = 火縄銃、戦輪 = 返し輪）。狩人の初期武器は弩。

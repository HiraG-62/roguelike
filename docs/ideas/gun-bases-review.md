# 銃の器ごとの見直し（2026-10-03。案の段階・未着手）

拠点の武器掛けの試用は、これまで銃の家系ごとに「一番早く出る器」の弾で固定だった（長銃 = 火縄銃、砲 = 喇叭銃、短銃 = 拳銃、投擲 = 投げ短剣、戦輪 = 返し輪）。そのため各武器種の型（戦意の溜まり方と放出）・右レーン・派生・奥義・改鋳・文が、その代表の弾を前提に作られてしまっている。武器掛けで器を選べるようにした（同日）ので、全組み合わせが見えるようになる。ここではその食い違いを洗い出し、直し方の案を並べる。**方針と論点（4・5 章）をユーザーが決めてから着手する。**

## 1. 器ごとの弾の性質（今）

| 武器種（型） | 器と弾の性質 |
| --- | --- |
| 長銃（rifle） | 火縄銃・手砲 = 溜め撃ち / 小銃・電磁砲・弩 = 貫通の単発（押しっぱなしで連射）/ 三連弩 = 三点 |
| 短銃（pistol） | 拳銃・回転式拳銃 = 素 / 三連銃 = 三点 / 短機関銃 = 揺れのある連射 |
| 砲（artillery） | 喇叭銃・散弾銃 = 散弾（どちらも同じ） |
| 擲弾（artillery） | 曲射筒・擲弾筒 = 曲射 |
| 仕掛け | 撒き菱筒・置き撃ち筒 = 設置弾 |
| 投擲（thrower） | 投げ短剣 = 揺れのある連射 / 吹き矢・導きの珠 = 追尾 / 跳ね銃 = 跳弾 |
| 戦輪（thrower） | 返し輪・飛刃 = 戻る / 円月輪 = 跳弾 |
| 二丁拳銃（pistol） | 二丁拳銃・双回転式 = 素（同じ） |

## 2. 食い違いの一覧

実測は vitest の一時テスト（各器を右手に入れた `createGame`）。

### 2-1. 砲: 型がまるごと死んでいる（最優先）

- 型 artillery の戦意は「置いた弾」の数（`data/weaponForms.ts` の artillery、`gain: placedShots`）。数えるのは設置弾と曲射だけ（`system/morale.ts` の `isPlacedShot`）。砲の器はどちらも散弾なので、**戦意は常に 0**（3 秒撃ち続けて 0。仕掛けは 4、擲弾は 3）
- 放出の零距離砲（右）は振りとしては出るが、放出にも起爆にもならない
- 奥義「全弾発射」の起爆の半分、改鋳「吸着」（設置弾だけが対象）と「連爆」（放出の命中が起点）が死ぬ。改鋳の 3 択は装備中の型の改鋳を先に並べるので、砲を持つと死んだ札が先頭に出る
- 文: 砲の desc・特色（`data/weaponFeatures.ts`）・零距離砲の段の文・型の文「弾を置いて広げ、一斉に起爆する」が成り立たない
- 経緯: 砲は元々「散弾・曲射・設置」の 3 系統の器を持っていた（`weapon-redesign.md` 155 行）。曲射と設置を擲弾・仕掛けへ分けたとき、型が据え置かれた

### 2-2. 擲弾: 型の前提が仕掛け寄り

- 曲射は飛んでいる間しか「置いた弾」に数えない（寿命 0.9 秒以下）。放出の蹴り飛ばしは右の 3 段目（筒払い 0.37 秒 → 筒突き 0.41 秒の後）なので、放出の時点で床に残る曲射は 0〜1 個（計算のみ・未実測）
- 改鋳「吸着」は設置弾だけが対象なので死ぬ

### 2-3. 長銃: 死んではいないが、放出が溜め撃ち前提とずれている

| | 火縄銃・手砲（溜め） | 小銃・電磁砲・弩 | 三連弩（三点） |
| --- | --- | --- | --- |
| 放出（満ちた 1 発） | 溜めの段を問わず満ちた後の最初の発射で使う。**タップ（0.6 倍）でも使い切る**。設計メモは「満ちた後の 1 発 = 最大溜め」（`weapon-forms-impl.md` 234 行） | 押しっぱなしの連射の中で自動で出る（止まって 5 秒で 2 回）。「狙った 1 発」ではなく「止まっていると周期的に強い弾」 | **1 本目だけ**が放出。2・3 本目は通常の弾（`updateBurst` が放出を通さない） |
| 派生 | **溜め撃ちで入力列が消える**（撃つ溜めの最中も連撃の窓が減る。`player.ts` の `tickButtonChain` は近接の溜めしか見ない）。31 フレーム以上溜めると「左→右→左」の派生が出ない。派生の弾は溜め無しの 0.6 倍 | 問題なし | 派生の弾が 1 本（三点にならない） |
| 奥義 | 狙撃手の息の「速く撃てる」は射撃間隔にだけ効き、溜めの 1.1 秒には効かない（1 発あたり 1.27 → 1.23 秒でほぼ無効） | 問題なし | 持続の奥義の補正が 2・3 本目に乗らない |
| 改鋳 | 問題なし | 問題なし | 散華は 1 本目の命中でだけ起きる |

- 死にデータ: rifle 型の終撃にある `aimedShot` はどこからも読まれない（長銃に狙い撃ちの段は無い）

### 2-4. 短銃: 弾倉 8 発固定が器に合っていない

| | 拳銃・回転式 | 短機関銃 | 三連銃 |
| --- | --- | --- | --- |
| 弾倉（型） | 問題なし（5 秒で装填が 24%） | 装填が時間の **44%**。5 秒の火力が拳銃を下回る | 1 回の射撃 = 1 発と数えるので 24 本撃てる（装填 12%）。強装填が 3 倍の弾に乗る |
| 右（狙い撃ち） | 問題なし | 揺れが狙い撃ちにも乗る | 1 本で撃つ（三点にならない） |
| 派生・奥義 | 問題なし | 問題なし | 派生の弾が 1 本ずつ。集中の貫通 +1 が 2・3 本目に乗らない |

### 2-5. 投擲・戦輪・二丁拳銃・仕掛け

- 仕掛け・二丁拳銃: 問題なし
- 投擲: 型・手元返し・派生は問題なし。文「刃を投げる」「左で投げる」が吹き矢・導きの珠・跳ね銃に合わない。奥義「早業」の「まっすぐ」は追尾の器では嘘になる。改鋳「双刃」（投げる刃が 1 枚増え）は投擲の右レーンに対象の段が無く効かない（器の差ではなく武器種の問題）
- 戦輪: 問題なし（右の輪投げ・二輪は技が持つ戻る弾）。円月輪では左の弾が戻らないので、応手「戻りの弾での敵弾消し」は輪投げからしか出ない（小）

### 2-6. 武器種をまたぐ問題: 1 回の射撃の形が捨てられる

散弾の粒・三点の続き・溜めの段が、派生の弾・放出・持続の奥義・狙い撃ちで捨てられる。

- 派生の弾は `count: 1` で撃つので、砲の「装填撃ち」（倍率 1.5）が 1 粒・合計 3.5 になり、通常の射撃（3 粒・合計 7.1）の半分
- 三点の続きは放出・持続の奥義を通さない（2-3・2-4）

### 2-7. 計測の代表もずれている

連打計測（`qa/combatProbe.ts`）は表の順の最初の器（長銃 = 小銃、戦輪 = 円月輪、砲 = 散弾銃）で、試用と指南書は一番早く出る器（長銃 = 火縄銃、戦輪 = 返し輪）。狩人の初期武器は弩。

## 3. 横断的な方針（推奨）

1. **戦意の溜まり方と放出は武器種（無ければ型）単位で決め、器の弾の性質に依存させない。** 避けられない武器種（砲・擲弾）は、武器種ごとに型の戦意を上書きする口で表す（前例は棍の `moraleLabel`）
2. **弾の性質は「1 回の射撃の形」（粒・三点・溜めの段・揺れ）として扱い、補正で捨てない。** 放出・派生の弾・持続の奥義・狙い撃ちの補正は射撃全体に掛ける。派生の `count` は「射撃の回数」と読み、三点の続きも同じ射撃にする。溜め撃ちだけは「放出 = 最大段の発射」
3. **弾の性質が無いと成り立たない部品（改鋳・奥義の部品・文）は、出現条件か条件付きの文で出し分ける**（改鋳に `requires` を足す）

理由: 器を選んで試せるようになったので、型の側を弾に依存しない形に寄せておけば、器を足すたびに型が壊れることがなくなる。

採らない案: 器ごとに型の変種を持たせる（25 器 × 型で数値と文が膨らむ。弾倉の大きさのような数値 1 つだけは例外として弾に持たせる）/ 弾の性質を別の武器種へ移す（所持品・名のある遺物・QA への波及が大きい）。

## 4. 問題ごとの案

### P1 砲の戦意（2-1）

- **案 A（推奨）: 零距離の散弾で溜める。** 武器種ごとの戦意の上書き口を作り、砲は「零距離（例 40px 以内）で当てた散弾の粒」で溜まって冷める形にし、零距離砲を放出にする。散弾・零距離砲・奥義「火薬庫」（近い敵ほど強い）が一本の筋になる。欠点: 同じ型でも溜まり方が違う武器種ができる
- 案 B: 散弾が「置いた弾」を残す（外れた粒や反動で火薬の残りを床に置く）。型・改鋳・全弾発射がそのまま生きる。欠点: 画面が散らかり、新しい弾の挙動が要る
- 案 C: 砲を artillery から外し、新しい型を作る。一貫するが重い（改鋳 2・FORM・用語集・指南書）
- どの案でも: 改鋳「吸着」は設置弾を撃つ器だけに出す。全弾発射と零距離砲の文を「床に設置弾があれば」に。説明文 4 か所

### P2 派生の弾が粒・三点を捨てる（2-6）

- **案 A（推奨）: 派生の `count` を射撃の回数と読み、1 回の射撃の粒（弾数の性質 + 散弾）は残す。** 散弾の派生の火力が約 3 倍になるので砲の派生の倍率を引き直す
- 案 B: 砲のデータだけ count を 3 にする（装備の弾数の性質は乗らず、三点の派生も残る）

### P3 長銃の溜め撃ちと放出（2-3）

- **案 A（推奨）: 溜め撃ちの器は最大段の発射でだけ放出を使う。** あわせて、撃つ溜めの最中は連撃の入力窓を止める（1 行のバグ修正）。派生の弾は溜め 1 段目で撃つ。狙撃手の息の速さを溜めの時間にも掛ける
- 案 B: 溜めの器では戦意を「溜めの短縮」にする（満ちていれば押した瞬間に最大段）。欠点: 終撃が起点の改鋳「散華」と噛み合わない
- 案 C: 火縄銃・手砲を別の武器種へ移す（波及が大きい）

### P4 三点の放出と持続の奥義（2-3・2-4）

- **案 A（推奨）: 三点の続きを同じ射撃として扱う。** 放出・持続の奥義を通した弾を三点の続きにも使う。終撃は 1 本目だけ、倍率は 3 本すべて。state の形が変わるのでリプレイの版を上げる
- 案 B: 1 本目に 3 本分の倍率を乗せる（見た目と効果がずれる）

### P5 小銃系の放出が連射の中で自動で出る（2-3）

- **案 A（推奨）: 今のままとする。** 文は今のままで足りる
- 案 B: 押し直した最初の 1 発でだけ放出する（狙う手触りは出るが、連射の遊びが変わる）

### P6 短銃の弾倉（2-4）

- **案 A（推奨）: 弾倉の大きさを器の弾の数値に持たせる**（省略は今の 8）。短機関銃 16（撃ち切りまで 1.36 秒で拳銃と同じ）、三連銃 4〜5。弾倉の粒の HUD と手触りが保てる
- 案 B: 撃った秒で数える（弾に依存しない原則にいちばん忠実だが、HUD が秒の棒になる）
- 案 C: 装填の窓を射撃間隔に比例させる（強装填の拍が器ごとに変わる）

### P7 短機関銃の狙い撃ちが揺れる（2-4）

狙い撃ちと放出の弾には揺れを掛けない（小さな修正）。

### P8 擲弾の戦意がほぼ放出に届かない（2-2）

- 案 A: P1 の上書き口で「炸裂させた数」を溜めて冷める形にし、放出を筒払い（右 1 段目）へ移す
- 案 B: 曲射の落ちた所に、置いた弾として数える短い残り火を残す

### P9 文とデータ（2-5・2-3）

- 投擲の「刃」を「投げ物」へ。奥義「早業」の「まっすぐ」を削る
- rifle 型の終撃の `aimedShot` を消す
- 改鋳「双刃」: 投擲では「左の投げ物が 1 本増える」に読み替えるか、出現を戦輪・輪刃に限る

### P10 計測（2-7）

連打計測の武器種の節を、器ごと（銃 25 器）に測る節に広げる。

## 5. ユーザーに決めてもらう論点

1. 方針（3 章）でよいか。特に「戦意は器の弾に依存させない」「射撃の形を補正で捨てない」
2. 砲の戦意: 案 A（零距離で当てた散弾）/ B（散弾が置いた弾を残す）/ C（新しい型）
3. 擲弾も同じ段で直すか。直すなら「炸裂させた数」か「残り火」か
4. 火縄銃・手砲の放出を最大段の発射に限ってよいか（タップでは放出を使えなくなる）
5. 小銃系の放出: 連射の中で自動に出る今のままでよいか、押し直した 1 発にするか
6. 三点の放出は 3 本すべてに倍率を掛けるでよいか
7. 短銃の弾倉: 短機関銃 16・三連銃 4〜5 でよいか、秒で数えるか
8. 派生の弾を射撃の回数に揃えると散弾の派生の火力が約 3 倍になる。数値の引き直しを含めて進めてよいか
9. 投擲の文の「刃」→「投げ物」でよいか。跳ね銃は投擲に置いたままか
10. 改鋳「双刃」を投擲でも効かせるか、戦輪・輪刃だけに出すか

## 6. 実装の段（方針が決まった後）

1. **射撃の形を保つ**（`system/player.ts`・`system/weaponArts.ts`、`core/state.ts` は最小の Edit）: 撃つ溜めの最中は入力窓を止める / 三点の続きに放出と持続の奥義 / 狙い撃ちに揺れを掛けない / 派生の count を射撃の回数に / リプレイの版を上げる。テストは全銃の器で「派生の弾の合計威力 ≥ 通常の射撃 1 回」「三点の 3 本すべてが放出の倍率を持つ」「溜め撃ちから派生が出る」
2. **武器種ごとの戦意の上書き口と、砲（・擲弾）の戦意**（`data/weaponForms.ts`・`system/morale.ts`・砲と擲弾の balance json）。テストは全銃の器で戦意が 0 より大きくなり放出が起きること
3. **長銃の溜め放出（最大段だけ）と短銃の弾倉の大きさ**
4. **改鋳の出現条件・文の修正・死にデータの削除**
5. **計測を器ごとに**（`qa/combatProbe.ts`）

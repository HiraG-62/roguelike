# 陣図・本陣・旗倒れの実装の決定

2026-10-02。ブレスト `docs/ideas/brainstorm-20261002/`（面白さ順の 3）の設計書の下書き `raw/6-deep/D03-jin-zu-draft.md`（メインの作業ツリー `E:/dev/roguelike/docs/ideas/brainstorm-20261002/raw/6-deep/` にある）を実装する。**下書きと食い違うときはこの文書が優先**。

一言: 1 階に数個だけ「本陣」を立てる。本陣の大将が床に突撃の道筋（陣図）を 1 画ずつ書き、墨の入った画の隊だけが総掛かりで走ってくる。書き終える前に大将を怯ませれば筆が折れ、まだ書かれていない画の隊は来ない。大将を討つと旗が倒れ、近くの陣ごと背を向ける。

前提: 同じブランチで読み合いの手直し（`docs/ideas/reading-core-impl.md`。出端は黄の間に振り始めた一撃だけ）と墨の予告（`docs/ideas/ink-telegraph-impl.md`。予告を淡墨の下絵 → 濃墨の墨入れで描く）が入る。陣図の画も同じ文法で描く（書きかけ = 淡墨、墨の入った画 = 濃墨）。

## 1. 未決の問いへの決定（下書き 7 章。すべて推奨）

| # | 決定 |
| --- | --- |
| 1 | 墨の入った画は、筆を折っても必ず来る（赤は必ず来る、黄は消せる、を画の単位で守る） |
| 2 | 名札の見出しは「鶴翼の本陣」の形で出す。「陣図」「総掛かり」は Tips だけ |
| 3 | 本陣の大将は既存のメンバー 1 人の格上げ（新しく湧かせない。盤の乱数をずらさない） |
| 4 | 本陣の大将には精鋭の修飾子を付けない |
| 5 | 旗倒れで、近くの交戦中の素の陣の群勢を 25% 落とす |
| 6 | 章 1 の本陣は深度 4 の 1 つだけ（深度 1〜3 は 0） |
| 7 | 本陣の報酬は鍵を必ず落とすだけ（破陣まで他は足さない） |
| 8 | ミニマップの本陣の印は探索の前から出す |
| 9 | 下書きの「段 1・2 は本陣の数 0 の既定」は採らない。このブランチの最後に 1 回だけ `REPLAY_VERSION` を上げるので、本番の数で入れる |
| 10 | 偃月は後の段 |

## 2. 範囲

| 段 | 入れる |
| --- | --- |
| 1 最小形 | 下書き 4 章の「段 1 最小形」すべて（鶴翼の陣図・状態機械・割り込み・群勢の 3 つ・予告と同時攻撃の上限との通し・描画・仮の音 4 つ・Tips「陣図」・テスト・`jinzuProbe`） |
| 2 旗倒れと章 2 | 旗倒れの群勢の連鎖（決定 5）・馬印の仮の絵（今の三角を大きくして竿を足す。正式な絵は後）・魚鱗と鋒矢の陣図・ミニマップの印（決定 8） |
| 本番の数 | `HONJIN.count`: 章 1 は深度 4 だけ 1、章 2 は下書き 2-3 の目安。章 3〜4 は鶴翼・魚鱗・鋒矢の中から（他の陣形は後） |
| 入れない | 偃月・方円・雁行・衡軛の陣図、破陣、密書、破印、馬印の正式な絵 |

`REPLAY_VERSION` はブランチの最後に 1 回（統合役が上げる）。

## 1. 今のタイトル画面の問題

コード: `src/render/titleUi.ts` の `drawTitle`、`src/ui/title.ts`（`TITLE_MENU_ITEMS` ほか）、`src/main.ts` の `case "title"`。

### 見た目
- 背景が **西洋の城壁と塔の稜線 + 紫の霞**（`drawSkyline` / `SKY_GLOW`）。本編の「和の地下迷宮（墨・朱・金、苔の洞 → 地下寺院 → 廃城 → 深みの異界 → 最深の間）」とも、装備画面の「墨染めの帳に朱と金の漆の縁」とも合っていない。地下でもなく地上の城
- 題字が UI と同じ `drawTextShadow` の英字 `DEPTHBREAKER`（金 + 茶の影）。ロゴとしての形が無く、ドット文字のラベルと同じ格に見える
- 動きは横に流れる塵と昇る残り火だけ。「降りる」ゲームなのに、画面の中に下へ向かうもの（穴・階段・深さ）が無い

### 情報
- 右下に操作の一覧 5 行、左下に統計 5 行、中央にシードと 4 つのボタン。**重要度の差が無く**、最初に読ませたい「始める」は点滅する 1 行（`Enter で拠点へ`）だけ
- 統計の「最高スコア」「総撃破」は単一指標に近い数字で、原則 8（比較できない UI）の方向と温度が違う。「前回どうだったか」「どこまで行ったか」という次の 1 回につながる情報は出ていない
- 操作の一覧（移動・攻撃）はタイトルで読む情報ではない（拠点の最初の案内か Tips ノートの役目）

### 最初の印象
- 何のゲームか（和・地下へ降りる・手で避けて殴る）が 1 枚から伝わらない
- ゲーム名が 3 つある: ブラウザのタブ `Roguelike`（`index.html`）、タイトル画面 `DEPTHBREAKER`（`main.ts` の `GAME_NAME`）、Electron の `productName: DEPTHBREAKER`。`package.json` の name は `roguelike`

### 操作
- メニューが **ホットキー前提**（N / H / O / D / C / Q / A / T）。カーソルが無く、矢印キー・パッドでは図鑑・依頼・実績・設定・履歴・デイリーを選べない（パッドでは決定で拠点へ進むことしかできない）
- ボタンの外をクリックすると拠点へ進む（`frame.clickPressed` が拠点へ）。誤クリックで画面が変わる
- 設定・履歴・デイリーは画面上に押せる物が無く、右下の文字一覧を読んで覚えるしかない

## 2. 案（4 つ）

共通の方針（どの案でも）:
- メニューは 4 項目に絞り、**矢印 / パッド / マウスで選べるカーソル**を付ける: **拠点へ / デイリー / 記録 / 設定**。「記録」の下に 探索履歴・図鑑・依頼・実績・Tips ノート（6 行目は「戻る」）。今のホットキー（H C Q A T N O D）は残す
- 「続きから」は作らない（探索の途中保存が無い。始める = 拠点へ）。Electron 版だけ「終了」を足すかは別に判断
- シードは画面の隅に小さく 1 行（`シード xxx　N 編集`）。URL 共有の説明は Tips ノートへ
- 統計 5 行は「前回（階・相手）」と「最深」の 2 つだけに減らす（`RunHistoryEntry` の `depth` / `killer` / `cause`、`profile.meta.bestDepth`）
- 操作の一覧（移動・攻撃）はタイトルから外す
- 版（`APP_VERSION`）は右下に小さく残す
- 題字は文字ではなく **絵（スプライト）** として持つ（`pixelText` の対象外。UI 文字は今どおり `drawText`）

**手間**: L。長い絵（色つき・下絵）、軸と表装、題簽。段取りは A と同じ + 絵の送り（表示だけの状態）

**正直な損**: 絵の量がいちばん多い（章が増えると描き足す）。明るい紙の色は、暗い本編と並ぶと浮く。題簽に縦書きの和名が前提で、英字の名前だと寝かせることになる

### 案 D　拠点が題字

**一言**: タイトルはもう遊んでいる。拠点の部屋に暗がりと題字が掛かり、歩き出すと題字が上がって、そのまま井戸から出立。

## 3. 推奨

**A　門**。最初の 1 枚で「和の地下迷宮へ降りる、手で戦う旅人」が伝わり、メニュー 4 つ + 石碑の 2 行で情報が最小になる。開始の演出が「降りる」動詞そのもので、絵の手間も M に収まる。灯の色で前回の章が分かるので、1 枚絵でも記録とつながる。

C の墓標は「探索履歴」画面の作り直しとして、B の絵巻は踏破や深みの節目の演出として、別の段で取り込める（タイトルは A のまま）。

## 4. ゲーム名

### 4-1. 今の名前 DEPTHBREAKER の評価

- **合っている**: depth（深さ）+ breaker（壊す・突破する）で「降りて殴る」芯を英語 1 語で言えている。Electron の `productName`・セーブのフォルダ名・タイトル画面に既に使われていて、英題として通じる
- **合っていない**:
  - 和の地下迷宮（墨・朱・金、鳥居・地蔵・寺院・枯山水）の手触りが名前から出ない。英語の造語で、本編の表示が日本語の世界観語（気力・見切り・奥義・祝福・刻印符）で揃っているのと温度が違う
  - 「◯◯breaker」は英語圏のゲーム・道具の名前でよく見る形で、検索で埋もれやすい（同名の作品があるかは未確認）
  - 日本語話者には読みにくく（デプスブレイカー、8 拍）、ロゴにすると英字 12 字で横に長い
- 今は名前が 3 つに割れている（タブ `Roguelike` / 題字 `DEPTHBREAKER` / `package.json` の `roguelike`）

### 4-2. 候補（11）

形は「漢字 2〜4 字 + 読み」を基本にし、英題かローマ字を添える。同名の有名作は知っている範囲の注意で、**どれも断定ではない**（商標・ストアの検索は決める前に要確認）。

| 表記 | 読み・英字 | 意味と由来 | 世界観との結び付き | 覚えやすさ・検索 | ロゴ |
| --- | --- | --- | --- | --- | --- |
| **底穿ち** ★1 | そこうがち / 英題 DEPTHBREAKER | 底を穿つ = 地の底まで掘り抜く。今の英名をそのまま和にした形 | 降りる・殴る・最深の主を越えて深みへ、が 1 語。英題として DEPTHBREAKER を残せる | 造語なので埋もれにくいと思う。「うがち」はやや難読 → ロゴに読みかルビ。スキル「刺し穿ち」と字が重なる（衝突ではない） | 3 字。「穿」の画数が多く、ドット 16 だと潰れ気味 → 題字は 2 倍以上か墨書き |
| **根の国** ★2 | ねのくに / NE NO KUNI | 祝詞の「根の国 底の国」。地の底の異界 | 章を降りるほど異界になる構成（苔 → 寺院 → 廃城 → 深み）と神話が重なる | 短く読みやすい。神話の一般語なので検索では埋もれやすく、作品名で使われた例もありそう | 3 字で画数が少なく、ドットでも墨書きでも締まる |
| **墨淵** ★3 | ぼくえん / BOKUEN | 墨の淵。底の見えない淵 | 画面の墨・朱・金、最深の間の墨の池にそのまま結び付く | 造語で検索に強いと思う。読みが推測しにくく（すみぶち?）、意味も伝わりにくい | 2 字で四角く、落款のように使える |
| 奈落行 | ならくゆき / NARAKU YUKI | 奈落へ行く | 実績「奈落の縁」・最深の主の「奈落の手」と同じ語 | 分かりやすい。「奈落」は作品名に多い語で埋もれやすい | 3 字。素直 |
| 黄泉下り | よもつくだり / YOMOTSU KUDARI | 黄泉へ下る（古語の読み） | 死んでは拠点から降り直す繰り返しが題材と合う | 雅だが読めない人が多い。「黄泉」は頻出語 | 4 字で縦書き向き |
| 漆ノ底 | うるしのそこ / URUSHI NO SOKO | 漆塗りの器の底 | UI の「朱と金の漆の縁」と同じ素材 | 響きは良いが、何のゲームか伝わりにくい | 「漆」が細かい |
| 九十九折 | つづらおり / TSUZURAORI | 幾重にも折れ曲がる坂道 | 章ごとに折り返して降りる道筋 | 一般語・地名で埋もれやすい | 4 字、画数が少なく軽い |
| 奥ノ院 | おくのいん / OKUNOIN | 寺社のいちばん奥 | 地下寺院の章と最深の間 | 実在の地名（高野山の奥之院など）と重なり、検索で埋もれる | 3 字。素直 |
| 黄泉路 | よみじ / YOMIJI | 死者の国への道 | 死と降りの両方 | 短く読みやすい。曲名などで多く使われていそう | 3 字 |

### 4-3. 推奨 3 つと 1 番

1. **底穿ち（そこうがち）/ DEPTHBREAKER** — 今の英名の芯（深さ × 突破）を保ったまま和の表記にでき、英題 DEPTHBREAKER を残せる（Steam の表記・海外向けと地続き）。動詞が入っていて「降りて穿つ」遊びが名前から読める。造語で埋もれにくい
2. **根の国（ねのくに）** — 神話の地の底。短く、ロゴがいちばん締まる。検索では埋もれやすい
3. **墨淵（ぼくえん）** — 画面の色（墨）と最深の間に直結。読みの分かりにくさが損

見本では「名前」のボタンで全候補（比較用に今の DEPTHBREAKER も）を題字に出せる。字形は「ドット」（DotGothic16 を二値の点にして朱の漆・金・墨で塗る）と「墨書き」（Yuji Boku を点にした墨の筆）の 2 つ。

### 4-4. 名前を変えるときに触る所（実装は名前が決まってから別に行う）

- 表示: `src/main.ts` の `GAME_NAME`（今は題字を文字で描いている。題字を絵にするなら絵の差し替え）、`index.html` の `<title>`、`electron-builder.yml` の `productName`
- **Electron のセーブのフォルダ名**（`electron/main.ts` の `APP_DIR_NAME = "DEPTHBREAKER"`）も新しい名前に変える。**旧フォルダからの移行はしない**（開発段階のため）
- `package.json` の `name`（npm の名前。英小文字。変えるかは任意）
- ブラウザ版の保存キー（`roguelike.profile.v1` など）は表示に出ない内部の名前なので据え置きでよい
- `docs/` と `CLAUDE.md` の名前の記述、`CHANGELOG.md`

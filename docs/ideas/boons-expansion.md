# 祝福の拡張（100 種超・系譜・結び・抽選・ビルド例）

作成日: 2026-09-24
前提: `docs/DESIGN_PRINCIPLES.md`、`IDEAS.md`「現状」、`docs/ideas/README.md`、`docs/ideas/run-structure.md`（祝福・デュオ・契約の原案）、`docs/ideas/build-diversity.md`（シナジー網 4 章）、`src/system/boons.ts`、`src/data/tuning.ts` の `BOON`、`src/core/status.ts`、`src/skills/data.ts`、`src/system/statusEffects.ts`、`src/system/keystones.ts`、`docs/GLOSSARY.md` を読んだ。
今の実装: 祝福は 44 種（呪い付き 13）。`BoonDef` は `tags` / `cursed` / `requires`（装備タグ 1 つ）/ `rarity` だけを持ち、重みは「装備タグの一致数」で上がる。フックは player / combat / skills / floor の 20 か所ほど（`onBoonSwing` `onBoonShoot` `onBoonDash` `onBoonDashEnd` `onBoonMeleeHit` `onBoonCrit` `onBoonKill` `onBoonShatter` `onBoonJust` `onBoonRoomLock` `onBoonRoomClear` `onBoonSkillHit` など）。
状態異常 13 種のうち、祝福が「出す」経路を持つのは燃焼・冷気・感電・脆弱（崩し）だけで、弱体・恐怖・沈黙・麻痺・堅守を扱う祝福は 0。今回の拡張はこの穴を最優先で埋める。

凡例: コスト S = 数時間 / M = 1〜2 日 / L = 数日以上。面白さ ★1〜5。呪 = 呪い付き（強い効果 + 代償）
数値は全て `src/data/tuning.ts` の `BOON` に定数化する前提の初期値。
「触るファイル」列: 全案で `src/system/boons.ts`・`src/data/tuning.ts`・`src/system/boons.test.ts` を触るので省き、それ以外に触る実在ファイルだけ書く。新規は「新規」と明記。

### この文書で定義する新語（`docs/GLOSSARY.md` へ追加する候補）

| 表記 | 内部名（案） | 意味 |
| --- | --- | --- |
| 出す | `BoonDef.gives` | その祝福が作り出す状態異常・現象（燃焼・弾・設置物・コンボなど）。要追加: `BoonDef.gives?: readonly BoonTag[]` |
| 食う | `BoonDef.eats` | その祝福が前提にして参照・消費するもの。要追加: `BoonDef.eats?: readonly BoonTag[]` |
| 系譜 | `BoonDef.lineage` | 同じ「主（ぬし）」から出る 4 段の祝福。前段を持っていると次段が 3 択に出る。Hades の神に当たる |
| 奥義 | 系譜の 4 段目 | 系譜の最終段。3 段目 + 装備タグを要求し、遊び方を 1 段変える |
| 結び / 結び祝福 | `BoonDef.duo` | 特定の 2 つの祝福を持つと出る合体祝福（Hades のデュオ）。**共鳴の「二重」と衝突するので「二重祝福」ではなく「結び」を表示名にする** |
| 刻み | - | この文書では使わない（新しい状態異常は増やさず、既存 13 種の付与経路を増やす方針） |

### 要追加の型（全体）

- 要追加: `BoonTag` に `"freeze" | "paralyze" | "vulnerable" | "weaken" | "fear" | "silence" | "guarded" | "counter" | "skill" | "placed" | "reaper"`（`vulnerable` は現状 `stagger` に畳まれているので分ける）
- 要追加: `equipmentTags` がスキル石のタグ（`melee` / `area` / `projectile` / `placed` / `lightning` / `cold` / `movement` / `defense` / `channel`）と `SkillDef.applies` の状態異常を読む。スキルと祝福が掛け算になる入口
- 要追加: `BoonDef.lineage?: LineageKey` / `BoonDef.after?: BoonKey`（前段）/ `BoonDef.duo?: readonly [BoonKey, BoonKey]` / `BoonDef.gives?` / `BoonDef.eats?`
- 要追加: フック `onBoonStatusApplied`（`statusEffects.ts` の `afterApply`）/ `onBoonStagger` と `onBoonStaggerEnd`（`poise.ts`）/ `onBoonHurt`（`combat.ts` の `damagePlayer`）/ `onBoonProjectileHit` と `onBoonProjectileExpire`（`projectiles.ts`）/ `onBoonCounter`（`combat.ts`）/ `onBoonDescend`（`floor.ts`）

## 5. 祝福 × スキル × 装備 のビルド例 15

   - 弱点: 弾を撃たない近接の敵ばかりの階では燕返しが空振る。入力の精度がそのまま火力。
6. **月蝕の四重奏（月蝕系譜 + 織り交ぜ K02 + 両輪 K08 / 4 スロット別種 / 精神・霊力・マナの性質）**
   - 核: 4 つのスキルを順番に回し、コスト軽減と CD 短縮を交互に得る。
   - 伸ばし方: 奥義の月蝕で 4 連の後にコスト 0 の窓を作り、刻印符の多いスキルを撃つ。
   - 弱点: 1 本を連打すると織り交ぜで損をする。沈黙を受けると全てが止まる。
7. **崩しの重戦士（押し斬り M03 + 総崩れ U09 + 重荷 Z11 / 地裂き / 筋力・怯み値）**
   - 核: 重い一撃で怯ませ、脆弱を部屋中に伝えて地裂きでまとめて削る。
   - 伸ばし方: 腐食で堅守を消し、起き上がり狙いで怯み明けもカウンターにする。
   - 弱点: 重荷で遅く、射撃の敵に距離を取られる。怯まない敵には無力。
8. **硝子の不死鳥（硝子の見切り + 再起 + 不死鳥 U10 / 突進斬り / 吸血の誓約・ジャスト窓）**
   - 核: HP 1 で全てを避け、死んでも階ごとに 1 回だけ戻る。
   - 伸ばし方: 薄氷の命で常時ジャスト窓を広げ、奪弾で弾幕を攻撃に変える。
   - 弱点: 1 階で 2 回ミスすれば終わる。状態異常の継続ダメージが天敵。
9. **設置結界師（結界線 K05 + 氷の結界 U20 + 氷像 FR2 / 地雷・引力球・氷結地帯 / 範囲・霊力）**
   - 核: 設置物と凍った敵を柱に線を張り、引力球で敵を線の上へ集める。
   - 伸ばし方: 先手 F1 で封鎖直後に張る時間を作り、静寂の間で沈黙からコストを下げる。
   - 弱点: 設置に時間がかかり、突進してくる猪や蝙蝠の群れに崩される。
10. **死神遊び（死神遊び X2 + 死神の鎌 Z6 + 死神の影 X1 / 加速 / 移動速度・ジャスト窓）**
    - 核: 最初から出る死神を JUST で怯ませつつ、死神の通り道へ敵を誘導して即死させる。
    - 伸ばし方: 引力球で敵を死神の前に集め、死神の影でマナとゲージを回す。
    - 弱点: JUST を 1 回落とすと死神の一撃が重い。封鎖中も死神は来る。
11. **恐怖の背討ち（威圧 FE2 + 背討ち FE1 + 追い込み FE3 / 突進斬り / 会心倍率・攻撃速度）**
    - 核: 3 段目の撃破で周りを怯えさせ、背を向けた敵を会心で狩る。
    - 伸ばし方: 狩り立てで出血の恐怖を足し、狩猟 U19 で逃げるほど出血させる。
    - 弱点: 恐怖免疫の後は通常の会心率に戻る。鬼火の恐怖付与は敵側が主役を取る。
12. **沈黙の狙撃手（口封じ SI1 + 狙い目 VU1 + 静寂の間 SI2 / 撃ち抜き / 射撃速度・貫通）**
    - 核: 射撃型の敵の予備動作を弾で止め、撃ち抜きの脆弱に貫通を重ねる。
    - 伸ばし方: 鷹目系譜で画面外の予備動作まで読み、天弓で溜め撃ちを足す。
    - 弱点: 近接主体の敵（猪・ゴーレム）は沈黙しても止まらない。
13. **換金バースト（渡り鳥 C4 + 換金 C5 + 臨界 U13 / 旋風斬り / 必殺ゲージ・バースト範囲）**
    - 核: 違う敵を渡り斬ってコンボを積み、バーストでマナに換えて旋風斬りを回す。
    - 伸ばし方: 過充填の爆発で倒した分もゲージに戻し、満タンを保つ。
    - 弱点: 敵が 1 体のボス戦で渡り鳥が機能しない。
14. **片翼の剣（片翼 Z1 + 断裂波 + 終撃のみ / グレネード / 弾数・射撃の性質・燃焼確率）**
    - 核: 射撃を捨て、常に 3 段目から扇状の弾と衝撃波を同時に出す。
    - 伸ばし方: 火渡りで燃焼を弾で運び、跳弾で狭い部屋を埋める。
    - 弱点: 遠距離に射撃が無い。近づけない光線眼が脅威。
15. **色借りの共鳴（借り物の響き L4 + 灰燼系譜 + 色の誘い L3 / 雷撃 / 紅と金が拮抗した装備）**
    - 核: 燃焼の祝福を重ねて紅を 1 色ずつ足し、二重の共鳴を支配へ押し上げる。
    - 伸ばし方: 色の誘いで紅の遺物を拾い、ラン中に装備を組み替えて支配を固める。
    - 弱点: 祝福の偏りに依存し、序盤の 3 択が噛み合わないと空回りする。

## 今すぐ入れるべき 5 つ

1. **出すタグ・スキル石タグを重みに数える（4-1 + 4-2）**: 祝福同士・スキルと祝福が網になる土台。`equipmentTags` と `boonWeight` の拡張だけで済み、以降の全祝福の価値を上げる。
2. **系譜の仕組み + 灰燼 1〜2 段（2 章）**: `requires` の隣に `after` を足すだけで Hades の神の手触りが出る。火種・延焼は既存の `applyBurn` と `onBoonSwing` で書ける。
3. **奪弾（R08）**: 既存の `onBoonJust` の `justWipe` のループをそのまま流用でき、弾を自分の弾に書き換えるだけ。ジャスト回避の報酬として最も派手。
4. **口封じ（SI1）・睨み（WE3）・威圧（FE2）**: 祝福が 1 つも持たない沈黙・弱体・恐怖に「出す」経路を作る。`applyStatus` と既存フック（`onBoonJust` / `onBoonKill`）で書ける。
5. **死神遊び（X2）**: 「死神には JUST が成立しない」既存ルールを 1 か所反転するだけで、死神が恐怖から遊び相手に変わる。`applyStagger` を流用できる。

## 最初に入れるべき 20 個（6〜20 位）

6. **起き上がり狙い（P4）**: `onStaggerEnd` にフックを 1 つ足すだけ。堅守を読み合いに変え、怯みの設計と噛み合う。
7. **属性の轍（D07）**: `hazards.ts` のプレイヤーの炎を流用。装備で最強の元素を読むので、同じ祝福がラン毎に違う帯になる。
8. **呼び戻し（R07）**: 射撃ボタンを離すという未使用の入力に意味を付け、常に操作していたい原則に合う。
9. **結びの仕組み + 燕返し（U04）**: `duo` の判定を入れる最初の例。見切り斬りと回避一掃は両方実装済み。
10. **狩り立て（BL1）**: 出血と恐怖の掛け算。出血の「動かすほど効く」性質を恐怖で活かす。
11. **霜読み（CH1）**: 冷気の遅延をカウンターの機会に変える。`ACTION.counter` の判定に条件を 1 つ足すだけ。
12. **腐食（PO3）**: 堅守の付与を 1 行で止める。毒構成が怯み構成と組める。
13. **看破（VU2）**: カウンター → 脆弱。`combat.ts` のカウンター判定に付与を足すだけ。
14. **呪いを受けて 4 択（4-5）**: 呪いを通貨に変える抽選ルール。呪い付き 13 種の出番が増える。
15. **両輪（K08）**: マナ型と CD 型が混在する今のスキル 14 種に、混ぜる理由を与える。
16. **一念（K09）**: スロットを封じる呪い。4 スロット時代に 1 本特化の遊びを作る。
17. **氷伝い（SH3）**: 冷気 × 感電の既存相互作用（凍結が早まる）に連鎖の軸を足す。`chainLightning` を流用。
18. **借り物の響き（L4）**: 祝福と共鳴（装備）を直結する唯一の経路。`resolveResonance` に配合を足すだけ。
19. **試練の徒（F3）**: 試練の部屋に報酬の理由を与える。`offerBoons` の再呼び出しで済む。
20. **片翼（Z1）**: 射撃の性質を近接構成で活かす呪い。装備の読み替えで「死に性質」を減らす。

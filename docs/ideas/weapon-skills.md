# 技: 共通技と武器技（行為の列で書くスキル石）

2026-09-25。ユーザーの依頼「スキルに全武器共通で使えるものと武器種別スキルを用意したい。種類はできる限り多く、各武器種 10 種以上」。

## 1. 仕組み

- **技** = 行為の列（`skills/arts/`）で書くスキル石。既存のスキル石と同じく拾い・倉庫・スロット・刻印符・変異軸・使い込みに乗る
  - **共通技**（`common*`）: どの武器種でも撃てる。道具・魔法・体術の汎用品。武器技より 1 回あたり控えめ
  - **武器技**（`<武器種><名前>`）: その武器種を装備しているときだけ撃てる（違う武器種では「〇〇専用」と出て払わない）。武器種の手触りを伸ばす
- 抽選の重み（`data/balance/skills/ART/_index.json` の `weights`）: 装備中の武器種の武器技は厚く、ほかの武器種の武器技は薄い（持ち替え用に集められる）
- 定義: TS（`skills/arts/<群>.ts`）に名前・アイコン・動詞・タグ・素性・行為の種類と起点、数値は `data/balance/skills/ART/<武器種 | common>.json` の `<技の key>.<行為の名前>`。key の一覧は `skills/arts/keys.ts`
- 発動: `skills/arts/engine.ts`。命中はすべて `skills/hit.ts` の `skillHit` を通すので、刻印符（呪い・追撃・返金・伝播・散り際・属性の付与…）・連携の記録・使い込みがそのまま乗る。反響・遅延・投げ刃・罠化・散り際は発動地点から起きる（remote。自分は動かない）

### 1.1 行為（`ArtActKind`）

| 種類 | 何をする | 必須の数値 |
| --- | --- | --- |
| `arc` | 起点から前方の扇（reach・deg）に当てる | reach, deg |
| `ring` | 起点の周りの円に当てる。`anchor: "target"` なら照準地点で爆ぜる | radius |
| `line` | 起点から照準方向の帯（壁で止まる） | length, width |
| `dash` | 照準方向へ踏み込む（distance が負なら下がる）。通り道の帯（width）に当てる。invuln 秒は攻撃を受けない | distance |
| `blink` | 照準地点へ跳ぶ（壁の手前で止まる） | （技の range） |
| `shot` | 弾を扇に撃つ（`shot`: plain / ricochet / gale〔敵弾を切る〕…） | count, spreadDeg, speed, life, bulletRadius |
| `chain` | 起点に近い敵から近くの敵へ jumps 回跳ねる | range, jumps, jumpRange |
| `pull` | 半径の敵（ボス以外）を起点へ引き寄せる（damage・状態異常があれば当てる） | radius, toDistance |
| `buff` | 自分の強化（damageMul・speedMul・invuln・heal・mana・self の良い状態異常） | duration |
| `detonate` | 床の自分の設置弾（仕掛け・擲弾の地雷）を起爆 | — |

共通の数値: `delay`（撃ってから出るまでの秒。自分起点なら出る瞬間の位置と向き）、`ahead` / `side`（起点をずらす px）、`angleDeg`（向きを回す）、`damage`（Scaling）、`knockback`、`hits`（多段）、`heavy`（壁叩きつけ）、`poise`（怯み値の上書き）、`execute`（止め）、`vsMul`（TS の `vs` の状態異常を持つ敵への倍率。`consume` で消す）、`terrainRadius` / `terrainTime`（TS の `terrain`）、状態異常の名前（`"burn": { stacks, duration, potency }`）。

TS 側の行為: `{ kind, n: "<数値ブロック名>", anchor?, shot?, terrain?, vs?, consume?, clearsBullets? }`。

### 1.2 数値の目安（ステータス基礎値 各 5）

- 気力型の cost は 16〜26、**平均 18 前後**（`system/mana.test.ts` の「満タンから 3〜4 発」を割らない）。再使用型（移動・強化・防御）は cooldown 5〜18 秒
- 威力は 1 回の発動で単体に入る合計が **気力 1 あたり約 2〜2.5**（範囲が広い・状態異常を付ける・止めを持つなら低め、単体・溜めが要るなら高め）。例: cost 18 → 単体に合計 36〜45
- Scaling の係数は技の中身から選ぶ（`docs/STATS_AND_SCALING.md`。筋力 = 重さ、技巧 = 速さ・刃、体力 = 体を張る、精神 = 集中、霊力 = 魔法・状態異常）。Σ係数は 1〜2.5
- 状態異常の potency は 燃焼 3・感電 2・出血 1、ほかは 0。持続は `combat/STATUS/<名前>.json` の duration 前後
- 怯み値 poise は 1 ヒット 6〜40（重い一撃ほど高い）

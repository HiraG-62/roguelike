## 0. 結論（2026-10-01 時点。左は 0-1 で改訂）

- 「棒に本」に見えるのは、手に持つ絵が帯に吊るす写本（girdle book）として描かれているため。握り（結び目）から 12 ドットの編み紐と環の先に閉じた本が付いていて、剣と同じく照準の向きへ回され、弧を描いて振られる
- 推奨は **「記して、読む」書**。開いた本を胸の前で持ち、攻撃では照準へ突き出す（盾の `braced` と同じ動き）。左の 3 段は頁から文字の刃を走らせ、既存の状態異常「烙印」を記す。起爆はスキルの命中が担う（既存の烙爆）。型 `tome`（スキルの命中で術が溜まる、再使用 ×0.7、無詠唱）とそのまま噛み合う
- ロジックは **JSON だけ** で書ける。新しい system・型・状態異常・効果音は不要。絵も `braced` と向き 1 の絵を使えば renderer / playerRig に手を入れずに済む

## 1. 今の見た目の原因と直し方

### 原因

- `scripts/actor/sheets/wpnBook.mjs` の冒頭に「帯に吊るす写本（girdle book）」。紐は `capsule(1,0,RING_X-1,0)`（`RING_X = 12.6`）、本は x 14.5〜30。つまり「握り → 細い線 → 本」で、形が棒の先の本そのもの
- `weaponSheets("wpnBook", draw, { size: 76 })` がこれを 32 方向に回して描く（`scripts/actor/weapon.mjs`）
- 構えは `{ grip: "one", body: "ready", restDeg: -30 }` で、待機中も切っ先を前上へ向けて担ぐ
- 振りは `src/render/renderMath.ts` の `weaponPose` が形どおりに動かす。左が箱（振りかぶって振り下ろす）、ダッシュ攻撃と無詠唱が円なので、紐の先の本が剣の弧で回る
- 12px の代わりの絵（`src/data/sprites/weapons.ts` の `BOOK_SIDE` / `BOOK_DIAG`）も「柄 + 紐 + 本」で同じ形

### 直し方

| 項目 | 内容 |
| --- | --- |
| 絵 | `wpnBook.held` を「開いた魔導書」に描き直す。斜め上から見た見開き（浅い V 字の 2 頁）、牛血色の表紙の縁、金の角、頁の中央に淡い紫の印。幅 16〜18 × 高さ 10〜12 ドット。原点（手のひら）は背の下端の中央で、手の拳が本の下縁に重なり下から支えて持つ |
| 向き | **向き 1（`dirs: 1`）**。本は回さず常に頁を見せる。`rigWeapon` は `actorDir(angle, sheet.dirs)` で `dirs <= 1` なら 0 を返す（`src/render/actorSprites.ts`）ので実行時の変更は要らない。左向きは組み立てた絵ごと反転 |
| 構え | `meta.stance = { grip: "one", body: "light", restDeg: 0, restHand: [6, 5], swayDeg: 2, braced: true }`。`braced` は振りの間も向きを照準に保ち、伸び縮みだけを手の距離に使う（`src/render/playerRig.ts`）。体のコマは突きになり、予備動作で引いて振りで本を前へ突き出す。待機と移動中は胸の前で開いて持つ |
| 振りの間の絵 | `wpnBook.swing`（向き 1）を足す。頁が浮き上がり中央の印が明るく光る。鞭の `wpnWhip.swing` の仕組みがそのまま効く |
| 頁のめくれ（待機中） | 第 1 段では入れない（`rigWeapon` は常にフレーム 0 を描くので、入れるなら `renderer.ts` に最小の変更が要る） |
| 手間 | 生成器（`scripts/actor`）で描く。手描きの `Frame` は 12px の代わりの絵（`BOOK_SIDE` / `BOOK_DIAG` を見開きに）だけ |

## 2. 通常攻撃の作り直し（推奨案「記して、読む」）

- **左で記す**: 左の 3 段は突き出した頁から文字の刃を走らせる（近接扱い）。命中ごとに **烙印**（`brand`、既存。最大 5、4 秒）を 1 重ねる。3 段目は文字の帯が扇（120°）に広がり群れに記す
- **スキルで読む**: 烙印の付いた敵にスキルが当たると全部が起爆する（既存の `detonateBrand`。射撃かスキルの命中で起爆し、近接では起爆しない）。同じ命中で型 `tome` の術も溜まる（`skillHit`）
- **右と派生**: 名前と key は据え置く。右 1 は無詠唱（放出・次のスキルの気力 0）、右 2 は頁払い（間合いを取る扇）、右 3 は閉じ打ち（本を閉じた衝撃）。派生「頁飛ばし」（左右左）の頁の弾は射撃扱いなので **武器の側で唯一の起爆手段**（スキルが再使用中のときの手）。右とダッシュ攻撃は烙印を付けない（「左で記す」の線引き）
- **残す役割**: 「気力がよく戻る」「スキルの再使用が短い」（`FORM.tome.skillCooldownMul` 0.7）は残す。どちらも烙印を読む手段（スキル）を増やす方向に揃う
- **なぜこれか**: 杖は弾の魔法を撃ち分ける武器なので、頁から弾を撃つと「弱い杖」になる。棍は回収が最大の近接、手鈴は設置物と従魔、短銃・投擲は弾。「通常攻撃は下ごしらえ、スキルが本番」の手触りは書にしか無い。刻印符・スキルの烙印（`brandSear` / `brandBlast`）とも自然につながる
- 比べた案: 頁から短い術の弾（杖と被る・自分で起爆してスキルの出番が減る）/ 詠唱の溜め（溜めは大剣・戦鎚・刀にある。軽い武器が足を止める）/ 頁を叩きつける衝撃（今の打撃の延長で「棒に本」の動きのまま）

## 5. 不確かな点

- 向き 1 の見開きで真上・真下を狙ったときの見え方（照準が上だと体の後ろに隠れる）。違和感が強ければ上向き用の 2 枚目（向き 2）を足す
- 烙印の威力（potency 4 / 霊力 0.2）が強すぎないか（probe と `brandBlast` を持たせた 1 対 1 で見る）
- 書の共鳴の語に `explode` を足すか（烙印は `explode` に数えられる）。共鳴の釣り合いが動くのでこの段では足さない

## 6. ユーザーの回答（2026-10-01）

1. 持ち方: **胸の前で開いて持ち、攻撃で前へ突き出す**
2. 頁のめくれ: **後回し**（まずは振りの間だけ頁が浮いて光る）
3. 印の仕組み: **書の専用の印を作ってよい**（既存の烙印を流用しない。印の設計は `tome-mark` の節を足す）

## 6-0. 回答前の質問（記録）

1. **持ち方**: 胸の前で開いて持ち、攻撃のたびに前へ突き出す形でよいか（推奨）。別の候補は片手で頭の上に掲げて頁から術を出す形
2. **頁のめくれ**: 待機中に頁がぱらぱら動くアニメは後回しにして、まずは振りの間だけ頁が浮いて光る絵でよいか（推奨）
3. **印の仕組み**: 左で付ける印は既存の状態異常「烙印」を使い、スキルで起爆する形でよいか（推奨）。書だけの新しい印を作る案もある

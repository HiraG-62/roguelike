# 銭と地図の上の出来事: 通貨・商人・賭け・通貨のビルド

作成日: 2026-09-29
前提: ユーザーの依頼「マップ上の要素を増やしてみるのも手。通貨の概念を追加し、マップ上に商人が現れたり、ギャンブルができたりしても面白い。所有している通貨量で火力が上がるビルドや、攻撃する度に通貨を消費して火力が上がるビルドも作れる。通貨の概念は割と必須であってもいい」。

姉妹文書: `docs/ideas/build-core.md`（ビルド）、`docs/ideas/encounter-core.md`（敵・遭遇・部屋・ランの流れ）、`docs/ideas/run-arc.md`（章・持ち込みと袋・出口の予告）。この文書は 3 つを「通貨」という 1 本の軸で貫く。

数値はすべて目安。採用が決まったら `src/data/balance/**/*.json` に置く。新語は案で、採用したら `docs/GLOSSARY.md` に足す。

## 0. 結論

- 通貨を **ラン内の全ての選択の共通の物差し** にする。今の「欠片」（契約者と封印庫だけの小さな資源）を格上げし、表示名を **銭（ぜに）** に変える（内部 key `shards` は据え置き）
- 銭が面白くなる条件は 4 つ。**(1) 毎階に確実な使い道がある (2) 持っていること自体に価値がある (3) 腕が稼ぎになる (4) 拾いに行くこと自体が行動になる**。今の欠片は (1) も (2) も無く、溜まるだけ
- 地図の上の要素を「取る・開ける・払う・話す・賭ける」の 5 種に整理し、商人（市・行商・闇市）・賭場・宝箱と鍵・壺・通行料・寄進の祠などを置く。**賭けの主役は運ではなく「腕に賭ける」**（次の部屋を無傷で、30 秒以内に…に銭を張る）。アクションのローグライクだからこそ成り立つ賭け
- 通貨のビルドは 6 つの型: **持つ**（懐の重さで強い）/ **使う**（払うほど強い）/ **稼ぐ**（生涯の稼ぎで育つ）/ **投げる**（銭を弾にする）/ **買う**（敵を買収する）/ **守る**（銭が身代わりになる）。「店で使うか、力として握るか」が Balatro のお金と同じ張力を生む
- 系譜「財」・武器のベース「銭袋」・流儀の候補「盗人」・名のある遺物（打ち出の小槌・六文銭・招き猫…）で、ビルドの全層に通貨の道を通す

## 2. 他作品の通貨から学ぶこと

| 作品 | 通貨がしていること | 学ぶこと |
| --- | --- | --- |
| Balatro | 利子（5 につき 1、上限あり）で「貯める」に価値。持ち金で強くなるジョーカー（持ち金につき倍）と、使うと強くなるジョーカーがある | **持つ・使うの両方を力にする**と、店の 1 回 1 回が重い判断になる |
| Binding of Isaac | 銭・鍵・爆弾の 3 つの小さな通貨。爆弾は通貨でもあり動詞（壁を壊す・攻撃）でもある | **通貨が動詞を兼ねる**と、使い道の判断が戦闘と探索に広がる |
| Enter the Gungeon | 薬莢（店）と鍵（宝箱）。店の鍵を使うか、宝箱を開けるか | **2 つ目の通貨が「どれを開けるか」を作る** |
| Spelunky | 金は得点でもあり店の通貨でもある。店主を襲うと強敵になり、以後の店主が敵対 | **店を襲う**という選択が物語を生む |
| Noita | 敵が落とした金は時間で消える | **拾いに行く**こと自体が戦場での行動になる |
| Risk of Rain 2 | 金で箱を開ける。箱の値段は時間とともに上がる | **値段が動く**と「今使うか」が判断になる |
| Dead Cells | 金の扉は所持額で開く（払わない）。呪われた宝箱は「一撃も受けずに 10 体」で解ける | **持っているだけで開く扉**、**腕で解く箱** |
| Hades | カロンの店と「カロンの袋を盗む」。井戸で階の途中に買い物 | 道中の店と、店主へのちょっかい |
| Slay the Spire | 金で店・出来事の代価・カードの削除。削除の値段は回数で上がる | 同じ行為の値段が上がり、繰り返しに歯止め |
| ソニック | 被弾でリングをばらまき、すぐ拾えば取り戻せる | **被弾の重さを「拾い直せる損」にする** |

## 3. 柱

1. **銭は物差し**: ラン内の選択（部屋に寄るか・賭けるか・回復するか・強くするか）がすべて銭で比べられる。無料の贈り物（宝・祝福）は残し、全部に値札は付けない
2. **毎階に出口**: 1 階に少なくとも 1 か所、銭を使える場所がある（市・行商・賭場・祠のどれか）
3. **持つことに価値**: 利子・金の扉・通貨のビルドで、使わずに握る理由を作る。使うか握るかの張力が経済の芯
4. **腕が稼ぐ**: 無傷の制圧・見切り・カウンター・腕の賭けで稼ぎが増える。上手い人は多く買える
5. **拾いに行く**: 銭は床に落ち、時間で消える。拾うことが戦場の立ち回りになる（遠くの銭を取りに行くか）
6. **失う危険**: 被弾でこぼれる・盗まれる・死ぬと消える。持っている量がそのまま危険にもなる
7. **値段は動く**: 深度・回数・評判で値段が変わる。今買うか、先で買うか
8. **通貨は動詞にもなる**: 投げる・払って強くする・買収する・身代わりにする。ビルドの 1 つの道として

## 4. 通貨の構成

| 通貨 | 永続か | 役割 | 今との関係 |
| --- | --- | --- | --- |
| **銭** | ラン内（死ぬと消える） | 全ての売り買い・賭け・通行料・通貨のビルド | 欠片を置き換える（表示名の変更と役割の拡大。内部 key は `shards` のまま） |
| **鍵** | ラン内 | 宝箱・封印庫・鍵の扉を開ける。1 章に 3〜5 本しか手に入らない | 新規（推奨。11 章で判断）。「どれを開けるか」を作る 2 つ目の通貨 |
| **瓶** | ラン内 | 持ち運べる回復（使うと生命 35%）。上限 2〜3 本。市で買える・泉で汲める | 新規（推奨）。回復を「使うか温存するか」の資源にする（encounter-core 8-3 の呪われた泉の「瓶に汲む」を一般化） |
| 残響 | 永続 | 遺物のクラフト・荷車の段階 | 据え置き |
| 寄進 | 永続（任意） | 章の境で銭を拠点へ預ける。拠点の解放・図鑑の頁に使う | 新規の案（11 章で判断）。ランの外の動機を補う |

名前の案: 銭（推奨。日常語で、世界観の「渡し守」「六文銭」と繋がる）/ 金貨 / 冥銭（雰囲気は強いが「冥」が色の名前と衝突）。「金」は色（金響）と衝突するので避ける。

## 5. 稼ぎ

### 5-1. 源と目安（章 1、1 階あたり。章ごとに ×1.3）

| 源 | 量 | 腕か運か | 備考 |
| --- | --- | --- | --- |
| 雑魚の撃破 | 1（群れの小物は 3 体で 1） | — | 床に落ちる（5-2） |
| 精鋭の撃破 | 6 | — | 修飾子が遊び方を変えるものほど多く |
| 階の主 / 部屋主 | 15 / 10 | — | |
| 部屋の制圧 | 4 | — | |
| 目的の達成（encounter-core 5-3） | 8〜12 | 腕 | 破壊・護衛・防衛・追跡 |
| **無傷の制圧** | 制圧の 2 倍 | 腕 | 部屋の交戦中に一度も被弾しなかった |
| **見切り・カウンターの撃破** | +1 | 腕 | その一撃で倒した敵 |
| 壺・木箱（壊せる容れ物） | 0〜3 | 探索 | 部屋の隅・通路の行き止まり |
| 宝箱 | 15〜25（+ 遺物） | 鍵 | 6-2 |
| 賞金首・決闘 | 10 / 8 | 腕 | 今のランイベント |
| 腕の賭けの勝ち | 賭け金 ×2〜3 | 腕 | 7-2 |
| 遺物の売却 | 遺物の格で 10〜40 | 判断 | 袋の遺物（持ち帰りと競合。6-4） |
| 利子 | 階の到着時に持ち金の 10%（上限 15） | 貯める | Balatro の利子 |
| 息（早降りの報酬、encounter-core 8-1） | 残り猶予に応じて 10〜25 | 腕 | 全部倒す人の稼ぎとは別の道 |

目安: 全部倒す人は 1 階 90〜120、急ぐ人は 40〜60 + 息。**上手い人（無傷・賭け）は 1.5 倍**。

### 5-2. 床に落ちる銭

- 倒した敵の足元に銭が散る。**8 秒で消える**（消える前の 2 秒は点滅）
- 引き寄せ半径は 1.5 m（拾う操作は要らない。歩いて触れる）。遺物・性質で広げられる
- 交戦中に「遠くに散った銭を取りに行くか」が立ち回りの判断になる。敵の群れの中に落ちた銭は危険の中にある
- 強欲の精鋭・盗賊は床の銭を拾って逃げる（倒すと倍で返す。今の強欲の / 盗賊の追跡を銭へ広げる）

### 5-3. 失う

| 失い方 | 量 | 取り戻せるか |
| --- | --- | --- |
| **被弾** | 持ち金の 5%（最低 1）が周りにこぼれる | 3 秒以内に拾えば戻る（ソニックのリング）。被弾のコストが「生命 + 拾い直せる損」になり、encounter-core の「被弾に重さを」と噛み合う |
| 盗まれる | 盗人の敵が触れると 10〜20 を奪って逃げる | 倒せば倍で戻る |
| 死ぬ | 全部 | 寄進した分だけ残る（任意） |

被弾でこぼれるのを既定にするかは 11 章で判断（推奨は既定で 5%、通貨のビルドで増減）。

| 壺・木箱 | 壊す（攻撃が当たれば壊れる。敵の攻撃でも壊れる） | 銭 0〜3、まれに瓶 | 戦闘中に巻き込んで割る / 敵を寄せて割らせる |

### 6-3. 払うもの（地図の上の施設）

| 施設 | 払うもの | 得るもの |
| --- | --- | --- |
| 通行料の橋 | 銭 | 溝を渡る近道（encounter-core 6-1 の溝と組む） |
| 寄進の祠 | 銭を投げ入れる（量は自由） | 寄進の合計が節目を越えるたびに祝福 1 つ（ラン内）。寄進の永続化は 4 章 |
| 願いの泉 | 銭 10 を投げる | 3 回に 1 回、何か良いこと（祝福の格・瓶・呪いが解ける） |
| 傭兵の酒場 | 銭 | 1 階だけ戦う味方 |
| 両替商 | 銭 ⇔ 鍵・残響 | 通貨の交換（交換比は悪い） |
| 質屋 | 持ち込んだ遺物を預けて大金 | 次の質屋で高く買い戻す。**死ぬと預けた遺物は失われる**（永続の遺物を自分で賭ける。11 章で判断） |

### 6-4. 売る

- 市・行商で **袋の遺物を売れる**（`run-arc.md` の袋）。持ち帰り枠に入らない遺物は売って銭に
- 「持ち帰る」「売る」「装備する」の 3 択が、拾った遺物 1 つごとの判断になる。拾う判断が戻る
- 売値は買値の 1/3。装備中の遺物は売れない（外してから）

## 7. 地図の上の要素

### 7-1. 5 つの種類

| 種類 | 何をするか | 例 | 置き方の原則 |
| --- | --- | --- | --- |
| 取る | 触れて拾う | 銭・鍵・瓶・遺物・石 | 戦闘の中に落ちる（銭）か、探索の先にある（鍵・瓶） |
| 開ける | 壊す・鍵を使う・課題を果たす | 壺・宝箱・金の宝箱・呪われた宝箱・ミミック | 部屋の隅・行き止まり・見えるが遠い所 |
| 払う | 銭を払って使う | 通行料の橋・寄進の祠・願いの泉・金の扉 | 近道や分かれ道の上 |
| 話す | NPC と取引する | 市・行商・闇市・賭場の主・契約者・傭兵・捕らわれ人 | 毎階 1 か所は必ず（柱 2） |
| 賭ける | 銭や生命を張る | 賭場・腕の賭け・闘獣・宝箱の当て物 | 章ごとに顔を変える |

encounter-core 6-3 の設置物（樽・柱・鐘・水門…）は「使う」要素で、ここでは扱わない。

### 7-2. 商人の種類

| 商人 | 出る場所 | 品揃え | 特徴 |
| --- | --- | --- | --- |
| 市 | 毎階（主の部屋の前室、encounter-core 8-4） | 瓶・遺物・刻印符・磨き・鍵・引き直し | 定番。値段は章で決まる |
| 行商 | 階の中を **歩き回る**（部屋から部屋へ）。1 階に 0〜1 人 | 市より安いが品は 3 つ | 見つけに行く。敵に襲われていることがある（助けると値引き・見捨てると品が床に落ちる） |
| 闇市 | 隠し部屋・鍵の扉の奥 | スキル石・呪い付きの強い遺物・誓約 | 高いが他で買えない |
| 章の市 | 章ボスの前室 | 研ぎ・磨き・瓶を多め | 章ボスの前に整える場所 |
| 賭場の主 | 賭場の部屋 | 7 章 | |
| 渡し守 | 章の境・死神の巣 | 時間・蘇り | |

今の契約者 9 人は、この表の商人の「顔」として配り直す（行商 = 行商、修理屋 = 市の一角、賭場の主 = 賭場、渡し守 = 渡し守、鍛冶 = 章の市、占い・案内人 = 情報、語り部 = 来歴、灰の公証人 = 契約）。**人は残し、立つ場所と役割を整理する**。

### 7-3. 商人との関わり

- **値段は動く**: 同じ品は買うたびに +20%。深度で上がる。行商を助けると以後の階で 10% 引き
- **評判**: 商人を助ける・約束を守る（契約を果たす）で上がり、襲う・契約を破ると下がる。評判は品揃えと値段に効く（ラン内。永続にするかは 11 章）
- **商人を襲う**（Spelunky）: 市の主を攻撃すると強い敵になる（店の品を守って戦う）。倒せば品は全部ただ。以後、このランの商人は全員値段 ×2 か出てこない。**やるかどうかは自由**。決定性は保てる（全部 state の中）
- **値切り**: 市で「値切る」を選ぶと、その場で小さな腕の試し（次の部屋を 20 秒以内に制圧すれば半額、失敗すれば値段 +50%）。腕の賭け（8 章）の一種

## 8. 賭け

### 8-1. 賭けの 5 つの型

| 型 | 中身 | 期待値 | 何が面白いか |
| --- | --- | --- | --- |
| **腕に賭ける**（主役） | 次の部屋・この階の課題に銭を張る。勝てば 2〜3 倍 | 腕次第で正 | 上手い人が得をする。自分を信じるかの判断 |
| 運に賭ける | 丁半（サイコロの偶数・奇数で 2 倍）・くじ | 0.9〜1.0 | 手軽な刺激。1 部屋 3 回まで |
| 見抜きに賭ける | 宝箱 3 つのうち 1 つがミミック。壺振り（どの壺に銭が入ったか、揺れで分かる） | 目の良さ次第 | 観察が報われる |
| 闘獣に賭ける | 檻の中の 2 つの群れのどちらが勝つか（encounter-core 10-2 の縄張り）。**手を出して片方を助けてもよい**（ばれると賭けは無効） | 介入次第 | 戦闘を観戦し、干渉する |
| 引き受ける | 自分で呪い・縛りを受けて報酬を増やす（階の入口で「血の月を受ける」など、encounter-core 8-5） | 正 | 難しさを自分で選ぶ |

### 8-2. 腕の賭けの一覧（例）

| 賭け | 条件 | 倍率 |
| --- | --- | --- |
| 無傷 | 次の部屋を被弾せずに制圧 | ×2 |
| 早業 | 次の部屋を 20 秒以内に制圧 | ×2 |
| 一掃 | 主を 40 秒以内に倒す | ×3 |
| 見切り | この階で見切りを 5 回 | ×2 |
| 順番 | 支援の敵を最初に倒す（編成に支援がいる部屋で） | ×2 |
| 素手 | 次の部屋を近接だけで（スキル禁止） | ×2 |
| 死神と踊る | 死神が出てから 30 秒、階に留まる | ×3 |

- 張れる額は持ち金の 50% まで（全額を 1 回で溶かさない）。張ったら取り消せない
- 賭場の主の品書きに 3 つ並び、1 つを選ぶ。今の契約（無傷 / 疾走 / 狩り / 沈黙）はここへ吸収する

### 8-3. 賭け金の種類

銭 / 生命（今の生命賭け）/ 最大生命 / 持っている祝福 1 つ / 時間（死神の猶予）/ 持ち込んだ遺物（質屋と同じく、11 章で判断）。**賭け金が大きいほど報酬も大きい**。今の「最大生命 10%」は帳消しになる賭け金なので、1 章に 1 回の大きな賭け（祝福や遺物を張る）を置く。

## 9. 通貨のビルド

### 9-1. 6 つの型

| 型 | 仕組み（例） | 指の動き・判断の変化 | 弱み |
| --- | --- | --- | --- |
| **持つ** | 持ち金 1 につき増 +0.5%（上限なし）。持ち金 100 ごとに倍 ×1.1 | 店で使わず握る。被弾でこぼれるので避けることが火力を守ることになる | 買い物ができない。被弾・盗人で痩せる |
| **使う** | 攻撃のたびに銭を払い倍を得る（決めごとに 5 銭で倍 ×2、など）。スキルを気力ではなく銭で撃つ | 倒して拾い、払って倒す、の循環。拾いに行く動きが必須 | **銭を落とさないボス戦で痩せる**。散らばった銭を取れないと止まる |
| **稼ぐ** | このランで稼いだ総額（使っても減らない）につき増。build-core の積み「蓄」の銭版 | 稼ぎの源（無傷・賭け・壺）を全部拾う | 序盤は弱い |
| **投げる** | 銭を弾として投げる（威力は銭の額に比例）。投げた銭は床に落ち、拾い直せる | 投げて拾い直す、位置取りの循環（投具の型と同じ手触り） | 拾えないと弾切れと貧乏が同時に来る |
| **買う** | 銭を払って敵を買収する（その敵は 20 秒味方になる。精鋭は高い） | 誰を買うかの判断。敵の群れを割る | 買収した敵は倒しても銭を落とさない |
| **守る** | 被弾を銭で受ける（受けたダメージの半分を銭で払う。払えなければ生命）。銭の障壁 | 銭が 2 本目の生命になる。稼ぎがそのまま守り | 使うほど守れなくなる |

**張力**: どの型も「店で使う」と競合する。持つ型は買えば弱くなり、使う型は店と攻撃で銭を取り合う。Balatro と同じく、店の 1 回 1 回が「今の力」と「先の力」の交換になる。

### 9-2. 系譜「財」（build-core 4-4 の 9 本目）

| 札 | 例 |
| --- | --- |
| 手（左） | 命中で銭がこぼれる（1 体につき 1 回、深度で増える） |
| 手（右） | 放ちで銭を投げる（投げた銭は拾い直せる） |
| 手（ダッシュ） | 通り抜けた敵から銭を掠め取る（1 体 1 回） |
| 手（スキル） | スキルを気力ではなく銭で撃てる（両方ある時は選べる） |
| 手（奥義） | 散財: 持ち金を全部使った一撃（威力は払った額に比例） |
| 理 | 利子の上限が倍 / 金の扉が半額で開く / 被弾でこぼれた銭が自分へ戻ってくる |
| 積み | 稼いだ総額につき増 / 使った総額につき倍 |
| 昇華 | 黄金律: 持ち金が 2 倍を超えるたび（50 → 100 → 200…）倍が 1 段上がる。被弾でこぼれる量も倍 |

### 9-3. ほかの層の通貨の道

| 層 | 案 | 中身 |
| --- | --- | --- |
| 武器のベース | 銭袋（投具の型） | 左で銭を投げる。当たると銭は床に落ち、拾うと戻る。威力は持ち金の対数に比例 |
| 流儀の候補 | 盗人 | ダッシュで敵をすり抜けると銭を掏る（1 体 1 回）。気力は「掏った数」で湧く。商人を襲っても評判が落ちにくい |
| 名のある遺物 | 打ち出の小槌（右手・重打） | 決めが当たるたび銭が出る |
| | 六文銭（首飾り） | 死んだとき、持ち金を全部払って 1 回だけ蘇る（渡し守への払い） |
| | 招き猫（指輪） | 銭の引き寄せ半径 ×3、行商が必ず出る。被弾でこぼれる量 ×2 |
| | 欲の皮（体） | 持ち金 1 につき防御力 +0.2。被弾で倍こぼれる |
| | 質草の指輪（指輪） | 質屋で預けたものを 1 章の間は無料で買い戻せる |
| | 金の卵（首飾り） | 利子が 2 倍・上限なし。ただし銭を使うと 1 階の間利子が止まる |
| | 身代わり地蔵（頭） | 被弾を銭で受ける（守る型の核） |
| 誓約 | 清貧 | 銭を持てない（拾った銭は即座に気力になる）。代わりに全ての増 +30% |
| | 黄金の檻 | 持ち金が多いほど倍（100 ごとに ×1.15）。被弾で持ち金の半分がこぼれる |
| | 喜捨 | 銭を使うたび使った額の 1% ぶん最大生命が増える（ラン内）。売ることができない |
| 刻印符（機関） | 銭払い | 石を気力ではなく銭で撃つ。銭で撃つと倍 ×1.3 |
| 性質（条件の族） | 懐 | 持ち金が N 以上のとき増 |

### 9-4. 原型の例

| 原型 | 組み | 手触り | 伸び方 | 弱み |
| --- | --- | --- | --- | --- |
| 成金 | 持つ型 + 黄金の檻 + 欲の皮 + 財の昇華 | 一切買わず、被弾を避けて稼ぎ続ける | 持ち金につき倍 | 1 回の被弾で半分。店に頼れない |
| 散財の剣客 | 使う型 + 打ち出の小槌 + 剣 | 決めで銭を出し、次の決めで払う | 雑魚が多いほど回る | ボス戦で痩せる |
| 銭形 | 投げる型 + 銭袋 + 招き猫 | 投げて拾う往復 | 持ち金の対数 | 広い部屋で拾えないと弾切れ |
| 親分 | 買う型 + 群れの系譜 + 傭兵 | 敵を買って群れを割る | 買った数 | 買収しても銭が落ちない。ボスは買えない |
| 地蔵 | 守る型 + 身代わり地蔵 + 瓶を多め | 銭で受けて前に出る | 稼ぎが守り | 使うと守れない |
| 賭博師 | 腕の賭け + 賽の目の指輪（build-core）+ 利子 | 毎部屋に賭け、自分の腕で増やす | 賭けの勝ち | 負けが続くと一気に痩せる |

## 10. 釣り合いと歯止め

- **物価と収入を同じ曲線に**: 値段と稼ぎを章ごとに ×1.3 で揃える。深度で稼ぎだけが伸びて物価が置いていかれる（今の遺物の期待値と同じ失敗）を避ける
- **溜め込み**: 利子の上限、盗人、被弾でこぼれる、死ぬと消える、で持ちすぎに危険を付ける。金の扉と持つ型で「持つ理由」も付ける
- **使いすぎ**: 引き直しの値段が回数で上がる。同じ品は買うたびに +20%
- **無限の循環**: 「使う型」は銭を落とさない敵（ボス・部屋主の取り巻き・買収した敵）で止まる。「投げる型」は拾える時間（8 秒）で止まる。「守る型」は被弾が稼ぎを上回ると止まる。**強さの天井は置かず、循環の燃料が尽きる場面を必ず作る**（build-core 柱 4 と同じ考え）
- **単一指標を出さない**: 持ち金は数字で見せてよい（資源なので）。ただし「この遺物は何銭の価値」のような価値の比較は出さない（売値は品の格だけで決め、性能から計算しない）
- **QA**: bot に「市で瓶を買う」「袋の遺物を売る」「腕の賭けを 1 つ張る」の方針を足す。報告に「1 階の稼ぎ（源別）・使い道の内訳・死亡時の持ち金・賭けの勝率」を出す

1. **欠片を銭に置き換える**（推奨）。表示名は「銭」を推奨。代案: 金貨 / 冥銭 / 欠片のまま

4. **被弾で持ち金の 5% がこぼれる（拾い直せる）を既定にする**（推奨）。通貨のビルドで増減する
5. **質屋・遺物を賭ける**（持ち込んだ永続の遺物を失う危険を自分で選べる）。推奨は「入れる」。`run-arc.md` の「持ち込んだ遺物は死んでも戻る」の例外になるので確認したい
6. **寄進（章の境で銭を拠点へ預け、永続の通貨にする）**。推奨は「入れる、ただし使い道は拠点の解放と図鑑に限る（強さには使えない）」。ランの外の動機になるが、強さに使えると周回稼ぎになる
7. **商人を襲えるようにする**（推奨）
8. **系譜「財」を 9 本目の系譜にする**（推奨）か、各系譜に通貨の札を 1〜2 枚ずつ混ぜる形にするか

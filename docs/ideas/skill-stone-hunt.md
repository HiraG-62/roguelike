# スキル石の厳選（2026-10-02）

スキル石は拾うと永続し、同じスキルをいくつも拾えて倉庫が散らかっていた。ユーザーと方針を詰めた結果、「取得済みは出さない」「ドロップをやめて習得制にする」ではなく、**同じスキルの石を集めて良い個体を求めるハクスラ**に寄せた。散らかりは UI で解く。

## 決めたこと（ユーザーの決定）

| 項目 | 決定 |
| --- | --- |
| 方向 | ドロップは今のまま。同じスキルでも個体ごとにランダムな違いを持たせ、良い物を求めて集める（薄くなっていたハクスラの要素を補う） |
| 同じスキルの複数所持 | できる（用途の違う個体を持ち分けたい）。UI で同じスキルを 1 項目に束ね、その中から選ぶ |
| 変異 | 目立たせる。候補の頁（付け替えの画面）で書付を開かずに見えるようにする |
| 宿り符 | 名前は「宿り符」。**リンクを使わずに**符の効果が付く。全部を損得の釣り合いで考えるとアイテム集めの面白さが損なわれる。符の種類 × 変異の掛け合わせなので最強の 1 個は決まらない。確率は低めで（深度 1 で 1% → 20 階以降 5%） |
| 所持数の上限 | 遊びの上の意味は無い（保存データの歯止めだけ）。遺物と同じ 400 にし、処分に得を付ける |
| 使い込みの芽 | 装備の芽と同じ厳しさに（節目 10 倍・1 ランで 1 つまで） |
| 最初から使える石 | 今のまま（初期の石とジョブの石だけ） |
| 刻印符の拾い方 | 遺物・スキル石と同じく、カーソルを合わせて拾うキーで拾う |

## 仕組み

### 個体差

- 変異軸: 重み `SKILL.variantCountWeights` を `[0, 55, 45]` にし、軸を持つスキルの石は必ず 1〜2 本（`skills/generator.ts`）
- 宿り符 `SkillStone.dwell`: 石の seed から決定的に抽選する。確率は `dwellChance(depth)`（`STONE_TUNING.dwellChanceMin` → `dwellChanceMax` を `dwellCapDepth` まで直線）。種類はそのスキルに付けられる符から、床の符と同じ重み（`modifierWeight`）
- 効き方: `activeModifiers(def, links, modifiers, dwell)` が宿り符を先頭に置き、リンクを数えない。ぶつかる符（型替え符どうし・`excludesModifiers`）は宿り符を優先し、同じ符をラン内で付けても重ねない（その符はリンクも使わず、手持ちへ戻る）。`effectiveSlotModifiers` の先頭にも入れるので、共鳴・統一ルール・連動は他の符と同じに読む。穴の並び（`slotModifierView`）とリンクの使用（`usedLinks`）からは除く

### 見せ方（`ui/stoneDiff.ts`・`render/candidatesUi.ts`）

- 候補の札は 2 段: 上 = 名前と系統の丸印、下 = 宿り符（金）→ 変異の増減（伸びる側から。`variantEffects` が軸をまたいで同じ量を掛け合わせる）
- 束: 同じスキルの石が 2 個以上なら 1 枚「名前 ×n」（下の段に束の中の宿り符の名前）。決定で `target.group` を付けた候補の頁を積む（見出し「スキル 2 › 油流し」）
- 差の欄: 同じスキルなら 宿り符の差 → 量ごとの「今 → 候補」（良くなる量 = 得る）→ 使い込みの芽の差。違うスキルなら 得る動詞 → 候補の変異 → 失う動詞。行は `MENU_BUDGET.diffRows` まで
- 床: 宿り符のある石は光柱・菱形・名前が金。拾ったログも金

### 処分（`disposeStone`）

- 長押しで処分し、冥響を得る（`STONE_TUNING.shatterUmbra` / 宿り符は `shatterUmbraDwell`）
- 今の枠に同じスキルの石を付けていれば、処分する石の使い込み（発動・命中）の `pourShare`（0.5）を注ぐ。芽そのものは移さず、受け手の次の発動で節目を判定する。遺物の鍛冶の「注ぎ」と同じ形
- 束の長押し（今の枠に同じスキルを付けているときだけ）: 宿り符の無い石と、ほかの枠に付けていない石をまとめて注ぐ

### 使い込み

- 節目 `WEAR_TUNING.milestones` = 400 / 1600 回、`perRunPerStone` = 1。このランで芽を出した石の id は `SkillRunState.wearBudsThisRun`（ラン内だけ）
- 使い込みは石ごとのまま。乗り換えると育ちは付いてこないが、注げば半分は移る

## 検討して採らなかった案

- 取得済みのスキルは出さない: 105 種を集め終えると石のドロップが空になる。変異も意味を失う
- ドロップの廃止・習得制: 新しい技を拾う瞬間が消える
- 所持 = 習得（1 スキル 1 個体）にして重複は刻み直しの材料: 用途の違う個体を複数持てない（ユーザーの指摘）
- 宿り符がリンクを 1 本使う: 厳選の価値が下がる（ユーザーの指摘）

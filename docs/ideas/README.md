## Wave 方針

1. **Wave 2（既存レシピで量産）**: 敵（`enemies.md`）/ 祝福（`boons-expansion.md`）/ 装備（`loot-expansion.md`）/ スキル（`skills-expansion.md`）/ 状態異常・地形（`status-and-terrain.md`）。既存の型に沿ってデータを足すだけで進む
2. **Wave 1b（横断シナジー基盤）**: 語彙・イベント・ルール文法・UI（`synergy-web.md`）。Wave 2 で増えた要素同士を繋ぐ土台を先に敷く
3. **Wave 3（ラン構造・武器種・ボス）**: バイオーム・部屋・イベント・階層（`run-expansion.md`）、武器種・射撃の型（`meta-and-weapons.md` 1〜2 章）、ボス・部屋主（`enemies.md` 3・5 章）
4. **Wave 4（メタ）**: 拠点・図鑑・依頼・起点・縛り（`meta-and-weapons.md` 3 章以降、`run-expansion.md` 7〜8 章）

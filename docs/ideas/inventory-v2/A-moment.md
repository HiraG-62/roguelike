# 持ち物を「決める瞬間」へ散らす（案 A: 決める瞬間型）

作成日: 2026-10-01
前提: `IDEAS.md` の現状、`docs/LOOT_DESIGN.md`、`docs/ideas/core-synthesis.md`、`docs/ideas/inventory-overhaul-ideas.md` の 0 章、`docs/DESIGN_PRINCIPLES.md`、`CLAUDE.md` の不変条件 5・11・12 を読んだ。今の持ち物は Tab の 5 タブ（装備 / ステータス / スキル / 残響 / 流れ）で、どれも「一覧 + 詳細欄」。ラン中も倉庫（最大 400）から付け替えられ、刻印符は拾うと空きのあるスロットへ自動で入り溢れると古い順に消え（`src/system/skills.ts`）、祝福の 3 択と芽の 2 択だけが既に「その場で決める」形になっている。
表記: 本文の「流れ」（keyword）は、表示では **系統**（個別は「燃焼系」のような **〜系**）と呼ぶ（2026-10-01 決定。`docs/GLOSSARY.md`）。この資料は決定前に書いたので「流れ」のまま残す。読むときは「燃焼の流れ」→「燃焼系」、「流れの源 / 糧」→「系統の源 / 糧」と読み替える。

## 1. 思想

**「メニューで管理しない。決めることは、それが起きた場所で、その場に要る分だけ見て決める」**

- 今のごちゃごちゃの根は「いつ開いても、あらゆる判断に備えた情報を 1 か所に用意している」こと。遺物 6・石 4・符 11・祝福 20・倉庫 400・ステータス・共鳴が同じ器に入るので、比べる相手も読む順も画面が決めてくれない
- この案は判断を 4 つの瞬間（**床で拾う / 階の切れ目 / 拠点の台 / ランの終わり**）に割る。どの瞬間も「比べる相手は 1 つ」「並ぶのは 3 つまで」。画面がその判断のためだけに作られるので、要らない情報が最初から存在しない
- Tab で開くのは **佇まい**（今の自分を眺める 1 枚の絵）だけ。編集はできず、文も数字もほぼ無い。流れ・系譜・行動の印と刻みだけが残る
- タブが無くなるので、仕組みを足しても画面は増えない。足すときに決めるのは「どの瞬間で決めさせるか」だけになる

### 新しい名前（採用が決まったら `docs/GLOSSARY.md` へ）

| 名前 | 意味 |
| --- | --- |
| 見立て | 何かを手に取る瞬間に、その物の上に出る小さな札。比べる相手は「同じ部位の今の 1 つ」だけ |
| 踊り場 | 階段を降りた直後・次の階の前に出る 1〜3 頁。この階に残した決めごと（拾い物・芽・押し出された符）があるときだけ出る |
| 佇まい | Tab で開く唯一のメニュー。今の自分の 1 枚の絵。指して読むだけで、何も変えられない |
| 支度の台 | 拠点の庭に並ぶ 6 部位の台（図書館では 4 つの書見台）。乗ると倉庫から候補が 3 枚だけ宙に浮く |
| 引き出し | 支度の台の 3 枚それぞれの並び（新 / 合 / 名）。上下でその並びの次の 1 枚をめくる |
| 持ち帰り | ランの終わり（死亡・踏破の画面の後）に、このランの拾い物を 残す / 砕く で選り分ける 1 頁 |

## 2. 情報の予算

全画面（佇まい・見立て・踊り場・支度の台・持ち帰り・金床・祝福の 3 択）に同じ上限を掛け、`render` のテストで数える。

| 項目 | 上限 | 今との差 |
| --- | --- | --- |
| 文字の行 | 1 画面 12 行（うち BODY 12px は 4 行まで、残りは SMALL 8px）。1 行 20 字まで | 今は詳細欄だけで 3 頁に割っても溢れる |
| 一字の印（流れ・部位・系譜・行動・石） | 1 画面 24 個 | — |
| 並ぶ物（札・候補） | 3 つ。4 つ目からは「めくる」か「次の頁」 | 倉庫の一覧 16 行 |
| 比べる相手 | 常に 1 つ（同じ部位・同じスロットの今の物） | 今は比べる場所が床のツールチップだけ |
| 数字 | 1 画面 6 個（段・何枚目・残響の数）。ステータスの値・倍率・計算式は出さない | ステータスタブ・詳細欄に多数 |
| 操作の案内 | 足元 1 行、動詞 3 つまで | 隠れた操作が多数 |

予算を超える情報の行き先:

| 情報 | 行き先 | 方法 |
| --- | --- | --- |
| 性質の全文 | 見立ての「覗く」（押している間だけ札が下へ伸び、≤ 6 行） | 畳む |
| ステータスの値・体の性能・計算式・係数 | メニューから消す。拠点の訓練場の木人と武器掛けで、当てた浮き文字で確かめる。仕組みは Tips | 世界に置く / 消す |
| 共鳴の源・糧の内訳 | 佇まいで流れを指すと、源（実線）と糧（点線）の持ち物へ糸が伸びる。数は足元の 1 行だけ | 時間で見せる（指したときだけ） |
| 倉庫 400 の全体 | 一覧を持たない。支度の台の引き出し 3 本 × 先頭 1 枚 | 畳む |
| 祝福の説明 | 3 択の瞬間だけ全文。後は佇まいで指したとき名前 + 1 行 | 時間で見せる |
| 来歴の年表・芽の履歴 | 記録室（世界） | 世界に置く |
| 奥義の選択 | 拠点の武器掛け（今も試し撃ちはそこ） | 世界に置く |
| ジョブ・起点・縛り | 井戸（今のまま） | 世界に置く |
| 状態異常・銭・鍵・瓶・依頼の進み | HUD（今のまま） | 動かさない |

## 3. 6 場面の流れ

| 場面 | 決める場所 | 何を見る | 何を押す | 秒 |
| --- | --- | --- | --- | --- |
| (a) 床の遺物を拾って比べ、付け替える | 床（世界は止めない） | 近づくと遺物の上に見立て（4 行）: 名 / 得る流れ・失う流れ / 段が変わる共鳴 / 変わるステータスの ▲▼（数字なし） | G = 拾う（倉庫へ。今のまま）、**G 長押し = 拾って付ける**（外した物は倉庫へ）、Shift を押している間 = 覗く。交戦中は見立てを上 2 行に畳む | 2〜3 |
| (b) 拠点で次のランの装備を組む | 庭の支度の台 6 つ | 台に乗ると引き出し 3 本（新 = 新しく拾った順 / 合 = ほかの部位・石・ジョブ・型と分け合う流れが多い順 / 名 = 銘・名のある遺物・芽の残る物）の先頭 1 枚ずつ。札の中身は見立てと同じ 4 行 | ←→ 札、↑↓ その引き出しをめくる、決定長押し = 付ける、X 長押し = 砕く。付けると台の上の印が替わり、次の台へ歩く。変えないなら出撃の長押し（今のまま） | 1 部位 5〜10、全部で 1 分以内 |
| (c) 石を替える / 符を別のスロットへ移す | 石: 床・図書館の書見台 4 つ。符: 床・踊り場 | 石の見立てに 4 スロットの列（石の印 + 符の刻み 4/3/2/2）。符は触れると今どおり自動で入り、足元に「符 ○○ → 2」の帯が 2 秒 | **G を押しながらスキルキー 1〜4 = そのスロットへ差す**（石は元の石が倉庫へ、符は行き先が変わる。スキルキー単独は今どおり技）。付いた符の組み替えは踊り場の「符を組む」頁（4 列 × 刻み。符を選び、列を選ぶ）。溢れて押し出された符は消さずに踊り場まで残す | 差す 1、組む 5 |
| (d) 祝福を 3 択から取り、全体を確かめる | 3 択の画面（今の瞬間のまま） | 札は 紋・名・規則 2 行・宿る行動の印・噛み方の印 1 つだけ。画面下に 5 行動の帯（今の加護の刻み）を 1 行、取ると乗る行動が光る | 今と同じ（1 / 2 / E、呪いを受けて 4 択）。全体は Tab の佇まいで、行動か系譜の紋を指すと名前が足元に並ぶ | 取る 5〜10、確かめる 3 |
| (e) 今のビルドは何が強いか | 佇まい（Tab。止まる） | 最上段に共鳴している流れ ≤ 3 と「あと 1 つ」≤ 1 を大きな印と刻み ●●○ で。指すと源・糧の持ち物へ糸、足元に「燃焼の流れ 2 段 ― 源 3・糧 2」 | 方向キー / マウスで指すだけ。Tab / Esc で閉じる | 5 |
| (f) 砕く・残響で加工する | 砕く: 持ち帰り・支度の台。他の 4 操作: 鍛冶場の金床 | 持ち帰り: このランの拾い物の印の列（≤ 17）と、指した 1 つの見立て。金床: 乗ると装備中の 6 部位が金床の周りに並び、部位を選ぶと遺物 1 枚と操作の印 4 つ（注ぎ / 移し / 呼び戻し / 煽り。残響の数つき）。注ぎ・移しは同じ部位の引き出しから捧げる 1 枚を選ぶ。結果は変わった 1 行だけ「前 → 後」で光る | 持ち帰り: ←→ 指す、X = 砕く ⇄ 残す、決定長押し = 終える（既定は全部残す。倉庫が `DECIDE.takeHomeShatterAt` を超えたら既定を砕くにする）。金床: 決定長押し = 実行 | 持ち帰り 10、金床 1 操作 10〜15 |

**ラン中の倉庫**: ラン中に選べるのは「持ち込んだ 6 つ + このランの拾い物」だけにする（400 は拠点でだけ触る）。1 ランの拾い物は 4.5〜16.7 個なので、踊り場の拾い物の頁は普通 0〜2 枚で済む。この階で拾って付けなかった遺物がその階の踊り場に並び（↑↓ でこのランの前の拾い物へ）、Enter 1 回で「そのまま」。

**芽**: 芽が出たら踊り場で 2 枚から選ぶ（今の HUD の札はそのまま「芽あり」の印として残す）。拠点では、芽のある部位の台の上に印が立ち、乗ると先に 2 択が出る。

## 5. 捨てるもの・諦めるもの

| 捨てる / 諦める | それでも成り立つ理由 |
| --- | --- |
| **ラン中に倉庫 400 から付け替える自由**（最大のルール変更。ユーザーの確認が要る） | 「持ち込む 6 つ」を拠点で決める重みが増え、ラン中の拾い物 1 つ 1 つの意味が濃くなる（原則 10 の「緊張はラン内で作る」と噛む）。拾い物は 1 ラン 4.5〜16.7 個なので、ラン中に選ぶ母数は元々小さい |
| メニューでステータスの値・体の性能・計算式・行動ごとの係数を読むこと | 原則 8 をメニュー全体で徹底できる。数字で詰めたい人は拠点の訓練場の木人と武器掛けで浮き文字を見る（既にある）。仕組みは Tips |
| 倉庫を一望する・並び替え 8 軸・絞り込み・一括処分 | 引き出し 3 本で「新しい物」「今の流れと噛む物」「愛着のある物」は 1〜3 めくりで出る。倉庫を膨らませない入口として持ち帰りを置く。特定の 1 つを探すのに時間がかかる場面は残る（正直な弱点） |
| ラン中にいつでも符を並べ替えること | 符の判断は「拾った瞬間」（G + スキルキー）と「踊り場」で足りる。代わりに押し出された符を消さずに踊り場まで残す（小さな得） |
| 装備していない遺物を直接加工すること（注ぎ・移し・呼び戻し・煽り） | 加工したい遺物はほぼ「今付けている物」。捧げ手は同じ部位の引き出しから選べる。砕くは装備外でも持ち帰りと台でできる |
| 祝福の説明をいつでも全文で読むこと | 取る瞬間に全文を読んでいる。後から要るのは名前と 1 行（佇まい）。全文は図鑑の祝福の頁 |
| 前の案の資産（流れを灯す・跳ぶ・試着の全体 ▲▼・入れ替えると の長い節・旅装の行動の欄） | 「比べる相手 1 つ・3 行」に絞ると要らなくなる。見立ての 4 行は前の案の床の札（E-7）を育てた形 |

## 6. 前の案（旅装）との決定的な違い

1. **メニューで編集しない**: 旅装は「全部を 1 枚に載せ、頁へ潜って組む」家。この案はメニューを読むだけの絵にし、組む操作をすべて世界（床・台・金床）と切れ目（踊り場・持ち帰り）へ出す。開く画面の数ではなく、開く理由そのものを減らす
2. **比べ方が「全体の差」ではなく「相手 1 つの 3 行」**: 旅装の試着は全体の ▲▼ と「入れ替えると」の長い節を出す。この案は比べる相手を同じ部位の今の 1 つに固定し、流れの出入り・共鳴の段・地金の矢印だけ。数字は 1 つも出さない
3. **倉庫を「一覧で管理」せず「入口と引き出しで細らせる」**: 旅装は 400 の一覧に新着・愛用・並び・絞り・一括を足す。この案は一覧を持たず、ランの終わりの持ち帰りで増える前に選り分け、拠点では引き出し 3 本の先頭だけを見る。ラン中は倉庫そのものに触れない

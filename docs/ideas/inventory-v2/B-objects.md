# 持ち物を「物として置く」: 影法師と荷札

作成日: 2026-10-01
前提: `IDEAS.md` 現状・`docs/LOOT_DESIGN.md`・`docs/ideas/core-synthesis.md`・前の案 `docs/ideas/inventory-overhaul-ideas.md` の 0 章・`docs/DESIGN_PRINCIPLES.md`・`docs/ideas/graphics-style.md`・`docs/GLOSSARY.md` を読んだ。今の装備画面は 5 タブ × 「左に一覧・右に詳細欄」。持ち物は 遺物 6 部位（ベース 119 = 右手 29 武器種で約 74・他 5 部位で 45）/ 倉庫 400、スキル石 4 スロット + 刻印符（4 / 3 / 2 / 2）、祝福 9 系譜（加護・摂理・研鑽・真髄・融合・芯・呪い付き）、源と糧の共鳴（流れ〔keyword〕ごとに段 1〜3）。武器種ごとの 12px の絵は `src/data/sprites/weapons.ts` にある。
表記: 本文の「流れ」（keyword）は、表示では **系統**（個別は「燃焼系」のような **〜系**）と呼ぶ（2026-10-01 決定。`docs/GLOSSARY.md`）。この資料は決定前に書いたので「流れ」のまま残す。読むときは「燃焼の流れ」→「燃焼系」、「流れの源 / 糧」→「系統の源 / 糧」と読み替える。

---

## 1. 思想

**「体を見れば、何を持っているか分かる。文字は手に取った 1 つにだけ付く」**。

画面は旅人の**影法師**（墨の人形）1 体と、その体に置かれた物だけになる。頭にあるから頭の遺物、腰の印籠だからスキル、背中の紋だから祝福。**位置が意味を運ぶのでラベル・タブ・見出し・一覧が要らない**。共鳴は腰帯に結んだ紐（結び目の数 = 段）、系譜の進みは背の紋の縫い取りの濃さで見せる。文字は焦点を当てた物から下がる**荷札** 1 枚（6 行まで）だけ。今の「ごちゃごちゃ」は「全部の情報を文字で並べ、それを詳細欄に詰める」から生まれている。文字の常設を 0 にすれば、詰める場所そのものが無くなる。

## 4. 主要な 6 場面

| 場面 | 何を見て | 何を押して | 何秒 |
| --- | --- | --- | --- |
| (a) 床の遺物を比べて付け替える | 床では物の絵 + 名前 1 行 + 流れの印 3 つまで（今の床のツールチップの本文を消す）。拾うキーの長押し（0.3 秒）で一時停止し表が開く。拾った遺物は**あてがわれた**状態（その部位の上に重なり、元の物は半透明で後ろ）。腰帯の結び目が締まる（白く明滅）/ ほどける（朱）、新しい紐は薄く垂れる。荷札は「得る 2 行 / 失う 2 行」（共通の性質は書かない） | 決定 = 付け替える（外した物は葛籠へ落ちる）/ 戻る = 葛籠へしまう。短押しは今まで通り拾うだけ | 2〜4 秒 |
| (b) 拠点で倉庫から次のランの装備を組む | 表で部位に焦点 → 決定でその部位の**蔵の棚**（右半分、絵 24）。棚の焦点を動かすだけで影法師の部位にあてがわれ、腰帯が動く。流れで探すときは腰帯の組紐に焦点 → 決定で「引く」と、棚でその流れを持つ物だけが手前に出て、他は沈む | 移る（棚）→ 決定 = 付け替える。戻るで影法師の部位選びへ | 1 部位 5〜15 秒、6 部位で 1 分弱 |
| (c) スキル石を替え、刻印符を移す | 印籠に焦点 → 決定で**開く**: 4 段が横に並んで大きくなり、段ごとに石と鉤（4 / 3 / 2 / 2）が見える。下に石の箱（絵 12 / 頁） | 石: 段の石で決定 → 箱の石を選ぶとあてがい（その型で付けられない札が朱く揺れる）→ 決定。札: 札で決定 =**つまむ** → 別の段の空き鉤で決定 = 掛ける（掛けられない鉤は暗い）。つまんだまま戻るの長押し = 燃やす（ラン内なので消える） | 石 5 秒、札 3 秒 |
| (d) 祝福を 3 択から取り、全体を確かめる | 3 択は三方に載った 3 つの紋。焦点の紋の荷札（名前 + 効果 3 行）と同時に、画面下の小さな背の影法師で、乗る袖・裾の枠が光り、背紋の系譜が点線で 1 弧進み、腰帯に変わる結び目が明滅する。全体はメニューで**振り向く** → 背紋と加護の点を見る | 決定で取る（紋が背へ飛んで縫い付く）。全体: 振り向く → 紋に焦点 → 荷札の上段にその系譜の札が小さく並び（5 枚まで）、左右で 1 枚ずつ本文を読む | 3 択 3〜6 秒、全体 2 秒（1 枚ずつ読むなら 1 枚 2 秒） |
| (e) 今のビルドは何が強いか | 腰帯: 結び目の多い紐が今の芯の流れ。背紋: 濃い紋が今の系譜。この 2 つで「燃焼 3 結び・灰燼が金」と一目 | 組紐に焦点 → その流れの源（実線の引き糸）と糧（輪の引き糸）の物へ糸が伸び、他は沈む。背にある出どころは影法師の縁で「背へ回る」糸の端になり、振り向くと続きが見える。荷札: 段・源 / 糧 / 強めの数・次の段まで何が要るか | 一目 1〜2 秒、出どころまで 5 秒 |
| (f) 遺物を砕く・残響で加工する（拠点の鍛冶場） | 蔵の棚の下に炉・金床・残響の壺 5。炉に置いた物を長押しで砕くと、性質の色の粒が壺へ飛んで水位が上がる。金床に置いた物は大きく（64px）なり、荷札の本文が性質を 1 行ずつ選べる行になる。揺らぎは行の右の目盛り（中心の線 = 期待値、点 = 今） | 砕く: 棚で決定 → 炉 → 長押し 0.6 秒（がらくたの印の物は炉で長押し 1.5 秒で一括）。注ぎ: 金床に 1 つ、同じ部位の 2 つ目を重ねる → 長押しで光が流れる。煽り・移し・呼び戻し: 金床の荷札で性質の行を選び → 長押し（目盛りの点が揺れて止まる。壺の冥響が減る） | 砕く 2 秒 / 個、煽り 3 秒 |

芽（遺物の 2 択の成長）は、物に緑の芽が出ていれば焦点 → 荷札が 2 択の本文になり、左右で選んで決定。

## 6. 捨てるもの・諦めるもの

| 捨てる | 代わりにどこで | 正直な損 |
| --- | --- | --- |
| 多数の遺物の性質を一度に読み比べる一覧 | 棚は絵だけ。性質は 1 つずつあてがって荷札で読む | 「400 個から性質 X を持つ物を探す」は、流れの紐を引いて絞るまで総当たりになる。流れに乗らない地金の差では絞れない |
| 数値の常設（ステータス・行動の威力・銭の額） | 荷札の裏・影法師の顔の荷札の裏 | 数字で「強くなった」と確かめたい人には 1 手（めくる）増える |
| 流れの全体表（網タブ・48 の流れ） | 画面には共鳴中 4 本と緩み 2 本だけ。全部は図鑑に「流れ」の頁を足す（要新規頁） | まだ何も持っていない流れの源 / 糧を画面で眺めて計画することはできない |
| 並び・絞りの 8 軸（`src/ui/stashFacets.ts`） | 部位 × 引いた組紐 × 愛用 / 新着 の 3 つだけ | 深度順・揺らぎ順で並べたい人の道具が無い |
| マウスのホバーの速さ | 物の間を跳ぶ焦点（マウスは吸い付き） | 一覧の上下より 1 手多い場面がある（印籠の段から腰帯へ等） |
| 絵の手間を小さく保つこと | 7 章の約 80 枚 | 24px でベース 45 種の違いは描き分けきれない。違いの芯は「部位の形 + 響きの色」に置き、ベース名は荷札の 1 行に任せる。絵が読めないと全部崩れる |

**それでも成り立つ理由**: 持ち物の画面でプレイヤーが下す判断は (1)「今着ている物」と「候補 1 つ」のどちらか、(2)「どの流れを太らせるか」の 2 つしかない。どちらも 1 対 1 か流れが単位で、一覧も合計の数値も要らない。全種の一覧・計算式・仕組みの説明は判断の最中ではなく調べるときに要る情報なので、裏・図鑑・Tips へ出してよい。単一の強さの数も出さない（結び目は流れごと、加護の点は行動ごとで、足し合わせる場所が画面に無い）。

## 8. 前の案（旅装）との決定的な違い 3 点

1. **文字の量の桁**: 旅装は全部を 1 枚の帳に並べ、一字の印で詰めた（文字は約 60 行 + 印 100 個で、量は減っていない）。こちらは常設の文字 0・荷札 6 行。位置が意味を運ぶのでラベルも要らない
2. **比べ方**: 旅装は「入れ替えると」の ▲▼ の文字の塊を読む。こちらは**あてがう**: 物が体に重なり、腰帯の結び目が締まる / ほどけ、背紋の縫いが進むのを見る。文字は得る / 失うの 4 行だけ
3. **骨組み**: 旅装は 4 頁 + 流れの表 + 詳細欄で、タブ・一覧・詳細欄という今の骨組みのまま。こちらにはタブも一覧も詳細欄も無く、あるのは体の**表と背**（振り向く）と**物を開く**入れ子（葛籠・印籠・棚）だけ。倉庫も行の一覧ではなく、部位ごとの絵の棚にする

## 新しい用語（採用が決まったら `docs/GLOSSARY.md` へ。画面に文字では出さず、Tips ノートで使う）

| 語 | 定義 |
| --- | --- |
| 影法師 | 持ち物の画面の主役の、墨で描いた旅人の人形。持ち物は体の決まった場所に置く |
| 荷札 | 焦点を当てた 1 つの物から下がる文字の札。画面の文字はこれだけ。表 6 行・裏 8 行 |
| めくる | 荷札を裏返し、数値・計算式・来歴を見る |
| 振り向く | 影法師の表（遺物・スキル）と背（祝福）を切り替える |
| あてがう | 候補の遺物・石を体の部位に重ね、付け替えた後の結び目・紋の変化を先に見る（state は変えない見積もり） |
| 腰帯 / 組紐 / 結び目 | 共鳴の見せ方。共鳴中の流れが腰帯から垂れる組紐になり、結び目の数が段。緩んだ紐はあと 1 つで段が立つ流れ。「帯」1 字は帯電の略字と紛れるので腰帯と呼ぶ |
| 引く | 組紐に決定。その流れの源・糧の物へ引き糸が伸び、棚ではその流れを持つ物だけが手前に出る |
| 背紋 | 背中の 3 × 3 に 9 系譜の紋を縫い取ったもの。縫い取りの濃さが枚数、金が真髄 |
| 印籠 | スキル 4 スロットの入れ物。段に石、鉤に刻印符 |
| 葛籠 / 蔵の棚 | ラン中の倉庫の入口 / 拠点で部位ごとに開く倉庫の絵の格子 |

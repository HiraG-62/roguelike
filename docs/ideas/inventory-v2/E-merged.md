# 持ち物メニューの作り直し E: 装束と紋（A・B・D の統合）

作成日: 2026-10-01
前提: 4 案（`docs/ideas/inventory-v2/A-moment.md` / `B-objects.md` / `C-one.md` / `D-flow.md`）とその見本、`CLAUDE.md` の不変条件 5・11・12、`docs/DESIGN_PRINCIPLES.md`、`docs/GLOSSARY.md`（表示文字列の書き方・2026-10-01 の「系統 / 〜系」）、`IDEAS.md` の現状、`docs/LOOT_DESIGN.md`、今の実装（`src/ui/inventory.ts`・`src/render/inventoryUi.ts`・`src/render/synergyUi.ts`・`src/ui/statusTab.ts`・`src/ui/echoTab.ts`）。
ユーザーの評価: 好みは A・B・D。A・B の「体の周りの部位から直接選ぶ」が良い。D はデザインとして一番好きで、系統を表すデザインとしては断トツ。ただし系統が主語なので装備選びには使いにくい。**ラン中も倉庫から付け替えられる今のルールは保つ**。
動く見本: `preview/E.html`（一覧 `preview/index.html` の先頭のカード）。

## 1. 思想

**物は体で選び、強さは紋で読む。** 持ち物メニューは「装束」と「紋」の 2 面だけにする。装束は「何を身に着けているか」の面で、主語は部位（体の周りの 6 部位と腰のスキル石）。紋は「強さがどう流れているか」の面で、主語は系統（D の帯と珠）。今のごちゃつきは、主語の違う問い（どれを着るか / 何が強いか / 数字はいくつか）を同じ一覧と詳細欄に詰めていることから来ている。E は問いごとに面を分け、両面に同じ遺物を「部位の印」と「珠」で 2 回描いて、指せば向こうの面で光り、選べば向こうの面へ跳ぶようにする。文字は焦点の 1 つにだけ付く荷札（2 行）と、数字の出口の書付だけ。

## 2. 骨組み

```
Tab（持ち物キー）
 ├─ 装束（体の面。開いた直後）
 │    体の周り: 右手・頭・体・足・指輪・首飾り ── Enter → 候補と比べる（部位の倉庫 5 枚ずつ）
 │    腰: スキル石 4 と符の鉤 ──────────────── Enter → スキル（石・符）→ 石の候補
 │    中央の人影（体）──────────────────── Enter → 書付「体」（ステータス・体の性能・奥義）
 │    右: 紋の写し（帯と珠を縮めた図。名前なし）── Enter → 紋の面でその系統を開く
 └─ 紋（系統の面。Tab でここへ）
      帯 = 系統（段 4 + 伏流 2）、珠 = 出どころ ── 珠で Enter → 装束のその部位へ跳ぶ
      帯で Enter → 系統を開く（源 / 糧の札）── 札で Enter → 装束へ跳ぶ / ＋ → 系統で絞った候補
      下の台: 身 6（→ 装束）・加護の帯 5（→ 加護の頁）・系譜・芯
どこからでも: 書付キー → 焦点の物の書付（全文・数字）。倉庫の遺物の書付から鍛冶の操作
拠点の鍛冶場: 装束が「金床の構え」で開く（体 → 金床、腰 → 残響の壺 5）
```

### 体 ⇄ 紋 の行き来（E の要）

| 起点 | 操作 | 行き先 / 起きること |
| --- | --- | --- |
| 装束の部位を指す | 焦点を当てるだけ | 右の紋の写しでその遺物の珠だけが白く光り、外すと細る帯が ▼ / 消 で点滅。他の珠は墨に沈む |
| 装束の部位 | 面を替える（Tab） | 紋の面で同じ遺物の珠に焦点。荷札に「外すと 燃焼系 が細る」 |
| 装束の紋の写しの帯 | 決定 | 紋の面でその系統を開いた頁 |
| 紋の珠（遺物） | 決定 | 装束のその部位に焦点（装備中）/ その部位の候補でその遺物に焦点（倉庫の物） |
| 紋の珠（石 / 祝福 / ジョブ・型） | 決定 | スキルのその石 / 加護のその行動 / 書付「体」 |
| 紋の伏流の破線の「＋」・系統を開いた頁の「＋ 源を足す」 | 決定 | 系統で絞った候補（全部位）。左の小さな体で替わる部位が点滅 |
| 紋の台の身 6 | 決定 | 装束のその部位 |
| 加護の頁の「乗る遺物」 | 決定 | 装束のその部位 |

面を替えると深い頁は閉じ、1 段目に戻る（焦点の物は持ち越す）。Esc は 1 段ずつ戻り、1 段目で閉じる。

## 4. 情報の予算

全画面（装束・紋・候補・系統・スキル・加護・金床）に同じ上限を掛け、`render` のテストで数える。書付だけは予算の外（数字と全文の出口）。

| 項目 | 上限 | 数え方・今との差 |
| --- | --- | --- |
| 文の行 | **4**（見出し 1・荷札 2・操作案内 1）。比べる場面（候補）だけ **6**（荷札 1 + 差 3） | 札の名前・丸印の 1 字・珠は数えない。今の装備タブは 30 行超 |
| BODY（10px 以上）の行 | 1（比べるとき 1） | 荷札の 1 行目だけ。他は SMALL 8px |
| UI が出す数 | **4**（階・件数「2/4」・段の数・残響の量） | 性質の文に含まれる値は文の行で縛る。ステータスの値・倍率・計算式は書付だけ |
| 候補 | **5** 枚 | 送り（↑↓ / ホイール）で次の 5 枚。件数は見出しの右だけ |
| 比べる相手 | **1**（同じ部位・同じスロットの今の物） | 書付の見開きだけ 2 頁 |
| 系統の帯 | 段 4 + 伏流 2（紋・紋の写しとも） | 5 本目からは紋の「系統を選ぶ」盤 |
| 1 本の珠 | 源 4・糧 4・強め 2 | 超えたら畳んだ珠（点 1〜3） |
| 印（部位・石・行動・系譜・丸印） | 28 | 装束: 部位 6 + 石 4 + 系統の点 ≤ 12 + 丸印 6 |
| 色 | 段の立った系統の色 4 + 墨 + 白金（焦点）+ 響きの色（遺物の絵だけ） | 5 色の分類名は書付の中だけ |

見本の実測（各場面の画面下の「情報の予算」）: 装束 4 行・数 1、候補 6 行・数 2、紋 4 行・数 1、系統 4 行・数 0、スキル 4 行・数 0、加護 4 行・数 0、金床 4 行・数 0〜1。

## 5. 比べ方

1. **部位を選ぶ**: 装束で部位を指すと、荷札が「右手 打刀「王殺しの不屈」/ 源 燃焼系　糧 瀕死系」、紋の写しでその遺物の珠が光り、外すと細る帯が点滅する（「この部位が何を支えているか」を先に見せる）
2. **候補**: 決定でその部位の倉庫の遺物を 5 枚ずつ。並びは 合（失う系統が少ない順 → 新しく立つ系統が多い順）/ 新（新着・深い順）/ 名（名のある遺物・銘・芽のある物。愛用の印を足すならここ）。札は部位の絵・名前・系統の丸印 3 つまで。失う帯がある札は左端に朱の点。系統から来たとき（紋の「＋」）は全部位から、その系統に源 / 糧を足す物だけ
3. **今の 1 つと比べる**: 焦点の候補は左の小さな体の部位に**あてがわれ**（B。今の物と 0.5 秒ごとに入れ替わって見える）、右の動く紋で帯が **太る ▲ / ひび ▼ / 消える / 新しく立つ（新）** と動く（D。4 コマ、動かない帯は墨に沈む）。下は**差だけ**: 得る（緑）/ 失う（朱）を合わせて 3 行、共通の性質は書かない、溢れは「ほか n」。地金は荷札の右に「筋力 ▼ 技巧 ▲」を 2 つまで
4. **決める**: 決定で即付け替え。外した物は倉庫の先頭に戻り、同じ候補の一覧にも出るので 1 手で戻せる（だから長押しにしない）。数字で並べたいときは書付キーで候補と今の見開き
5. **石も同じ**: 腰の石 → スキルの頁 → 石で決定 → 同じ候補の画面（左の体の代わりに腰の石 4 が並び、替わる石が点滅）
6. **祝福の 3 択**（今の画面のまま）に足すもの: 札の後ろに紋の写しを薄く置き、焦点の札で太る帯を ▲、乗る行動の枠を点滅（D の (d)）

すべて「仮の出どころ列で数え直す」純関数（`countProfiles` + `resonanceSteps`）で、state は変えない。付け替えは今の `loadoutDirty` → `captureLoadout` の経路に乗せる（決定性は崩さない）。

## 13. ユーザーに聞くこと

1. **装束の右に紋の写しを常に出すか**: 推奨は「出す」。部位を指しただけで「この部位が何系を支えているか」が見え、体 ⇄ 紋の行き来の要になる（代わりに装束の右半分が埋まる）
2. **付け替えの決定は短押しでよいか**: 推奨は「短押し」。外した物は倉庫の先頭と候補の一覧に残り 1 手で戻せる。長押しは砕くだけにして意味を揃える
3. **祝福の置き場**: 推奨は「紋の台（加護の帯・系譜）と加護の頁だけ」。B の背紋（振り向く）はやめる。祝福は行動に乗る物なので、行動の角枠で読む方が素直
4. **装備中の遺物も鍛冶の対象にするか**（10 章の提案）: 推奨は「注ぎ・煽り・移しは装備中も可、砕くは倉庫だけ」
5. **名前**: 面の名を「装束」と「紋」にしてよいか。推奨は「そのまま」（紋は一字だが D の評価が高く、帯と珠の絵と一緒に覚えられる）。あわせて誓約の「系統」の呼び替えを決めたい（12 章の注意）

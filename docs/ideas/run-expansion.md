## 0. 新しい用語（この文書で定義して使う）

| 表記 | 内部名（案） | 意味 |
| --- | --- | --- |
| バイオーム | biome / `BiomeKey` | フロアの「テーマ」。見た目・地形タイル・敵の出現表・固有の部屋を束ねる。フロア種別（形状: 回廊 / 洞窟）とは直交し、1 フロア = 形状 × バイオーム。要追加: `GameState.biome` |
| 地形タイル | `Tile` の追加分 | 歩けるが効果を持つ床（氷・毒沼・溶岩・水流・ひび床など）。敵にも同じ効果が掛かる |
| 分岐路 | fork | 階段を 2〜3 個置き、それぞれが次のバイオームにつながる。扉の紋で行き先を予告 |
| ランイベント | runEvent | 部屋・時間・条件で起きる一時的なルール変更。必ず予告（文字 + 音 + 画面の兆し）を出してから始まる。要追加: `GameState.runEvent` |
| 欠片 | shards | ラン内通貨。死ぬと消える（永続の残響と住み分け）。要追加: `GameState.shards` |
| 契約者 | npc | ラン中に会う NPC。取引・契約（祝福の変種）・目撃をする。戦わない |
| 契約 | pact | 契約者と結ぶ「条件付きの祝福」。条件達成で報酬、失敗で代償 |
| 起点 | origin | ラン開始時に選ぶ出発条件。ハンデと報酬を同時に持つ。要追加: `Profile.unlockedOrigins` |
| ラン修飾子 / 位階 | runMod / tier | 自分で積む縛り。合計点が「位階」。位階ごとの最高到達を記録。要追加: `GameState.runMods` |
| 長居の代償 | linger | 死神以外の「同じ階にいるほど悪化する」仕組みの総称 |

共通の作法:
- 地形の危険はすべて予告を持つ（ひび → 崩落、泡 → 噴出、旗 → 突風）。予告時間は深層でも基準の 60% を下限にする
- 地形は敵にも効く。押し込み・誘導・壁叩きつけで「地形を武器にする」ことを報酬にする
- ラン内の報酬はルール変更か、ラン内限りの一時効果。永続装備の性質を直接書き換えない（例外は来歴への記録だけ）
- 数値はすべて tuning の新しい定数群（`BIOME` / `ROOM_KIND` の追加分 / `RUN_EVENT` / `LINGER` / `ORIGIN` / `RUN_MOD` / `NPC`）に置く前提

## 最初に入れるべき 12 個（上位 5 つが「今すぐ入れるべき 5 つ」）

1. **地形タイル基盤 + 熔鉱炉（1-6）**: Tile に溶岩を 1 つ足し、`terrain.ts` で効果を掛けるだけで「敵を押し込む」遊びが生まれる。壁叩きつけのノックバックと燃焼の付与（`applyStatus`）をそのまま流用できる。
2. **分岐路（4-1）**: バイオームを選ぶ理由がシナジーになり、全要素の掛け算の入口になる。既存の階段と `chooseFloorKind` を複数化するだけで済む。
3. **祭壇（2-3）**: 誓約のラン内付与は「ラン内はルール変更」の最短経路。既存の `KEYSTONES` と排他グループをそのまま使える。
4. **ランイベント基盤 + 増援・賞金首・停電（3-3 / 3-13 / 3-1）**: 同じ部屋でも毎回違う戦闘になる。試練の波の処理、エリートの抽選、暗闇の描画を流用できる。
5. **ラン修飾子（位階）基盤と 5 種（8-2 / 8-3 / 8-7 / 8-12 / 8-19）**: 積み重ねる縛りは遊ぶ時間を最も長くする。多くは tuning の倍率を差し替えるだけで作れる。
6. **図書館（2-4）**: 刻印符の偶然頼みを減らし、スキル石のビルドを狙えるようにする。`MODIFIERS` と `canAttach` を流用できる。
7. **骨の墓所（1-9）**: 既存の骨壁ハザードと骸骨卿の見た目を流用できる。2 つ目のバイオームとして最も安い。
8. **影の自分（5-2）**: 入力記録を流用できる決定的な時間圧で、死神と違う味を持つ。
9. **起点 3 種（7-2 / 7-4 / 7-5）**: 「最初から尖っている」ランを作る。祝福・誓約の付与関数を流用できる。
10. **灰の公証人と契約（6-2）**: 祝福の変種として、腕前に賭ける選択を足す。祝福の付与とチャレンジ判定を流用できる。
11. **共鳴炉（2-28）**: 響きと共鳴をランの中で意味のあるものにする。`resolveResonance` の結果を読むだけで作れる。
12. **鏡（2-9）**: 自分のビルド全体が敵になる山場を作る。コストは L だが、装備・スキル・祝福のすべてと噛み合う唯一の部屋。

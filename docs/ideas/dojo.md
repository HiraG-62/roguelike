# 稽古の間（拠点の稽古場から入る検証用の専用ステージ）

2026-10-03 ユーザーの依頼: 「稽古場をアップグレードしたい。今のはそのままに、専用ステージに移動できるようにしたい。DPS チェック、敵の数や種類の変更、敵の攻撃方法などを変更でき、多様な検証ができるように。触るだけで HP・気・奥義ゲージが全回復するオブジェクトも。他にも便利そうな要素があれば足す」

## 1. 形

- 拠点の稽古場（木人 3 体と武器掛け）は**そのまま**。稽古場の中に台「稽古の間」（`HubSpotKey` の `dojo`）を足し、インタラクトで専用ステージへ移る
- 稽古の間は拠点と同じ箱庭（`system/sandbox.ts` の `createSandboxState`、`state.sandbox = true`）。地図は `map/dojoMap.ts`（40x26 の 1 部屋）。保存しない・ランに持ち込まない・撃破数とドロップに数えない（拠点と同じ）。統一ルール・地形・弾の歯止めも回す（`simulateSandbox(..., rules = true)`。武器指南書の実演と同じ）
- 西の壁沿いの台（`DojoSpotKey`）:
  - **手水鉢**（spring）: 触れるだけで生命・気力・奥義ゲージを満たす（`DOJO.springCooldown` 秒に 1 回。浮き文字と効果音）
  - **武器掛け**（rack）: 拠点の武器掛けの画面をそのまま開く（武器種の試し・借りる・資源の調整）
  - **稽古帳**（board）: 設定の画面（下の 2 章）
  - **戻り口**（exit）: 拠点の稽古場へ戻る（Esc でも戻る）
- 画面の右上に**計測の欄**: 経過・合計・毎秒の傷（全体と直近 3 秒）・命中数・会心・1 発の最大・出どころの内訳（近接 / 射撃 / スキル / 継続 / 付帯）・被弾・撃破。左下に今の設定の要約 1 行
- 単一指標を出さない原則（`docs/DESIGN_PRINCIPLES.md`）は装備・ビルドの UI の決まり。稽古の間の計測は検証の道具として例外にする（装備画面・ツールチップには出さない）

## 2. 稽古帳の行（`system/dojoConfig.ts` の `DOJO_ROWS`。数値の候補は `world/DOJO.json`）

| 行 | 値 | 敵の湧き直し |
| --- | --- | --- |
| 相手 | 木人 + ボスと商人・壺を除く全敵（`dojoEnemyKeys`） | する |
| 数 | 1 / 2 / 3 / 5 / 8 / 12 | する |
| 深さ | 地下 1〜30 階（`state.depth` ごと替える。敵の生命・威力・予備動作の秒に効き、自分の地金もその深さで決め直す。地図の章の様式も変わる） | する |
| 修飾 | なし + その敵に付くエリート修飾子（`eliteKindsFor`） | する |
| 動き | 本気 / その場で攻める（動かない）/ 追うだけ（攻めない）/ 棒立ち | しない（今いる敵に効く） |
| 攻めの速さ | 攻撃間隔の時計 0.5〜3 倍 | しない |
| 並び | 横一列 / 囲む / 散らばる（決まった配置） | する |
| 間合い | 自分の立ち位置から 3〜18m | する |
| 倒れない | 生命を毎ステップ満タンへ戻す（DPS を測る用。傷は計測に入る） | しない |
| 湧き直し | 全滅したら `DOJO.respawnDelay` 秒後に同じ設定で湧き直す | しない |
| 無傷 | 自分が傷を受けない（被弾は計測に数える） | しない |
| 気力が尽きない / 奥義ゲージが尽きない | 毎ステップ満たす | しない |
| 時の流れ | 1 / 0.5 / 0.25 倍（予告の読み・技の見え方の確認） | しない |
| 今すぐ湧き直す / 計測を始めから / 生命・気力・奥義を満たす | 動作 | — |

設定は拠点の間だけ覚える（main.ts の変数。ゲームを閉じると既定に戻る）。保存はしない

## 3. 型と境界

- `src/system/dojoConfig.ts`（契約。設定・行・表示名・計測の表示の型）
- `src/map/dojoMap.ts`（地図と台の位置）
- `src/system/dojo.ts`: `createDojo` / `stepDojo` / `setDojoConfig` / `respawnDojo` / `resetDojoMeter` / `restoreDojoPlayer` / `setDojoTrialWeapon` / `dojoMeterView`
- `src/system/dojoMeter.ts`: 傷の記録の集計（被弾は `damagePlayer` / `damagePlayerDot` が `state.hurtTap` へ 1 発ずつ積む。生命を払う代償は数えない）。命中は `combat.ts` の `damageEnemy` が `state.damageTap`、被弾は `state.hurtTap`（どちらも `core/state.ts` の任意の配列。稽古の間だけ付ける）へ積み、`stepDojo` が毎ステップ汲み出す。本編では付けないので挙動・決定性は変わらない
- 敵の動きの制御は `stepDojo` が `simulateSandbox` の前後で敵を直す（攻撃間隔の時計・予備動作の取り消し・位置の戻し）。本編の敵の処理には手を入れない
- `src/ui/dojoBoard.ts`（稽古帳の画面ロジック）/ `src/render/dojoUi.ts`（稽古帳・計測の欄・台の絵と名札）
- `main.ts`: 画面 `dojo` / `dojoBoard`、拠点の台 `dojo` から入る。武器掛けは拠点の画面を稽古の間の state に向けて開く

## 4. 決めたこと・聞くこと

- 「敵の攻撃方法」は「動き」（本気 / その場で攻める / 追うだけ / 棒立ち）と「攻めの速さ」「修飾」の 3 行と解釈した。個々の技を選ぶ（例: 突進だけ出させる）は敵ごとの AI の中に手が要るので見送り。**ユーザーに確認**
- 名前（稽古の間・手水鉢・稽古帳・戻り口）は推奨で決めた（`docs/GLOSSARY.md`）

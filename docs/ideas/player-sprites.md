# プレイヤーの見た目の作り直し（高精細の体・武器・動き）

作成日: 2026-09-26
状態: 試作（見習いの体 + 剣・双剣・槍・片手銃）。ユーザーの確認待ち。残りのジョブ 9 種・武器種 23 種は確認後に並列で作る

## 1. 目的と決めたこと（ユーザーの判断）

- エフェクトの高精細化（`fx-sprites.md`）に合わせ、プレイヤーの体と手に持つ武器も **2 倍の密度**（絵の 1 ドット = 論理 0.5px）で描き直す
- 見習い（ジョブなし）は世界観（深層へ潜る探索者）に合った姿、各ジョブはそのジョブのイメージどおりの専用の姿
- 動きを細かく作り直す: 待機でも呼吸で少し揺れる・武器種ごとの非攻撃時の構え・新しい攻撃エフェクトに合う振り
- 武器を派手にしっかり作り直す（双剣は両手に 1 本ずつ・槍は穂先を大きく鋭く・斧はハルバード・戦槌はウォーハンマー・爪は手にはめる・銃の家系をしっかり）

## 2. 方式

- 絵は生成スクリプトで PNG に焼く（`scripts/actor/`。エフェクトの `scripts/fx/` と同じ流儀で、色は段ではなくそのまま持つ）
- **体**（`sheets/body<ジョブ>.mjs`）: 人型の骨組み（`rig.mjs`）の点を受け取り、部品を塗る。時間割は全ジョブ共通（待機 8・歩き 8・ダッシュ 2・構え・振り抜き・被弾）。肩・頭の位置を位置の印で渡す
- **武器**（`sheets/wpn<武器種>.mjs`）: 握りを原点、+x を切っ先に描き、32 方向を描き直す（回転でドットを崩さない）。片刃は刃を反対側へ向けた写し（`.heldM`）も持つ。両手持ちは添え手の位置 `meta.offGrip`
- **腕は体に描かない**。実行時に肩から手（武器の握り）まで 2 本の骨で引く（`render/playerRig.ts` の `elbowOf` / `armPixels`、色は体の `meta.arm`）。構え・振り・二刀・両手持ちを絵の枚数を増やさずに作れる
- 組み立て（`renderer.ts` の `drawRiggedPlayer`）: 右向きの作業面に 後ろの武器 → 後ろの腕 → 体 → 前の武器 → 前の腕 の順で重ね、左向きなら絵ごと反転する。被弾の閃き・ダッシュの残像は作業面の白い写し
- 構え（`STANCES`）: 武器種ごとの待機の向き・手の位置・持ち方（片手 / 両手 / 二刀）と体の構え。振りの向きは今までの `weaponPose` をそのまま使う
- 体の待機は棒立ちにせず、武器の系統ごとに 4 種の構えを持つ（`rig.mjs` の `IDLE_STANCES`）: ready（半身に開いて腰を落とす）/ heavy（足を大きく開いて低く）/ light（前のめりで踵を浮かせて弾む）/ aim（足を前後に開き上体を起こす）
- 体か武器のアトラスが無い・読めていない間は、今までの 24x24 の体と 12x12 の武器で描く（段階的に置き換える）

## 3. 体つきと動きの方針（ユーザーの判断: スタイリッシュに）

- 4 頭身強。頭を小さく脚を長く、肩を張り腰を絞る（`rig.mjs` の骨の長さ）。背は論理 26〜27px（当たり判定は変えない）
- 布（外套の裾・襟巻き・頭巾の先）は姿勢の `flow`（動きの勢い）で後ろへなびき、`sway` で揺れる。止まれば垂れる
- 移動は前傾の走り（膝を高く上げ、接地で沈む）、ダッシュは低く長い踏み込み、待機は半身に開いて腰を落とす構え
- 攻撃の動きは後で作り込む前提。体の姿勢は骨組みの値（`pose`）だけで決まるので、振りごとの予備動作・振り抜き・残心の体のコマをシートとして足せる（今は全武器で共通の構え 1 枚・振り抜き 1 枚）

## 4. 確認の手順

`node scripts/actor/gen.mjs --only <シート> --preview <dir> [--marks]` で確認用 PNG（`--marks` で原点と位置の印）。書き出しは `npm run actor:gen`。

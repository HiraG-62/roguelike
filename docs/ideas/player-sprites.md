# プレイヤーの見た目の作り直し（高精細の体・武器・動き）

作成日: 2026-09-26
状態: 全 12 ジョブの体と全 29 武器種の手に持つ武器を実装（見習い + 剣・双剣・槍・片手銃を見本にユーザーが確認し、残りを並列で制作）

## 1. 目的と決めたこと（ユーザーの判断）

- エフェクトの高精細化（`fx-sprites.md`）に合わせ、プレイヤーの体と手に持つ武器も **2 倍の密度**（絵の 1 ドット = 論理 0.5px）で描き直す
- 見習い（ジョブなし）は世界観（深層へ潜る探索者）に合った姿、各ジョブはそのジョブのイメージどおりの専用の姿
- 動きを細かく作り直す: 待機でも呼吸で少し揺れる・武器種ごとの非攻撃時の構え・新しい攻撃エフェクトに合う振り
- 武器を派手にしっかり作り直す（双剣は両手に 1 本ずつ・槍は穂先を大きく鋭く・斧はハルバード・戦槌はウォーハンマー・爪は手にはめる・銃の家系をしっかり）

## 2. 方式

- 絵は生成スクリプトで PNG に焼く（`scripts/actor/`。エフェクトの `scripts/fx/` と同じ流儀で、色は段ではなくそのまま持つ）
- **体**（`sheets/body<ジョブ>.mjs`）: 人型の骨組み（`rig.mjs`）の点を受け取り、部品を塗る。時間割は全ジョブ共通（待機 8・歩き 8・ダッシュ 2・構え・振り抜き・被弾）。肩・頭の位置を位置の印で渡す
- **武器**（`sheets/wpn<武器種>.mjs`）: 握りを原点、+x を切っ先に描き、32 方向を描き直す（回転でドットを崩さない）。光は武器に固定する（`localLight`。向き・写しが変わっても陰影の並びが同じで、振りの途中でコマごとに刃の明暗が入れ替わらない。体の光は画面に固定）。片刃は刃を反対側へ向けた写し（`.heldM`）も持つ。両手持ちは添え手の位置 `meta.offGrip`
- **腕は体に描かない**。実行時に肩から手（武器の握り）まで 2 本の骨で引く（`render/playerRig.ts` の `elbowOf` / `armPixels`、色は体の `meta.arm`）。構え・振り・二刀・両手持ちを絵の枚数を増やさずに作れる
- 組み立て（`renderer.ts` の `drawRiggedPlayer`）: 右向きの作業面に 後ろの武器 → 後ろの腕 → 体 → 前の武器 → 前の腕 の順で重ね、左向きなら絵ごと反転する。被弾の閃き・ダッシュの残像は作業面の白い写し
- 構え（武器の絵の `meta.stance`。読むのは `playerRig.ts` の `stanceFromMeta`）: 武器種ごとの待機の向き・手の位置・持ち方（片手 / 両手 / 二刀）と体の構え、手にはめる（`worn`: 拳を描かず武器の絵が手になる）、構えたまま押す（`braced`: 大盾は振りの間も照準へ向ける）。武器を足す人が共有の表を触らずに済むよう、武器の絵のファイルが持つ。振りの向きは今までの `weaponPose` をそのまま使う
- 銃の構え（`playerRig.ts` の `aimReach`）: 握りを照準へ出す距離は固定せず、両手とも腕を伸ばしきらずに届くいちばん前の距離を選ぶ（長い銃ほど肩まで引いて構える）。両手で構える銃は後ろの腕が握り・前の腕が先台を持ち、両腕とも銃の下に描いて先台を握る拳だけを銃の上に重ね直す（`RigPose.gunHold`・`handPixels`。肩に重なる銃床の上に腕が浮かず、腕が交差しない）
- 二刀の後ろの手は体の後ろ。構えの `offFront` を持つ武器（拳の両拳の構え）だけ手前に描く（手の位置で決めると、前へ傾くコマで肩ごと前へ出て手前に来る）。二丁の銃は後ろの手も照準へ向け、少し奥・下へずらす
- 体の待機は棒立ちにせず、武器の系統ごとに 4 種の構えを持つ（`rig.mjs` の `IDLE_STANCES`）: ready（半身に開いて腰を落とす）/ heavy（足を大きく開いて低く）/ light（前のめりで踵を浮かせて弾む）/ aim（足を前後に開き上体を起こす）
- 体か武器のアトラスが無い・読めていない間は、今までの 24x24 の体と 12x12 の武器で描く（段階的に置き換える）

## 3. 体つきと動きの方針

- 約 2.7 頭身・短い肩掛けの姿（3.5 頭身・4 頭身強となびく長い外套も試したが、ユーザーの判断でこの版）。背は論理 23px（当たり判定は変えない）
- 攻撃の動きは 5 章（振りの形ごとの体のコマ・鞭の振り・残心・残像）。体の姿勢は骨組みの値（`pose`）だけで決まる

## 4. 確認の手順

`node scripts/actor/gen.mjs --only <シート> --preview <dir> [--marks]` で確認用 PNG（`--marks` で原点と位置の印）。書き出しは `npm run actor:gen`。

## 5. 攻撃の動き（見本: 剣）

剣の 1・2 段は予備動作 2 コマ・振り 5 コマ・戻し 6 コマ（60fps）しかない。溜めを長くできないので、見栄えは「溜めの形の強さ」「振りの速さ」「振り抜いた後の残心」で作る。

- **体のコマ**（`rig.mjs` の `ATTACK_KEYS`、各 6 枚）: 0-1 予備動作（溜め → 溜め切り）/ 2-3 振り（踏み込み → 伸び切り）/ 4 振り抜き / 5 戻し。形は 5 種: 振り下ろし `atkSlash`（肩の上へ振りかぶり前足を浮かせ、踏み込んで上体を倒す）/ 斬り上げ `atkRise`（低く沈み、踵を上げて伸び上がる）/ 叩きつけ `atkSlam`（伸び上がって反り、深く沈み込む）/ 突き `atkThrust`（体重を引いて大きく踏み込む）/ 回転 `atkSpin`。骨組みの `reach` で肩を前へ入れて腕を伸ばす
- **選び方**（`playerRig.ts` の `attackClip` / `attackFrame`）: 突き・構えて押す盾 = 突き、自分の周りの円 = 回転、重い段か重い構えの箱 = 叩きつけ、それ以外の扇・箱は振る向きで振り下ろし / 斬り上げ。溜めを押している間は溜め切りのコマ
- **武器の軌道**（`renderMath.ts` の `swingAngle`）: 予備動作は腕を畳んで引き（`WINDUP_TUCK`）、振りは 4 次の ease-out（`whipEase`。振りの 4 分の 1 で 6 割以上の角度）で中ほどに腕を伸ばしきり（`SWING_EXTEND`）、戻しは振りの先へ `SWING_OVERSHOOT` だけ流れてから少し戻る（`overshootCurve`）。突きは戻しの頭で伸ばしたまま止める
- **振る向き**（`renderMath.ts` の `screenSwingSign`）: 偶数段は振り下ろし・奇数段は斬り上げで、左を向いても右向きと同じ振りに見える（画面での回りを左右で返す）。重い箱（叩きつけ）は段によらず必ず上から振り下ろす。武器の軌道・振りのエフェクトの反転・命中の光の線・体のコマはこの向きで揃える
- **構え直し**（`playerRig.ts` の `restBlendOf`）: 戻しの前半は振り抜いたまま残心を見せ、後半で待機の構えへ寄せる（長い戻しで刃を下へ向けたまま止まって見えない）。寄せる角は必ず体の前を通す
- **拳**（構えの `punch`）: 箱の振りを突きの動きにし、左右の拳を交互にまっすぐ打ち出す
- **撃った反動**（`playerRig.ts` の `recoilOf`、構えの `recoil`）: 手元から弾が出た瞬間（`fxAttack.ts` の `playerShotAge`）に銃を後ろへ引いて銃口を跳ね上げ、`RECOIL_TIME` で戻す。強さは武器の構えの `recoil`（大筒 1.8・長銃と擲弾 1.5・二丁拳銃 0.7、既定 1）。強い銃は体ごと 1px 後ろへ揺れる
- **鞭**: 振りの間は束を解いた絵（`wpnWhip.swing`。実行時は `<武器>.swing` があれば振りの間に替える）にし、エフェクトのしなる線を鞭そのものに見せる。戻しでエフェクトの線が薄れたら、縄（`whipRope.ts`、色は武器の絵の `meta.rope`）が伸び切った形から先を垂らして手元へ巻き戻り、構え直しの半ばで巻いた束の絵へ戻る。縄が前へ長く伸びるので組み立ての作業面は横に広い（`RIG_W`）
- **腕の長さを越えない**（`playerRig.ts`）: 振りの伸び・突きでも拳は肩から腕の長さ（`ARM_SPAN`）の内（`swingHandReach` / `withinReach`。突きの伸びは体の踏み込みと肩の入れが受け持つ）。両手持ちの添え手は柄を滑らせて届く所を持ち（`slideOffGrip`）、どこも届かなければ手を離して体の脇へ下ろす。体の前の添え手は腕を武器の下に描き、柄を握る拳だけを武器の上に重ね直す
- **見た目の向き**（`renderMath.ts` の `visualFacing` / `attackFacingLocked` / `turnedAttackDir`）: 予備動作・振りと、戻しのうち振りのエフェクトの尾が残る間（`FX_ATTACK` の `sprite.swingFade` と `slash.fadeTime` の長い方）は振り出した向き（`attack.dir`）で左右・振る向き・エフェクトの反転を決める（途中でカーソルを反対へ動かしても裏返らない）。エフェクトが消えた後の戻しはカーソルの向きへ振り向き、戻しの形も左右に写して構え直す
- **振りの残像**（`renderer.ts` の `RIG_SWING_GHOSTS`）: 振りの間だけ、少し前の進みの武器を 2 枚薄く重ねる。手にはめる武器は描かない
- 段ごとに踏み込む足を入れ替えるのは、次の段の溜め・待機との間で足が瞬間移動して見えるので見送り

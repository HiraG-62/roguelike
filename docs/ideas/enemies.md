# 敵・ボス・エリートの量産

作成日: 2026-09-24
前提: `docs/DESIGN_PRINCIPLES.md`、`docs/GLOSSARY.md`、`IDEAS.md`「現状」、`docs/ideas/run-structure.md` の 3〜4 章、`src/data/enemies.ts`、`src/data/enemyCombat.ts`、`src/system/boss.ts`、`src/system/elites.ts`、`src/system/reaper.ts`、`src/system/boons.ts`（祝福の名前）を読んだ。
今の実装の要点は次のとおり。通常敵は 9 種で、behavior は chaser / shooter / charger / knight / bomber / laser / golem / bat / wisp。ボスはスライム王と骸骨卿の 2 体で、どちらも 2 段階。エリートは爆裂 / 反射 / 障壁 / 迅速 / 連結の 5 種。死神は無敵で壁を抜けて直進するだけ。
地面の攻撃は `HazardKind`（bomb / laser / shockwave / landing / boneWall）で、手下の生成は `createEnemy` を使う。敵からプレイヤーへの状態異常の付与は `EnemyCombatDef.inflicts` で行う。怯みは怯み耐性・強靭・堅守の仕組みで表す。
凡例: コスト S = 数時間 / M = 1〜2 日 / L = 数日以上。面白さ ★1〜5

**実装状況（2026-09-24）**: 名前の後ろの【実装済み】【一部実装】が入った項目。追加の仕組みは再配色（`EnemyDef.recolor`）・死骸（`GameState.corpses`）・取り巻き（`Enemy.leaderId`）・修飾子の作業領域（`Enemy.eliteWork`）。部屋種類「巣」は作らず、部屋主は通常の抽選に低い重みで混ぜた。

**実装状況（Wave 3、2026-09-24）**: 地形を作る敵を優先し、「敵の地形は敵にも効く」を守った（地形の層は両陣営に効く。敵の炸裂は `blastBoth` で敵にも当たる）。追加の仕組みは 地形の予約（`GameState.terrainSeeds`。影の予告の後に地形を置く）・鼓舞（`Enemy.rally`: 帯電 / 急かし / 旗の加護）・潜行（`Enemy.hidden`: 描かれず当たらない）・2 つ目の修飾子（`Enemy.eliteExtra`）・死神のバリアント（`Reaper.variant`）。表に無い追加は 油壺の王（ボス。油の坑道・熔鉱炉）・双子の死神と静かな死神（死神）・封魔の + 障壁の（相乗）・火種鼠 / 霜蛙 / 熔岩蛙 / 油スライム / 雷眼（再配色種）。ボスの回転は 8 体（`src/system/boss.ts` の `BOSS_ROTATION`）。コードは `src/data/enemiesWave3.ts` / `enemyCombatWave3.ts`、`src/system/enemyWave3.ts` / `enemyTerrain.ts` / `boss<名前>.ts` / `reaperVariants.ts`

**重複の扱い**: `run-structure.md` 3〜4 章で既に出ている未実装案はここでは再提案しない。対象は、敵では弓骸骨 / 魔術師 / 蜘蛛 / 死霊術師 / 癒しの鬼火 / 砲台 / ミミック / 忍者 / 分裂体 / 幽霊 / 蜂の巣 / 反射蟹 / 盗人、エリートでは Splitting / Vampiric / Teleporting / Frozen Trail / Summoner / Mortar / Enraged / Magnetic / Undying、ボスでは Gorgon Eye / Iron Boar Chieftain / Lich / Mirror Knight / Warden / Hunger。これらは引き続き候補で、数には含めていない。

**全体の作法**
- 予備動作（windup）は必ず見せる。深層でも `scaledWindup` の下限（基準の 60%）は守る。画面外や暗闇の外からの攻撃には、画面端の矢印か音で予告する
- 数値はすべて `src/data/tuning.ts` の `ENEMY_AI.<behavior>` に置く。ボスは `BOSS.<key>`、エリートは `ELITE`、死神は `REAPER` に置く
- 敵の状態異常付与は、既存の 13 種を `src/data/enemyCombat.ts` の `inflicts` で渡す。行動停止系（凍結・麻痺・怯み）は拘束上限に任せる。プレイヤーへの付与は深度条件（`minDepth`）で段階的に解禁する
- ボスの撃破報酬に「確定で最強になる遺物」は置かない。報酬は既存の「rare 以上 2 個」に、ラン内のルール変更（祝福・刻印符）か素材（残響）を足す形にする
- **シナジーの作法**: 敵が作る地形（溜まり・油・ガス・地雷・風）は、原則として敵にも効くようにする。プレイヤーが敵を押し込み、引き寄せ、燃やすことで、敵の仕掛けをプレイヤーのビルドの一部として使えるようにする。1 体の敵に「咎められるビルド」と「得をするビルド」の両方を用意し、特定のビルドだけが一方的に損をする敵は作らない

## 1. 通常敵（46 種）

怯みの傾向は怯み耐性の目安で書く。低 = 〜15、中 = 25〜50、高 = 60〜120、不 = 怯まない（`poise` を指定しない）。強靭は予備動作中と攻撃中に受ける怯み値の倍率で、括弧内に書く。
付与の「深n」は `minDepth`。深度 n 以上でだけ付与する。

触るファイル（共通）: `src/data/enemies.ts`（`ENEMIES` と、新規なら `EnemyBehavior`）、`src/data/enemyCombat.ts`、`src/system/enemies.ts`（`STRIKE_SPEED_MUL` / `WINDUP_MOVE_MUL` と分岐）、`src/data/sprites.ts`、`src/data/tuning.ts`（`ENEMY_AI`）、`src/system/enemies.test.ts`。地面の攻撃が要るものは `src/system/hazards.ts` と `src/core/state.ts`（`HazardKind`）も触る。

## 最初に入れるべき 10 個

コスト対効果の順に並べる。シナジーの穴（7 章）の S 案は、敵を足さずに既存の要素どうしの掛け算を増やせるので、1 番目に置いた。

1. **シナジーの穴の S 案 7 つ（H1 / H2 / H4 / H5 / H6 / H8 / H10）**: 既存の敵と既存の要素に小さな分岐を足すだけで、状態異常・スキル・祝福の出番が一斉に増える。敵の数は増えないが、答えの数が倍になる
2. **再配色種の仕組みと 6 種（V1 毒スライム / V4 金色スライム / V5 骨猪 / V8 氷眼 / V11 溶岩ゴーレム / V16 飛ぶ本）**: `EnemyDef` の 1 行、パレットの差し替え、死後の挙動の key だけで敵の数が一気に増える。既存の behavior・`boneWall`・状態異常の付与をそのまま使える
3. **既存 behavior の流用 6 種（E1 若苗スライム / E3 棘鼠 / E4 双眼 / E11 三叉光線眼 / E15 影蝙蝠 / E18 天井吊り）**: 数値と小さな分岐だけで作れる。`swarm`・`phasing`・`laser`・`landing` を流用し、テレグラフの語彙も広がる
4. **エリート修飾子 6 種（M1 残響の / M3 伝染の / M4 堅牢の / M9 報復の / M14 分光の / M15 刻限の）**: どれも S。既存の修飾子の枠（`EliteKind`、`ELITE_PREFIX`、オーラ）に乗る。分光のは状態異常を混ぜる方向へ、堅牢のは怯み値ビルドへ、それぞれビルドの問いを足す
5. **「敵の地形は敵にも効く」規則 + 油壺運び（E28）+ 導火鼠（E29）**: 1 つの規則で燃焼・ノックバック・引力球が敵の仕掛けと掛け算になる。燃焼ビルドとノックバックビルドの両方に見せ場ができる
6. **死骸の仕組み + 骨拾い（E21）+ 墓守の鐘（E40）+ 貪食の（M8）**: 死骸を 1 つ足すだけで【死】の軸の敵が 3 つ作れる。祝福の氷砕・疫病・野火に「死骸を残さない」役割が付く
7. **マナ結晶 + マナ喰い（E23）+ 結晶ダニ（E25）**: マナの経済に敵側から関わる初めての要素。奪われても取り返せる形なので、常に操作していたいの原則に沿う。マナ系の祝福・誓約と直結する
8. **残像打ち（E32）と群れの長 + 狼（E17 / E44）**: 止まる人を罰する敵と、一斉攻撃の予告を読む群れ。どちらも手動操作と予告を読む遊びの芯を強める
9. **フロアテーマの枠（`FloorTheme`）+ 洞窟・墓所・炎の坑道の 3 テーマ**: 上の敵を出現表にまとめる器。共通の敵にテーマの色を掛けるだけで、階ごとの顔が変わる
10. **ボス 2 体（B2 双子の騎士 / B7 霜の巨人）と部屋種類「巣」+ 喰らう宝箱（L8）**: 双子は盾騎士と射撃、霜の巨人はゴーレムの衝撃波と壁叩きつけを流用できる。ボスが重複なしで回る範囲が 6 階から 12 階に延び、巣は祝福と刻印符を報酬に使える

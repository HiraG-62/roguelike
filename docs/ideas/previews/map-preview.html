      歩ける面積

      生成床（マス）割合主の道（歩）行き止まり最大の部屋（マス）

      上 = この seed、下の小さい数 = seed 1〜20 の平均。床 = 壁でないマス（地形も含む）で、割合は地図全体 64x40 = 2560 マスに対して。主の道 = 開始 → 主の間の最短の歩数（上下左右に 1 マス = 1 歩）。今の洞窟・回廊はグラフが無いので、左端の中ほどに近い床から歩いて一番遠い床まで。行き止まり = 床を細線にした端の数（6 マス未満のひげと、開始・主の間の近くは除く）。最大の部屋 = 5x5 が丸ごと入る広がりのうち一番広いものの面積。

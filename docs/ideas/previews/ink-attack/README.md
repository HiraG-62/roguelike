## 配色の案（2026-10-02。ユーザーの要望「黒い墨が主・差し色は控えめ。1〜2 案は差し色を強く」）

どれも筆致（掠れ・毛羽・飛沫）は同じで、配色の 7 段と線の周りの滲みだけを変えた。上段は実寸（洞窟 / 氷窟の撮影の上に置いた）、下段はその一部を 2 倍。置いた絵: 剣の左 3 段（鋼）・大剣の左 3 段（炎。旅人が原点）・大鎌（闇）・槍の薙ぎ（鋼）・剣の重い命中（鋼）・大剣の重い命中（炎）

| ファイル | 案 |
| --- | --- |
| `ink-A.png` | A 濃墨・銀の滲み。差し色ほぼ無し（芯の 1 段だけ属性をくすませた色） |
| `ink-B.png` | B 濃墨・くすんだ差し色の芯（明部 2 段が属性のくすんだ色）+ 薄い色の滲み |

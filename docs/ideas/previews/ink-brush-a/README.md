# 墨の筆致の見本 案 A（金泥の掠れ → 濃墨に朱の芯）

2026-10-02 に敵の攻撃予告の見た目を決めるために作った 4 案の見本のうち、案 A。予告には案 B（薄墨 → 濃墨 + 朱）が採用され（`docs/ideas/ink-telegraph-impl.md`）、案 A は **プレイヤーの攻撃のエフェクトの候補** として残す（ユーザーの指示）。

| ファイル | 中身 |
| --- | --- |
| `mock-A.png` | 線・輪・扇。上の段が金泥の掠れ（細い筆・毛羽）、下の段が濃墨の一筆に朱の芯 |
| `mock-A-time.png` | 4 コマの時間の進み（書き始め → 書き終わり → 墨入れ → 直前） |
| `mock-A-crowd.png` | 12 本が重なる乱戦 |
| `mock.js` | 見本の描画コード（Canvas 2D）。案 A は `drawA`。単体では動かない（見本の撮影の台は残していない） |

使うときの注意: 見本はなめらかなベクターの筆（4 倍のバックバッファ相当）で、毎フレームの描き直しは重い。実装するなら `src/render/inkBrush.ts` のように筆の形を焼いて使い回す。描画で `state.rng` を使わない（座標ハッシュ）。予告の予約色（薄墨・濃墨・朱・胡粉。`src/data/signs.ts`）と紛れない色にする（プレイヤーの攻撃が敵の予告に見えないように）。

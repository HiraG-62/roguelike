## 3. 実装メモ（2026-10-02 段 1 の筆致・段 2・段 3。決定との差）

- **筆致**: 下絵 = 淡墨の掠れ（繊維の筋が切れて紙が透ける。中央の筋は黄、外の筋は暗い淡墨に黄を差した `sketchDullColor`。黄の帯の中に収まることを `signs.test.ts` が検査）、墨入れ = 濃墨の一筆（入りの墨溜まり・抜きの払い・縁のがたつき・赤い芯。範囲は縁だけを筆で引き、墨入れは縁の内側へ薄く滲む。面は塗らない）。形は `render/inkBrush.ts` が長さ・半径を量子化してキャッシュし、`BrushPen` が行列で回して置く
- **負荷の実測（headless のソフトウェア描画）**: 1 回の fill / stroke に約 15〜50µs の固定費があり、塗りの範囲が画面全体に広がる巨大な path にまとめると逆に倍遅い（30 本の細い帯: 別々 0.5ms / 1 つの path 1.0ms）。clip・drawImage の回転も遅い。そこで線 1 本 = 2〜3 回の塗りに絞り、頂点を粗くし、自分の体の上を切るのは clip でなく区間そのものを切った形で作る。目標 0.5ms には届かない（乱戦 30 体で前半の約 2.2ms が約 2〜3 倍。GPU の実機は未計測）
- **柝頭・附打・唸りは main 側（`audio/narimono.ts`）**: `system/parry.ts`・`system/enemies.ts` が別レーンの所有のため、sim の `pushSfx` は触らず、drain のときに「新しい受け流しの印があれば `counter` を `tsukeHeavy` へ」「並の敵の新しい予備動作だけのフレームの `enemyWindup` を止める」を通す。後で `parry.ts` の積む名前と `startWindup` の 1 行を直せば、この変換は消せる。附打は `tsukeHeavy` だけ作った（見切り `tsukeLight`・処刑の `tsukeTriple`・音量の沈みは未着手）。`just` の音は `combat.ts`（別レーン）のまま
- **被弾筋は描画側の検知**: `HurtLog.trace` を足さず、`state.hurt.last` が新しい記録に替わった瞬間に当てた相手（近接 = 同じ key の攻撃中の敵、射撃 = 前のフレームの敵弾）を探して引く。出どころの位置が無い被弾（状態異常・地形・爆発）は引かない。`render/threatCueUi.ts`
- **殺気**は赤への立ち上がりの 1 回だけ、画面の外で自分に掛かる敵のみ（`system/threat.ts` の `threatensPlayer`）。暗闇の階は光の外の「自分に掛かる墨入れ」だけを幕の上へ描き直す（`telegraphLayer.drawDark`。`darkness.ts` の光線の予備動作の線は止めた）
- **符号表の例外**: 精鋭の 5 色（爆裂・迅速・報復・灼熱・強欲）を直し、`ELITE_COLOR_OVERRIDE` を消した（号令の気は `ELITE_COLOR` 自体が持つ）。敵の種類の色・状態異常の色の例外は残す

## 4. 見た目は案 B に決定（2026-10-02 ユーザー）

見本 4 案（A 色は今のまま・墨の質 / B 薄墨 → 濃墨 + 朱 / C B のドット絵化 / D 墨の滴 → 一筆 + 朱の導火）から **案 B「薄墨 → 濃墨 + 朱（胡粉の滲みを下に敷く・なめらかな線）」** に決定。1 章の決定 1（黄と赤の色はそのまま）と 2（○ 黄 / ● 赤）はこれで置き換える。

- **2 段の言い分け**: 下絵 = 薄墨（半透明の明るい灰の淡い滲み + 水の多い筆の毛の束が掠れる。明るく淡い帯）、墨入れ = 濃墨（真っ黒な一筆。入りで押さえて墨溜まり → 胴 → 抜きで払う、縁の毛が先で掠れる）+ 入りの朱の点 + 敵の側への墨の飛沫。暗い床で黒が沈まないよう、墨の下に胡粉の滲みと毛羽を敷く。明暗と形で分けるので灰色でも分かる
- **黄と赤は予告に使わない**: 線・光線・輪・扇・十字・折れ線・着地の影・爆弾・頭上の印（薄墨の ○ / 濃墨の玉に朱の芯の ●）・体の明滅（止まらない段は朱）・陣図（書きかけ = 薄墨、墨の入った画 = 濃墨。的・筆先・矢じりも墨と朱）・殺気・被弾筋（朱を持たない墨）・暗闇の描き直し・予告の図解（下絵 = 薄墨の帯、墨入れ = 胡粉で縁取った濃墨の帯、危ない範囲は朱を薄く）
- **言葉**: 表示の「黄 / 赤」は「下絵 / 墨入れ」へ（「予告が黄の間」→「予告が下絵の間」）。内部の関数名（`yellowAt` など）はそのまま
- **符号表**: 予約色は薄墨・濃墨・朱・胡粉。世界から灰と白は取り上げられないので、**独占して検査するのは濃墨と朱だけ**。薄墨は「色味の無い灰（彩度の上限）・濃墨より十分明るい」、胡粉は「濃墨より十分明るい」を検査する。怯みの印は予告と同じ胡粉（`GOFUN_COLOR` = `TELEGRAPH.gofunColor`。「墨の入っていない紙」の 1 つの意味）。朱に近い世界の色（猪・壺・光線眼・燃焼系の状態異常・精鋭「貪食の」など）は既知の例外。溶岩の穴の本体は朱そのものの色なので地図の検査の例外（朱の点は必ず濃墨の中に置くので形で分かれる）
- **細部の決め**: 扇は「要 → 左の辺 → 弧 → 右の辺」を 1 筆でなぞる（朱の入りは要の側に 1 つ）。輪・扇の筆は半径の 2 割までに細める（小さな範囲を帯で埋めない）。線は敵の体の縁から書き始める（体を黒で塗りつぶさない）。自分の体の上は線ごとに切るのをやめ、描き込み全体に 1 回だけ「体の円を抜いた」切り抜きを掛ける（輪・扇も抜け、線の形をキャッシュしたまま使える）。墨入れの胡粉は攻撃の直前（残り `imminentSec`）と攻撃中に濃くなる。描く順は層ごと（下絵の滲み → 下絵の筋 → 胡粉 → 墨 → 朱）で、他の線の胡粉が墨を曇らせない
- **負荷**: 滲みのぼかしは毎フレーム掛けず、形ごとに 1 度だけ低い解像度の画像に焼いて使い回す（下絵 2 / 胡粉 4 画素 per 論理 px。画素の合計に上限）。朱の点・頭上の印も焼いた小さな画像。`filter: blur` は焼くときだけ、`shadowBlur` は使わない
- **見本との差**: 見本の「下絵の書き始め（線が伸びていく）」は入れていない（届く先が遅れて見えるため）。毛の束は見本の「毛ごとに太さの変わる短い線分」ではなく、束ごとに一定の太さの折れ線 2 本（明・暗）で近似した

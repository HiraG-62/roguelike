# 墨の予告（墨の文法）の実装の決定

2026-10-02。ブレスト `docs/ideas/brainstorm-20261002/`（面白さ順の 2）の設計書の下書き `raw/6-deep/D01-ink-grammar-draft.md`（メインの作業ツリー `E:/dev/roguelike/docs/ideas/brainstorm-20261002/raw/6-deep/` にある）を実装する。**下書きの 7 章の未決の問いは、下の表のとおり推奨で決めた**。下書きと食い違うときはこの文書が優先。

前提: 世界観は墨が主軸（ストーリーには触れない）。同じブランチで読み合いの手直し（`docs/ideas/reading-core-impl.md`）が入っている: 出端は黄の間に振り始めた一撃だけで **文字を出さない**（墨の飛沫と止めで見せる）。黄の最短秒（下書きの `red(T)` / `yellowMinSec`）は **作らない**。体の点滅を `attackCommitted` に従わせる黄赤一致はレーン A で済んでいる。

## 1. 未決の問いへの決定

| # | 問い | 決定 |
| --- | --- | --- |
| 1 | 黄と赤の色そのもの | 今の #ffd040 / #ff4040 のまま。形と動きと音を足す |
| 2 | 頭上の「!」 | ○（黄）/ ●（赤）に替える |
| 3 | 柝頭と附打 | 両方とも木の音。柝頭は高く乾いた小さな 1 打、附打は板の低く強い打。紛れたら柝頭を墨の雫へ |
| 4 | 柝頭の判定 | main 側（`audio/cues.ts` の立ち上がりの流儀）で行い、左右に振る。sim と版には触らない |
| 5 | 殺気 | 画面外だけで始める |
| 6 | 色替え 4 つ | 入れる（怯みの星とゲージを胡粉へ・号令の気を黄から外す・血の粒を臙脂へ）。床の銭の黄は形で分ける例外 |
| 7 | 予告の描く順 | 全部の敵の後に描く。線は自分の体の上だけ切る |
| 8 | 暗闇の階 | 光の外の「自分に掛かる墨入れ」を幕の上に描く。下絵は描かない |
| 9 | 並の敵の予備動作の唸り `enemyWindup` | 止める（精鋭とボスだけ残す） |
| 10 | 表示の設定 3 つ | この段では作らない（後の段） |
| 11 | 出端の音 | レーン A で決めた今の音のまま（`counter` の澄んだ音 + 墨の飛沫）。赤の命中の `hitCommitted` も今のまま。附打は受け流しの音の分離に使う |
| 12 | 色覚の確認 | 後の段 |

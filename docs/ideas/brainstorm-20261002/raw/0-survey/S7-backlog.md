## 1. 何があるか（骨格と遊びの流れ）

**流れ**: タイトル「門」→ 拠点「門前町」（宵の町。井戸で支度＝ジョブ 10・起点・縛り → 依頼 3 択 → 石段で出撃）→ 4 章 × 5 階（章ボス固定: 5 スライム王 / 10 盗賊王 / 15 油壺の王 / 20 鏡の騎士）→ 深度 21「最深の間」で最深の主（四門 → 陥没 → 第三の顔）→ 「地上への道」で**踏破**、または降り続けて**深み**（22〜。5 層ごとに変異が積まれ、「〜につき」と研鑽の上限が外れる）。ランの長さの想定は 50〜70 分。

**1 階の中身**: 階の型 8 種（cavern / river / ring / court / drunk / isle / terrace / prefab）を seed で抽選した開放型の迷宮に、敵を**陣**で約 80〜100 体配る（八陣 + 物見、役割 7、格 並・猛・精鋭、群勢と敗走、大将、後詰）。毎階に**階の主**、主を倒すと分岐の階段が出て、**出口の予告**（祝福 / 遺物 / 銭 / 鍵 / 瓶 / 危険 / 錬磨）を見て次を選ぶ。祝福は祝福の出口を選んだ階だけ 3 択。毎階の市・旅商人・闇市、壺・木箱・鍵付きの宝箱、賭け 7 型、隠し部屋、契約者 9、ランイベント 28、死神（長居の圧力）。

**戦闘の核**: 手動の 3 段以上の連撃（型ごとに段数が違い、連刃は 6〜8 段）、左右クリックを混ぜた派生、敵の攻撃は**コミット**（予告の線 黄 → 赤）、全武器共通の**受け流し**（R）、ダッシュ 1 回 1.2 秒、武器の重さ 3 段、怯みと堅守、処刑、背面の一撃、見切り。奥義（F、武器種ごと 3 本から選ぶ）、スキル石 4 枠（共通技 60 が武器の型で形を変える変形表 + 手書き 45、変身含む）、刻印符 30（**ラン内だけ**）。回復は瓶（B）と降階 35% が主。

**ビルドの層**: 永続の遺物（6 部位、地金は今の深度で決め直す / 性質は拾った深度で固定、性質 71・転じ 12・誓約 20・名のある遺物 18、来歴と芽、残響のクラフト 5 操作）× ラン内の祝福（9 系譜 × 加護 / 摂理 / 研鑽 / 真髄、融合、格 5 段と錬磨、加護は 1 行動 2 枠）× 武器の型 15（戦意と放出・共通の瞬間 6・改鋳 30）× 流儀（ジョブのダッシュの形と気力の源）。全部が**源と糧の共鳴**（同じ語の出どころと食い手が揃うと段が立つ）で繋がり、状態異常 35・反応 24・地形の層 10 が属性 7 とジャンル（範囲 × 質）の上で掛け合う。深みの到達点（無尽・燎原・常在）が厳選の目標。

**メタ**: 図鑑・依頼 32・実績 41（称号）・死因 / 次の山 / 前回比・**仇**（前のランで倒された敵が名札付きで出る）・ボスの間（章ボスに挑み直す）・予告の図解・解放制・位階（縛りの点の合計）と踏破の碑・寄進（井戸の景色が 4 段で育つだけ）・デイリー・リプレイ。

## 2. 強み

- **決定性が全部の土台**: 同 seed + 同入力で同結果。リプレイ・デイリー・仇の写し・QA の bot・`qa:probe` の計測がこの上に乗る。ボス技も「乱数なしでプレイヤーの状態から選ぶ」（`pickMove`）ので読みが成立する
- **「陣」という単位**: 開放型マップで薄れた「部屋」の代わりに、陣形・群勢・大将・敗走で遭遇を組む。決着が全滅だけでない（敗走 76%）のは他の見下ろしアクションにあまり無い
- **ルール文法と共鳴**: 祝福・遺物・石・符・流儀・型が同じ「起きたこと → 語 → 効果」で書かれ、共鳴・紋・手がかり枠・連携図鑑で可視化。単一指標を出さずに相乗を見せる仕組みが一貫している
- **ハクスラとローグライクの二層の線引き**が明文化済み（地金は深度追従・性質は発見深度・符はラン内・祝福はルール変更）
- **和の世界観語の体系**（墨淵・門・門前町・陣・八陣・気力・見切り・銭・寄進・仇）と、名前の原則（熟語・文にしない・字面で働き）がある
- 計測の道具が厚い（フル QA・probe・map:shot・hitch:probe）。コミット 654 件 / 約 10 日の量産速度

## 3. 弱み・懸念

**決めたのに入っていない大物**
- **持ち込み 2 部位・袋・持ち帰り・荷車**（`run-arc.md` 2 章。2026-09-28 に「持ち込み枠は固定 2（仮）・持ち帰らなかった遺物は消える・荷車は残響 5 色」で決定）が**未実装**。コードに袋も持ち込み枠も無く、`DESIGN_PRINCIPLES.md` 10「拾った瞬間に永続」のまま。ユーザーが最初に挙げた「永続装備を全部持ち込めるのでランごとの新鮮さが無い」は、地金の深度追従で数値面だけ緩和された状態。これに依存する案（売る・質屋の本来の形・位階の持ち帰り枠・帰還の扉）も宙に浮いている
- **寄進**は「入れる。使い道は後で考える」（core-synthesis 1 章 $12）のまま、景色が育つだけ
- 深みの主 5 体（骸骨卿・双子・霜の巨人・群れの母・司書）は旧来の作り。ユーザー「まだいい」
- 技（共通技）どうしの連携・設置型 / 持続型の技、技の数値 QA は未着手

**実プレイでの検証が無い**: 段取り 2〜10a（戦闘・陣・銭・祝福・遺物・ボス・メタ・深み）は「テストとビルドのみ通っている」（IDEAS「次にやる候補」）。HANDOFF 5 章に「実プレイの感想待ち」が 2026-09-25 から積もっている（右クリックの技・振りの速さ・銃の手触り・用語の直感性・浮き文字の量など）。GPU 実機の描画 ms も未測定

**QA の数字に出ている問題**（bot の限界を含む。ユーザー方針は「難易度は実プレイの感触で、明らかにおかしい所だけ直す」）
- 踏破率 3%（目標 5〜15%）、到達深度の中央値 3〜6、**深度 3 の死亡が最多**（48 / 179）、死因 1 位は出血
- **鍵: 得た 908 / 使った 4**。市の商人の 70% は何も売れない。賭けは 1 ランに 0.1 回以下。呪い付き祝福の取得 0.02 / ラン。8 種の状態異常（烙印・吸魔・彩痕・加速・硬化・怒気・激昂・帯電）が 0 件。bot が使わないだけかもしれないが、**判断の場面として機能しているか不明**
- ボス: probe で最深の主は 5 戦全敗・時間の 95% が第 1 段階（四門）。盗賊王・油壺の王・鏡の騎士の「行為で進む段階」0%（bot がその行為をしない）、鏡の騎士の撃破 34 秒（目標 80〜150）
- スキル由来の与ダメ 41%（目標 55〜65%）。ルールのイベントが上限で捨てられる（9 / 180 ラン、深み 22 で 3 / 3）
- 祝福の格: 深度 6+ で提示の 88% が大祝福以上（格の差の意味が薄い）

**絵が仮**: 章の市・行商・闇市の商人は色違い、共通技・ダッシュの形・応手 / 終撃・章ボスの新技は汎用の輪と粒、型 15・祝福・名のある遺物・誓約のアイコンは漢字 1 字、盗賊王の柵・踏破の碑は図形。階段は章ごとの絵が未

**複雑さと初見の伝わり方**: 用語の層が非常に厚い（系譜・加護・摂理・研鑽・真髄・融合・格・錬磨・地金・性質・転じ・誓約・共鳴・源・糧・型・戦意・放出・改鋳・流儀・陣・群勢・格・後詰…）。説明は Tips ノートに寄せる方針だが、**チュートリアル / 最初の 1 ランの導線に当たる仕組みはコードに無い**（解放制で出会う物を減らしているだけ）。HANDOFF 5 章でも「用語が直感的か」は未回答

**噛み合いの穴（既知の差）**: 指輪・首飾りの弾系の性質は銃が無いと効かない / 祝福「得物の誉れ」は長銃・投擲に終撃が無く半分しか効かない / 「持ち替え」は近接＝筋力の前提が崩れた / 計算式の頁にジョブの倍が出ない / 敗走した敵の 42% が逃げ切る / 遠くから撃たれた idle の敵は起きない（釣る遊びが無い）/ 左手の装備枠は枠だけで空

**資料のずれ**: `docs/ideas/README.md` のチェックリストは economy-core / encounter-core / build-core / run-arc を「未実装」としているが、実際は core-synthesis の段取り 1〜10a で大半が別の形で実装済み。新案を出す人はチェックリストを鵜呑みにせず `IDEAS.md`「現状」と CHANGELOG [Unreleased] を見ること

## 4. ユーザーが既に決めた方針と、却下・保留した案（逆行しないために）

**大方針**
- かさ増しではなく 1 つずつ考え抜く（2026-09-28、build-core 11 章 9 = B42 で承認）。これが memory の「出た案は全部入れる」（2026-09-24）より優先
- 「すぐ飽きる」対策は要素の量より**ランの流れ（始まり・盛り上がり・終わり）と判断の場面**（memo/20260928-1）
- ハクスラとローグライクの融合。**装備集めの要素を薄くしたくない**（build-core.review B36）。うまくいったランは壊れてよい、平均ではクリアがちょっと難しい（B39）
- スケールは固定値より「揺らぎの中の平均」（economy.review $6）。賭けはもっとガチの振れ幅で（$1）
- 回復手段は絞る。ビルドでサステインを得るのは可（encounter.review）。連打で敵弾を無効化できる状態は嫌う。「攻撃連打だけでは被弾が増え、プレイスキルで被弾を減らす」が目標
- ヒットストップは気持ちよさに必須。設定で切ると有利になる懸念 → 記録を競うモードでは固定（core-synthesis 10 章 2）
- ボス戦は「殴り続けて避けるの 1 パターン」をやめ、難しくてよいので戦略とプレイスキルを要求（encounter.review）
- 連撃は最低 3 段・上限なし、「3 段目＝終撃」と決めつけない。重い武器は足を止め硬直長め、軽い武器は止まらない
- スキル主役の武器種・ジョブをもっと増やしてよい（B17）。武器はこれからも足していく（B34）
- 銭で 6 型（持つ・使う・稼ぐ・投げる・買う・守る）が出せたなら、**他の軸にも同じ密度の種類が欲しい**（$5 → 軸 × 型の行列として承認）
- 名前: 熟語・文にしない・ださいのは不可（build-core.review に「ださい」「熟語」「文にするな」が 20 か所以上）。スキル石は「スキル」と呼んでほしい。「共鳴」の名は残す
- UI で説明しない、説明は Tips ノート（memo/20260925-2）。キー表記はキー設定に従う
- 右クリック（固有技）を封じる効果は作らない。旧データの移行・互換は作らない（2026-10-01）
- いずれマルチプレイ対応を目指したい（memo/20260925-1。ヒットストップ設定の動機）

**決定済みの具体**（再提案しない）: 刻印符はラン内 / 武器種を型に束ねる / ステ振り廃止 / 終撃連動・応手連動の符は可 / 加護は 1 行動 2 枠（3 枠目は真髄と名のある遺物）/ 敵の攻撃が敵にも当たる / 仇 / 解放制 / 欠片 → 銭・鍵・瓶・被弾で 5% こぼれる・質屋・商人を襲う・系譜「財」/ 処刑は生命 25% まで / 敵弾を近接で消すのは既定にしない / 最深の主は専用の新ボス（実装済み）/ ボス階は道中の戦闘なし・前室に回復なし / マップの型 8 種を全部採用 / 書の火力は今のまま / 章ボスの 1 発の引き下げは様子見

## 5. この領域の問い

1. 持ち込み 2 部位・袋・持ち帰りは決定済みなのに未実装。入れたとき「拾った瞬間に永続」で設計した来歴・芽・残響・倉庫 400 はどう意味を変えるか。逆に、入れないなら「ランごとの新鮮さ」を何で作るのか

3. 50〜70 分のランの中で「盛り上がり」はどこにあるか。章ボス 4 回と最深の主以外に、章の中盤に山はあるか（深度 3 の死亡集中と深度 6 以降の格の出すぎは、序盤が谷・中盤が平坦という形を示していないか）

6. 決定性とリプレイ・デイリーが揃っているのに、**他人と比べる・共有する**遊びがローカル記録止まり。Steam で売るとき、この資産（seed・入力列・仇・死因）を何に変えられるか
7. 状態異常 8 種が 0 件、ジョブ 10・武器種 29・型 15・流儀の組み合わせの中で、実際に選ばれない・効かない組（指輪の弾系・左手の空き枠・得物の誉れ）はどれだけあり、量を増やす前に「既にある物を効かせる」余地はどこにあるか

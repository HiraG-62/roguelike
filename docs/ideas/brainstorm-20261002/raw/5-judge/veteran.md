# 審査: Steam の辛口ローグライク古参の目

審査日 2026-10-02。対象は `raw/3-refine/L01〜L15` と `raw/4-gaps/G1〜G6`（final）の 293 案。全文と診断書 `raw/0-survey/` を読み、名前がコードに未実装であることを `src/` の検索で確かめた（本陣・初陣・墨痕・点睛・取寄・盾隙・門答など 0 件）。

採点: 5 = 発売までに必ず入れたい / 4 = 強く推す / 3 = 良い / 2 = 弱い・安直 / 1 = 要らない・原則違反・有害。5 は 11 件（約 4%）。

## 所見

### 光るもの

- **予告の文法を世界の法則まで通す線**（墨入れ・黄赤一致・出端・運筆予告・予告律・墨法）。「下絵は消せる、墨は消えない」は 3 レーンが独立に同じ所へ着いた。色覚・トレーラー・英訳・オンボーディングに同時に効き、ロジックをほぼ触らない。Hades にも Sekiro にも無い、このゲームの看板になれる
- **陣を「読む単位」にする線**（陣図・本陣・破陣・旗倒れ・布陣・決着三様）。200 体の地図を Survivors 系の群れでなく「床に書かれる大群の下絵」として見せる案は、見下ろしアクションで他に見たことがない
- **決定性を学びに変える線**（推敲・感想戦・走馬灯・定盤・実戦譜・定跡）。「死の 3 秒前に戻ってもう一手」は決定性でしか作れず、配信で一番伝わる
- **原則を曲げずに持ち込み問題を解く取寄**。「倉庫に手を伸ばせる回数を絞る」は、失う怖さに頼らず新鮮さを作る筋の良い答え
- **ボスの「待てば隙」を潰す G3 の改訂**（門答・残写・面影・誘火・引導）。今の鏡の騎士と第三の顔が反動ダウンで勝手に終わる欠陥を正確に突いている

### 足りないもの・危ういもの

- **重複が多すぎる**。予告の描き直し 6 本、結末の絵巻 9 本、開帳 5 本、稽古 6 本、時間の圧 5 本、熟達の帳 5 本。統合の段を挟まずに積むと、用語と画面だけが純増する。採点では束ね先を 1 本だけ高くし、残りは 3 に置いた
- **測る道具が遊ぶ物より多い**。読み手・変化図・実戦譜・定跡・詮議・鮮度・初動計・遡及審査・試演台・本歌取。どれも正しいが、10 本の開発用の道具を並列で作る体制ではない。先に要るのは「読み手」「実戦譜」「定跡」の 3 本だけ
- **「強くなった実感」が薄い**。ルール変更の原則に寄せすぎて、Hades の Pom や Balatro の倍が跳ねる快感に当たる物が、連判の判と開眼だけ。数値で壊れる瞬間を怖がりすぎている。共鳴の終点（開眼）と深み（無尽・燎原）以外にも、1 ランの中盤で「今日は壊れた」と叫べる山が要る
- **エンドゲームと社会性が早すぎる**。踏破率 3%・死亡の 7 割が章 1 の今、淵底・深律・裏銘・逆用・感応・淵譜・新参・手合は XL〜L の費用を払う時期ではない。人口が無いと回らない物（手合のリーダーボード・視聴者の果たし状・新参の週）は発売後
- **Shadow of Mordor のネメシスの轍**。宿怨・意趣・手負・武名は「苦しむ人ほど敵が育つ」構造に寄りやすく、特許の芯にも近い。奪銘・初仇のように「名と絵を奪うだけ」に留めた物だけを推す
- **章 1 は毎ラン通る 13 分**という制約（G6 五番立が指摘）は、他のレーンの多くが見落としている。初陣・口開け・手習のような教えの案は初回だけに閉じ、通常のランでは「読める人ほど短く抜ける」作りを守ること

### 推す入れ順（費用対効果）

1. 黄赤一致（S）→ 出端 → 盾隙 → 定盤（デイリーが 2 階から別の盤になる不具合）
2. 初陣 → 被弾筋・顔見世・混成操作（いずれも S）
3. 取寄 + 貸出 + 持越（ユーザーの決着が要る）
4. 墨入れ（予告の描き替え）→ 陣図（本陣 + 軍配 + 旗倒れ）
5. 推敲（局面写し → 走馬灯 → 感想戦）、揮毫（遺物 1 つで試す）
6. 門答・残写・誘火・面影（定跡の bot と同じ段で）

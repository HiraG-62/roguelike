# L04 ランの流れとリスクリターン（発散）

担当: ランの流れとリスクリターンの設計者。2026-10-02。
コードで確かめたもの: `system/exits.ts`（出口 7 種）・`reaper.ts`・`reaperVariants.ts`（取り立て屋は呪い付き祝福で出る）・`linger.ts`・`chapters.ts`（休符・予習の文）・`finale.ts`（踏破は見出し替え）・`donation.ts`（寄進はラン内の効果なし）・`contractors.ts`（占い / 案内人 / 渡し守）・`runEvents.ts`（28 種）・`specialRooms.ts`（宝物庫・封印庫・鍵付きの宝箱）・`bossDeepLord.ts`（四門）・`loot/provenance.ts`（来歴はラン中に装備へ直接積む）。
承認済みで未実装の案（encounter-core 8 章の「息」・砂時計の常時表示・死神の下の褒美・出来事 2 択、core-synthesis 7 章の陣太鼓・兵糧ほか、run-arc の袋）は新案として出さない。下の案のうちいくつかは、それらを「どう深めるか / どう置き換えるか」として書いた。

## この視点から見た今のゲームの課題

- **時間に値段が付いていない**。猶予は約 300 秒、階は 46〜127 秒で終わるので、死神はほぼ来ない。急ぐ人にも掃討する人にも時間の損得が無く、陣の 6 割が素通りされても何も起きない。三重の圧（死神・長居の代償・陣の歩き出し）は役割が重なったまま、どれも効いていない。
- **章の中が平ら**。休符 → 通常 3 階 → 章ボスで、通常の 3 階は同じ形。章ボスは章の中で一度も姿を見せず、試験の予習が「この章の主: 地下 10 階 盗賊王」の 1 行しかない。
- **判断が 1 階先までしか届かない**。出口の予告は次の 1 階の報酬とバイオームだけで、2 階先・章ボスまでの道を組む遊びが無い。バイオームを選ぶ理由も色と顔ぶれに留まる。
- **貯まるのに使わない資源**。鍵は 908 本中 4 本、市の 7 割が何も売れず、寄進は景色だけ。貯めた物を「どこで何と交換するか」の場面が足りない。
- **持ち帰りの緊張が無い**。拾った遺物は瞬間に永続、ラン中も倉庫から付け替え可（2026-10-01 に保つと決定）、一方で袋と持ち帰り（2026-09-28 決定）は未実装のまま並び立つ。死んでも失う物が無いので、「引き際」の判断が生まれない。踏破の後も深みで死んで失う物が無い。
- **終わりの形が弱い**。踏破は死亡画面の見出し替えで、帰還（上り階段）は何のために戻るのか曖昧。深みには「やめる理由」が無い。

## 案

### 灯明
- 種別: 改善（三重の時間の圧の整理 + 新しい資源）
- 領域: run
- 一言: 階ごとの死神の猶予を、ランを通して減っていく「灯明の油」1 本にまとめ、陣を決着させると油が継ぎ足される。
- 仕組み:
  - 油（秒）はランを通して 1 本。開始 240 秒、上限 420 秒。歩いても戦っても 1 秒に 1 減る。降階で +90（階を跨いで持ち越すので、急いだ分はそのまま貯金になる。承認済みの「息」を資源の形で実現する）
  - **陣の決着で継ぎ足す**: 全滅・敗走で +15、大将の撃破で +10、無傷の決着で +10。目安として 30 秒かけて潰した陣は損、大将を狙って 15 秒で敗走させた陣は得。「上手い掃討は時間を生む、だらだらした掃討は時間を食う」という交換レートが立つ
  - 油の残りで段が進む（今の三重の圧を 1 本の段にまとめる）: 90 秒を切ると眠った陣が暗がりから歩き出す（今の陣の歩き出し）→ 45 秒で長居の代償（影の自分 / 崩落 / 潮）→ 0 で死神。主の間を封鎖している間と主の間の階（`lordHall`）では減らない（今の死神の停止と同じ）
  - HUD は数字でなく灯明の炎の丈（段の境に刻み）。油が少ないと地図の暗がり（`mapLight`）がわずかに狭まるが、予告の線と弾は暗がりの影響を受けない
  - 既存の物の置き換え: 渡し守の「待たせる」は油を売る、縛り「急かす死神」は燃える速さ ×1.3、起点「死神の友」は油の上限が低い代わりに陣の継ぎ足しが倍、ランイベント「死神の通り道」は線上で油が燃える
- なぜこのゲームで: 陣・群勢・大将・敗走という「決着の形が全滅だけではない」単位があるから、継ぎ足しの量を決着の質で変えられる。大将を狙う・処刑で崩す・敗走させるといった陣の読みが、そのまま時間に換金される。急ぐ人も油を稼ぐために陣を選んで潰すことになり、6 割素通りの問題と死神が来ない問題が同じ 1 本で解ける
- 着想元: Darkest Dungeon の松明（光が資源で、減るほど危ない）、Risk of Rain の時間で上がる難度、FTL の追ってくる反乱軍の艦隊。変えた点: 時間を一方的な罰にせず、戦いの質で取り戻せる「通貨」にした。難度の数値を時間で上げず、段ごとに既存の圧（歩き出し・長居・死神）を順に出すだけにした
- 安っぽくならないための要点 / リスク: 継ぎ足しを撃破数に結ぶと「雑魚を狩るほど得」になり作業になる。必ず陣の決着単位で、決着の質（大将・無傷・敗走の速さ）で量を変える。油が切れやすすぎると焦りだけのゲームになるので、QA は「人の速さの bot」で 1 ランの死神の出現が 0.3〜1 回になる辺りを狙う。決定性は floorTime と同じく step の中だけで完結する
- 規模: L

### 落款
- 種別: 新要素（持ち帰りの緊張を、遺物を失わせずに作る）
- 領域: run
- 一言: そのランで積んだ来歴と残響は「乾いていない墨」で、宿坊・引き上げ・踏破で落款を捺すまで定まらない。
- 仕組み:
  - 遺物は今どおり拾った瞬間に永続で、ラン中も倉庫から付け替えられる（2026-10-01 の決定を保つ）。賭けるのは遺物ではなく、**このランで積んだ来歴（節目の進み）と残響**
  - ラン開始時と落款を捺した時点で、装備中の遺物の来歴を写しとして持つ。力尽きたら、写しより後に積んだ来歴の半分だけが乾き、残りは消える（残響も同じ）。選んだ芽はそのまま残る（芽を消すと「捨てた枝は戻らない」の物語が壊れるので）
  - 落款を捺す場は 3 つ: 章の休符の宿坊（下の案）、**上り階段の「引き上げ」**（帰還をこれに置き換え、ランをその場で生きて終える）、踏破。深みでは 5 層ごとに地上への道がもう一度開き、引き上げられる
  - 深い階ほど来歴の伸びが大きい（`bumpProvenance` は深度を受け取る）ので、潜るほど濡れた墨が増え、「もう 1 章行くか、ここで捺すか」の判断になる
- なぜこのゲームで: 来歴・芽・銘という「使い込みの物語」を持つ遺物はこのゲームの芯で、失って惜しいのは数値より物語の進みだから。原則 10「拾った瞬間に永続」と付け替えの決定を壊さずに、run-arc の袋が狙った「何を持ち帰るか」の緊張だけを取り出せる。帰還（目的が曖昧）と深み（やめる理由が無い）の 2 つの穴も同時に埋まる。「墨が乾く」は墨淵の字面そのもの
- 着想元: Loop Hero の撤退（キャンプで撤退すれば資源 100%、死ねば一部だけ）、Spelunky の「出口まで持って帰って初めて宝」。変えた点: 失うのは物でなく成長の履歴の半分で、遺物そのものは決して失わない
- 安っぽくならないための要点 / リスク: run-arc の袋（決定済み・未実装）を置き換える提案なので、ユーザーの判断が要る。死の罰を重くしすぎると「捺せる所で必ず引き上げる」安全策が最適になるので、引き上げはランを終える（その先の深度と踏破の上乗せを失う）ことで釣り合わせる。リプレイは来歴を記録しないので決定性に影響しない。保存は今どおり step の外（`endRun`）でだけ行う
- 規模: L

### 宿坊
- 種別: 拡張（章の休符）
- 領域: run
- 一言: 章の休符の階に宿坊を置き、湯治・落款・参詣の 3 つから 2 つだけを選ばせる。
- 仕組み:
  - 今の休符は泉（瓶を満たす）・寄進の祠・予習の文が全部ただで付く。これを宿坊の 3 つの「勤め」にまとめ、2 つを選ぶ
    - **湯治**: 瓶を上限まで満たし、生命を 40% 戻す（今の休符の泉）
    - **落款**: 濡れた墨を乾かす（上の案）
    - **参詣**: 章の布告を選び直せる、または絵図の霧を 1 段晴らす（下の案）
  - 宿坊の門前で寄進ができ、寄進の額で参詣の効き（晴れる段数）が変わる。寄進はラン内の効果が無いまま（拠点の景色も今どおり育つ）だが、「銭で情報を買う」使い道ができる
  - 章 1 は休符が無いので、深度 1 の開始部屋に宿坊の写し（参詣だけ）を置く
- なぜこのゲームで: 章の弧（休符 → 登り → 章ボス）は骨として立っているが、休符はただ受け取る階になっている。ランの今（瓶）・ランの成果（落款）・この先（参詣）という 3 つの時間軸を天秤に掛ける場面にすると、章ごとに 1 回、腰を据えた判断が入る。門前町・寺院の章の様式と言葉がそろう
- 着想元: Slay the Spire の焚き火（休むか鍛えるか）、Hades の休息の間。変えた点: 選ぶ軸を「強さ」でなく「今・成果・先」の 3 つの時間に分けた
- 安っぽくならないための要点 / リスク: 「2 つ選ぶ」の 3 つ目に毎回同じものが外れるなら判断は死んでいる。湯治を外すと章の頭で瓶が無い、落款を外すとここまでの章の来歴が濡れたまま、参詣を外すと章ボスの布告が厳しいまま、と三者に必ず痛みがあるかを確かめる。休符の泉は今「必ず満たす」なので、序盤の死亡集中（章 1）に響かないかは実プレイで見る
- 規模: M

### 絵図
- 種別: 拡張（出口の予告）
- 領域: run
- 一言: 章の頭に、章ボスまでの 3 階分の分岐を絵図として見せ、手前の 1 段だけが鮮明で奥は霧の中にする。
- 仕組み:
  - 宿坊（章 1 は深度 1 の開始時）で、その章の通常の階（例: 7・8・9）を 3 層 × 2〜3 個の点の図として先に作る。点は「バイオーム・出口の報酬・階の主」の組。点の間の線が、各階で出る分岐の階段になる
  - 手前の層は全部見える。2 層目は報酬の種類だけ、3 層目は点の数だけ（霧）。占いの「遠見」、宿坊の参詣、寄進で霧が晴れる
  - 祝福の系譜を 2 回通って真髄の手前まで寄せる、錬磨を章ボス直前に置く、苦手な階の主を避ける、といった 3 階先までの道が組める
  - 決定性: 章の絵図は `seed` と章の番号から作る別の乱数で作り、各階の `planForkStairs` はその絵図から読むだけにする（今の state.rng の消費順を章の頭に寄せる）
- なぜこのゲームで: 出口の予告が「報酬 + バイオーム（+ 系譜名）」の 2 軸をすでに持ち、祝福は祝福の出口を選んだ階でしか出ない。だから道を先まで組めることの価値が、他のゲームより大きい。系譜を何枚集めるかで真髄が確定する仕組みとも直結する
- 着想元: Slay the Spire の幕ごとの地図。変えた点: 地図を全部見せず霧を置き、晴らす手段を寄進・占い・宿坊という既存の物に結んだ。「1 階先の予告」の驚きを残しつつ、道を組む楽しみを足す
- 安っぽくならないための要点 / リスク: 全部見えると最適経路の計算になり、Hades の「扉を開ける」驚きが消える。霧の段を残すのが要。案内人の「分岐を増やす」は絵図に線を 1 本足す働きに書き直す必要がある。リプレイの版は上がる
- 規模: L

### 名乗り
- 種別: 拡張（出口の予告）
- 領域: run
- 一言: 階段の上に、降りた先の階の主の名を名乗らせ、相手を選んで降りられるようにする。
- 仕組み:
  - 分岐の階段の予告に 3 つ目の行として、次の階の主（部屋主 8 体のどれか、または「〜の長」）の名を出す。主は今 `buildFloor` で決めているのを、`planForkStairs` で先に引いて渡すだけ
  - 部屋主ごとに得手不得手がはっきりしている（浮遊眼に重打は 45〜90 秒、銃は盾騎士を正面から崩せない）ので、「報酬は欲しいが、主が苦手」という本物の板挟みが生まれる
  - 図鑑で「予告の図解」を開いた主には、名の横に小さな印を付ける（読める相手であることが分かる）
- なぜこのゲームで: 武器種 29 × 敵の相性差が大きいことは S1 の数字で分かっている。相性を「直す」のではなく、「武器で道の選び方が変わる」遊びに変える最小の一手。名乗りは和の戦の作法で、決闘のランイベントとも言葉がそろう
- 着想元: Inscryption の地図の上で戦う相手が見える点、FTL のビーコンに出る「店 / 敵艦」。変えた点: 主の名だけを出し、修飾子や強さは出さない（単一指標を作らない）
- 安っぽくならないための要点 / リスク: 名だけで何が得意か分からないと意味が無いので、部屋主ごとの絵（密度 2）と図鑑の頁が前提。表示が 3 行になるので、出口の文字の量は実機で確かめる
- 規模: S

### 布告
- 種別: 新要素
- 領域: run
- 一言: 章ボスが章の頭で「布告」を出し、章の 3 階に自分の流儀の掟を敷く。2 つの布告から 1 つを選び、厳しい方を受ければ撃破の褒美が増える。
- 仕組み:
  - 章ボスごとに布告を 2〜3 種持つ。宿坊（章 1 は深度 1）で 2 つが示され、1 つを選ぶ。片方は穏やか、片方は厳しく、厳しい方を受けると章ボス撃破後の改鋳が 4 択になる
  - 布告は章の陣に「章ボスの読みの予習」を混ぜる。例:
    - スライム王「分け身」: 章の陣のスライム系が死ぬと分かれる → 主の第 1 段階（分裂体の全滅で進む）の予習
    - 盗賊王「通行税」: 拾い損ねた銭は消えずに盗賊王の懐へ積もり、主の間で投げ銭として撃ってくる（避ければ拾い返せる）→ 逃げ撃ちの読み
    - 油壺の王「油撒き」: 章の陣の足元に油膜が敷かれる → 着火の段階の予習。炎のビルドには追い風
    - 鏡の騎士「写し身」: 章の精鋭が、直前にプレイヤーが撃ったスキルを写して撃ち返す → 模写の段階の予習
  - 布告は宿坊の参詣で選び直せる
- なぜこのゲームで: 章ボスは「章で覚えた行動の試験」と設計されているのに、章の中で何も教えていない。布告は、試験範囲を章の 3 階に予告として配る。行為で進む段階（bot が 0% の部分）を、人が章の中で体に入れてから主の間に入れる。章ボスが 4 体固定でも、布告の組み合わせでランごとの章の顔が変わる（飽き対策）
- 着想元: Balatro のボスブラインド（先に見えている縛りに合わせて組む）。変えた点: 縛りをボス戦 1 回でなく章全体に敷き、縛りの中身をボスの読みの予習にした。選ぶ余地を与え、厳しさと褒美を自分で決めさせる
- 安っぽくならないための要点 / リスク: 「敵の生命 ×1.2」のような数値の布告は入れない。どの布告も章ボスの技 1 つと結ばれていることを審査の条件にする。章ボスの撃破時間の目標（鏡の騎士 34 秒が速すぎる）にも効くので、布告を受けた側と受けない側で probe を分ける
- 規模: L

### 前哨戦
- 種別: 新要素
- 領域: run
- 一言: 章の 3 階目に章ボスが一度だけ陣の大将として現れ、刃を交えたぶんだけ本番の主の間が楽になる。
- 仕組み:
  - 章の 3 階目（3・8・13・18）のどこかの陣で、章ボスが大将として立つ（幟で遠くから分かる）。戦うかどうかは自由
  - 章ボスは第 1 段階の技だけで戦い、45 秒経つか、行為で進む条件（スライム王なら分裂体の全滅、盗賊王なら壁際に追い詰める）を 1 回満たすと「退く」
  - 前哨戦で与えた傷は本番に持ち越す（最大で生命の 15%）。行為の条件を満たして退かせた場合は、本番の主の間で第 1 段階を飛ばして第 2 段階から始まる
  - 前哨戦を挑んで負けかけても、退く条件で終わるので死ぬまで続くことは無い。ただし時間（灯明の油）と瓶は使う
- なぜこのゲームで: 章の中盤に山が無い問題と、ボスの読みが伝わらない問題（危ない間合い・行為で進む段階が意図どおり読まれていない）を同時に扱える。ボスの技は乱数を使わず `pickMove` でプレイヤーを読むので、前哨戦で見た技の選び方が本番でもそのまま通じる。「死を学びにする」線（死因 → 予告の図解 → 仇 → 御堂）をラン内に 1 段増やす
- 着想元: モンスターハンターの傷の持ち越し、ゼルダの中ボスが後で本番に戻ってくる構成。変えた点: 前哨戦の成果を「生命を削る」だけでなく「段階を飛ばす」にして、行為の読みを報酬にした
- 安っぽくならないための要点 / リスク: 章 1 の 3 階目は死亡が最も多い階なので、章 1 だけは退く条件を緩める（30 秒・陣の取り巻きなし）。本番を飛ばしすぎると章ボスが関門でなくなる（今でも全死亡の 4%）ので、飛ばせるのは第 1 段階まで。主の間の「道中の戦闘なし」の決定には触れない（前哨戦は通常の階で起きる）
- 規模: L

### 残党
- 種別: 新要素
- 領域: run
- 一言: その章で決着させずに素通りした陣は、章ボスの主の間に「残党」として加勢に来る。
- 仕組み:
  - 章の通常の階を離れるとき、大将が生きたまま残った陣の数を数える（敗走して逃げ切った陣も含む）
  - 主の間の段階の境で、残党が取り巻きとして波で来る。未決着 3 陣ごとに 1 波、最大 3 波。前室には残党の数だけ幟が立つ（数字は出さない）
  - 取り巻きを倒すとボスに怯み値が入る今の仕組みはそのまま。残党が多いほど危ないが、怯ませる機会も増える
- なぜこのゲームで: 陣の 6 割が素通りされても、今は何も起きない。残党は「避けて通る自由」を残したまま、その付けを章の終わりに回す。2 倍になった敵の総量が、章ボスまでの戦略の材料になる。灯明（急ぐと油が減る）とは逆向きの圧なので、急ぐ / 掃討するの間に本物の釣り合いができる
- 着想元: FTL の反乱軍の前進、Total War の撤退した軍が再集結する流れ。変えた点: 罰で終わらせず、取り巻きを倒すとボスが怯む既存の仕組みと結んで「来ても使える」両面にした
- 安っぽくならないための要点 / リスク: 敵の生命や攻撃を盛る形にしない（来るのは取り巻きの数だけ）。主の間の形が乱数なしの手描きなので、取り巻きの入口を間ごとに決めておく。落ち武者（承認済み）が入ると「逃がした敵が次の陣に合流」と二重になるので、合流した陣が未決着ならその分だけ数える
- 規模: M

### 間道
- 種別: 新要素（鍵の使い道）
- 領域: run
- 一言: 分岐に鍵 3 本で開く「間道」が混ざり、1 階を飛ばして 2 階下へ降りられる。
- 仕組み:
  - 分岐の階段のうち 1 本が錠の付いた間道になる（章の 1〜3 階目だけ。章ボスの階を跨がない）。鍵 3 本で開く
  - 降りると 1 階を飛ばす。飛ばした階の出口の報酬・到着の報酬は無い。灯明の油は 1 階分の降階で済む
  - 得るもの: 深い階で拾う遺物は性質の強さが深度で決まるので、早く深い所の遺物と来歴に手が届く。ランが 1 階短くなる
  - 失うもの: 祝福と遺物の機会が 1 階分減ったまま、深い敵に当たる
- なぜこのゲームで: 性質の強さを拾った深度で固定し、地金だけを今の深度に合わせるという、このゲーム固有の装備の決まりがあるから、「浅い所を飛ばす」に意味が出る。鍵（908 本中 4 本しか使われない）に、道そのものを変える使い道ができる
- 着想元: Spelunky の近道、Balatro のブラインドを飛ばしてタグを得る判断。変えた点: 飛ばす見返りを「深さ」そのものにし、装備の深度固定と結んだ
- 安っぽくならないための要点 / リスク: 間道が常に得だと、上手い人は全部飛ばしてランが短くなるだけ。飛ばした分の祝福の機会が痛いことを QA で確かめる。鍵の出方（陣の大将 50%）と値段は、使い道が増えた後に合わせ直す
- 規模: M

### 禁宝
- 種別: 新要素
- 領域: run
- 一言: 宝物庫の奥の禁宝を持ち出すと、階じゅうの陣が目を覚まして寄ってくる。階段までの退き戦になる。
- 仕組み:
  - 宝物庫のうち一部（目安 1 章に 1〜2 回）の奥に禁宝の台座がある。中身は名のある遺物か、2 階深い遺物 2 つ。台座の前で予告（「持ち出せば階が騒ぐ」）
  - 取ると、眠っている陣が全部起き、長蛇の形で禁宝を持つプレイヤーへ寄ってくる。灯明の段が 1 つ進む（長居の代償が即始まる）
  - 階の主を倒した後なら階段まで走り抜けるだけの退き戦、倒す前なら主までの道が戦場になる。どちらの順で取るかが判断になる
  - 寄ってくる陣は群勢を持つので、大将を討てば敗走する。陣の読みで退き道を切り開ける
- なぜこのゲームで: 陣の起き方（気付いた者の周り → 後詰）と長蛇の歩き出しは既にあり、それを一度に全部起こすだけで、階の中に 1 つ山場が立つ。陣が「避けて通る障害物」から「退き道に立ちはだかる軍勢」に変わる瞬間が作れる
- 着想元: Spelunky の黄金の偶像（取ると大岩が転がる）。変えた点: 襲ってくるのを罠ではなく、陣形と群勢を持った敵の軍勢にし、陣の読みで突破できるようにした
- 安っぽくならないための要点 / リスク: 起きた陣が一度に来ると同時攻撃の上限と予告の上限を超えて、読めない乱戦になる。寄ってくる順と速さは陣形ごとにずらし、波として届くようにする。性能（200 体が一度に動く）も確かめる
- 規模: M

### 掛売
- 種別: 新要素（銭の使い道）
- 領域: run
- 一言: 市で品を掛けで買え、借りが残っている間は死神の代わりに取り立て屋が早く来る。
- 仕組み:
  - 市・章の市で、持ち金を超える品を掛けで買える（借りの上限は章ごとに決める）。借りは階を降りるたびに 2 割増える
  - 借りがある間、その階の死神は取り立て屋になり（今は呪い付き祝福を持つと出る亜種）、灯明の油が借りの額に応じて早く尽きる
  - どこかの市に触れると、持ち金から自動で返す
  - 商人を殺して借りを踏み倒すこともできる。その場合は無法者に加えて、そのランの死神がずっと取り立て屋になる
- なぜこのゲームで: 取り立て屋という亜種と、商人を殴れる体の作りが既にある。序盤に欲しい遺物・瓶を先に取り、後の階で稼いで返す「前借りのテンポ」は、市の 7 割が何も売れない問題に直接効く。商人を襲う方が得という今の疑い（無法者のランの方が深く行く）にも、取り立て屋を付けることで代償を足す
- 着想元: Darkest Dungeon・Spelunky の店での借りと店主の怒り、Hades のカロンの店。変えた点: 借りの罰を店の外の時間の圧（死神の亜種と灯明）に結んだ
- 安っぽくならないための要点 / リスク: 借りを返す手段が自動の 1 つだけだと考えなくなる。返すか、次の市まで持ち越して品を買い足すか、を毎回選べるように「返す」を台座での操作にする案もある（市の画面に 1 行増える）。賭場の主の賭けと銭の行き先が混ざるので、銭の流れの表（economy-impl）に 1 列足す
- 規模: M

### 誂え
- 種別: 新要素（銭の使い道）
- 領域: build
- 一言: 市で部位と系統を指定して遺物を誂え、章ボスの前室の章の市で受け取る。
- 仕組み:
  - 市で 1 章に 1 回、部位と系統（共鳴の「〜系」から 1 つ）を選んで注文し、代金の半分を払う。受け取りは章の市（章ボスの前室）で、残りを払う
  - 遺物は**受け取った深度**で作る。指定した系統の性質が 1 つ必ず付き、他は普通に抽選。揺らぎも普通に掛かる
  - 早く注文するほど代金が安い（注文した深度で値段を決める）。受け取る前に力尽きれば、前金は失われる
- なぜこのゲームで: 共鳴は近接・怯み・気力のような汎用の系統で自動的に立ち、燃焼・冷気・爆発のように狙って組む系統は立ちにくい（S3）。誂えは「狙った系統を 1 本だけ確実に引き寄せる」手段を、ランダムに性質を足すクラフトに頼らずに、銭と時間の賭けとして与える。章の市が「受け取りの場」になって、章ボスの前に準備の山ができる
- 着想元: 昔の誂え物（注文して後で受け取る）。ゲームでは Monster Hunter の素材を集めて作る流れ。変えた点: 素材でなく時間を払わせ、ランの章の弧の上で受け取りを章ボスの直前に置いた
- 安っぽくならないための要点 / リスク: 系統を 1 つ確定させるだけで、値の揺らぎや他の性質は抽選のまま（BiS を作らない）。拾った瞬間に永続の決まりに従い、受け取った時点で倉庫に入る
- 規模: M

### 朱印
- 種別: 新要素
- 領域: run
- 一言: 各章に隠れた札所で朱印を受けると、最深の主の四門の門柱が 1 本ずつ朱で封じられて始まる。
- 仕組み:
  - 各章に札所が 1 つある。たどり着く条件は章ごとに 1 種で、既存の仕組みから作る
    - 苔の洞: 隠し部屋の奥の祠
    - 寺院: 章の中で寄進の祠に一定額
    - 廃城: 陣の大将を処刑で 3 体
    - 奈落: 前哨戦で章ボスを退かせる
  - 朱印は持ち物の外に、ランの記録として残る（宿坊で見られる朱印帳）
  - 最深の間で、朱印の数だけ四門の門柱が朱で封じられる。封じた門柱は光線を撃たず、一撃で折れる。4 つ揃えば四門は形だけになり、陥没から始まる
- なぜこのゲームで: 最深の主は bot の 5 戦全敗で、時間の 95% を四門で使っている。四門を弱めるのではなく、「ランの間に何をしてきたか」で崩せる形にすると、50〜70 分の弧の最後がそれまでの寄り道の総括になる。第三の顔（被弾の多かった章ボスの技を借りる）と対になり、「苦手が返ってくる」と「積んだ寄り道が返ってくる」が最深の主の両面になる
- 着想元: 四国の札所巡りと御朱印帳、Spelunky の隠し道（世界ごとの品を集めて先へ進む）。変えた点: 隠しの見返りを別ルートでなく、最後の主の第 1 段階の形にした
- 安っぽくならないための要点 / リスク: 札所の条件が「何体倒す」になると依頼と区別が付かない。どれも場所か行為に結ぶ。条件の中身は Tips ノートと語り部の 1 行で匂わせ、UI に説明を書かない。最深の主の調整（今は全敗）と一緒に測る
- 規模: L

### 相生
- 種別: 拡張（バイオームを選ぶ理由）
- 領域: run
- 一言: 前の階と次の階のバイオームの組み合わせで、その階に反応の地勢が生まれる。
- 仕組み:
  - 分岐で選ぶバイオームと今の階のバイオームの組が決まった組（6〜8 組）なら、次の階が「相生の階」になる。階段の予告に組の印を出す
  - 例:
    - 油の坑道 → 熔鉱炉 = 火計: 陣の足元に油、篝火が置かれ、燃え広がりやすい
    - 沼 → 氷窟 = 凍沼: 水たまりが氷床になる
    - 草原 → 熔鉱炉 = 野火: 草むらが広く、炎が走る
    - 熔鉱炉 → 氷窟 = 湯煙: 煙の層が多く、陣の気付きが遅い
    - 骨の墓所 → 暗闇 = 百鬼: 眠った陣が多い代わりに、物見がいない
  - 相生の階は、その属性に合う色の残響が多く出る
- なぜこのゲームで: 地形の層 10・反応 25 が両陣営に効く設計があるのに、バイオームを選ぶ理由は色と顔ぶれだけ（バイオーム固有の仕組みは未実装）。相生は新しい仕組みを足さず、既存の地形の層の撒き方を組で変えるだけで、2 階先までバイオームの道を組む理由を作る。炎のビルドが火計を目指す、のようにビルドと道がつながる
- 着想元: Loop Hero のタイルの隣接で別のタイルに変わる仕組み、陰陽五行の相生。変えた点: 隣接を空間でなく「降りてきた順」にし、結果を既存の地形の層の撒き方で表した
- 安っぽくならないための要点 / リスク: 組を増やしすぎると覚えられない。8 組以内にし、図鑑の「場所」タブに見つけた組を残す。予告の文字が増えるので、印は 1 字でなく絵（地形の層の色）にする
- 規模: L

### 機転
- 種別: 拡張（承認済みの出来事 2 択）
- 領域: run
- 一言: 出来事の 2 択に、今のビルドが満たすときだけ現れる 3 つ目の選択肢を足す。
- 仕組み:
  - 出来事（encounter-core 8-3、承認済み・未実装）の台座 2 つの間に、条件を満たすと 3 つ目の台座が立つ。条件は共鳴の系統（段 1 以上）・流儀・武器の型のどれか
  - 例:
    - 檻の精鋭 + 霜枷の系譜: 檻ごと凍らせて褒美だけ取る
    - 呪われた泉 + 輪廻の系譜: 呪いを研鑽の数えに変える
    - 封じられた扉 + 鎖の型: 扉を鎖で引き倒し、危険な部屋を通らずに中の宝だけ取る
    - 祭壇の火 + 巫女: 灯して消す（両方の効果を半分ずつ）
  - 3 つ目は 2 択のどちらより得だが、ビルドを寄せた人にだけ出る
- なぜこのゲームで: 源と糧の共鳴が「語」で全要素をつなぐ設計なので、その同じ語を出来事の鍵に使える。ビルドの寄せ方が戦闘の外の場面でも報われ、ランごとに出来事の顔が変わる
- 着想元: FTL のイベントの青い選択肢（装備や乗員で開く）。変えた点: 鍵を個別の装備でなく、共鳴の系統・流儀・型という束ねた語にした
- 安っぽくならないための要点 / リスク: 3 つ目が毎回出ると 2 択の痛みが消える。1 階に 1 つの出来事で、3 つ目が出るのは体感 3 回に 1 回くらい。出来事の 2 択を先に入れることが前提
- 規模: M

### 伏せ札
- 種別: 改善（出口の予告）
- 領域: run
- 一言: 分岐に「伏せ札」の階段が混ざり、降りると持っていない系譜の祝福が格を 1 つ上げて出る。
- 仕組み:
  - 分岐の 4 本に 1 本くらい、報酬を伏せた階段が出る
  - 降りると祝福の 3 択が出る。系譜は**今持っていない系譜**から選び、格を 1 段上げる
  - 系譜を絞って真髄を目指すか、違う系譜を混ぜて融合（違う 2 系譜の加護が同じ行動に乗ると確定で並ぶ）を狙うかの賭けになる
- なぜこのゲームで: 出口の予告が系譜名まで見せるので、「見えない」こと自体が判断の材料になる。見えない中身を「新しい系譜」に限ることで、運だけの賭けでなく、融合の 12 枚と真髄の 4 枚の間の戦略の分かれ目になる
- 着想元: Slay the Spire の「？」の部屋、FTL の未探索のビーコン。変えた点: 中身を完全に乱数にせず、「持っていない系譜」に限った
- 安っぽくならないための要点 / リスク: 格のインフレ（深度 6 以降で提示の 88% が大祝福以上）を悪化させないよう、格の上げ方は格の目安（`BOON.gradeDivineBase`）の見直しと一緒に決める。占いの遠見で中身を先に見られるようにすると、占いの値打ちも上がる
- 規模: S

## 章の弧としての組み合わせ（上の案をつないだときの 1 章）

| 階 | 起きること | 判断 |
| --- | --- | --- |
| 休符（宿坊） | 布告 2 つ、絵図、湯治・落款・参詣から 2 つ | 章の厳しさと褒美 / 今・成果・先のどれを取るか |
| 2 階目 | 絵図の上の分岐、名乗り、伏せ札、相生 | 3 階先までの道 |
| 3 階目 | 前哨戦（章ボスが大将の陣）、禁宝の機会 | 本番の前に削るか、時間を残すか |
| 4 階目 | 間道（1〜3 階目から使えば、ここへ飛べる）、誂えの準備 | 灯明の油と残党の数の帳尻 |
| 章ボス | 前室で誂えの受け取り・掛売の清算、残党の幟、布告の答え合わせ | ここまでの選択の総括 |

案はそれぞれ単独でも入る。灯明・落款・絵図・布告の 4 つが骨で、残りはその上に乗る。

## 惜しくも落とした案

- 夜討ちの階: 陣を起こさず先制で大将を討つ忍びの階。陣の気付きの仕組みと噛み合うが、出口の「危険」と布告で役が足りる
- 焼入れ: 宿坊で祝福の格を押し引きで上げ、割れれば札を失う。錬磨が使われていない問題の解に見えるが、格の数値盛りに寄る
- 馴染み: 同じ契約者を章の中で 3 回使うと特別な品が出る。契約者を章の弧にする案だが、解放制と台座の数が先
- 前借: 次の階の出口の報酬を今もらい、代わりに次の階は死神から始まる。掛売と灯明で同じ緊張が出る
- 首級: 大将を討った数を章ボスの前室で通貨にする。鍵と役が重なる
- 合戦の階: 敵どうしの 2 軍が争う階に割って入る。敵の攻撃が敵に当たる（承認済み）が揃ってから
- 短篇: 2 章 + 最深の間の短いラン。Steam Deck と中断セーブ無しへの答えだが、メタと UX の領分
- 心願: ランの頭に副目標を選ぶ。依頼と役が重なる
- 通行料: 階の主に銭を払って戦わずに通る。隠し部屋の抜け道と重なる
- 命の灯: 2 回だけ死を肩代わりし、使うたびに何かを永久に失う。回復を絞る方針と瓶の役に重なる
- 山の鐘: 主の部屋で鐘を鳴らすと主が 2 体になり報酬が倍。数を足すだけで判断が浅い
- 線香の砂時計: 死神の時計を線香で見せる。灯明に統合した

## 0. 先に結論

- 骨子は 3 案。**甲「写し」**（写経所の墨池。L06 の正本を詰めた物）/ **乙「沈殿」**（書塚。L07 を独立の芯として詰めた物）/ **丙「薄墨」**（過去帳の硯池。新しく起こした案）。7 項目（なぜ潜るか・門前町・章 1〜4・和洋混在・死に戻り・最深の主・結末）を 3 案とも埋めた（2-1）
- 推奨は **甲に、乙の「深いほど古い層」と「禁教で沈められた南蛮の書」を接いだ形**。理由: 実装済みの写しの仕組み 8 つ（鏡像・写し身・模写・第三の顔・影の自分・仇・御堂の写し・リプレイ）が説明を足さずに理の現れになり、草紙地層と断簡の器がそのまま使えるため
- コードを読んで、ブレストの前提を 5 つ直した（3 章で詳しく）
  1. **ボスの登場の黒帯（2 秒）の間も sim は動いている**。`introTimer` を見ているのは描画だけ（`system/boss.ts` の `updateBossIntro` が減らすだけで、他の system は読まない）。口上を黒帯に出すと、読む間にボスが動く。→ 口上は主の間の手前の「門の通路」に入った時に出す
  2. **章は敵の出現を絞っていない**。抽選に出る 82 種は深度 10 までに全部解禁され（`balance/enemies/stats/*.json` の `minDepth`）、章 1 で盾騎士（深度 3）・ゴーレム（4）・浮遊眼（1）が出る。重みはバイオーム（`system/biomes.ts` の `family`）だけ。→ 正典の地層は「仕切り」でなく「濃淡」で書き、混ざる理由を持たせる
  3. **最深の主の陥没は溶岩**（`bossDeepLord.ts` 239 行 `seedTerrain(…"lava"…)`）。L06 の「陥没 = 硯の海」は、地形の kind を変えずに最深の間だけ描画の色を朱墨に寄せる形で取る
  4. **語の衝突**: 「帳」は刻印符の名（`skills/types.ts` 287 行、循環の 10 枚の 1 つ）、「出自」は性質の出自（`loot/types.ts` 86 行）と実績「百の出自」、「来歴」は装備の来歴、「写本」は書の器、「深淵」は深みの告知と称号「深淵を覗く者」で使用済み。→ 正典の語を「元帳」「草紙」に替える
  5. **再配色の種は元の絵の密度を継ぐ**（`data/sprites/dots.ts` の注記）。→ 面構の順は敵の key ごとでなく **元の絵（`recolor.base`）ごと** に写る秒を合算して決める。スライムの元絵 1 枚を描き直すと 7 種が同時に上がる

## 1. 目的と、成功したかを何で判断するか

### 目的

1. ユーザーが決定稿を書く前に、芯の違う骨子 3 案から 1 つ（または接ぎ木）を選べるようにする
2. 選んだ骨子を、以後の命名・口上・断簡・描き直しの物差しにする（並列のエージェントが語を足しても衝突しない）
3. 表に出す物は最小（章名の札・口上・図鑑の 1 行・絵馬）。新語の予算（1 段で表に出る新語は 2 まで）を守る
4. 和洋の混在を「片付いていない」から「設定」に変える。描き直し（面構）の順と名の付け方を 1 本の規則で決める

### 判断の物差し

| 何を | 目安 | どう測るか |
| --- | --- | --- |

## 2. 仕様

### 2-1. 正典の骨子 3 案

3 案とも同じ 7 項目に、2 つの項目を足した（「ラン内の物が消え、遺物が残る理由」と「英語の一文」）。前者は原則 9・10（層の住み分け・拾った瞬間に永続）に物語の理由を与える所で、骨子の出来をいちばん分ける。

#### 甲「写し」— 淵は写す（推奨の芯）

| 項目 | 中身 |
| --- | --- |
| 芯の一文 | 淵は写す。落ちた物を下絵に引き、墨を入れ、写しとして吐き出す |
| なぜ潜るか | **表**: 町は淵から上がる遺物で食べている。石段の先へ降りて持ち帰るのが写し所の務め。**中**: 淵の写しが町へ滲み始めた。下で会う契約者は町衆の写しで、上の本人は淵へ降りたことが無い。**底**: 淵の底で今も写し続けている「最初の写し」を止める |
| 門前町とは | 墨池寺（仮の名）の門前町。寺の写し所は昔、和漢の経と草紙に加えて、長崎から来た南蛮の書も写して売った。百年分の墨を吸った写し所の墨池が底抜けになり、淵になった。町は淵の口に鳥居を立てて塞ぎ、写し所は淵へ降りる者を「元帳」から写し起こす。社・御堂・書庫・記録の蔵は写し所の名残 |
| 章 1〜4 の土地 | **深いほど古い写し**（乙の接ぎ木）。苔の洞 = 近ごろの写し損じ（町の草紙・御伽の挿絵。墨池の溢れが苔になる）/ 地下寺院 = 焼けた写し所の旧い経蔵（経巻・灯明。地蔵は寺の側の飾りで、敵にしない）/ 廃城 = 写された軍記と、禁教の頃に墨で塗り潰して沈めた南蛮の書 / 深みの異界 = 写し所の始まりの頃の紺紙金泥の経と地獄草紙（金の文字の敷石 = 金泥。写しは裏返るので鳥居が逆さに立つ）/ 最深の間 = 墨池の底の硯（砂紋 = 磨り跡、四本の門柱 = 紙を押さえる文鎮、陥没 = 硯の海が朱墨に煮える）/ 深み（22〜）= 紙背、写しの裏に写った写し |
| 敵が和洋混在の理由 | 淵は写し所が写した物を写す。写し所は南蛮の書も写したので、騎士・ゴーレム・ホムンクルスは「挿絵が起きた物」。新しい写しは上に積もり、古い写しは軽くなって浮くので、章は濃淡で混ざる（章 1 に盾騎士が出てよい） |
| 死に戻りの理由 | 主人公は写し所が元帳から写し起こした「写し」。淵で倒れると墨が抜けて反故になり、元帳が残る限り写し所はまた写し起こす。体は毎回新しい（ジョブ = 写しの手本の違い） |
| ラン内の物が消え、遺物が残る理由 | 遺物は拾った瞬間に元帳へ写される（原則 10 の「瞬間」に理由が付く）。祝福・刻印符・銭は淵の中で書き足された物で、反故と一緒に消える |
| 最深の主の正体 | 写し所を開いた写し手が、墨池の底で自分を写した「最初の写し」。以来ずっと淵を写し続けている。第三の顔は、このランであなたが最も手こずった主の写しを写して使う |
| 結末（1.0、L06-16 結願） | **閉じる**: 硯を割り、墨池を涸らす。写しが止まり、町に朝が来る。あなたは最後の写しとして筆を置く（深みは紙背の裏写りとして残るので、ゲームは続く）。**書き継ぐ**: 硯の座に着き、あなたが写し手になる。以後、第三の顔はあなたの最も使った技を写す |
| 英語の一文 | The Abyss copies whatever falls in. You are one of its copies. |
| 明かす順 | 表 = 出撃で白描に墨が入る（L06-04 臨写）・最初の死で墨が抜ける / 中 = 口上の「また写されて来たか」・断簡・契約者と町衆の食い違い（L06-15 町衆）/ 底 = 結願 |

- 強み: 実装済みの写しの仕組みがすべて理の現れになる（下の突き合わせ表で直接 14 / 17）。御堂（`system/bossHall.ts`。倒した主に「今の装備の写し」で挑み直す）は設定がそのまま説明になる
- 弱み: 「写された主人公」はクローンものの型に近い。「写し」の語が既に UI に多い（紋の写し・装備の写し・写し身）ので、正典で使うほど意味が薄まる。主人公の原本が誰かを明かさないと、底が「最初の写し」だけになり弱い（未決の問い 3）

#### 乙「沈殿」— 淵は呑む

| 項目 | 中身 |
| --- | --- |
| 芯の一文 | 淵は呑む。捨てられた書き物は沈んで墨に還り、層を成し、ときどき浮かぶ |
| なぜ潜るか | **表**: 町は淵から浮かぶ物（遺物）で暮らす。浮かぶ物が減り、井戸の水が黒くなったので、降りて取って来る。**中**: 主人公は、自分の名を書いた書付を書塚に沈められた者。名が淵の中にあるので、淵は主人公を呑み切れない。断簡は名の手がかり。**底**: 書塚に最初に埋められた経筒が、沈んだ物すべてを写して吐き出している |
| 門前町とは | 寺の裏山の経塚（平安の埋経）が、いつからか町の書塚になった。町の人は要らない書き物（帳簿・恋文・貸本・禁教で隠した南蛮の書）を供養のつもりで納めた。塚の底が抜けて淵に。鳥居は塚の結界 |
| 章 1〜4 の土地 | 深いほど古い地層。苔の洞 = 近ごろの反故（町の帳簿・貸本の御伽草子）/ 地下寺院 = 戦火で焼けて納められた寺の経 / 廃城 = 戦国の軍記と、禁教で沈めた南蛮本 / 深みの異界 = 平安の埋経と地獄草紙（金の文字 = 埋経の金泥。逆さの鳥居 = 結界が裏返った）/ 最深の間 = 最初の経筒の座 / 深み = 文字より前の墨 |
| 敵が和洋混在の理由 | 南蛮の書は禁書として沈められた。騎士・ゴーレム・ホムンクルス・石化の蜥蜴は沈んだ頁から起きた「異本」。図書館の司書の禁書（`bossLibrarian.ts` 第 2 段階）もこの層に入る。古い物ほど浮かぶので章 1 にも出る |
| 死に戻りの理由 | 墨還り。倒れると墨に溶けて沈むが、名の無い物を淵は沈め切れず、門前町の井戸から浮かべる |
| ラン内の物が消え、遺物が残る理由 | 一度浮かんだ物は二度と沈まない（遺物）。祝福・刻印符は淵の文字で、地上では読めない |
| 最深の主の正体 | 最初の経筒に封じられた守り手。末の世まで経を守る務めのまま、沈んでくる書き物を全部守ろうとして呑み続けた。第三の顔 = 呑んだ物語のうち、あなたを最も沈めかけた主を吐き出す |
| 結末 | **引き上げる**: 経筒を地上へ。淵は満ちて二度と呑まず、町は何も捨てられなくなる。あなたの名は断簡の中の誰かとして戻る。**沈め直す**: 自分の名も経筒に納めて守り手を継ぐ（第三の顔があなたの技を吐く） |
| 英語の一文 | Whatever is thrown away sinks here. Nothing stays down. |

- 弱み: 淵に意志が無く、悪役が立たない。名を失った旅人は型どおりの記憶喪失もの。写しの仕組み（鏡の騎士・第三の顔・影の自分）とは「沈んだ物語が写す」と 1 段間接になる

#### 丙「薄墨」— 淵は名を書く

| 項目 | 中身 |
| --- | --- |
| 芯の一文 | 淵は名を書く。薄墨の名は消せる。濃墨の名は消えない |
| なぜ潜るか | **表**: 寺は町の過去帳を預かる。ある時から、生きている町の者の名が過去帳に薄墨で浮かぶようになった。淵の底で誰かが先に名を書いている。降りて止める。遺物は淵に沈んだ故人の持ち物。**中**: 主人公の名も薄墨で書かれている。断簡は名を書かれた者たちの最期。**底**: 名を書く「書き手」 |
| 門前町とは | 過去帳を預かる寺の門前町。淵は過去帳の墨を磨る硯池だった。渡し守・語り部・灰の公証人（「署名は灰で書く」）は、名の薄い者を見送る町の稼業。寄進は供養 |
| 章 1〜4 の土地 | 名を書かれた者の層。苔の洞 = 行き倒れと獣（名の無い死・御伽）/ 地下寺院 = 焼けた寺と経 / 廃城 = 戦死者（足軽・城の主・海を渡って来た異国の兵）/ 深みの異界 = 六道の挿絵 / 最深の間 = 書き手の座（硯）/ 深み = 名の無い者の底 |
| 敵が和洋混在の理由 | 名を書かれた者は国を問わず流れ着く（南蛮船で来て死んだ兵、異国の書で名を与えられた怪物）。ただしスライム・ゴーレムは「名になり損ねた墨」「異国の墓の石像」と説明が苦しい |
| 死に戻りの理由 | 主人公の名はまだ薄墨で確定していない。淵で倒れても渡れず、石段に戻される（渡し守が乗せない）。敵の予告 = 淵が死を書く: 下絵（薄墨）のうちは斬って消せ、墨入れ（濃墨）は返せ |
| ラン内の物が消え、遺物が残る理由 | 遺物は故人の遺した物。拾えば遺品として寺の帳に記されるので失われない。祝福・刻印符は薄墨の書き込みで、戻れば消える |
| 最深の主の正体 | 名を書く筆そのもの（書き手）。第三の顔 = このランであなたの名を最も濃くした主の筆跡で書く |
| 結末 | **名を消す**: 自分と町の者の薄墨の名を消し、筆を折る。あなたは名の無い者になる。**名を書く**: 自分の名を濃墨で書き、書き手を継ぐ |
| 英語の一文 | Pale ink can be erased. Dark ink cannot. Your name is still pale. |

- 強み: 核の規則「下絵は斬れ、墨は返せ」と死に戻りが **同じ一つの理** になる（3 案で唯一）。「遺物」が字義どおり故人の遺した物になり、盗賊（`runEvents.ts` の盗賊の追跡は床の遺物を狙う）が墓荒らしとして筋が通る。死神・渡し守・銭・L06-12 黄泉膳とも直結する
- 弱み: 冥府から何度も戻る話は Hades と比べられる。過去帳は実在の寺の記録で、六道・浄玻璃の鏡は信仰の図像に近い（配慮の線が最も細い）。草紙地層がそのまま使えず、敵の分類の軸が「どんな死者か」に変わる（2-3 の表を作り直す）。トーンが最も暗い

- **合算の効き**: 元絵 `slime` を密度 2 にすると 6 種の再配色も上がる。`bat` は飛ぶ本・灰蝙蝠・腐肉蝿・影蝙蝠の 4 種、`eye` は呪い眼・氷眼・双眼・雷眼の 4 種、`golem` は 5 種、`bomber` は投網兵・連投・地雷撒きの 3 種を連れて上がる。ただし飛ぶ本（写経所）が蝙蝠の絵の再配色である（`recolor: { base: "bat" }`）ように、**元絵が同じでも草紙が違う種** があるので、描き直しの時に再配色を切り離すかを 1 体ずつ決める
- **配色の規則**: 輪郭は全草紙で同じ墨（1 ドット、閉じた線）、塗りは版 3 つまで（地・陰・差し 1 色）。草紙の違いは塗りの版だけ（G2-03 の改訂どおり。L06-13 の「南蛮 = 輪郭なし」は採らない）。御伽 = 淡彩 / 南蛮 = 陰に 2 ドット間隔の網 / 六道 = 朱を 1 色差す / 写経所 = 紙の地色 / 軍記 = 鉄と藍 / 淵 = 墨の濃淡だけ
- **見本**: 御伽 = 狼、南蛮 = 盾騎士、軍記 = 焙烙足軽の 3 体をユーザーの目で確かめてから次へ

## 7. 未決の問い（ユーザーに聞くこと）

1. **骨子はどれにするか**。推奨は甲 + 乙の接ぎ木（実装済みの写しの仕組みが説明なしで理になるため）。丙を選ぶなら、Hades と比べられることと、過去帳・六道を扱う配慮の線を先に決める
2. **寺の名**。仮に「墨池寺」。正典の固有名詞は寺の名と主の名だけに絞る、でよいか
3. **主人公の原本は誰か**（甲の場合）。推奨は「明かさない。元帳に名が無い写し」。原本を決めると、結末が「原本探し」に引っ張られて写しの理が薄まるため
4. **章名の表記**。階の札を「二の巻　地下寺院」にするか「二　地下寺院」にするか。章 2 を「地下寺院」、章 4 を「深みの異界」に揃えてよいか。推奨は「二の巻」（巻は絵巻の正典と合い、深度の数字と紛れないため）
5. **新語の数え方**。表に出る新語を「草紙」の 1 語と数え、6 つの分類名（淵・御伽・写経所・軍記・南蛮・六道）は数えない、でよいか
6. **沈黙の修道士の扱い**。南蛮に残す（伴天連の挿絵）か、写経所へ移して僧の名にするか。推奨は南蛮に残す（僧を敵にする配慮の判断を増やさないため）
7. **リプレイの口上**。リプレイの再生では選ぶ材料が無いので「初見」の行に落とす、でよいか。記録に持たせるなら記録の形を変えることになる
8. **ゴブリン 3 種の改名**（焙烙足軽・連投足軽・煤玉足軽）と、地雷撒きを「埋火足軽」にするか。推奨はゴブリン 3 種だけ先に変え、地雷撒きは今のまま（埋火は読みが難しいため）
9. **眼の類を御伽に移す**（L06-13 からの変更）でよいか。推奨は移す（最初の 30 秒に写る顔を和で始めるため）
10. **深みの告知の文**（「更なる深みへ……。深淵が汝の力を解放する」）を正典の文体に直すのは、断簡の段まで待ってよいか
11. **文の決定稿の範囲**。正典・口上・断簡・謎掛けは「エージェントが下書き、ユーザーが決定稿」でよいか（Steam の AI 生成コンテンツの申告の範囲がこれで決まる）

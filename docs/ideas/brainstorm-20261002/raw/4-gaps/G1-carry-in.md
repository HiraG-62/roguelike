## 0. 見立て

- 3 つの前提がぶつかっているのは「何本持って入れるか」ではない。**緊張を何から作るか** で食い違っている。(a) は失う怖さ（袋が消える）から、(b) は応じられる自由（いつでも倉庫から替えられる）から、(c) は失わない約束から作る。(a) の「消える」と (c) は正面から矛盾する。(a) の「2 部位」と (b) は数の上で矛盾する
- ただし (a) の芯は「消える」ではない。memo 0928 の原文は「倉庫から持ち込める装備は 2 部位まで。**残りはラン内で拾った装備で埋める**」で、狙いは「全部持ち込めるので新鮮さが無い」（S7）。「消える」と「荷車」は芯を支える手段として後から付いた物
- (b) の芯も「400 の全部から何本でも」ではないと読む。2026-10-01 にユーザーが退けたのは A-moment の「ラン中は持ち込んだ 6 つと拾い物だけ・判断は階の切れ目の踊り場で」で、退けたのは **いつ替えるかを縛ること** と読める（要確認。7 章の問い 1）
- そこで、失う怖さの代わりに **倉に手を伸ばせる回数の少なさ** を緊張の源にする。倉庫は見えていて、いつでも手を伸ばせる。ただし 1 回の探索で倉から手に取れるのは 2 本まで。残りの 4 部位は道中の物で埋めるしかない。拾った物は拾った瞬間に倉に入る。何も消えない
- 事実の確認: ラン中の付け替えは今も `loadoutDirty` → `captureLoadout` で装備の写しが記録に乗っている。HANDOFF 5 章で却下された「倉庫の遺物の呼び出し」は step の中で倉の物を床に出す仕組みで、メニューから着替える経路とは別物。**倉から手に取る回数を数えるのは UI の仕事で、step は数を読まない**。だから回数を絞っても決定性には触れない

- ラン中の装束の候補は「袋と持ち込み 2」だけ。倉庫 400 は拠点でしか見えない

- **失う物の見え方**: はっきり見える。持ち帰り画面で選ばなかった物が墨に溶けて消える。死ぬ前から「袋 n・持ち帰り m」で分かる

### B 蔵出（Open Vault）: (a) を撤回する。(b) と (c) を保ち、新鮮さはビルドの規則で作る

- 強み: 最新の決定（10-01）を一字も崩さない。コードの変更が最も小さい

### C 取寄（Requisition）: (a) の芯と (b) の「いつでも」と (c) を保ち、袋・持ち帰り・荷車・「消える」を畳む
- 1 回の探索で、倉庫の遺物を身に着けられるのは **2 本まで**。出発のときに着て出た倉の物も 1 本に数える。残りの取寄はラン中いつでも使える（交戦の外。下の飛脚を採るなら「次の階の頭に届く」）

- **拾う判断の場所**: (1) 開いた 4 部位を道中の物で埋める判断。毎階に起こる。(2) 取寄を今使うか、道中の当たりを待つか。祝福で燃焼に傾いたら倉の燃焼の指輪を呼ぶか、指輪が落ちるのを待つか。(3) 市での下取（周辺案）
- **失う物の見え方**: 何も失わない。残りの取寄は装束の右上に札 2 枚で見える。倉の候補には封の印が付いていて、試着すれば紋の写しは今のまま動く（E の ▲▼）。そのため払う前に何が起きるかが分かる
- 強み: 判断が戦いの中（毎階の拾い物）と、ランの中ほど（取寄の時機）にある。信念を曲げない。今の記録の経路をそのまま使える
- 弱み: 9-28 の決定 2（消える）と 4（荷車）を畳むので、memo の「持ち帰りの枠を施設で増やしたい」が消える。終わりの山場（何を持ち帰るか）が無くなる

## 2. 推奨: C 取寄

採る理由（1 文）: 信念 10 を曲げず、(b) の「いつでも」を残したまま、memo の芯である「残りは道中で埋める」を毎階の判断として実現できる。この 3 つを満たすのは C だけ。

- A の「失う怖さ」は強いが、その判断はランの終わりのメニューで 1 回だけ起き、プレイ中の手には返らない。C の判断は毎階の拾い物と、ランの中ほどの取寄の時機にある。「要素の量よりランの流れと判断の場面」というユーザーの方針に近いのは C
- B は今のままでいられるが、ユーザーが最初に挙げた診断を退ける。退ける根拠（地金が深度に追従するので数値の雪だるまは止まった）は、新鮮さの問いには答えていない
- C で消える物（持ち帰りの山場・荷車の進行）は、周辺案の荷解と預札で別の形にして返す。消えない物（来歴・芽・残響・誂え・伝世・看取・仇）は、どれも C の方が噛み合いがよい（表を参照）

## 3. 案（推しの順）

### 取寄（とりよせ / Requisition）
- 種別: 改善（run-arc 2 章の作り直し）
- 領域: run
- 一言: 1 回の探索で倉の遺物に手を伸ばせるのは 2 本まで。いつでも伸ばせる。残りの部位は道中の物で埋める
- 仕組み:
  - 井戸の支度の最後に「取寄 2」の札。拠点で着ていた 6 部位のうち、着て出る物に印を付ける（0〜2 本。前回の 2 本が既定）。印の無い部位は空で出る。右手が空ならジョブの初期武器（借り物）
  - ラン中の装束では、倉の候補に封の印が付く。試着すれば紋の写しは今のまま動く。決定を 2 回押すと取寄（砕くと同じ 2 段の確定）で、札が 1 枚墨に沈む。取寄した物は、その探索のあいだ自由に脱ぎ着できる
  - 取寄は交戦の外（陣の交戦中・封鎖中・主の間ではない時）でだけ使える。飛脚を採るなら届くのは次の階の頭
  - 道中で手に入れた物は数えない。拾った瞬間に倉に入る（原則 10）。次の探索ではそれも倉の物になる
  - 序盤の空き部位は run-arc 2-3 のドロップの戻し（深度 1〜2 の落ち率と、1 階で 1 本の確定）で埋める。数値は `CARRY.json`（`requisitions: 2`）と `LOOT_DROP` に置く
  - ラン中の鍛冶は「この探索で手に取った物」どうしに限る。ラン中は倉の上限で拾いを止めない
  - 決定性: 取寄の数は UI（`src/ui/` の装束）が守り、step は読まない。記録は今の `captureLoadout` の写しのまま。版の上げは序盤のドロップ率の変更による 1 回
- なぜこのゲームで:
  - 段取り 7d で「地金は今の深度で決め直し、性質は拾った深度で固定」に分けてあるので、地下 14 階で取寄した物も体の数値は 14 階の物になる。遅く呼んでも時代遅れにならず、早く呼んでも数値で序盤が壊れにくい。だから「いつ使うか」が純粋に方向の判断になる。地金が拾った深度で固定の他作では、取寄はただの救済か壊れのどちらかになる
  - 来歴 → 芽 → 銘の物語は、着ないと進まない。取寄 2 本が「どの物語をこの探索で進めるか」の選択になる。伝世（L05-15）の家の品を連れ出すことに重みが付く
  - 装束の試着（紋の ▲▼）がそのまま「払う前に見る」道具になる。新しい画面は要らない
  - 根付（L03-02）が段 3 を札に、取寄が 4 部位を道中に寄せる。2 つ合わせて「土台は倉、上はラン」の住み分け（原則 9）が装備の側でも成り立つ
- 着想元: Hades の形見（1 つだけ、区画の境で替えられる）と、Hades 2 の秘儀の器（器量の上限）。PoE の倉庫は全部が使える。変えた点: 形見は効果が小さくて固定。ここでは倉の全部が候補で、手を伸ばせる回数だけを絞った。器量のように重さを数で持たせない（遺物ごとの重さは事実上のアイテムスコアになり、原則 8 に反する）
- 安っぽくならないための要点 / リスク:
  - 取寄を「回数のゲージ」に見せない。札 2 枚の絵で、数字は出さない
  - 出発で 2 本とも使う人が大半になったら、中ほどの判断は死ぬ。それでも「残り 4 部位は道中」の芯は残る。中ほどの判断は飛脚・預札で後押しし、bot と人の記録で使う時刻を数える
  - 序盤の死にやすさ。深度 1〜3 の死が今の最多（S4）。ドロップの戻しで足りないなら、1 階の宝物庫の確定を足す（数値の上乗せでなく、置き方で）
  - 9-28 の決定 2・4 を畳むので、ユーザーの承認が先（問い 1）
- 測り方: bot（方策 2 通りで到達・鮮度・素手との差）。人が取寄を使う時刻は記録の装備の事象から数える
- 規模: L

### 飛脚（ひきゃく / Courier）
- 種別: 拡張（取寄の届き方）
- 領域: run
- 一言: 取寄は頼んだ瞬間には届かない。次の階に降りた頭で、飛脚が階段の脇で手渡す
- 仕組み:
  - ラン中の取寄は「注文」になり、札に小さな飛脚の印が付く。届くのは次の階の到着（`floor` の遷移）の直後で、main.ts が装備に当てて `loadoutDirty` を立てる。記録はその瞬間の装備の写しになる
  - 注文は交戦中でも出せる。ただし届くのは次の階。ボスの前で慌てて呼んでも、その戦いには間に合わない
  - 階段の上の出口の予告と同じ並びで、頼んだ物の絵が小さく出る（「次の階で受け取る」）
  - 到着の 0.5 秒、飛脚が包みを置いて去る。拠点の町衆（L06-15 の渡し守）と同じ顔にできる
- なぜこのゲームで: メニュー中はゲームが止まる（E-merged）。即時の取寄は「止めて呼ぶ」になり、ボス戦の途中で守りの物を差し込む逃げ道になる。届くのを次の階にすれば、取寄は出口の予告（どの報酬の階へ降りるか）と同じ時間軸の判断になる。注文は記録の外の UI で、受け取りが階の遷移なので決定性に触れない
- 着想元: 時代劇の飛脚、Darkest Dungeon の出発前の補給。変えた点: 補給を出発前でなく道中に置き、受け取りを階の境に固定した
- 安っぽくならないための要点 / リスク: 演出を長くしない（0.5 秒、入力は止めない）。届く前に死んだ注文は、取寄の札が戻る（何も失わない）
- 測り方: 人のリプレイ（注文の階と、届いた次の階の結果）
- 規模: S

### 下取（したどり / Trade-in）
- 種別: 拡張（座組 L10-08 の市座の「売る」）
- 領域: run
- 一言: 道中で拾った遺物を、市でその場の銭に替えられる。倉に残すか、このランの力に替えるか
- 仕組み:
  - 市座（または今の市）の台座で、この探索で拾った遺物を 1 本差し出すと、深度に応じた銭（`MARKET.tradeInByDepth`）になる。差し出した物は倉から出る（自分で選んで手放すので、失わせることにはならない）
  - 取寄した倉の物は差し出せない（倉の 400 を換金する稼ぎ口にしない）
  - 下取で得た銭は、その市の遺物・瓶・祝福の購入にだけ使える「下取の札」ではなく、普通の銭になる（帳簿を増やさない）
- なぜこのゲームで: C では道中の物は全部永続になるので、拾う判断が「着るかどうか」だけに細る。下取は、着ない拾い物に「倉の思い出」か「このランの瓶 1 本」かの判断を与える。市の 7 割で何も売れていない（S4）問題に、売る側から効く。座組の市座が「買う・売る」を名乗りながら、売る中身が無かった所を埋める
- 着想元: PoE の売り（店に投げて通貨にする）、Diablo の売却。変えた点: 店に投げるのは作業の後始末ではなく、ラン内の力と倉の物語の交換。下取できるのはこの探索の拾い物だけにした
- 安っぽくならないための要点 / リスク: 下取の額を高くしすぎると「拾って全部売る」作業になる。額は市の最安の瓶 1 本前後が目安。名のある遺物は額を上げない（固有の物を換金の的にしない）
- 測り方: 人のリプレイ（下取した物と、その後に買った物）。bot は市を使わないので測れない
- 規模: S

### 初物（はつもの / First Fruits）
- 種別: 拡張（根付 L03-02）
- 領域: build
- 一言: その探索で手に入れた遺物も、共鳴の段 3 の朱枠を埋められる
- 仕組み:
  - 根付の規則「段 3 の朱枠はラン内で得た源か糧だけが埋める」の「ラン内」に、その探索で手に入れた遺物（拾い物・市・仇討ち・誂え）を足す。取寄した倉の物は今のまま埋められない
  - 紋の珠のうち初物の珠は、縁に朱を一筆引いて描く（数も文字も出さない）
  - 判定は来由（L15-04）か、`foundAt` と出発の時刻の比較
- なぜこのゲームで: 根付は「上は潜って埋める」を札だけで担うが、札は祝福の出口を選んだ階でしか出ない（3 択 2.98 枚 / ラン）。初物があれば、遺物を拾う瞬間が「朱枠に届くか」の判断になる。C では開いた 4 部位の判断を濃くし、B では B の唯一の新鮮さの源になる。L10-10 共鳴選別の「段 3 にはラン内で選んだ物が要る」とも矛盾しない（着ることが選ぶこと）
- 着想元: 初物を神に供える習わし（その年に初めて採れた物に力がある）。Slay the Spire の「そのランで取ったカードだけで組む」。変えた点: 倉の物を否定せず、上の 1 段だけを初物の席にした
- 安っぽくならないための要点 / リスク: 倍（×1.15 / 段）は据え置き。初物の朱が紋の上で目立ちすぎると、帯の読みを邪魔する（E の色の予算: 段の色 4 + 墨 + 白金）。朱の一筆は細く
- 測り方: bot（段 3 の出どころの内訳と、狙う系統の共鳴の分布）
- 規模: S（根付の上に乗る）

### 預札（あずけふだ / Pawned Writ）
- 種別: 拡張（質屋・質札 L04-14）
- 領域: run
- 一言: 使っていない取寄の札を質屋に預けて銭を借りる。同じ章のうちに請け出せば札が戻る
- 仕組み:
  - 質屋の質草を 2 種にする。祝福の札 1 枚（質札 L04-14）と、取寄の札 1 枚（預札）
  - 取寄の札を預けると銭が入り、札は質屋の帳場に掛かる。同じ章の市で同じ額を払えば請け出せる。章ボスの主の間に入った時点で流れる（その探索はその札が使えないだけ）
  - 預けた札は、装束の札の絵に質屋の判が押されて見える
- なぜこのゲームで: 質屋は「持ち込んだ遺物を預ける＝永続の物を失う」で保留されていた（economy-core 11 章）。預札は物を預けず、権利を預ける。失うのは「この探索でもう 1 本倉に手を伸ばせる」選択肢だけなので、信念 10 に触れずに質屋を建てられる。取寄を「出発で全部使う」より「持っておく」理由にもなる（後で預けられるから）
- 着想元: 質屋と手形の質入れ、Spelunky の店の借り。変えた点: 質草を物でなく「倉に手を伸ばす権利」にした
- 安っぽくならないための要点 / リスク: 利子を取らない（帳簿は判断でない。L04-14 と同じ）。額は祝福の札より低い（祝福は戦い方が 1 つ消える痛み、取寄は可能性が 1 つ消える痛み）
- 測り方: 人のリプレイ
- 規模: S（質屋が建つ段に相乗り）

### 荷解（にほどき / Unpacking）
- 種別: 改善（持ち帰り画面の代わり）
- 領域: ux
- 一言: 拠点に戻ると、その探索で手に入れた物が荷として井戸の脇に並び、1 本ずつ「納める・砕く・注ぐ」を決める
- 仕組み:
  - 死亡・踏破の後、拠点に着いた最初の画面で、荷（その探索の拾い物）を 5 本ずつ並べる（E の候補の部品を流用）。焦点ごとに 3 つの動詞: 納める（何もしない。倉に置く）/ 砕く（残響に）/ 注ぐ（来歴の半分を同じ部位の倉の物へ。既存の操作）
  - 既定は全部「納める」。Esc で飛ばせる。何も消えない
  - 倉庫が 400 を超えていたら、荷解の画面が先に開く（ラン中は上限で拾いを止めないので、溢れはここで捌く）
  - 荷車の建物（建てるなら）を荷解の場にする。段階も費用も持たない
- なぜこのゲームで: A の持ち帰り画面が持っていた「探索の終わりに拾い物を振り返る」山場を、失わせずに残す。注ぎがあるので、取寄に選ばれなかった拾い物の来歴も、家の品の物語に流し込める（「この刀は 37 回目の探索で拾った短刀の来歴を継いでいる」）。倉庫 400 の肥大（並べ替え 8 軸を捨てた E の「正直な損」）を、入口で細くする
- 着想元: A-moment の「入口で細らせる」発想（持ち帰りで選り分ける）、PoE のリーグ終わりの倉庫整理。変えた点: 選り分けを強制せず、既定は全部残す。整理は注ぐという物語の動詞でする
- 安っぽくならないための要点 / リスク: 毎回の作業にしない（既定は全部納めるで、1 キーで抜けられる）。数値の比較を出さない（E の候補と同じ荷札 2 行）
- 測り方: どちらでも測れない（UX）。倉庫の件数の推移を保存データから数える
- 規模: M

### 鮮度（せんど / Freshness）— 開発側の計測だけ。UI に出さない
- 種別: 基盤
- 領域: platform
- 一言: 「ランごとの新鮮さ」を QA の数字にする。死んだ時に働いていた性質と源のうち、その探索で手に入れた物から来た割合と、前のランとの重なり
- 仕組み:
  - `src/qa/` の集計に 2 つの指標を足す。(1) 初物率: 死亡・踏破の時点で装備に乗っている性質・源のうち、その探索で手に入れた遺物から来た割合。(2) 重なり: 連続する 2 ランで働いていた性質の key の集合の重なり（Jaccard）
  - `report.md` に深度ごとに出す。目標の目安（初物率は章 1 末で 0.5 以上、章 4 で 0.6 以上、重なりは 0.4 以下）は JSON に置く
  - UI には出さない（原則 8。単一の指標をプレイヤーに見せない）
- なぜこのゲームで: ユーザーの診断「新鮮さが無い」を、A / B / C のどれを採っても同じ物差しで測れる。取寄の方策（出発で 2 本 / 待つ）を bot で比べる土台になる。L01-01 読み手・L09-14 初動計と同じ「bot に物差しを持たせる」系列
- 着想元: PoE のリーグ開始の多様性の統計（ビルドの使用率）。変えた点: ビルドの種類でなく、「そのランで手に入れた物が働いている割合」を測る
- 安っぽくならないための要点 / リスク: bot は装備を替えない（`src/qa/bot.ts`）。取寄と拾い物を着る簡単な方策（空き部位に着る・同じ部位なら新しい物）を bot に足さないと、初物率は 0 のまま
- 測り方: bot そのもの
- 規模: S

## 5. 捨てた案と理由

| 案 | 中身 | 捨てた理由 |
| --- | --- | --- |
| 器量 | 遺物ごとに重さを持たせ、探索の器量の上限まで倉の物を着られる（Hades 2・Rogue Legacy 2） | 遺物ごとの重さが事実上のアイテムスコアになる（原則 8）。数の上の詰め合わせパズルになる |
| 殻だけ | 取寄の外の倉の物も着られるが、地金だけが効き性質は眠る | 400 から地金の最良を選べるので、道中の物の地金が常に負ける。「残りは道中で埋める」が数値の側から崩れる |
| 伏せて芽で開く | 持ち込み以外の倉の物は性質が伏せられ、ラン内の来歴の節目で開く | 毎探索の同じ解放の作業になる。来歴の節目の意味（物語）を鍵開けに貶める |
| 帳写し | 拾った物は永続だが、ラン中に使えるのは帳に写した物だけで、写す枠が持ち帰り枠 | 道中の物を使える数を絞るので、新鮮さの源を自分で細くする。取寄と逆向き |
| 銘だけ持ち込み | 持ち込めるのは銘のある遺物 2 本だけ | 最初の数時間は銘が無く、持ち込み 0 と同じになる。新規の人に厳しく、熟練者には効かない |
| 来歴昇格 | 来歴を積んだ物だけが永続に昇格する | 引揚の言い換え。拾った瞬間の永続を曲げる |
| 縛り 19 を既定 | 持ち込みなしを既定にし、位階で持ち込みを開く | 永続装備の約束（遺物を集める理由）を最初の数時間に見せられない。縛りのまま残す |
| 宿替 | 休符の階で取寄の 1 本を返して別の物を呼べる | 1 探索で倉の物が 3〜4 本になる。固定 2 に反する |
| 目録 | 出発の前に「呼べる候補 6 本」を選んでおき、ラン中はそこからだけ取寄 | 支度の段が 1 つ増える。E の候補 5 枚・並び「合」で、ラン中の 400 はすでに細っている |
| 取寄を鍵で買う | 鍵 1 本で取寄 +1（治安「鍵で払う」の流れ） | 持ち込み枠を増やす設備と同じ。新鮮さの源を売り物にする |
| 季の倉 | PoE のリーグのように期間で倉を分け、新しい季は空の倉から | 失わせないに反する。個人開発で運用できない |
| 仇に取られる | 死ぬと取寄の物を仇が奪い、討てば取り返す | 装備を賭ける（却下済み）の変形。奪銘 L15-05 は名と姿だけなので別物 |
| 疲れ | 続けて取寄した物は効きが落ちる | 罰と数値。同じ 2 本を選ぶ人を罰しても新鮮さは生まれない |
| 識別 | 道中の遺物は性質が伏せられ、着て戦うと分かる | PoE の識別は作業。E の試着の比べ方と食い違う |
| 深みだけ持帰 | 章は原則 10、深みだけ袋と持ち帰り（L13 批評の住み分け） | 2 つの規則が 1 本のランに並ぶ。L13 が関所で稼ぎを閉じたので理由が無い |
| 荷車を残響の器に | 荷車の段階で残響の上限が増える | 数値の上乗せ。荷車を残すための理由づけ |

## 6. ユーザーに聞くこと

1. **袋をどうするか（各レーンの問いを 1 つに束ねた物。L05-15 伝世の「持ち込み 2 の時期と家の品」、L13 批評の「場所で住み分けるか」、L13-04 古物封じの「決定と同時に見る」、L03-02 根付の「入る世界と入らない世界」、L10-03 棚卸の「撤退の扉」）**: 10-01 の「ラン中も倉庫から付け替えられる」で守りたかったのは「いつでも替えられる」ことか、「400 の全部から何本でも」か。推奨: 前者と読み、C 取寄（倉から手に取れるのは 1 探索 2 本・いつでも・拾った物は瞬間に永続）を採り、9-28 の決定 2（消える）・4（荷車）と袋・持ち帰り・撤退を畳む。後者なら B 蔵出（初物で新鮮さを足す）。失う怖さそのものが欲しかったなら A 持帰
2. **荷車**: C では持ち帰りの段階制が要らない。荷車は建てない（推奨。建物の数を増やさない）か、荷解の場として段階なしで建てるか
3. **取寄の届き方**: 次の階の頭に届く飛脚（推奨。止めて呼ぶ逃げ道を断ち、出口の予告と同じ時間軸の判断になる）か、交戦の外ならその場で着られるか

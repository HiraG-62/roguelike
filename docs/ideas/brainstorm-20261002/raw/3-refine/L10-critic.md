# L10 辛口の批評（整理と削減）改訂版

視点は変えない。「足す」より「束ねる・削る・磨く」。物差しは、発売前に要素を削った名作（Hades の早期アクセス中の祝福の入れ替え、Dead Cells の変異の削減、Into the Breach の「全部見せて要素を絞る」）と、Steam の低評価の典型（「何で死んだか分からない」「用語と UI が多すぎて最初の 1 時間で返金」「選ぶ物が多いのに正解が 1 つ」「同じ物が名前を変えて何度も出る」）。

批評（ローグライク古参 × 所有感と自分だけの物語）を受けて変えた大筋は 4 つ。

1. **削る根拠を bot の数字だけにしない**。人のリプレイで使用率を数える道具を、削減より先に作る（遡及審査に入れた）
2. **戦闘の 3 案は 1 つの束**として順番に入れ、1 段ずつ測る（間際に束ねた）
3. **削減は発売前の 1 段に集め、`REPLAY_VERSION` を 1 回だけ上げる**。保存・リプレイ・永続の銘が割れるのは今だけで済む（棚卸を新設）
4. **削った後に「ランを語らせる」物を同じ段で 1 つ入れる**。整理だけだとランが綺麗になり、無個性になる（墓誌・宿怨を取り込んだ）

追加で確かめたもの: `core/replay.ts` の `REPLAY_VERSION = 35` と結果欄の `score`、`system/nemesis.ts`（仇は修飾子 +1 を 1 回出すだけ）、`system/hazards.ts` の `friendlyBlastMul`（敵の爆発は敵にも当たる。承認済み E30 の一部が実装済み）、`data/actionText.ts` の `secondWave: "後詰"`、GLOSSARY の「芽」（節目の 2 択、選ばなかった方は消える）と「帰還（節目）」、スキル名「巻き戻し」と `player.ts` の「溜め直し」（どちらも使用中なので新しい語に使わない）、`DESIGN_PRINCIPLES.md` 原則 4（「カウンターヒット（怯み値 ×2）」）と原則 13（「部屋ロック → 全滅 → 解放」）が今の作りより古いこと。

## この視点から見た今のゲームの課題

1. **同じ役の仕組みが名前を変えて 2〜3 重にある**。時間の圧（死神・長居の代償・陣の歩き出し）、自分に課す条件（縛り・誓約・公証人の契約・腕の賭け）、店と手入れ役（10 の売り手）、振ると溜まる資源（気力・奥義ゲージ）
2. **読みの報酬が、読まなくても出ている**。カウンターは予備動作の全区間で成立し、bot が 1 分に 50〜95 回出す。そのたびにヒットストップが +2 され、世界が 2〜3 割止まる。「黄なら殴れ、赤なら受け流せ」が数字の上では「とにかく殴れ」
3. **受け流しが万能で、他の答えを食っている**。見切りはほぼ 0 回、割り込みの手段 9 つに序列が無い
4. **ラン内に数値盛りが残る**。祝福の格（×1.5〜×3.4）、流儀の「見切りでダメージ +%」、選ばなくても立つ汎用の共鳴
5. **用語の層（約 40）が整理されないまま増え、衝突している**。延焼の二重、部屋の時代の語の残骸。しかも **永続の銘** と **リプレイの結果欄** にまで古い語と数字が入り込んでいる
6. **削る根拠が bot の数字に偏っている**（ここは批評で自分の側の弱点として認めた）。鍵 908 本中 4 本・市の 70%・賭け 0.1 回 / ラン・状態 8 種 0 件は、bot が寄り道しない・賭けない・付け元を選ばない写しでもある。「珍しい」と「死んでいる」を分ける物差しが無い
7. **階の顔が立たない**。契約者・旅商人・隠し部屋・追加の部屋・ランイベントが互いに独立して抽選され、「この階は何の階か」が言えない
8. **ランの結末を語る物が数字しかない**。死亡画面・探索履歴・リプレイの結果がスコア・撃破・コンボ。仇は 1 回の顔見せで終わり、銘は定型の部品の組み合わせ

### 一階一題
- 種別: 整理・削減
- 領域: run
- 一言: 契約者・旅商人・追加の部屋・ランイベントを 1 階に 1 つの「題」にまとめ、出口の予告の 3 行目に載せる
- 仕組み:
  - 今は契約者 40%・旅商人 50%・隠し部屋 20%・追加の部屋（1 階 0.05〜0.26 個）・ランイベント 28 を別々に抽選している。通常の階は、このうち **1 つだけ** を題に持つ: 賭場・鍛冶・試練・巣・伏兵・霧・潮・契約・旅商人・ランイベントの 1 つ、など
  - 題は **出口の予告の 3 行目**（報酬・行き先・題）に、字 2 つ + 小さな絵の札で出る。分岐が「何を得るか」に加えて「どんな階を通るか」の選択になる
  - 題が 1 つしか無い分、題の中身を厚くする（題「賭場」なら台座が 3 つ、題「試練」なら目的のある波）
  - **型との相性を題に乗せる**（批評から）。題「巣」は浮く敵が多い、題「伏兵」は背後からの突進が多い、など。大剣で浮遊眼に 90 秒かかるような相性は均さずに残し、出口の予告で見せて **武器で道を選ぶ** 判断にする
  - 市（座組の市座）と階の主は全階に残る定番。休符・ボス階は今のまま。章ごとに題の候補を偏らせ、章の顔にもする
- なぜこのゲームで: 出口の予告はこのゲームの判断の要。陣形と敵の役割（`data/enemyRoles`）が既に階の中身を決めているので、題は新しい生成器ではなく **既存の抽選を 1 本の札に束ねる** 作業で済む。encounter-core 8-2「定番 + 章の顔」の延長
- 着想元: Hades の扉のアイコン（次の部屋の種類が見える）。Hades は報酬だけを見せるが、ここでは報酬と別の行に「階の出来事」を見せる。Slay the Spire の地図の「？」は伏せるが、ここでは開いて選ばせる
- 安っぽくならないための要点 / リスク: 題が読めないと 3 行目がただの文字列になる。解放制（`meta/unlocks.ts`）で初見の題を絞る。相性の題が「この武器では入るな」の看板にならないよう、題の相性は「遅いが届く」幅に収める（撃破不能の組は別途、不具合として直す）。ランイベントの「部屋」の語はこのとき陣の語へ書き直す
- 規模: L
- 議論で変わった点: 型との相性を題に乗せ、旧案「間合補完」の大半（相性を均す）をここへ吸収して「相性で道を選ぶ」側に倒した

### 間際
- 種別: 改善
- 領域: combat
- 一言: カウンターを予備動作の最後の一瞬に絞り、報酬を倍率から「出鼻挫き」へ替え、停止と奥義の溜まり方を 3 段で順に直す
- 仕組み:
  - **段 1 間際**: `isCounterable` の窓を、予備動作の **終わりの 25%（下限 0.12 秒）** に絞る。予備動作の前半に当てた命中は **割り込み**（怯み値は普通に溜まる。ダメージ・気力の倍もヒットストップの加算も無い。予備動作中の敵は強靭 ×1.3）
    - 間際の報酬は **ダメージ倍率を持たない**（批評から）。代わりに **出鼻挫き**: 敵の予備動作を頭へ戻し、もう一度溜め直させる（怯みではないので堅守は付かない）。気力 ×2 とヒットストップ +2 は間際だけに残す。同じ敵に 2 回まで、3 回目は戻らずに出る
    - これで間際は「欲張って後隙に本命を貰う」罰ではなく「本命を出させない」読みになる
    - 窓は予告の線が「張る」（細く震えて墨がにじむ）見た目と短い弦の音で示し、色は黄のまま
  - **段 2 停止配分**: 直近 1 秒の停止の合計に上限（目安 9 ステップ = 15%）を置き、処刑・殲滅 > 終撃・怯ませ・壁叩きつけ > 間際 > 会心 > 通常の順に配る。重い瞬間は最低 3 ステップを保証（同じ 0.2 秒に 1 回まで）。予算は state に持ち決定的に減る。設定の 0〜2 倍は予算にも掛ける。この優先度の表を **重さの辞書** として 1 か所に置き、墓誌の「最も重い瞬間」にも引かせる
  - **段 3 功名**: 奥義ゲージの `perSwingSec` を 0（または 1 割）にし、功（受け流しの成功・見切り・間際・背面・壁叩きつけ・処刑・陣の大将の撃破・陣の敗走）だけで溜める。**型ごとの重みの表**（型 15 行）を置き、戦意を満たした状態の功は 1、満たしていない状態は 0.5。盾は受けの重みを下げ、書・手鈴は型の放出を功に数える。「功」の語は表示に出さず、溜まる音だけで分ける
  - 順番: 段 1 → probe（「狙う bot」と「狙わない bot」の 2 本。狙わない bot のカウンターが 60 秒に 10 回以下、完遂率 50〜70%）→ 段 2 → 段 3。1 段ずつ測る
- なぜこのゲームで: 原則 4「予備動作は攻めの合図でもある」の本来の意図に戻す。黄 / 赤の 2 段の予告に、色も UI も足さずに 3 段目の読み（黄の頭 = 割り込み、黄の終わり = 間際、赤 = 受け流し / 躱し）が生まれる。気力 = 押す資源 / 奥義 = 読む資源と分けることで、S1 の問い 6「2 本は必要か」に答え、奥義が章ボスの段階の変わり目（ランの山場）に集まる
- 着想元: 格闘ゲームのカウンターヒットと、Sekiro の弾き（体幹を削るのではなく、相手の攻めを終わらせる）。格ゲーのように専用入力は作らず当て時だけで分け、Sekiro の「弾きが全部」にせず間際は攻めの側の読みにした。停止配分はコンボ補正を停止の時間に当てたもの。功名は Devil May Cry の魔人化ゲージから「多彩さの評価」を抜き、読みの成功だけにした（評価の段は出さない、原則 8）
- 安っぽくならないための要点 / リスク: 窓が狭すぎると連打の気持ちよさが消えるので、割り込みでも怯み値は溜める。出鼻挫きは戦闘を長引かせるので、完遂率と 1 戦の秒を両方測る。**反論**: 批評の「入力遅延の補正値を設定に持つ」は採らない。設定で判定が変わるとデイリーとリプレイの比較が割れる。遅延は判定ではなく見た目で吸収し、「張り」を窓の 2 フレーム前から出す。功名は読みが苦手な人の奥義を奪うので、戦果（大将・敗走・処刑）を功に必ず含める
- 規模: L
- 議論で変わった点: 間際・停止配分・功名を 1 つの束にして順番を決め、間際の報酬を倍率から出鼻挫きへ、功名に型の重みの表を足した

### 棚卸
- 種別: 基盤
- 領域: platform
- 一言: 名前の衝突・スコア・部屋の時代の語・古い原則の文を、発売前の 1 段でまとめて洗い、`REPLAY_VERSION` を 1 回だけ上げる
- 仕組み:
  - 保存とリプレイと永続の銘を割る整理を、この 1 段に集める。発売後に同じことをすると、プレイヤーのリプレイと遺物の銘が壊れる
  - **名寄せ**（旧案を吸収）: 延焼（祝福 / 名のある連鎖）、流星群 / 流れ星、崩勢 / 崩落、堅守 / 硬化、怒気 / 激昂、鍛冶 / 鍛冶屋 / 鍛冶場、武器をまたいだ同名の技、章 2 の名、「深みの異界」と「深み」、「系」の字の重なり。**銘の部品を最優先**（批評から）: 来歴の節目「部屋制圧」（`loot/provenance.ts`）、銘の部品「封鎖を破る / 破城」（`loot/names.ts`）、語り部の「制圧が来歴に 2 回」。銘は永続の文字列なので、刻まれた後では直せない
  - **表示名の一意性の検査**を `audit:docs` に足す（祝福・性質・スキル・奥義・状態・反応・ランイベント・部屋・契約者・精鋭・浮き文字・世界観語）。ブレストで出る新しい名前（例: 旧案の「後詰」は陣の第 2 波と衝突していた）もこれで落ちる
  - **スコアを下ろす**（旧「死物整理」を吸収）: HUD の右上・死亡画面・探索履歴の行（`render/titleUi.ts`）・中央の「x1.2」（`comboMultiplier`）・`state.score`・`meta.bestScore`・**リプレイの結果欄の `score`**（`core/replay.ts`）。依頼・実績の条件に使っていないかを先に確かめる（`questHud.ts`）。空いた席は墓誌が埋める
  - **上り階段（帰還）は生成だけ止める**（批評を採用）。コードと来歴の節目 `returns` は残し、持ち込みと袋の段で「撤退の扉」として作り直す
  - **原則の文を今の作りに合わせる**: 原則 4（怯み値 ×2 → 間際と割り込み）、原則 13（部屋ロック → 陣の決着）。物差しが古いとレビューが古い文で差し戻す
  - 状態異常の並び（`STATUS_KINDS` の添字、異常整理）もこの段で一緒に動かす
- なぜこのゲームで: このゲームは決定性とリプレイと「拾った装備は瞬間に永続」を同時に持つので、整理のたびに 3 つが割れる。量産の速度（10 日で 650 コミット）のまま発売すると、割れる回数が発売後に移る。GLOSSARY の「既存の名前と衝突させない」は人の注意に頼っていて、すでに破れている
- 着想元: 大きな MMO のローカライズでの用語の一意性の検査（元の言語の側で掛ける）。発売前の「コンテンツ凍結」を、要素ではなく **語と形式** の凍結として行う
- 安っぽくならないための要点 / リスク: 名前を変えるだけで要素を減らさない言い訳にしない。異常整理・座組と同じ段で行い、消える名前は直さない。段が大きくなりすぎるので、検査の追加 → 銘の部品 → スコア → 原則の文の順に小さく切り、版上げは最後に 1 回
- 規模: L
- 議論で変わった点: 新設。名寄せと死物整理を吸収し、批評の「削減は発売前の 1 段に集める」「原則の文が古い」を段取りにした。帰還は削除から生成停止に変えた

### 遡及審査
- 種別: 基盤
- 領域: platform
- 一言: 柱 7 の審査を既存要素に遡って掛け、使用率は bot ではなく **人のリプレイ** でも数える
- 仕組み:
  - **審査の欄**: 祝福だけが持つ `BoonDef.changes`（押す物 / 押す時 / 立つ場所 / 狙う相手 / 見る物）を、性質・誓約・名のある遺物・精鋭・ランイベント・契約者・追加の部屋・状態異常・流儀の Rule にも必須にする。5 択の enum + 対象の 1 語で、文は書かせない
  - **写し数え**（批評から）: `ui/replayStore` に溜まったユーザー自身のリプレイを headless で流し直し、鍵・市・賭け・帰還・状態異常・誓約の使われ方を数える qa の 1 モード。リプレイは入力列なので、遊んだ時の判断がそのまま再現される。bot の数字と並べて「bot だけが使わない」と「人も使わない」を分ける
  - **物差しを 2 本にする**: 「使った回数」に加えて「使った時に、そのランの山場になったか」（墓誌の句に選ばれた回数）。10 ランに 1 回の倍々勝負が墓誌に載るなら、それは珍しいだけで死んでいない
  - フル QA の report.md に「使われない要素」の節を足し、2 回続けて 0 件の物を名前で並べ、HANDOFF の「実プレイの感想待ち」へ渡す。審査の enum で「どれも変えない」と出た誓約は、数値だけの誓約として先に落とす候補にする
- なぜこのゲームで: ユーザーの方針「柱 7 の審査を通った物だけ入れる」は新しい物にしか掛かっていない。決定性とリプレイを持つこのゲームは、**人の遊び方を後から何度でも数え直せる** という、他のゲームに無い計測の道具を既に持っている
- 着想元: Dead Cells・Hades の早期アクセス中の削減（使用率のデータ + 作り手の 1 文の審査）。どちらもサーバの統計に頼ったが、ここでは手元のリプレイを流し直すだけで済む
- 安っぽくならないための要点 / リスク: 欄を埋めること自体が目的になる。enum に縛り、文は書かせない。写し数えは REPLAY_VERSION が違うリプレイを流せないので、棚卸の前に 1 回取っておく。0 件は削る根拠ではなく「人が遊んで確かめる一覧」
- 規模: M
- 議論で変わった点: 写し数えと「山場になったか」の物差しを足し、bot だけを根拠にする自分の弱点を塞いだ

### 決着三様
- 種別: 改善
- 領域: encounter
- 一言: 陣の決着の 3 つの形（全滅・大将撃破・敗走）に、時間・褒美・主の厚みの三すくみを持たせる
- 仕組み:
  - 今はどの決着でも同じ報酬が出るので、決着の形を選ぶ理由が無い
    - **全滅**: 遅い。陣の褒美は全部出る。逃げる者がいないので、主の間には何も残らない
    - **大将撃破**: 中くらい。陣の残りは散り（主へは帰らない）、褒美は大将の落とし物だけ
    - **敗走**: 最速。ただし逃げ切った敵は 12 秒で消えず、階の主の間へ帰って **残党** になる（1 体 = 主の取り巻き 1、上限 4）。主の間の入口に「残党 3」と見せる
  - 来歴は **量ではなく色** で返す（批評から）。全滅・大将撃破・敗走を遺物の来歴の別々の欄で数え（全滅は既存の殲滅 `lastKills`、大将撃破と敗走させた数を足す）、節目で出る芽の候補の系統がその欄で決まる。どの決着を選んでも遺物の育つ速さは同じ
  - 素通りした陣は何も起こさない。残党は通常の階の主だけで、章ボス・最深の主には入れない
- なぜこのゲームで: 敗走が決着の 76%、逃げ切りが 42% なのに、「逃がすと次が強くなる」は 9% しか起きていない。陣（遭遇の単位）・階の主（その階の総決算）・来歴（遺物の使い込み）・芽の 2 択が、初めて 1 本の判断で噛み合う
- 着想元: 三国志の戦の決着（大将を討つ・兵を散らす・殲滅する）と Into the Breach の「何を残すかを選ぶ」。どちらもターン制の判断なので、リアルタイムの陣の決着の形に置き換えた

### 裏書
- 種別: 整理・削減
- 領域: build
- 一言: 祝福の格（効果量 ×1.5〜×3.4）を廃し、錬磨を「札の裏に 1 行のルールを書き足す」行為に変える
- 仕組み:

- 規模: L
- 議論で変わった点: 名前を「奥書」（奥義と字が並び、本来は免許の伝授の文）から批評の推す「裏書」に替えた

### 精鋭淘汰
- 種別: 整理・削減
- 領域: encounter
- 一言: 承認済みの精鋭 21 → 12 を「読みを変えない物は削る」基準で今すぐ進め、残った物には名札でなく体の印を付ける
- 仕組み:

- 安っぽくならないための要点 / リスク: 削った分を新しい精鋭で埋め戻さない（12 は上限で目標ではない）。印の絵は敵の描き直しの段と同時に行う
- 規模: M
- 議論で変わった点: 体の印を宿怨と共有する前提にした（中身はほぼそのまま）

### 座組
- 種別: 整理・削減
- 領域: run
- 一言: 10 の売り手と 2 系統の腕の賭けを、動詞ごとの 4 つの座に組み直し、各座には必ず「人」を立たせる
- 仕組み:
  - 役（動詞）ごとに座を組み、部屋の設備は消して契約者の体と台詞を残す（批評から。座は動詞の束、立つのは人）
    - **市座**（買う・売る）: 市・章の市・行商を 1 つに。立つのは行商。旅商人は「助けると市座の品が 1 つ増える」出来事にする
    - **鍛座**（刃に属性を焼く・型に手を入れる）: 鍛冶と鍛冶場を 1 つに。立つのは鍛冶
    - **祓座**（呪いを解く・傷を縫う）: 修理屋と呪いの祠を 1 つに。立つのは修理屋
    - **契約**（腕を賭ける）: 公証人の契約 4 と腕の賭け 3 を、条件表 1 つ（無傷・疾走・狩り・沈黙・凌ぎ）にまとめ、公証人だけが出す。賭け札は銭 / その階の瓶 1 本。賭場の主は運の賭け 2 つ（丁半・倍々勝負）に絞り、振れ幅を大きくする
  - 闇市は隠し部屋の褒美として残す
  - **無法者の代償を本物に**: 商人を襲う方が到達が深い（7.2 対 4.0）。襲うとその章の市座が閉じ、契約者が台座に立たなくなる
  - **座の主の記憶**（批評から）: 行商・鍛冶・修理屋は、ランをまたいで「何を買ったか・襲われたか」を覚える（拠点の保存の 1 欄。ラン開始時に `RunSetup` へ写し、step の中では読まない）。変わるのは台詞と棚の並びだけで値段は変えない。襲った行商は次のランで最初の 1 回だけ、体の印の付いた用心棒を連れて立つ
  - 座の名前は表示に出さず、人の名前で呼ぶ
- なぜこのゲームで: 市の 70% が何も売れていない。数を減らすと 1 つ 1 つの市に「ここで何を買うか」の重みが戻る。自分に課す条件が縛り（拠点・位階）/ 誓約（遺物・ビルド）/ 契約（ラン内・腕）の 3 つと 1 文で言えるようになる（原則 9 の層の住み分け）。商人が敵の体で作られている強み（襲う・助ける・見捨てる）を残し、代償だけを本物にする
- 着想元: Hades の「カロン 1 人で店を全部担う」読みやすさと、Slay the Spire のネオウ（代償を選ぶ）。Hades は 1 人に寄せたが、ここでは動詞ごとに分け、人が客を覚える所まで延ばした
- 安っぽくならないための要点 / リスク: 賭け札は 2 種で固定し、台座の上で左右に倒すだけで選ぶ。**旧案の「鍵を賭け札にする」は保留**（鍵が使われない原因が bot の寄り道不足か、人も使わないかを写し数えで確かめてから）。記憶が値引きや好感度の数字になったら原則に背くので、台詞と並びに限る
- 規模: L
- 議論で変わった点: 契約統合と市座を 1 つに束ね、座には人を立たせ、座の主の記憶を取り込み、鍵の賭け札を保留にした

### 墓誌
- 種別: 拡張
- 領域: meta
- 一言: スコアを下ろした空席に、そのランの山場を 3 句で刻み、句を押すとその場面からリプレイが再生され、遺物には「事績」として残る
- 仕組み:

  - 句はランの時刻を持ち、探索履歴で句を選ぶとリプレイをその 5 秒前から再生する（headless で step を早送り）。句の文は記録時に文字列で保存し、`REPLAY_VERSION` が上がって再生できなくなっても読める

- なぜこのゲームで: 決定性とリプレイ・死因・仇・来歴と銘がそろっているのに、ランの結末は数字の羅列。棚卸で空く席を、比べられない物語で埋める（原則 8 を守ったまま、Steam で共有したくなる 1 行になる）。ゴール装備を作らないなら、遺物を手放せない理由は強さではなく思い出でなければならない
- 着想元: Dwarf Fortress の伝説モードと工芸品の彫刻（出来事が勝手に記録になる）、Hades の「誰に倒されたか」。DF のような年代記にはせず 3 句に絞り、押すとその場面が再生される所と、銘を持ち主が選ぶ所まで繋げた
- 安っぽくならないための要点 / リスク: 句の型が単調だと全部が「〜を倒す / 〜に倒れる」になる。型は 12 程度を手で書き、同じ型を 2 句に並べない。事績が「実績の言い換え」にならないよう、数の節目は来歴の側に残す。深い階の早送りの秒を測り、遅ければ階の到着ごとの state の写しを持つかを判断する。棚卸（銘の部品の名寄せ）の後に入れる
- 規模: L
- 議論で変わった点: 批評の派生案「墓誌」と「事績」を、同じ出来事の抽出器から出る 2 つの出力として 1 案に束ねた（整理の視点では、抽出器を 2 本作らない）

### 異常整理
- 種別: 整理・削減
- 領域: combat
- 一言: 状態異常 36 を「選んで付けられる・見て分かる・反応の片側」の 3 基準で絞り、良い状態は型の戦意へ還す

- 議論で変わった点: 3 基準をレシピの入口の審査に格上げし、削る根拠に写し数えを足した

- 議論で変わった点: 見せ方を時計から縁のにじみに替え、交戦中半速の定義を絞った

  - 仇の体に、最後にプレイヤーが当てた型の **傷** を 2〜3 ドット重ねる。型 15 を 4 つの傷（斬・打・穿・墨）に束ね、絵の数を抑える
  - 宿怨はプレイヤーを殺した技を **先に出す**（技選びの重みを 1 段だけ寄せる。予告は今のまま）。図解で読んだ答えをそのまま試せる
  - 討つと討った武器に事績「宿怨を断つ」が刻まれ、墓誌の「最も重い瞬間」の筆頭候補になる。3 ラン討てなければ「去った」として消える
  - `NemesisSpec` に殺した技と最後の型を足し、今と同じく `RunSetup` へ写す（決定性は壊れない）
- なぜこのゲームで: 死因 → 予告の図解 → 仇 → 御堂の線は既にあるのに、仇が 1 回の顔見せで終わる。「同じ技でもう一度殺しに来る」のは、テレグラフを読んで答えるこのゲームの核をそのまま再戦の形にする。新しい層は足さず、既存の仇を深める
- 着想元: Shadow of Mordor のネメシス（殺した敵が昇進し、傷を負って戻る）。階級や台詞の量産はせず、印 3 つと傷の絵だけに絞り、「同じ技で来る」というアクションの再戦に変えた
- 安っぽくならないための要点 / リスク: 詰まった人がさらに詰まる。印は読みを変える物だけで数値は上がらない（精鋭淘汰の審査をそのまま通す）。却下済みの「仇が階をまたいで追う」とは別物（1 ランに 1 体、置き場所は今のまま）
- 規模: M
- 議論で変わった点: 批評の派生案を採用。傷の絵を型 15 から 4 系統に束ね、削減の視点から絵の量を抑えた

### 剛柔
- 種別: 改善
- 領域: combat
- 一言: 敵の単発の攻撃を「受け流せる柔」と「躱すしかない剛」に分け、割り込みに序列を作る
- 仕組み:
  - **柔**: 受け流せる。**剛**: 受け流すと押し負ける（ダメージ半分 + 大きく押される + 硬直）ので、見切るか間合いの外へ出る
  - 質は敵ごとに付けず、攻撃の形の表 1 か所で決める（掴み・爆ぜ・突き抜け・重さが「重」の突進は剛、それ以外は柔）。目安は通常の敵の攻撃の 2〜3 割
  - **剛の判定は短く作り直す**（批評から）: 一瞬の爆ぜ・突き抜けにし、持続の長い光線・地形の噴出は剛柔の外（「場」として立ち位置で答える従来の扱い）に置く。剛の答えが「逃げる」ではなく「見切る」になるようにする
  - **盾の例外は型の側に置く**（批評から）: 盾の受けだけは剛を受けても押し負けないが、受け溜めは溜まらない。「形で決まる」は敵側で守る
  - 予告の線は柔を実線、剛を墨のかすれた二重線。色は変えず形で区別するので色覚の手当てにもなる
  - 結果の語彙: 黄の頭 = 割り込み / 黄の終わり = 間際 / 赤の実線 = 受け流し / 赤のかすれ = 見切り / 大振りの後 = 背面
- なぜこのゲームで: 「黄なら殴れ、赤なら受け流せ」を 1 文伸ばすだけで、ダッシュの形 12（流儀）と見切りの祝福・性質に出番が戻る。予告の図解（`telegraphDiagram`）にもそのまま 1 行で載る
- 着想元: Sekiro の「危」。Sekiro は 3 種を漢字 1 字で光らせるが、ここでは 2 種に絞り、予告の線の質感だけで常に見せる
- 安っぽくならないための要点 / リスク: 例外を増やすと覚えられない。ボスだけは段階で質を入れ替えてよい。間際の束を入れて probe を取り直してから着手する（同時に入れると、どちらが完遂率を動かしたか分からない）
- 規模: L
- 議論で変わった点: 剛の判定を短くする条件と盾の例外を足し、着手を間際の束の後に回した

### 文法統一
- 種別: 基盤
- 領域: build
- 一言: 遺物のトリガー文法と流儀の数値の Rule を、共通の瞬間と陣の語で書く統一 Rule へ移す
- 仕組み:
  - 「起きたこと → 効果」の文法が 3 系統ある: `loot/triggers.ts`（起点 10 × 条件 13、「部屋制圧時」が残り、効果は固定値）/ 性質「行動」43 / 祝福・流儀・型の統一 Rule
  - 1 を 3 へ移し、起点を共通の瞬間 6（先制・終撃・充溢・放出・応手・双撃）と陣の語（陣の決着・大将の撃破・敗走）で書き直す。効果は行動ごとの係数（原則 11）
  - 流儀の数値の Rule（剣士「見切りでダメージ +%」・拳闘士「被弾でダメージ +%」）をルール変更に書き換え、`LEGACY_FAVORED` を消す
  - 遺物にしかできない形は **芽の分かれ道** で決める（批評から）。発火の形の変化（例: 応手の発火が背面にも出る）を芽の 2 択の片方に置き、選ばなかった方は二度と出ない。数えた量で形を変えない
- なぜこのゲームで: Rule の連鎖の深さが 99.4% で 0、イベントの捨てが 99,950 件。文法が 3 本あると連鎖も共鳴も数え漏れる。1 本にすれば共鳴の「語」とトリガーが同じ辞書を引く
- 着想元: Path of Exile の「Cast when X」の乱立を後の版で統一の支援ジェムへ畳んだ整理。自動発動にはせず、効果は撃った行動の延長に限る
- 安っぽくならないための要点 / リスク: 既存の性質の数値が全部動き、決定性に触る。版を切って一度に移し、レビューは opus で行う。棚卸の段と同じ版上げに乗せるかは、段の大きさを見て決める
- 規模: XL
- 議論で変わった点: 「来歴に結んだ発火」（古い遺物ほど強い = ゴール装備への一本道）を捨てて芽の分かれ道に替え、規模を L から XL に上げた

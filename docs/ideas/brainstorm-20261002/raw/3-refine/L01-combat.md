## 議論を経た全体の方針

1. **順番を決める**: 読み手（計測）→ 出端 → 予告の見え方（殺気）→ 見得 → 脱墨。差し返し・撃墜・逸撃・突落は「どこに立つか」の上手さで、予告の線の先端が見えること（殺気の段）が前提
2. **新しい浮き文字は 1 波で 2 語まで**。出端と脱墨だけを文字にし、他（差し返し・立合・撃墜・挫鋒・逸撃）は **音・止め・絵の変化** で語る。応手の出どころ（今 9）を増やさない
3. **射撃の型を読みの語彙から締め出さない**。近接の案を出すたびに「銃・書・鈴での入口」を 1 行書く（29 種のうち 10 種）
4. **拍はゲームの時間で数える**。ヒットストップ・スローの間も Web Audio は進むので、拍を使う案（挫鋒）は `state.time` から拍を作り、太鼓は効果音としてゲーム側で鳴らす
5. **判定を変える案はリプレイを壊す**。出端・差し返し・脱墨を入れる段の頭で `replayStore` の版を切る
6. **教える場は迷宮の中、確かめる場は拠点**（木人）。最初の一振りを 3 か所で教えない

## 案（16。推しの順）

### 読み手
- 種別: 基盤
- 領域: combat
- 一言: 既存の bot に「反応の遅れ・黄 / 赤の区別・答えの選び分け」を足し、読む人と連打する人の差を測れるようにする
- 仕組み:
  - 一から作らず `qa/bot.ts` を拡張する。足すのは 3 つ: (1) 予備動作の始まりから入力までの **反応の遅れ**（bot の rng から決定的に引く）、(2) 黄の間なら殴る・赤なら受け流すという **色の読み分け**、(3) 予告の形（線 = 横へ歩く、弧・円 = 受け流しか見切り）による **答えの選び分け**
  - 反応の遅れの分布は推測で置かず、**ユーザーの実プレイのリプレイから測る**。リプレイは入力列なので、敵の予備動作の始まりから受け流し・ダッシュの入力までのフレーム数を抜き出す小さな解析を `src/qa/` に置く
  - 先にやる計測（S）: `combatProbe` に **カウンターの内訳（黄の間 / 赤の間）** と **ヒットストップの出どころ別の内訳**（終撃・重・撃破・カウンター +2・通常）を足す。出端と見得の表は、この数字を見てから決める
  - 出力は武器種 × 敵の表に「読む bot / 連打の bot の撃破秒の比・被弾の比」を足す。目標の例: 読む bot が被弾 1/3、撃破秒 0.8 倍。数字は UI に出さない（QA の道具）
- なぜこのゲームで: probe の「カウンター 60 秒に 50〜95 回」「見切りほぼ 0」は bot が読まないことの裏返しで、読みの手段の価値が今は測れていない。決定性があるので、反応の遅れまで含めて再現できる。下の全案の効き目はここで決まる
- 着想元: 格闘ゲームの CPU の反応設定。人の反応の分布をリプレイから取る点は、e スポーツの解析ツールに近い。ゲームの機能ではなく、開発の物差しとして入れる
- 安っぽくならないための要点 / リスク: 読む bot が人を超えると「上手い人」の基準が狂う。分布はリプレイの中央値〜上位 2 割を使う。bot の読みが予告の形に依存するので、筋目（下）を入れたら bot も更新する
- 規模: M（計測の内訳だけなら S）
- 議論で変わった点: 「基盤から作る」をやめ既存 bot の拡張に。反応の分布はリプレイから測る。カウンターとヒットストップの内訳を先に足す（批評の訂正を全面採用）

### 出端
- 種別: 改善
- 領域: combat
- 一言: カウンターを「黄の間に振り始めた一撃」だけに絞り、赤の間の命中は鈍く弾かれる
- 仕組み:
  - 判定: **振りの発生（攻撃の開始）が相手の黄の間に入っていれば出端**。命中の時刻では切らない（重打は永遠に取れなくなる）。赤の間に始めた振りの命中は通常の命中で、威力の倍・盾無視・気力 ×2・ヒットストップ +2 は付かない
  - 赤の間の命中には **鈍い音（低い木の打音・火花なし）** を付ける。黄の出端は今のカウンターの澄んだ音のまま。初心者は「偶然のカウンター」という当たりの合図を失う代わりに、音の対比で文字なしに黄 / 赤の違いを体で覚える
  - **射撃の入口**: 長銃の静止で満ちた 1 発・短銃の強装填の 1 発・書の溜めた一字・鈴の満ちた鳴りが、**発射の時刻が相手の黄の間** で、かつ命中すれば出端。弾の飛ぶ時間ぶん先読みが要るので、近接と別の技になる
  - **`onCounter` の棚卸しが本体の工数**: 発火の条件を「出端」と「受け流し」の 2 つに絞り直し、回数が 5〜10 分の 1 に減るぶん 1 回の効果を重くする。死に札になる祝福・性質・名のある遺物・来歴・刻印符を一覧にしてから数値を動かす
  - **奥義の配分（旧案「機先」をここに統合）**: `ENERGY.perSwingSec` 45 → 30 程度に下げ、見切り・受け流し・出端の上乗せで差を付ける。最初の 1 時間で奥義を必ず見られる下限を守る（81 本の専用の絵はこのゲームの一番の見せ物）
  - 戦意の放出の振り始めが出端と重なると放出の倍が 1 段上がる（剣の応報・重打の最大溜め・長柄の満ちた突き）。型ごとの「極み」は別の仕組みを足さずにここから生まれる
  - 目安: 連打の bot のカウンター 50〜95 回 → 5〜15 回、読む bot で 20〜40 回
- なぜこのゲームで: 「黄 = 殴って割り込める / 赤 = 受け流す」という核の一文を、報酬の側でも同じ言葉で言い直す。今は赤の間に殴っても怯み値は溜まらない（`windupCommitted`）のに報酬だけは満額で、画面と報酬が逆のことを言っている。共通の瞬間の放出・型の戦意・応手の数えにそのまま乗る
- 着想元: 剣道の「出ばな技」、格闘ゲームのカウンターヒット。格ゲーは発生前の全体がカウンターだが、ここは黄 / 赤の色の境で切るので、画面の色そのものが「今なら取れる」を語る。弾の出端は、弾速ぶん先に撃つ「置き」の考え方を射撃に移した
- 安っぽくならないための要点 / リスク: 最初の 30 分の気持ちよさが下がらないかを、弾かれ音の対比で補う。`onCounter` の再調整を後回しにするとビルドの系統が丸ごと死ぬので、同じ段で必ずやる。`isCounterable` が変わるので `replayStore` の版を切る
- 規模: M
- 議論で変わった点: 規模 S → M（`onCounter` の棚卸し）。赤の弾かれ音・射撃の出端・リプレイの版を追加。旧「機先」の配分（45 → 20 は下げすぎ → 30）を統合

### 殺気
- 種別: 改善
- 領域: ux
- 一言: 背後と画面外から来る赤を、その方向の画面の縁に墨の一筆で知らせる。予告の見え方の段の「位置」の担当
- 仕組み:
  - プレイヤーを狙う攻撃がコミット（赤）に入った時、その敵が画面外か、プレイヤーの向きから 120 度より後ろにいれば、その方向の画面の縁に短い墨の払いを 0.3 秒出す。文字・矢印の記号は出さない
  - **予告の見え方を 1 本の段にまとめる前提で、この案は「位置」だけを持つ**: 形は筋目（下）、色と筆致は L06 の下絵 → 墨入れ（黄は掠れた細い線、赤は濃墨）、音は L09 の柝（赤に変わる瞬間に 1 種類の拍子木）、位置は殺気。色・形・音・位置の 4 本の通り道で、1 本が欠けても読める
  - 役割ごとの音（前衛は低く…）は赤の瞬間に重ねると柝と濁るので、**黄の始まりの小さな音** に置く
  - あわせて予告の線の先端に小さな筆の止め（点）を描き、線の届く先を見えるようにする（今は 1px・不透明度 0.35 で先端が見えない）。差し返し・撃墜・逸撃・突落の前提
- なぜこのゲームで: 「敵の攻撃は必ずテレグラフ」が画面外と背後で破れている。200 体の地図・同時攻撃の上限 `2 + 起きている敵 / 3`・囲みの反応ルールの下で、1 対多の公平さの底を作る
- 着想元: Hades・Nuclear Throne の画面端の矢印。記号ではなく墨の筆致にし、世界の「墨が入る = 必ず来る」と同じ絵の言葉で言う
- 安っぽくならないための要点 / リスク: 出すぎると縁がうるさい。赤になった瞬間だけ・プレイヤーを狙う攻撃だけ。同時に 3 本を超えたら古いものから消す
- 規模: S（予告の見え方の段としてまとめると M）
- 議論で変わった点: L06 墨入れ・L09 柝・L11 濃淡予告と 1 本の段に統合し、殺気は「位置」の担当に。役割の音を黄の始まりへ移す。線の先端の止めを足す

### 見得
- 種別: 改善
- 領域: presentation
- 一言: 世界停止を「読めた瞬間」に配り直し、止まること自体を上手さの合図にする
- 仕組み:
  - ヒットストップを **読みの格の表** で配る（1 秒あたりの予算制にはしない。同じ一撃が直前の状況で止まったり止まらなかったりすると「止まる = 読めた」の学習が崩れる）
  - 表の目安（ステップ）: 通常 0〜1（今のまま）、普通の撃破 0〜1（陣の最後の 1 体・大将だけ今の 6）、終撃は重さで軽 2 / 中 3 / 重 5、出端 5、受け流し 7（画面の縁に墨の滲み）、脱墨 12（最後の 1 段で音楽に低域通過）
  - 撃破を止めない代わりに、音と破片を厚くして手応えを保つ
  - **止めを切った人のために、同じ瞬間に短い柝の音の印を必ず重ねる**。止め・音の 2 本で「読めた」を伝える
  - 表は `FEEL.json` に置く。読み手の「ヒットストップの出どころ別の内訳」を見てから数字を決める
- なぜこのゲームで: 世界停止の方式（決定済み）のまま量だけ動かすので、決定性もデイリーも崩れない。200 体の地図で撃破 6 ステップを毎回払う渋滞が消え、出端・脱墨という読みの語彙と止めが結びつく
- 着想元: 歌舞伎の見得、Hades の止めの強弱。カメラのズームは「やらないこと」なので使わず、止める長さと墨の滲みだけで語る
- 安っぽくならないための要点 / リスク: 終撃を一律 3 に削ると重い型の手応えが死ぬ。重さで分ける。測る前に表を決めない
- 規模: S
- 議論で変わった点: 終撃を重さで分ける。止めを切った人へ柝の音の印。表は計測の後に決める（L10 停止配分の予算制ではなく、格の表を採る理由を明記）

### 脱墨
- 種別: 新要素
- 領域: combat
- 一言: ボスと陣の大将の 3 段以上の連撃を全段受け流すと、相手から墨が抜け、数秒のあいだ攻撃が赤に入らなくなる
- 仕組み:
  - 対象は **ボスと陣の大将の、3 段以上の連撃だけ**。精鋭と並は今どおり受け流しで即怯み（受け流しを覚えた人への報酬を奪わない）
  - 連撃の続きは最初から赤（`chainWindup`）なので、「赤は受け流しで止める」の文法がそのまま試される。受け流しの音は段ごとに音程が上がり、最後の 1 段で和音が解決する（耳で「あと何段」かを数えられる）。1 段でもダッシュで避ければ脱墨は消えるが、被弾もしない。**安全に避けるか、全部受けて崩すか** の判断
  - **無敵の扱いを決める**: 脱墨の対象の連撃を受けている間だけ、受け流し成功の無敵（`parryInvuln` 0.3 秒）を 0.15 秒に縮める。次の段が無敵で素通りして「受けたのか消えたのか」曖昧になるのを防ぎ、全段を自分の手で受けさせる
  - 成功すると **脱墨**（3 秒）: 相手の予備動作は最後まで黄のまま（コミットしない）。何を出しても出端で潰せる。相手の絵は描画の分岐 1 本で墨の塗りが抜け、輪郭だけの白描になる。抜けた墨は奥義ゲージに流れる（読みの換金の一番大きな源）
  - 判断: 3 秒を出端を取り続けて怯み → 処刑へ使うか、奥義を撃ち込むか。ダウン（殴るだけの時間）と違って相手は動き続けるので、読みが途切れない
- なぜこのゲームで: 「下絵（黄）は消せる、墨（赤）は消えない」という核の規則を、報酬の側で **一時的に裏返す** 唯一の瞬間。連撃が長いほど上手い人の見せ場が増える、という向きに変わり、章で技を覚える段（`depthStages`）の連撃とボスの連撃が見せ場になる
- 着想元: Sekiro の体幹崩しと連続弾き、Furi のパリィの連なり。体幹ゲージは持ち込まず「1 本の連撃を全部」という区切りのはっきりした条件にし、報酬を「一撃で終わる忍殺」ではなく「相手の文法の書き換え」にした
- 安っぽくならないための要点 / リスク: 段階の移り変わり（行為で進む段階）の間は脱墨を止める。章ボスの 1 段階に 1 回取れる程度の頻度に保つ。白描は敵ごとの絵を足さず描画の分岐で作る
- 規模: M
- 議論で変わった点: 旧「封殺」を条件、批評の派生「脱墨」を報酬として 1 本に統合（浮き文字は「脱墨」の 1 語）。精鋭を対象から外す。無敵 0.3 秒の衝突を「対象の連撃中だけ 0.15 秒」で解く

### 差し返し
- 種別: 新要素
- 領域: combat
- 一言: 突きの予告線の先端の半歩外に立って空を切らせると、戻りの最初の一撃が堅守を抜ける
- 仕組み:
  - 対象は **突きの形（線の予告）の攻撃だけ**、かつ前衛・突撃の役割で届く距離 40px 以上
  - 攻撃の持続が終わった時、プレイヤーが「線の先端から 8〜16px 以内」「線に触れていない」「無敵でない（見切り・受け流しではない）」なら **空振り**。伸び切った線がそのまま一瞬残り、筆が掠れて消える（= 空振りの合図。浮き文字は出さない）
  - 報酬は **戻りの隙の最初の命中が堅守を 1 回だけ無視する** だけ。戻りの延長は入れない（読んでいない人にも効く「敵が弱くなる」数値は足さない）。応手の出どころにも数えない
  - ダッシュ 1 回 1.2 秒の重さに対する、唯一の無料の守り。重打・刃斧は空振りさせて溜めの一撃を通す、が型の技になる
  - 射撃の入口: 長銃は「空振りした敵の戻りを静止で撃つ」がそのまま差し返しになる（遠くから空を切らせる立ち位置が長銃の読み）
- なぜこのゲームで: 反応ルール「隙を狙う」の裏返しで、プレイヤー側にも隙を狙う語彙ができる。長柄の穂先（先端で当てる）と同じ「間合い」の言葉で揃う。見下ろしの画面で、線の先端という目で見える条件に落とせる
- 着想元: 格闘ゲームの差し返し（空振りの硬直を刺す）と牽制の間合い。フレーム管理は持ち込まず「線の先端の外」という見える条件にした
- 安っぽくならないための要点 / リスク: 線の先端が見えないと成立しないので、殺気の段（先端の止め）の後に入れる。群れの小物に付けると常時発生するので役割で絞る
- 規模: M
- 議論で変わった点: 「届く距離 ×1.5 の内側」という見えない条件を、予告線の先端の半歩外に結び直す。戻り +0.25 秒と応手の数えを削除。報酬は堅守の無視 1 回だけ

### 筋目
- 種別: 拡張
- 領域: encounter
- 一言: 予告に攻撃の当たりの形をそのまま描き、その形の既定を敵の出自から引く。章ごとに読む形が 1 つ増える
- 仕組み:
  - 第 1 段（M）: 予告に **実際の当たりの形** を描く。弧の攻撃は弧、突進は線、衝撃波は円、弾は射線。新しい規則（本手でなければ報酬半分など）は足さない。形を見れば「線は横に歩けば避けられる」「弧・円は歩いても避けられない」が勝手に分かり、正しい守りは **安全さとして** 報われる
  - 第 2 段（M〜L）: 形の既定を敵の出自で引く。L06 草紙出典が採られれば出典ごとの家の筋（御伽 = 突き、写経所 = 震え、軍記 = 払い、南蛮 = 弾、六道 = 黄が長く赤が極端に短い起こりの速い攻撃）。採られなければ章の様式で同じことをする。予告の線の筆致も家ごとに変える（細い描線・太筆・銅版の平行線・朱のにじみ）。黄 / 赤の色は共通
  - **章を越えるごとに読む形が 1 つ増える**（章 1 は 2 筋、章 2・3・4 で 1 つずつ）。章の休符で新しい筋の敵が 1 体だけ先に出る
  - 110 体に手で付けず、家の既定 + 例外の数十件。例外の敵ほど記憶に残るように作る
  - 「掴み（受け流せない筋）」は作らない。同じ役は「黄が長く赤が極端に短い攻撃」= 出端が本手、として既存の文法の中で作る
- なぜこのゲームで: 色で「いつ」、形で「何で」を読む 2 段の読みになり、割り込みの手段 9 つに暗黙の序列ができる。色に頼らない区別は色覚への手当てにもなる。ランの流れ（章ごとに覚えることが増える）と読みの語彙を 1 つの分類で結ぶ
- 着想元: Sekiro の「危」（攻撃の種類で答えが違う）、Hollow Knight の地域ごとの敵の動きの系統、Monster Hunter の骨格の共有。骨格の共有は制作の都合だったのを、物語の出自と読みの語彙に結び直した
- 安っぽくならないための要点 / リスク: 200 体の地図で形まで読めるのは手前の 2〜3 体。遠い敵の予告は形を省いて色だけにしてよい。出典の改名はユーザーに先に聞く。L02 攻め筋・L10 剛柔と同じ問題への答えなので、統合で 1 本にする
- 規模: L
- 議論で変わった点: 旧「手筋」の 5 筋 + 報酬半分 + 掴みを捨て、「当たりの形を描くだけ」に縮小。批評の派生「筋目」（出自で既定を引く・章で 1 つ増える）を第 2 段として取り込み、名前も「筋目」に（「手筋」は L03 と衝突）

### 立合
- 種別: 改善
- 領域: combat
- 一言: 怯みから立ち上がった敵の初手だけ黄を長くし、そこを出端で取ると堅守を打ち消して再び崩せる
- 仕組み:
  - 起き上がりの攻撃は足さない。怯みが解けた直後の **最初の攻撃だけ、黄の間を 1.5 倍** にする
  - その黄に出端を当てると、堅守を打ち消して再び怯む（音で知らせ、浮き文字は出さない）
  - 判断: 堅守で半減した怯み値のまま殴り続けるか、相手の初手（立ち上がりの下絵）を待って出端で取り直すか。罰ではなく、待つ人への追加の得で選ばせる
  - 射撃の入口: 弾の出端（上）がそのまま使える。長銃は怯んでいる間に静止を溜め、立合に満ちた 1 発を置く
- なぜこのゲームで: 怯み → 堅守 → 殴る、の後の単調さに、新しい絵も攻撃も足さずに判断を入れる。処刑の上限 25% は変えず、怯ませやすさの側で伸ばす方針（core-synthesis 3-7）に合う。ビルドの換金の時間（処刑・スキル・状態異常）は奪わない
- 着想元: 相撲の立合、格闘ゲームの起き攻め。起き攻めは攻める側の読み合いだが、ここは「待つ側に得がある」形にひっくり返し、フェイントは作らない
- 安っぽくならないための要点 / リスク: 黄 1.5 倍はその 1 撃だけ。すべての敵の初手が遅くなると全体が易しくなるので、怯みからの立ち上がりに限る
- 規模: S
- 議論で変わった点: 旧「逆襲」（起き際の全方位の払い）は「怯ませたら下がる」が正解になる嫌われ敵の定番として捨て、批評の磨き方（初手の黄を長くして待つ人に得）に置き換え、名前も「立合」に

### 撃墜
- 種別: 拡張
- 領域: combat
- 一言: 浮く敵は撃つ間だけ高度を下げる。その降下の間に出端を入れると地に落ちる
- 仕組み:
  - 浮遊眼・鬼火・蝙蝠などに **「浮く」の印** を付ける。読むのは描画（影の大きさ）と撃墜の判定だけで、当たり判定・地形の層の効き方は今のまま（高さの概念は入れない）
  - 予備動作の間だけ影が縮んで高度を下げる（絵の合図）。その間に出端が入ると **撃墜**: 地面に落ち、怯み値が通り、処刑できる。重い型は落ちている時間が長い（軽 1.0 秒 / 重 1.8 秒の目安）
  - 射撃の型は撃墜を取りやすいが、重い型より短い。浮く敵に射撃が強すぎる今の偏りは別に見る
  - 型ごとの届く手（鎖の引き落とし・重打の地打ち・刃斧の傷）は L10 間合補完の「型ごとの答え」と一緒に決める
- なぜこのゲームで: 重打・刃斧・盾・鎖の鎌が浮遊眼に 45〜90 秒かかる偏り（probe）に、射程を伸ばすのではなく「時機を読む」という重い型の理念で答える。出端の語彙をそのまま空へ延ばすので、新しい技の言葉が増えない
- 着想元: Monster Hunter の飛竜を地に落とす、Dead Cells の空中の敵。地上の手段で空を落とす発想だけ取り、合図を敵の予備動作に一本化した
- 安っぽくならないための要点 / リスク: 「浮く」の印を当たり判定に広げない。撃墜の文字は出さず、落ちる音と影の戻りで語る
- 規模: M
- 議論で変わった点: 高さの概念を入れず、描画と判定だけが読む印に縮小。条件を「降下の間の出端」1 つに。型ごとの 3 手は L10 へ渡す

### 先受
- 種別: 改善
- 領域: ux
- 一言: どの段の戻りでも、最後の 0.1 秒に押した受け流しとダッシュを落とさず、戻りが明けた瞬間に出す
- 仕組み:
  - 今は振りの間 `canStartParry` が false なので、戻りの終わりぎりぎりに押した受け流しは消える。手触りでは「押したのに出なかった」になり、反応ルール「終撃の硬直を狙う」（`punishBias`）が理不尽に感じられる
  - 戻りの最後 0.1 秒に押された受け流し・ダッシュを 1 つだけ保持し（攻撃の `buffered` と同じ考え方の別の席）、戻りが明けた最初のステップで出す。名前も浮き文字も出さない（技ではなく手触りの直し）
  - 保留中の「ダッシュ取り消し不可中の先行入力」と同じ段で決める
- なぜこのゲームで: 手動操作で常に入力したくなる密度は、押した入力が裏切らないことが前提。受け流しが核の守りなので、その入力の取りこぼしは他のどの案より体験を損なう
- 着想元: 格闘ゲームの先行入力の受付。キャンセル（戻りを打ち切る）にはせず、戻りの長さそのものは変えない
- 安っぽくならないための要点 / リスク: 受付を広げすぎると「受け流しを常に押しっぱなし」が強くなる。0.1 秒・1 入力だけ。受け流しの硬直 0.35 秒の罰は変えない
- 規模: S
- 議論で変わった点: 旧「残心」（終撃の戻りの最後 0.12 秒で受け流せる技）は先行入力と見分けが付かないので技としては捨て、批評の提案どおり全段の先行入力の UX 改善に。名前「残心」は `playerRig.ts` の描画の言葉に譲る

### 挫鋒
- 種別: 拡張
- 領域: encounter
- 一言: 陣太鼓のある陣は拍の頭で先鋒 1 体だけが口火を切り、そこを出端で挫くと太鼓が一小節黙って陣の連携が崩れる
- 仕組み:
  - 陣太鼓を持つ陣だけ、**先鋒の 1 体**（旗指物で見て分かる）の予備動作の始まりを拍の頭に揃える。他の敵は今どおり連携ずらし（`coordDelay`）で動く。同時の赤は増えない
  - 拍は **ゲームの時間（`state.time`）** で数え、ヒットストップで止まる。太鼓は効果音としてゲームの拍で鳴らし、曲の打楽器とはテンポだけ合わせて位相は追わない
  - 先鋒の黄に出端を当てると **挫鋒**: 太鼓が 1 小節止まり、その間は連携ずらしが無くなってばらばらに来る（各個に読みやすい）。陣の群勢が 1 段下がる
  - 拍に合わせることは要求しない（先鋒の黄に当てればよい。拍は来る時刻を教えるだけ）。音を切っている人にも旗と予告の線で同じ情報が届く
  - 太鼓そのものを壊す道具としての扱いは L02 陣具に任せ、こちらは「拍と先鋒」の担当
- なぜこのゲームで: 1 対多で「誰から読むか」を音と絵で 1 体に絞る。出端（1 対 1 の読み）を陣（1 対多）の崩しへ広げる橋。seed と深度で決まる決定的な合成音楽を持つこのゲームの資産を、攻めの読みに結ぶ
- 着想元: 戦国の一番槍・先駆け、Crypt of the NecroDancer の拍。リズムゲームにはせず、拍の頭に来る 1 体だけを拍に乗せた
- 安っぽくならないための要点 / リスク: 太鼓の陣は章に 1〜2 陣。軍記の出自の陣（廃城の章）に置けば章の顔になる
- 規模: M
- 議論で変わった点: 旧「陣拍子」（陣全体を拍に揃える）は同時の赤が増えて `telegraphCap` と衝突し、音とゲームの時計もずれるため、批評の派生「挫鋒」（先鋒 1 体・ゲームの時間の拍）に置き換え

### 逸撃
- 種別: 拡張
- 領域: combat
- 一言: 突進を受け流すと、相手は勢いのままプレイヤーの脇を抜けて後ろへ滑り、照準で ±45 度だけ曲げられる
- 仕組み:
  - 線の形（突き）の攻撃を受け流すと、その敵は即怯みの代わりに **勢いのまま脇を抜けて後ろへ 0.3 秒滑る**（闘牛の受け流し）。照準の向きは、その経路を ±45 度だけ曲げる
  - 滑る間に当たった他の敵は、その敵の攻撃の威力と怯み値を受ける。同じ陣の仲間に当たると群勢が下がる
  - 何もしなくても「背後に回り込んでいた敵に当たる」が起き、狙う人はさらに曲げて列を貫ける（鋒矢・長蛇のような縦の陣形への答え）
  - 射撃の弾には付けない（弾返しはビルドだけ、の決定を守る）
- なぜこのゲームで: 受け流しの最中に右手（マウス）へ仕事を与える。承認済みで一部だけの「敵の攻撃が敵にも当たる」（E30）を、プレイヤーの読みと照準を通す形で入れる
- 着想元: 闘牛の受け流し、Hades の敵を敵に飛ばす遊び。受け流しの成功の中に「向き」の選択を入れた点が違う
- 安っぽくならないための要点 / リスク: L02 同士討ち（攻撃の種類ごとの規則）と 1 本にし、こちらは「受け流しの経路」の担当。滑った先が穴なら突落（下）と繋がる
- 規模: M
- 議論で変わった点: 照準の既定が「来た方へ跳ね返す」になる問題を、既定を「脇を抜けて後ろ」+ 照準は曲げだけ、に変えて解く

### 虚実
- 種別: 新要素
- 領域: combat
- 一言: 重い振りの下絵を見て構えを変える敵がいて、こちらは下絵の間に振りを消して誘える
- 仕組み:
  - 章 3 以降の一部の敵（盾騎士・槍兵・鏡の騎士など、各章 2〜3 種）は、プレイヤーの **溜め・重い型の終撃の予備動作** を見ると、盾を向ける / 横へ退く / 突き返しの予備動作に入る。突き返しは必ず黄 → 赤の予告を持つ（敵のフェイントは作らない）。反応には再使用の間を置く
  - プレイヤー自身の重い振りの予備動作に淡い下絵の線を描く（敵に何が見えているかをこちらも見る）
  - 予備動作の前半なら、ダッシュか受け流しで振りを消せる（既存の `cancelAttack` の経路）。消すと敵は構えを変えた分だけ隙をさらす（盾の向きが固まる・突き返しが空を切る）
  - 代価は溜めていた戦意の半分。何度でも誘えるわけではない
  - 敵の反応は決定的（乱数なし）なので、同じように誘えば必ず同じように返る。覚えることが攻略になる
- なぜこのゲームで: 盾騎士が銃の家系 4 種で撃破不能（正面ブロック）、重い型は時機を読むと言いながら答えが少ない、の 2 つに数値でなく読みで答える。敵だけが予告する非対称を、「淵の中ではすべてがまず下絵として描かれる」という世界の理で対称にする。オート攻撃では誘えないので、手動操作のゲームでしか成立しない
- 着想元: 剣道の「誘い」と「起こり」、格闘ゲームの溜め技のフェイント。人どうしの読み合いだったのを、決定的に反応する敵に向けた
- 安っぽくならないための要点 / リスク: 反応する敵を絞らないと「重い振りは常に読まれる」になって重い型が弱くなる。溜めのダッシュでの捨て方と揃える。当初案で落とした「敵の読み返し（受け流しの多用で敵が間を外す）」とは別物で、こちらは敵がフェイントをせず、プレイヤーだけが誘える
- 規模: M〜L
- 議論で変わった点: 批評の派生案を採用。盾騎士の銃での撃破不能への答えとして、射撃の型にも「長銃の静止の溜めを見せて盾を向けさせ、短銃へ持ち替えて横から撃つ」の入口を検討項目に残す

### 突落
- 種別: 拡張
- 領域: combat
- 一言: 重い終撃で飛ばした敵が穴の縁を越えると落ちる。壁叩きつけの兄弟
- 仕組み:
  - 既存の壁叩きつけ（`ACTION.wallSplat`、重い命中で付く `e.wallSplat`）と同じ入口で、飛ばされた敵が一定の速さで `Tile.Pit` の縁を越えたら **落ちる**（撃破扱い）。浮きの層・空中状態は作らない
  - ボス・前衛・大将は落ちない（縁で止まる今の扱い）。逸撃で滑った敵・挫鋒で崩れた陣にも効く
  - 落とした敵は銭と来歴の数えを半分にする（群れを穴に捨てる作業にしない）。地形の層（溶岩・毒沼）の縁なら落とさず、着地で状態異常
- なぜこのゲームで: 「穴は落とせず縁で止まる（落下は後の段）」と「地形を踏むから使うへ」（S2 の問い 6）を、戦闘の手から通す。重い型の終撃の向き（照準）に「どこへ飛ばすか」の判断が乗る
- 着想元: Hades の壁への叩きつけ、Into the Breach の押し出し。見下ろしの画面の押し出しを、重い型の終撃の向きの読みに限った
- 安っぽくならないための要点 / リスク: 穴の多い階型（isle・ring）で強すぎないか見る。落ちる絵（墨に沈む 2 コマ）と音
- 規模: S〜M
- 議論で変わった点: 旧「浮き崩し」（本物の空中状態・浮かせ続け・穴越え。L）は「よくある浮かせコンボ」の縮小版として捨て、批評の提案どおり「穴に落とす」の 1 点を壁叩きつけの兄弟として切り出し

### 名場面
- 種別: 新要素
- 領域: presentation
- 一言: 踏破の画面と記録の蔵で、そのランの上手かった瞬間を 3 つ、短いリプレイで見せる
- 仕組み:

## 捨てた案と理由

| 案 | 扱い | 理由 |
| --- | --- | --- |
| 手筋（5 筋・本手でなければ報酬半分・掴み） | 捨てて「筋目」に縮小 | 同時に読む情報が多すぎる。報酬半分は理由の見えない隠れた罰で攻略情報になる。掴みは「コミットを止められるのは受け流しだけ」に例外を開ける |
| 封殺（単独） | 「脱墨」に統合 | 精鋭が受け流しで怯まなくなるのは読む人への罰。並の連撃はほぼ 2 撃で軽い。条件として脱墨に吸収 |
| 残心（技として） | 捨てて「先受」に | 0.12 秒の窓は先行入力と見分けが付かず、上手さの瞬間にならない。名前は描画側に譲る |
| 逆襲 | 捨てて「立合」に | 起き際の全方位の払いは「怯ませたら下がる」を正解にし、ビルドの換金の時間を奪う。嫌われ敵の定番 |
| 墨入れ（武器に戦意を満たす） | L09 気色へ統合 | 同じ案。武器の絵は論理 16px で 4 段は読めないので 2 値 + 満ちた瞬間の明滅に絞って気色側で作る。名前「墨入れ」は L06 の予告の赤に譲る |
| 機先 | 「出端」に統合 | 数値の配分の変更だけで単独の案の重さが無い。出端で数が落ち着いてから決める（45 → 30） |
| 浮き崩し | 捨てて「突落」に | 空中の層は L の規模で、体験は浮かせコンボの縮小版。480x270 の群れの中で高さを影だけで読ませるのも厳しい |
| 陣拍子 | 捨てて「挫鋒」に | 陣全体を拍に揃えると同時の赤が増えて `telegraphCap` と衝突。音楽の時計とゲームの時計がずれる |
| 当て身 | 捨て（当初から） | encounter-core 4-4 の棘亀・章 4 の盾騎士と重なる |
| 鍔競 | 捨て（当初から） | 「コミットを止められるのは受け流しだけ」と衝突 |
| 受具（左手の受け流しの小物） | ビルドの視点へ回す | 左手 `offHand` の扱いと装備の層全体に関わる |
| 当て確 | 捨て（当初から） | 放出が振りの開始で消費される今の危険と役が重なる |
| 見切りの抜け | 捨て（当初から） | 見切り斬りを既定にしない決定に触れる |
| 群れ受け | 捨て（当初から） | 連携ずらし 0.35 秒の下ではほぼ起きない |
| 型の極意 | 捨て（当初から） | 出端 × 放出で作れる |
| 呼吸の資源 | 捨て（当初から） | 資源を増やすだけで気力・奥義の整理と逆行 |
| 敵の読み返し | 捨て（当初から） | 敵のフェイントになる。プレイヤーが誘う「虚実」とは別物 |

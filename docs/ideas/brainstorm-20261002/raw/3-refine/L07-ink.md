# L07 「墨」をシグネチャ・メカニクスに（改訂版）

対象: `raw/1-diverge/L07-ink.md` と批評 `raw/2-critique/L07-ink.md`。改訂で確かめたもの: `src/system/moments.ts`（`noteHitMoments` で終撃は**命中の瞬間**に積まれる。批評の指摘どおり）、`src/system/engagement.ts`（「交戦中」の唯一の判定がある）、`src/system/enemies.ts` の `enemyTelegraphShape`（line / laser / ring / cross / cone と、影・折れ線で見せる `null`）、`src/data/weaponForms.ts` の `RiposteSource`（応手の出どころ 9）、`src/system/elites.ts`（反射・残響・報復・灼熱・見切り・鎖縛・号令・強欲の働き）、`src/system/bossLibrarian.ts`（第 2 段階 = 禁書を読む 1.2 秒、止めると本を落とす）、`src/data/reforges.ts`（書の改鋳 = 速読 / 熟読）、`raw/1-diverge/L10-critic.md` 精鋭淘汰（残す 8 種と体の印）、`L06-world.md` 墨入れ・墨淵縁起・道行絵巻、`L12-social.md` 局面写し・二重記録・果たし状・預け仇・詰陣・手本影、`L15-identity.md` 押形（雅印を末に押す）。新しく使う名前（筆墨・墨法・破印・崩字・遺墨・変化図・落款譜・臨書・金泥・胡粉・濃墨）は src と GLOSSARY で 0 件を確かめた。

## この視点から見た今のゲームの課題（改訂）

- 「墨」はタイトル・最深の間の色・書の墨印・引き込みの渦にしか無い。トレーラーの最初の 5 秒は「和風の Hades」に見え、墨の手触りは書を持った人にしか届かない
- 予告は色 2 つ（黄 → 赤）に頼っていて、色覚の手当てが無い。「黄なら殴れ、赤なら受け流せ」は Tips にしか無い
- 受け流し・見切りの価値が数字に出ない（bot は狙わず、見切りはほぼ 0）。読みの報酬は「その場の 1 体」で閉じている。**しかも測る道具が無いので、読みに報酬を寄せる案を足しても調整できない**（批評の見落とし 4。改訂で最も重く受け止めた点）
- 精鋭の修飾子・陣の 6 割の素通り・見えない三重の時間の圧は、どれも「画面で読めない」問題
- 和の地下に洋物の怪物がいる理由が無い
- **墨を足す前に、黒と朱の意味の割り当てが無い**（批評の見落とし 1）。今でも朱は書の命中の落款（`tome-rework.md`）と予告の確定の両方にいる。墨の案を 1 本でも入れる前に表で決める必要がある

方針（改訂）: 核は変えない。「墨は振りの副産物として床に残り、読みで生き返る」。ただし入れる順を変える。**描画だけで決定性に触れない案（墨入れ・墨法・縁起）を先に出し、床の仕組み（墨痕・点睛）は祝福の系譜として試し、測る道具（変化図）と並べて育てる**。共通の文法に上げるかどうかは、`REPLAY_VERSION` の都合から EA の前に一度だけ決める。

## 入れる順の推奨

1. 墨法（色と形の表・床の層の予算）→ 墨入れ（予告の描き直し）: 描画だけ。トレーラーの「予告が筆で書かれる」絵はこれで撮れる
2. 書塚縁起の正典（文書だけ。ユーザーの判断を先にもらう）
3. 筆墨の系譜（墨痕・点睛を札 5 枚で試す）＋ 変化図の開発用（人の記録で点睛の値を測る）
4. 破印（精鋭淘汰と同じ段）・墨潮（時間の圧の整理）
5. 手応えがあれば: 墨痕・点睛を共通の文法へ上げる（EA の前）→ 字妖を一族へ広げる・書体・遺墨・臨書
6. 共有の器: 道行絵巻 → 落款譜

ユーザーに聞くこと: (a) 墨痕・点睛を共通の文法に上げるなら EA の前、上げないなら演出の案だけで EA に行く、の二択 (b) 書塚縁起の芯（異本・墨還り・書塚の語）(c) 左手の席を筆にするか（S1 問 5）(d) 書の改鋳「熟読」を写技に差し替えてよいか (e) 書だけは攻めの読み（読誦）でも点睛を起こせる型にするか

### 墨入れ
- 種別: 改善
- 領域: presentation
- 一言: 敵の予告を「淡墨の下絵 → 濃墨の墨入れ」として描き、黄 = 止められる、赤 = 確定を、色でなく線の質で伝える。L06 墨入れ・L09 柝・L11 濃淡予告と 1 本に束ねる。
- 仕組み:
  - **下絵の段（今の黄）**: 攻撃の届く先へ、掠れた細い淡墨の線が筆先から**伸びていく**。範囲の中は塗らない。線が途切れている = まだ止められる
  - **墨入れの段（今の赤）**: コミットの瞬間に一筆で引き切る濃墨の線になり、縁に朱の芯が入る。範囲の中は**斜線の網か、縁から 3 割までの滲み**で示し、下の油・水・草が見えるまま残す（批評 2-3。地形を読んで避ける・使うゲームなので塗りつぶさない）
  - 怯みで潰したときは下絵が**擦れて消え**、受け流したときは墨入れの線の**筆先が逸れて跳ねる**（L06 の演出をそのまま採る）
  - 暗い床（暗闇・深みの紫・反転層）では、下絵を**胡粉の白線**に切り替える。墨と胡粉は日本画の対なので、世界観を崩さずに沈みを防ぐ
  - 墨入れの瞬間に約 0.08 秒の擦過音を合成で鳴らす。画面外の射手の墨入れは左右に振って定位させる（encounter-core 10-4 の役割の予告音を具体化）
  - 色の組みの設定（色覚）は L11 の設計を取り込み、線の質の区別は設定に関係なく常に効く
  - 形ごとの描き方は line / laser / ring / cross / cone の 5 種と、影（落下点）・折れ線の 2 種の計 7 種に絞る（`enemyTelegraphShape` の分け方そのまま）
- なぜこのゲームで: 「黄なら殴れ、赤なら受け流せ」というこのゲームの核の一文を、**「下絵は消せる。墨は消えない」**という絵の比喩が Tips なしで教える。全部の敵の全部の段に予告があり、フェイントが無いので、1 つの文法で 110 体すべてが描ける。描画だけでロジック・決定性に触れない
- 着想元: 書道・日本画の下絵と墨入れ。弾幕ゲームの「予告線 → 実体化」は一般的だが、**「直せる / 直せない」の意味を線の質に割り当てた**点が違う
- 安っぽくならないための要点 / リスク:
  - 汎用の線に掠れのテクスチャを貼るだけで済ませない。下絵が「伸びていく」時間の表現（筆先の位置 = 予備動作の進み）があって初めて、待つ・殴るの判断に使える
  - `map:shot` に章ごとの「予告の見え方」の場面と、陣 200 体の中の場面を足して確かめる
  - 線の質と色の両方を持つので、色に頼っていた人の読みは変わらない
- 規模: M
- 議論で変わった点: 名前を L06 の「下絵 / 墨入れ」に揃え、範囲の塗りつぶしをやめて斜線か縁の滲みにし、入れる順を 3 番目から先頭へ移した。

### 墨法
- 種別: 基盤
- 領域: presentation
- 一言: 墨の案を 1 本でも入れる前に、黒・朱・藍・金と「閉じた面 / 開いた線 / 丸印 / 角印」の意味を 1 枚の表で決め、床に同時に描く層の上限を定める。
- 仕組み:
  - `docs/` に表を置き、描画の色と形はこの表からしか選ばない
    - **朱 = 敵の確定だけ**（墨入れの縁の芯）
    - 墨の**閉じた面** = 敵の範囲 / 墨の**開いた線**（飛白の掠れ）= 自分の墨痕
    - **藍** = 淵の墨（墨潮）/ **金泥** = 点睛の瞬間 / **胡粉の白** = 暗い床の上の下絵
    - 落款は形で分ける: **丸印** = 陣の決着 / **角印** = 作者（落款譜・雅印）
  - 今ある衝突を洗い出して直す: 書の命中の「朱の落款」（`tome-rework.md`）は朱を確定に取っておくため、墨の滲み + 金の細い縁などへ移す案を出してユーザーに聞く
  - **床の層の予算**: 1 タイルに同時に描く床の層は 3 種まで（地形・死骸・墨痕・淵の墨・予告の網・斬撃の軌跡の fx から、優先の順で上 3 つ）。予告は常に最上位
  - `map:shot` に「陣 200 体 + 墨痕 6 + 淵の先端 + 予告の墨入れ」の場面を足し、表に反する色が出ていないかを目で確かめる
- なぜこのゲームで: 墨入れ・墨痕・点睛・墨潮・道行絵巻・縁起はすべて黒と朱を使う。表が無いと、200 体の陣の中で床が読めなくなる。形で分ければ色覚に頼らない（墨入れの目的）とも揃う。`DESIGN_PRINCIPLES.md` の「予告は必ず読める」を、墨の側から守る規律
- 着想元: 地図の凡例・交通標識の形の文法（止まれ = 八角形）。色でなく形で意味を固定する考え方を、墨と印の語彙に移した
- 安っぽくならないための要点 / リスク:
  - 表を「推奨」にしない。新しい墨の演出を足すレシピ（`docs/recipes/`）に「墨法のどの行か」の欄を 1 行入れる
  - 朱を確定だけに絞ると、今の朱の演出のいくつかが変わる。変える物の一覧を先に出す
- 規模: S
- 議論で変わった点: 批評の見落とし 1・2 から新しく立てた案。原案は各案の中で色を決めていて、全体の割り当てが無かった。

### 墨痕
- 種別: 新要素
- 領域: combat
- 一言: 交戦中の終撃・放出の振りが、その当たり判定の形のまま床に墨の筆跡として残る。まず 10 番目の祝福の系譜「筆墨」の札として試し、手応えで全武器共通の文法へ上げる。
- 仕組み:
  - **振りで書く**（命中でなく）。終撃・放出になる振りの当たり判定の形（扇・箱・突きの線）が床に墨痕として残る。銃は着弾点から手前 1 タイル分だけ、砲の置いた弾は着弾の円。墨痕はそれ自体では何もしない
  - **濡れるのは交戦中に書いた筆だけ**（`engagement.ts` の交戦中の判定 + 起きている敵から約 8m 以内）。交戦の外で書いた筆は最初から乾いて灰になる。陣に入る前に空振りで 6 本仕込む「儀式」を消し、戦いの最中に空いた床へ書く判断だけを残す
  - 濡れ（黒く艶）→ 乾き（灰）→ 消える。濡れの長さは**型の終撃の頻度から決める表**（連刃のように段数の多い型は短く、重い型・長銃は長い）。乾きの色そのものが時計で、数字は出さない
  - 同時に床に残るのは最大 6 本（古い順に消える）。形は幾何（中心・向き・形）で state に持ち、タイルには書かない。`state.rng` は使わない
  - **試験の段 = 系譜「筆墨」の札 5 枚**: 加護「墨痕」（入口: 終撃・放出が墨痕を書く）/ 加護「点睛」（下の案）/ 摂理「墨色」（点睛で属性の墨が地形を変える）/ 研鑽「行書」（1.5 秒以内に続けて書いた墨痕の中心がつながる。書体の試し）/ 真髄「画竜」（点睛で起きた墨痕が 1 度だけ消えずに濡れへ戻る）。初めての探索の最初の出口では、筆墨を系譜の候補に必ず 1 つ並べる
  - **共通の文法に上げる段**: 実プレイと変化図で点睛の一瞬の値が出たら、墨痕・点睛を全武器の既定にし、系譜は「墨痕の文法を変える札」の 11 枚の系譜として残す
  - 判断: 終撃を「どこで出すか」が、その場の 1 体への火力から**「次の読みのために床へ何を置くか」**に変わる。通路の口・陣の大将の前・突進が来る線の上
- なぜこのゲームで: 型 15 はそれぞれ終撃・放出の形が違うので、同じ仕組みが 29 武器種で 29 通りの筆跡になり、武器を足すたびに書き味が増える。ラン内の要素はルール変更、という原則（系譜の段）にそのまま乗る
- 着想元: 大神の筆しらべ（描く）/ Splatoon（床を塗る）。描くための専用の入力を作らず、振りの副産物にした点と、塗った面積を強さにしない点が違う
- 安っぽくならないための要点 / リスク:
  - 墨痕は墨法の「開いた線」。黄・赤・朱を使わず、床の層の一番下で彩度を落とす
  - 6 本の上限を増やす性質・祝福を作らない
  - 刻印符の変形「軌跡」・性質「霜の轍」とは、「残るのは通常の終撃の振り」「単独では効かない」で分ける
  - 共通の文法に上げると state の核に触れ、`REPLAY_VERSION` が上がる。発売後に上げると記録・果たし状がすべて読めなくなるので、上げるなら EA の前（ユーザーに聞く a）
- 規模: M（系譜の段）/ L（共通の文法へ上げる段）
- 議論で変わった点: 命中でなく振りで書き、濡れは交戦中だけに絞り、銃は着弾の手前だけにし、寿命を型の表にし、最初は系譜「筆墨」で試す形に改めた（批評 2-1）。

### 点睛
- 種別: 新要素
- 領域: combat
- 一言: 受け流しか見切りを決めた瞬間、**読んだ攻撃の形と交わる**濡れた墨痕だけが金泥に光って生き返り、その形のままもう一度斬る。
- 仕組み:
  - 起点は受け流しの成功と見切りの 2 つだけ（応手の出どころ 9 のうち純粋な読みの 2 つ）。カウンターは含めない（狙わずに 60 秒 50 回以上出る）
  - **起きるのは、読んだ攻撃の予告の形と交わる墨痕だけ**。突進の線を受け流せばその線と交わる筆が、輪の叩きつけを見切れば輪の中の筆が起きる。予告が `null` の攻撃は実際の当たり判定（落下の影の円・二度突きの折れ線）で交わりを取る。射手の弾は射手から自分までの弾道の線で取る。画面の反対で雑魚の一撃を受け流して大将の前の仕込みを起爆する、は起きない
  - 威力と怯み値は**元の振りの行動ごとの係数 × 0.5**。新しい係数を作らず、書付の計算式にも「点睛 = 元の段 × 0.5」と出せる。交わる本数は実際は 1〜3 本
  - **墨色**（旧案を吸収）: 点睛の瞬間、墨痕に乗った属性が**既にある地形だけ**を変える。炎 = 油・草に火 / 冷気 = 水たまりが氷床 / 雷 = つながった水へ導電。無から地形を作らない（毒沼を書く、は捨てた）。自分の書いた氷床で滑る危険は残す
  - 演出: 墨痕が金泥に光る → 筆を払う擦過音 → 複数の当たりを 1 回にまとめた一拍のヒットストップ。エフェクトの生成器（`scripts/fx/`）で「墨痕が起きる」を形ごとに作る
  - 判断: 3 本の墨痕を陣の前に置き、大将の突進の予告（下絵が伸びる向き）を見て、その線の上に筆があるかを確かめてから受け流しを待つ。避けるだけでは何も起きない
  - 書の特権の案（ユーザーに聞く e）: 書だけは、墨印を読む（読誦）ときも読誦の円と交わる墨痕が起きる。守りの読みでなく**攻めの読み**で床を起こせる唯一の型にし、全武器が墨を書く中で書の顔を立てる
- なぜこのゲームで: 「予備動作は攻めの合図」の最大の表現。陣（八陣）は形のある集団なので、墨痕と予告の形と陣形の幾何が 3 つとも噛み合う。共通の瞬間「応手」の語を食う祝福・共鳴の糧にもなる
- 着想元: 画竜点睛。仕組みは「仕込んで起爆」（PoE の地雷・Hades の Cast）に近いが、**起爆の鍵が敵の攻撃の読みで、しかも読んだ攻撃の形が起爆の範囲を決める**点が違う
- 安っぽくならないための要点 / リスク:
  - 光る色は朱にしない（墨法: 朱は確定だけ）
  - 受け流しを外したときの硬直 0.35 秒は据え置く
  - bot は受け流しを狙わないので、`probe.md` では点睛は 0 回と出る。**変化図（開発用）か bot の受け流しの方針と同じ段で入れ、測れないまま数値を決めない**
- 規模: M（系譜の段、墨痕と同じ段で）
- 議論で変わった点: 「濡れた墨痕すべて」を「読んだ攻撃の形と交わる墨痕だけ」に改め、光を朱から金泥へ、墨色を独立の案から点睛の 1 行（既存の地形の変換だけ）へ吸収し、墨脈の代わりに書の特権を問いとして足した（批評 2-2・2-5・見落とし 8）。

### 変化図
- 種別: 基盤
- 領域: platform
- 一言: 記録の中の 1 つの読み（受け流し・見切り・点睛）を「しなかった」に差し替えて先を再計算し、その読みが何を変えたかを測る。bot が読まない穴を、人の記録と決定性で埋める。（批評の派生案を採る）
- 仕組み:
  - **開発用（先に作る）**: 開発者の実プレイの記録を再生し、応手のイベントごとに、その入力を「押さない」か「ダッシュ」に差し替えた枝を作る。枝を 5 秒（300 フレーム）進めて、被弾・与えた怯み・撃破・陣の決着までの秒を元の枝と比べ、`probe.md` の新しい節「読みの値」に型ごとに並べる
  - 1 本の枝 ≒ 0.15 秒。頭から再生する素朴な形でも開発用なら回る。L12 局面写しが入れば、そこから枝を切って 1 探索 50 回の読みで約 8 秒
  - **プレイヤー側（後段）**: 探索の終わりに、差し替えで結果が最も大きく変わった読みを 1〜3 つ選び、道行絵巻の上に圏点で印し、その 2 秒を見返せる。数字は出さない
- なぜこのゲームで: 同じ seed と同じ入力で同じ結果になるからこそ、「その 1 手だけを変えた世界」を正確に作れる。点睛・写技・破印・一筆は読みに報酬を寄せる案で、今の QA はそれを 0 と測る。この道具が無いまま積むと調整できない
- 着想元: チェスの解析（好手・悪手の印）。エンジンの探索はせず、1 手の切除だけにした。実験の対照群の考え方
- 安っぽくならないための要点 / リスク:
  - 窓は 5 秒に限る（長いと分岐後の差が混沌になる）
  - プレイヤーに「この受け流しの価値 +38」のような数値を見せない（単一指標）
  - 記録が開発者の手癖に偏る。型ごとに 3 本以上の記録を揃える
- 規模: M（開発用）/ L（局面写しとプレイヤー側まで）
- 議論で変わった点: 批評の派生案。点睛を入れる前提条件として推しの上位に置いた。

### 破印
- 種別: 新要素
- 領域: encounter
- 一言: 精鋭の修飾子は体の印で見せ、印ごとに「それを割る既存の動詞」を 1 つ結ぶ。割ればその働きが撃破まで止まる。L10 精鋭淘汰と合流。
- 仕組み:
  - 精鋭淘汰で残す 8 種に、名札でなく体の印を付け、割る動詞を 1 対 1 で結ぶ
    - 反射（背の鏡片）→ **背面の一撃**
    - 号令（旗）→ **怯み中の終撃**
    - 見切り（溜め・スキルで跳ぶ）→ **カウンター**（予備動作の黄に当てる）
    - 残響（攻撃を 1 回繰り返す）→ 1 撃目の**受け流し**（写しの 2 撃目が出なくなる）
    - 報復（怯むと輪の衝撃波）→ その輪の**見切り**
    - 鎖縛（光の鎖で結ばれる）→ **鎖の線を終撃で断つ**
    - 灼熱（通った跡が燃える）→ **水たまり・氷床の上で怯ませる**
    - 強欲（拾って逃げる）→ **壁叩きつけ・引き寄せ**で逃げ足を止める
  - 割れた印は墨入れの演出で砕け、浮き文字は体言止めの「破印」1 語だけ。止まるのは撃破まで
  - 判断: 陣の中の精鋭を見て「この敵にはこの手」を選ぶ。反射の精鋭の背へ回るか、旗の大将を怯ませて終撃で陣全体の一斉の予備動作を止めるか
- なぜこのゲームで: 割り込みの手段 9 つに序列が無い（S1 問 2）問題に、**敵の側から動詞の語彙表を作る**答え。精鋭が「この手を覚える教材」になる。怯み・終撃・応手・地形・壁叩きつけという既存の語だけで解け、新しい操作は要らない。陣では精鋭の席が陣形の中に決まっているので、どこから崩すかの判断の軸になる
- 着想元: Monster Hunter の部位破壊、Diablo III の精鋭に地面の見た目を付けた経緯。壊す対象を「その能力の象徴」にし、壊し方を能力ごとに変えた
- 安っぽくならないための要点 / リスク:
  - 印の絵は敵の描き直しの段と同時に行う（密度 1 の敵の上に乗る）
  - 動詞の対応は Tips ノートの「精鋭」の頁に置き、UI に説明文を書かない。図鑑で割った回数に応じて頁が埋まる
  - 動詞が 8 つとも違うのが価値。同じ動詞を 2 種に使い回さない
- 規模: M
- 議論で変わった点: 頭上の縦書きの字をやめて L10 の体の印にし、「上から 1 字」の順の規則を捨てて印ごとの動詞に替え、名前を抹字から破印にした（批評 2-9）。

### 書塚縁起
- 種別: 基盤
- 領域: world
- 一言: 墨淵は捨てられた書き物が沈む淵、洋物の怪物は沈んだ異国の書の写し「異本」。この芯を 1 つ決め、死・拠点・敵・最深の主を墨で語り直す。L06 墨淵縁起と合流。
- 仕組み:
  - 骨組みは L06 の正典（「写す」を世界の法則にする・三層の明かし順・語りの禁則）。中身を L07 から入れる
    - **墨淵** = 門前町の寺が守る書塚（経塚）の底。経文も異国の書も帳簿も恋文も、捨てられた書き物は淵に沈んで墨に還り、淵の墨は沈んだ物語を写して吐き出す
    - **敵** = 異本。スライム・ゴブリン・盾騎士は沈んだ異国の物語の写し。鏡の騎士（写す騎士）と第三の顔（写された自分）も同じ線で読める。図鑑に出どころを 1 行
    - **死** = 墨還り。倒れた敵は墨溜りに溶けて流れる（旧案「墨継」の見た目だけを残す。`Corpse` の位置と寿命はそのまま）。プレイヤーも墨に溶け、門前町の井戸から上がる。井戸は硯の海として描き、寄進で育つ景色は海が深くなる絵にする
    - **最深の主** = 淵に沈んだ最初の書。踏破は「淵の物語に落款を押して閉じる」こと
  - 縁起の側で落款を使うのは**踏破の 1 回だけ**（墨法の落款の意味を溢れさせない）
  - 語り部の 1 行の台詞を、到達した章と図鑑の埋まりから導いた縁起の断片にする（新しい保存キーは持たない）
- なぜこのゲームで: 和の入口と洋物の敵の食い違い（S5 3-5・S6 3-1）を、**敵を 1 体も描き直さずに設定の強みへ裏返す**。墨入れ（下絵 = 淵が書きかけた物）・墨痕・墨潮・字妖・道行絵巻のすべてに「なぜ墨なのか」の理由を与える。Steam のストアの 1 段落目を書ける芯
- 着想元: 経塚（平安期の埋経）・寺社の縁起絵巻。Hades の台詞の量では作らず、図鑑の 1 行・死の絵・井戸の景色・語り部の 4 か所に絞る
- 安っぽくならないための要点 / リスク:
  - 本編を止める会話は作らない
  - 「異本」は敵名の接頭辞にしない。図鑑の分類と文だけ
  - 新しい語（墨還り・異本・書塚）は GLOSSARY に足す前にユーザーに聞く（問い b）。英語圏の訳（L11 訳語台帳）と同時に決める
- 規模: M
- 議論で変わった点: L06 の正典を骨組みにして合流し、落款を踏破の 1 回に絞り、墨継の見た目と鏡の騎士・第三の顔を異本の線に入れた。

### 墨潮
- 種別: 整理・削減
- 領域: run
- 一言: 死神・長居の代償・陣の歩き出しの三重の時間の圧を、「淵の藍い墨が床に満ちてくる」1 つの見える仕組みにまとめる。陣を決着させた所は満ちるのが遅くなる。
- 仕組み:
  - 階に着くと、穴と行き止まりの口から**淵の墨**が床へ染み出す。広がりは決定的なタイル単位の塗りつぶしで、先端のタイルの集合だけを毎秒進める。地図と画面の両方に常に見え、残り秒の数字は出さない
  - 淵の墨に触れた眠った陣は起きて歩き出す（陣の歩き出しの置き換え）。淵の墨の上では、バイオームごとの長居の代償（影の自分・崩落）が起きる。「潮」はこの仕組みに吸収する
  - **陣を決着させると、その陣の範囲に丸印の落款が押され、そこは満ちるのが 3 倍遅くなる**（止めない。墨は回り込む）
  - **死神は、階の歩ける床の 6 割が満ちたら**、いちばん近い淵の墨から立ち上がる。出口に届くかどうかでは決めない。出口の周りに堰を作って死神を永遠に来させない抜け穴を塞ぐ
  - 淵の墨は地形の層 10 に足さない（働くのは陣の起床と長居の代償だけ）。描くのは先端の線を強く、後ろは薄い藍の色調だけにし、戦いの床を塗らない
  - 判断: 急ぐ人は墨より先に主へ走る。掃討する人は墨の来る側の陣から倒して時間を買う。**陣と時間の交換が地図の上の形として見える**
- なぜこのゲームで: 陣の 6 割の素通りと、残り 30 秒まで見えない締め切りに同時に答える。L10 漏刻（時計）・L06 朱入れ（額縁の線）と同じ問題への答えだが、地図の形と交換の規則で**判断を生むのはこれだけ**なので、3 つから選ぶならこれを推す（漏刻の「常時の表示」は地図の満ち具合が担う）。塗りつぶしは seed から決まるので、今日の挑戦では全員が同じ潮を相手にし、影法師（L12）と並べると「相手がどこから陣を倒したか」が見える。「淵が満ちる」はゲーム名そのものの体験
- 着想元: Spelunky の幽霊・Risk of Rain の難度の時計、Into the Breach の盤面の見える脅威。見えない時間を地形として見せ、「陣を倒すと遅れる」交換を足した
- 安っぽくならないための要点 / リスク:
  - 淵の墨は墨法の藍、縁に泡の点の動きで、自分の墨痕（開いた黒の線）と形でも分ける
  - 広い地図（基準の 3.5〜5 倍）で塗りつぶしを毎ステップ全体にかけない
  - 死神の 5 変種は墨から立つ姿として残す。「死神は倒せない、長居するな」は変えない
  - 6 割の閾値・満ちる速さ・遅れの倍率は balance の JSON に置き、章で速さを変えてランの弧を墨で語る
- 規模: L
- 議論で変わった点: 落款を「止める」から「3 倍遅らせる」に、死神の条件を「出口に届く」から「床の 6 割」に改め、淵の墨を地形の層から外した（批評 2-11）。

### 字妖
- 種別: 新要素
- 領域: encounter
- 一言: 生きた漢字の敵。攻撃は自分の筆画を筆順どおりに放つことで、画を折ると別の字に崩れる。初手は図書館の司書の禁書から抜け出る 4 字に絞る。
- 仕組み:
  - **初手（M）**: 図書館の司書の第 2 段階「禁書を読む」（1.2 秒、沈黙・怯みで止めると本を落とす）に結ぶ。**読みを止め損ねると、禁書から字が 1 体抜け出る**。止めれば出ない。既存の「止めろ」の判断に、止め損ねの代償の顔が付く
    - 字は 4 つ: 「一」（横一線の薙ぎ）/「川」（縦 3 本が左から順に落ちる）/「口」（4 画で周りに箱を閉じる。4 画目の前に抜けないと閉じ込められる）/「大」（横画の薙ぎ + 2 本の払い）
    - 次に来る画の位置は**下絵**で見え、引く瞬間に墨入れになる（墨入れの文法そのまま）
    - **崩字**は 1 組だけ: 「大」の横画を怯みで折ると「人」に崩れ、薙ぎを失う
  - **広げる段（L → XL）**: 手応えがあれば章 3〜4 の一族へ（12〜16 字、どれも画の形が攻撃の形として読める字）。熟語の合体は最後。合体は秒の時計で起こさず、**隣り合った 2 字の間に下絵の線が引かれ、それが墨入れになると合体**、という予告の文法に乗せる。合体の前に片方を崩すか倒すかが判断になる
- なぜこのゲームで: 筆順は決まっているので、フェイント無しで「読みを覚える」遊びになる。日本語を知らない人も形として覚えられる。章 3〜4 に新しい顔がいない問題に、廃城・深みの金の文字の敷石と地続きの顔で答える。書塚縁起では「写しの元の文字そのもの」。ストアの GIF で一目で分かる、今回の敵案でいちばん売れる顔
- 着想元: 大神の筆しらべ・Scribblenauts・Typing of the Dead。どれも「文字を入力する」遊びだが、ここでは**書き順が敵の技の順番**で、入力は手動のアクションのまま
- 安っぽくならないための要点 / リスク:
  - 画ごとの怯み値・崩字の表・合体の判定は普通の敵の数倍の手間。初手で 4 字・崩字 1 組を超えない
  - 字の絵は題字の生成器（`scripts/title/gen-logo.mjs`）の系統で点字を作る。字形の元にフォントを使うなら帰属を CREDITS で整理する
  - 図鑑に字の読みと意味を添える（英語圏）
- 規模: M（初手）/ XL（一族と合体まで）
- 議論で変わった点: XL の一族から始めるのをやめ、司書の禁書から 4 字が抜け出る初手に絞り、合体を秒の時計から下絵 → 墨入れの予告に替えた（批評 2-10）。抜け出る条件を「読みを止め損ねたとき」にして司書の既存の判断に結んだのは改訂で足した点。

### 一筆
- 種別: 整理・削減
- 領域: encounter
- 一言: スコアにしか効かないコンボ倍率「x1.2」と `state.score` を外し、被弾せず陣を散らかさずに畳んだ決着を「一筆」と呼ぶ。見ていた周りの陣が怖じる。
- 仕組み:
  - HUD の「N ヒット x1.2」と `state.score` を外す（L09・S5 と同じ結論）
  - 一筆の条件: 陣への先制から最後の 1 体まで、**被弾しない**、かつ**その陣の生きた敵のうち、自分の型の届く範囲（近接は振りの届き + 踏み込み、銃は射程）から 2 秒以上外れ続けた者がいない**。陣を散らかさず畳んだかを測る。連打では満たせない
  - 画面の端に、筆の線が伸びて掠れて途切れる絵だけを出し、数は出さない
  - 報酬: 一筆で決着すると、近くの起きている陣が**怖じ**、その陣の最初の 1 手の予備動作が 1.3 倍に伸びる（先制を取りやすい）。群勢を下げると、L10 決着三様の「敗走 = 主の後詰」で罰にもなるので、そちらは使わない
  - 陣の決着の種類（全滅・大将撃破・敗走）に「一筆」が並び、道行絵巻では専用の落款になる
- なぜこのゲームで: 陣・予備動作という既存のルールに上手さが返る。スコアを消したら結末を何で語るかの答えの一部。「一筆書き」の比喩がそのまま判定の規則
- 着想元: Devil May Cry のスタイルランク・Hades の無傷の部屋。点数でも報酬でもなく、**次の陣の先制の取りやすさ**に変えた
- 安っぽくならないための要点 / リスク:
  - 銭や数値の倍を付けない
  - 遠距離の型では「届く範囲」が広すぎて条件が甘くなる。射程でなく有効な距離（減衰の手前）で取る
  - 変化図で、一筆が狙われているか（狙った人と偶然の人の差）を見る
- 規模: M
- 議論で変わった点: 判定を「入力が 1.5 秒途切れない」から「陣を届く範囲から散らかさない」に改め、報酬を群勢の低下から「怖じ = 最初の予備動作が長い」に替えた（批評 2-12）。

### 写技
- 種別: 拡張
- 領域: combat
- 一言: 書を持って受け流しか見切りを決めると、その敵の攻撃の予告の形が頁に写る。次の無詠唱が、写した形の墨の術になって照準へ撃ち返される。
- 仕組み:
  - 書の改鋳の 1 つ。今の「熟読」（術が満ちると気力）と差し替えるか、3 つ目の改鋳にするかはユーザーに聞く（問い d）
  - 受け流し・見切りに成功すると、その攻撃の予告の形（`enemyTelegraphShape` の 5 種）を頁に 1 つ写す。頁は 1 枚で上書き
  - 右 1 の無詠唱が写した形の術として出る。**置き直しの規則**: line・laser・cone は自分から照準へ、ring・cross は照準の点を中心に。照準はマウスなので手動の原則が保たれる
  - 威力は書の霊力の係数。敵の攻撃の数値は使わず、形と範囲だけを借りる
  - 予告が `null` の攻撃（落下の影・二度突きの折れ線）は写せない。図鑑の予告の図解に「写せない」と出るのは、それ自体が情報になる
  - 判断: **どの攻撃を受け流すか**の選り好みが生まれる。光線眼の長い線を写したいから、目の前の猪の突進は受け流さずに避ける
- なぜこのゲームで: 全部の敵の攻撃が予告の形をデータで持つので、110 体の攻撃がそのまま写せる辞書になり、敵ごとの手作業が要らない。図鑑の予告の図解と同じ語彙を使う。鏡の騎士（自分を写す敵）と対になり、書塚縁起の「写す」の法則をプレイヤーの側で体現する
- 着想元: 星のカービィのコピー能力、Sekiro の見切り。奪うのは技でなく形で、威力は自分の数値に置き換える。強い敵ほど強い技、にはしない
- 安っぽくならないための要点 / リスク:
  - 書は今日（`1d93ac29`・`c8b70836`）左の墨文字と構えを改めたばかり。**人が遊んで書の手触りが固まってから**入れる
  - 絵は墨文字の筆字と同じ生成器の語彙で描く
- 規模: M
- 議論で変わった点: 写した形の置き直しの規則と、`null` の予告は写せない規則を足し、入れる時期を書の改訂が遊ばれた後へ下げた（批評 2-8）。

### 落款譜
- 種別: 拡張
- 領域: platform
- 一言: 書き出した道行絵巻の隅に角印を押す。印の枠は遊んだ履歴が彫る雅印、印面は seed・縛り・版・結果を篆刻に符号化した物で、画像を落とし込めば同じ挑戦がすぐ始まる。（批評の派生案に、原案の雅印を合わせる）
- 仕組み:
  - **印の枠 = 雅印**（原案）: 新しい保存キーを持たず、位階・踏破の回数・流儀ごとの探索の数から導く純関数で彫る。枠の形は位階、中央の 1 字はいちばん使った流儀、朱の濃さは踏破の回数、欠けは深みの到達点。選べる飾りにしない
  - **印面 = 記録**（批評の派生案）: seed・縛り・流儀・版・結果のハッシュ（約 100 ビット）を、誤り訂正付きの 16×16 の篆刻の線に符号化する。PNG のメタデータの塊には足跡か入力列を入れる
  - 読み込みは Electron へのドラッグ & ドロップかクリップボード。メタデータが残っていれば再生・影法師・果たし状をすぐ始め、SNS の再圧縮で落ちていても印面から「同じ条件で挑む」は始められる。再生の結果が印面のハッシュと合えば「照合済み」
  - L15 押形（遺物の書き出し）の末の落款にも同じ印を押す
- なぜこのゲームで: プレイヤーが実際に共有する単位はコードでなくスクリーンショット。決定性のおかげで、印 1 つから同じ挑戦を作り直せ、サーバが要らない。枠が「誰が」、印面が「どの探索か」を語るので、1 つの印に 2 つの意味を重ねても墨法の「角印 = 作者」から外れない
- 着想元: PICO-8 のカートリッジ（PNG の中のゲーム）、Mario Maker のコース ID、QR コード、書画の雅印。QR の見た目を篆刻の朱印に置き換え、作者印として自然に置いた
- 安っぽくならないための要点 / リスク:
  - 印面が QR のノイズに見えたら台無し。篆刻の字の線を 2 値のモジュールに合わせる設計をドット絵の段で詰める
  - X・Discord・Steam のスクリーンショットでメタデータと印がどう壊れるかは**未確認**。実装の前に確かめる
  - 雅印の朱は墨法の例外（作者印の朱）になる。角印という形で確定の朱と分ける
- 規模: M
- 議論で変わった点: 単独では押す場所が無かった雅印を、批評の派生案「落款譜」の印の枠として合わせ、1 案にした。

### 遺墨
- 種別: 新要素
- 領域: run
- 一言: 力尽きた誰かが最期に床へ残した濡れた墨痕が、同じ種か同じ仇に挑む他人の探索に「乾かない筆跡」として残る。起こせるのは受け取った人の読みだけ。（批評の派生案を採る）
- 仕組み:
  - 力尽きた瞬間の濡れた墨痕（最大 6 本。形・向き・属性の色味）を記録の末尾に数十バイトで書く
  - L12 果たし状（同じ seed）では同じ位置にそのまま置き、預け仇（別の seed）では仇の陣の中心からの相対位置で置く
  - 受け手の探索では、遺墨はその陣が起きるまで乾かない。点睛で 1 回だけ起き、消える。威力は受け手の終撃の係数で決め直す（送り手の強さを渡さない）
  - `RunSetup` に入れるので、受け手のリプレイも決定的に閉じる。今日の挑戦の記録には混ぜない
  - 判断: 床を見れば「この人は大将の突進の線に 3 本置いて、それでも死んだ」が読める。その遺墨を自分の受け流しで生かしに行くか、同じ死に方を避けて回り込むか
- なぜこのゲームで: 地図が seed で同じで、墨痕が床の幾何として state にある。この 2 つが揃って初めて、他人の最期を形のまま床に戻せる。点睛は読みでしか起きないので、他人の遺した物がただの火力の贈り物にならない
- 着想元: Dark Souls の血痕（情報）、Death Stranding の置き土産（道具）。そのどちらでもなく「起爆されなかった仕込み」を渡し、起こす鍵を受け手の読みにした
- 安っぽくならないための要点 / リスク:
  - 1 探索に遺墨は 1 組まで。真髄「画竜」などの延長は乗らない
  - 墨痕・点睛が共通の文法に上がってから（系譜の段では受け手が系譜を取らないと起こせない）
  - 見た目は自分の墨痕と分ける（輪郭に送り手の雅印の欠片）
- 規模: M
- 議論で変わった点: 原案で落とした「先人の墨溜り」の理由（オンライン無しでは自分の跡だけ）は誤りだった、という批評に納得し、果たし状・預け仇の上に乗る形で復活させた。

### 臨書
- 種別: 拡張
- 領域: ux
- 一言: 稽古場で手本の記録と並走するとき、その人が置いた墨痕を、置かれる 1 秒前から淡い下絵で床に見せる。真似るのは動きでなく「どこに書いて、どこで読んだか」。（批評の派生案を採る）
- 仕組み:
  - L12 手本影（型ごとの手本）と詰陣の局面の上に乗せる。手本の記録を先に再生し、墨痕・点睛のイベントを時刻つきで取り出しておく。描くだけで state には書かない
  - 手本の墨痕は置かれる 1 秒前から下絵で床に現れ、自分の墨痕が半分以上重なると下絵が墨で満ちる。点数は出さず、満ちる・満ちないの 2 段だけ
  - 終わると、道行絵巻の上に手本の筆（金泥）と自分の筆（墨）を重ねて見せる
  - 判断: 「受け流しの前に、なぜあの人は通路の口に書いたのか」を体で覚える
- なぜこのゲームで: 入力のゴーストは「どう動いたか」しか見せない。墨痕は読みの前の準備そのものなので、上手い人の**考え**が床に残る。書道の臨書が、比喩でなく仕組みの名前になる。下絵の語彙は墨入れと共有し、新しい表現を足さない
- 着想元: 書道の臨書、レースゲームの走行ライン、音楽ゲームの譜面の先読み。時刻の先読みでなく「配置の先読み」にした
- 安っぽくならないための要点 / リスク:
  - 本番の探索では出さない。稽古場と詰陣だけ
  - 手本の下絵は敵の予告の下絵と混同しうる。墨法で「開いた線 + 金泥の縁」と決め、閉じた面を使わない
  - 墨痕が共通の文法に上がってから
- 規模: M
- 議論で変わった点: 批評の派生案。下絵が敵の予告と混ざる危険を見て、墨法の形の規則を足した。

### 書体
- 種別: 新要素
- 領域: build
- 一言: 空いている左手の席に「筆」を持つ。筆は攻撃せず、書体で「墨痕が何で起きるか」の文法を変える。
- 仕組み:
  - 左手（`offHand`、今は席だけ）の遺物は筆。地金を持つ永続の遺物で、implicit として書体を 1 つ持つ
    - **楷書**: 点睛で起きるのは、読んだ攻撃の形に**完全に含まれる**墨痕だけ（厳しい）。その代わり起きた墨痕は 2 度斬る
    - **行書**: 1.5 秒以内に続けて書いた墨痕の中心がつながり、つなぎの線も墨痕になる。陣を囲う線が引ける
    - **篆書**（名のある遺物だけ）: 床に書かず、終撃の当たった敵の足元に丸い印を押す。敵が動くと印も動き、その敵が読んだ攻撃に交わると起きる
  - 筆の性質は「墨痕」の語（本数・寿命・起点の条件）だけ。**能力値の性質を付けない**（付けると左手が数値の副手になり、BiS の部位が 1 つ増える）
  - 先に系譜「筆墨」の研鑽「行書」で手触りを試し、良ければ筆へ移す
  - 判断: 同じ右手の武器でも、左手の筆で「どこに書き、何で起こすか」の考え方が変わる。大剣 × 楷書は重い一点の読み、槍 × 行書は長い線で陣を囲う
- なぜこのゲームで: 「右手 1 本が攻撃の全部を決める」設計を崩さずに左手を埋める。攻撃でなく墨の文法を持たせるので、二刀や盾の二重の攻撃にならない
- 着想元: 書道の五体。Diablo・PoE の副手（盾・矢筒）は数値の副手だが、ここでは副手がルールの文法を持つ
- 安っぽくならないための要点 / リスク:
  - 左手の席の使い道はユーザーの判断が要る（S1 問 5、問い c）。星座を隠した経緯もある
  - 書体は 3 つより増やさない。増やすのは筆の性質（墨痕の語）の側
  - 共鳴の「墨痕」の語が汎用の系統として自動で立たないよう、源は筆と筆墨の系譜だけに絞る
  - 墨痕・点睛が共通の文法に上がってからの段
- 規模: L
- 議論で変わった点: 書体を「何を書くか」から「何で起きるか」の文法に改め、霜の轍・軌跡と重なる草書を捨て、楷書の 2 度斬りに厳しい条件を付け、筆に能力値の性質を付けないと決めた（批評 2-7）。

## 捨てた案と理由

| 案 | 判断 | 理由 |
| --- | --- | --- |
| 墨継（墨溜りを通ると筆が濃墨になる） | 捨てる（見た目だけ書塚縁起の墨還りへ） | 近接は倒した所に立っているので狙わずに継げる。カウンターと同じ「狙わずに出る」病気で、「次の 2 本が濃墨」は画面に出しにくい隠れた状態。批評に納得。濃墨の「消えずにもう一度」は真髄「画竜」に移した |
| 墨脈（読誦が墨痕を伝う・墨流し） | 今は捨てる | 書は今日改めたばかりで、人が遊ぶ前に墨印 → 読誦 → 墨脈の 3 層目を積むのは順が逆。墨流しは導電と役が重なり、反応のイベントのあふれを悪化させる。書の顔は点睛の「攻めの読み」の問いで立てる |
| 墨色（独立の案として） | 点睛へ吸収 | 独立させると終撃のたびに地形が書ける方向へ膨らむ。点睛の瞬間に既存の地形を変えるだけの 1 行にした |
| 緑青で毒沼を書く・朱墨 / 青墨 / 金墨の名 | 捨てる | 無から地形を作ると床がすぐ飽和し、どの系譜でも同じ遊びになる。朱・金は墨法で別の意味に取ってある |
| 抹字の頭上の縦書きの字・「上から 1 字」の順 | 捨てる（破印へ） | 200 体の陣の中では読めず、英語圏に意味が届かない。順の規則に根拠が無い。体の印と印ごとの動詞に替えた |
| 雅印（独立の案として） | 落款譜へ合流 | 単独では押す場所が無く、落款の意味が溢れる。落款譜の角印の枠にした |
| 墨痕を最初から全武器共通にする | 段を分ける | 測れないまま state の核に触れるのは危うい。系譜で試し、EA の前に一度だけ上げるかを決める |
| 点睛で濡れた墨痕がすべて起きる | 捨てる | 読んだ相手と報われる場所が切れ、画面の反対の雑魚の受け流しで大将の陣が斬れる。交わる墨痕だけにした |
| 点睛の光を朱にする | 捨てる | 朱は敵の確定だけに取っておく（墨法） |
| 書体の草書（ダッシュの道に墨痕） | 捨てる | 性質「霜の轍」・刻印符「軌跡」と重なる |
| 一筆の「入力が 1.5 秒途切れない」 | 捨てる | 連打で満たせ、一筆が「無傷の陣」の言い換えになる |
| 一筆の報酬「周りの陣の群勢が下がる」 | 捨てる | L10 決着三様の敗走 = 主の後詰と組むと罰にもなる |
| 墨潮の「決着した範囲には墨が入らない」「出口に届くと死神」 | 捨てる | 出口の周りに堰を作れば死神が永遠に来ない抜け穴になる |
| 字妖を XL の一族から始める | 捨てる | 普通の敵 10 体分の手間を、手応えを見る前に払うことになる |
| 道行絵巻を入力列から描く | 捨てる | `REPLAY_VERSION` が上がった瞬間に昔の巻物が描けなくなる。二重記録の足跡の層から描く |
| 原案の「惜しくも落とした案」（渇筆・硯の墨選び・墨の分身・気力の呼び替え・面積の陣取り・煤・筆圧・処刑の落款・画面全体の水墨化・自由描画の筆しらべ・筆順で門柱を折る最深の主） | 据え置き | 批評も理由に同意。先人の墨溜りだけは誤りを認めて遺墨として復活させた |

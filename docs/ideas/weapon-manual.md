# 武器指南書（2026-10-02 実装）

Tips ノートの「武器種」タブを独立させた画面。武器種ごとに特色・型と戦意・技の一覧を載せ、技を選ぶと横の窓で**本物の動き**が流れる。

## 1. 何が載るか

| 節 | 中身 | 出どころ |
| --- | --- | --- |
| 見出し | 武器種名・型・重さ・左右の段数 | `MovesetDef`・`FormDef` |
| 特色 | 持ち味の一文（`data/weaponFeatures.ts` の `MOVESET_FEATURE`。押し方は書かない。`MovesetDef.desc` は押し方を含む武器掛けの一言なので使わない）・間合い・参照ステータス・固有の仕組み（引き寄せ・敵弾払い・弾の性質…） | `meta/weaponText.ts` の `featureText` |
| 型と戦意 | 型・戦意の溜まり方と放ち方・応手 | `formText` |
| 技の一覧 | 連撃 / 溜め攻撃 / コンボ派生（右の段も段カウンタを左右で共有する「押し方の列で出る技」なので同じ見出しに、右の段 → 名前付きの派生の順）/ ダッシュ攻撃 / 戦意の放出 / 奥義 3 本 | `meta/weaponManual.ts` の `weaponManualPage` |

手書きの表は持たない。武器種・段・派生・奥義を足せば自動で載る（網羅テスト `meta/weaponManual.test.ts`）。

技 1 つは「性質の札」（形・間合い・多段・踏み込み・無敵・引き寄せ・敵弾払い・付与・重い一撃・終撃・再使用）を持つ。単一指標（威力の数字）は出さない（`docs/DESIGN_PRINCIPLES.md`）。

## 2. 実演の仕組み

- **箱庭**: 拠点と同じ箱庭の state（`system/sandbox.ts` の `createSandboxState`）を、論理画面と同じ広さの稽古場（`map/demoArena.ts`）に作る。武器種の一番早い器を借りて持たせ、倒れない木人を正面に立てる。1 ステップは `simulateSandbox(…, rules = true)`（拠点の分に地形・統一ルール・弾の歯止めを足したもの。武器種の固有効果と放出の上乗せが本編と同じに出る）
- **台本**: 技は入力の台本 `DemoScript`（`tap` / `hold` / `holdUntil` / `dash` / `special` / `wait` / `waitUntil`）を持つ。`system/manualDemo.ts` の手が台本を本物の `FrameInput` にして流す。**押す瞬間は state から読む**（`readyForPress`: 振りの戻りか振っていない・先行入力や予約中の派生が無い・弾の段の後の間が明けた。銃の家系の左は振り終えてから）ので、段の秒数が JSON で変わっても台本を直さなくてよい
- **表示の札は台本から**: `cueToken` が手を「左」「右」「ダッシュ」「奥義」（長押しは印）にする。待ちの手と見せるだけの手（`hidden`。持続の奥義の間の連撃）は札にしない。窓の手の進み（`demoCueIndex`）で今の札が光り、長押しは押している割合の帯が伸びる
- **下ごしらえ**: 導出の戦意（繋ぎ・傷・飛んでいる弾）は `prelude` の手で溜め、`waitUntil fresh`（連撃の段と入力の列が 1 段目へ戻る）を待ってから見せる手に入る。溜め込む戦意は `setup.moraleFull` で満たす。奥義は `setup.ultimate` で選び、奥義ゲージを満たす
- **右の段の押し方**: 段カウンタは左右共有なので、右の i 段目は「i 手の後に右」。`laneSequence` が途中の手で派生に当たらない列を選ぶ（右の少ない順。反動で下がる段を途中に挟まない列を優先）。銃の家系の左（射撃）は段を進めないので右だけで数える
- **木人の距離**: 武器種の左の段の届きから決め、技ごとに 1 回だけ**実際に回して**当たる距離を選び直す（`calibrateFoeDistance`。届き・反動・弾の寿命は定義から決めきれない）。数値は `src/data/balance/feel/MANUAL.json`
- **決定性**: 箱庭の中の乱数（`state.rng`・固定の seed）だけを使う。同じ台本なら毎回同じ動き。本編の state・リプレイには触れない
- **描画**: `Renderer.renderDemo` が world 層だけを窓へ切り抜いて描く（本編と同じ絵）。床は実演専用のチャンク（ポーズから開いて戻っても本編の床を焼き直さない）。演出トラッカー（`track`）は触らない

## 3. 確かめない技（`expect: "none"`）

網羅テストは全技の実演が「木人に当たる / 戦意を放つ」かを確かめる。次だけ外す（テストが列を縛る）。

- 剣の受け流し（振らない構え）
- 反動で下がる振り（砲・擲弾の筒の振り、短銃の至近撃ち、爪の跳び退き）と、それを途中に挟む銃の家系の列。**下がってから振るので、密着した敵にも届かない**（実演で分かった。2026-10-02 時点の仕様のまま。直すかはユーザーに聞く）
- 砲の型の放出で、床に残る設置弾を撃たない器（砲・擲弾の一番早い器）。曲射は落ちた所で炸裂し、放出の段に届く前に床の弾が 0 に戻る

## 4. 入口と操作

- タイトルの記録（M）・ポーズのメニュー。ポーズからは今の武器種の頁で開く
- ↑↓ 技を選ぶ / ←→ 武器種 / ホイール 頁や一覧を送る / Enter・窓のクリック 最初から / Esc 戻る

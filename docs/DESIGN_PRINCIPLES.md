# ゲームデザインの原則

新しい要素を足す前に照らし合わせる短いリスト。詳細は `docs/LOOT_DESIGN.md` と `docs/ideas/*.md`。

## 操作

1. **常に操作していたい**: 入力の密度と精度に報酬を返す。操作していない時間（待ち・移動だけ・回復待ち）を減らす（`docs/ideas/action-feel.md` の F 章）。スキルは気力消費 + 共通最低間隔で「撃ち続けないと枯渇も渋滞もする」資源ループにし、左右クリックを気力を溜める手段に据えて常時入力を要求する（`docs/COMBAT_DESIGN.md` B 章）
2. **ヴァンサバ禁止**: オート攻撃・自動照準・放置で強くなる仕組みは入れない。スキルも手動で撃つ
3. **テレグラフ**: 敵の攻撃は必ず予備動作（windup）を見せてから出す。避けられない攻撃を作らない。深層でもテレグラフは基準の 60% を下限にする
4. **予備動作は攻めの合図でもある**: カウンターヒット（怯み値 ×2）・見切り・祝福の見切り斬り / 弾返しのように、読んだ人が得をする。無効化手段はデフォルトを最小限（ダッシュ無敵の短縮 + 見切り + リゲインのみ）に絞り、確定スタガーは廃止して怯み値の蓄積（攻撃を重ねるほど怯ませやすい代わりに単発では止まらない）に置き換えた。それ以外の無効化はスキル石・祝福・装備の性質へ回し、選んだ人だけが持つ（`docs/COMBAT_DESIGN.md` C・D 章）
5. **手触りの数値は 1 か所**: `src/data/tuning.ts`。実プレイで調整する前提で書く
6. **左手で完結するキー配置**: 右手はマウス。キーボード操作は左手の届く範囲に置く

## ビルド（装備・スキル・祝福）

7. **ゴール装備を作らない**: BiS（これさえあれば最強）が成立しない構造にする。各プレイヤーが自分の最強を追える
   - **トレードオフ**: 強いアフィックスほど代償を持つ
   - **逓減（ソフトキャップ）**: 1 軸を盛るより組み合わせる方が得
   - **キーストーン**: 遊び方そのものを変える。排他グループで同時に成立しない組がある
   - **トリガー文法**: trigger × condition × effect の組み合わせ。固定リストではなく文法
   - **シナジーの網**: burn / chill / shock / コンボ / ダッシュ / 射撃がタグで掛け合う
8. **比較できない UI**: DPS やアイテムスコアのような単一指標を出さない。ツールチップは「何ができるか」を語る。例外は拠点の稽古の間の計測の欄（自分で条件を決めて測る検証の道具。装備・ビルドの画面とツールチップには出さない。`docs/ideas/dojo.md`）
9. **層の住み分け**:
   - 永続装備 = 数値と方向性の土台
   - スキル石 = 動詞（何ができるか）。レベルや tier を持たない
   - 刻印符・祝福 = ラン内の揺らぎ。**数値盛りではなくルール変更**。装備タグと掛け算になる形
10. **持ち帰った遺物が永続**（2026-10-02 に「拾った瞬間に永続」から改めた）: ランへ持ち込めるのは右手の武器 + 2 部位（`CARRY.json`）。ラン中に拾った遺物は袋に入り、ランの終わりに枠の分（死亡 1・踏破 3。荷車で増やすのは後の段）だけ持ち帰る。持ち帰った分と持ち込んだ遺物は死んでも失わず、袋の残りは消える。緊張は「何を持ち帰るか」の判断とラン内要素（祝福・刻印符・Reaper）で作る。持ち帰りの枠が狭いので「この 1 つ」を選ぶ行為がビルドの方向を決め、ゴール装備を作らない哲学と噛み合う（`docs/ideas/run-arc.md` 2 章）
11. **ステータスは行動ごとの係数で効く**: ステータスが決まった行動を伸ばす固定の効果は作らない。行動（武器種の各段・銃・スキル・状態異常）ごとに「基礎値 + ステータス × 係数」を持ち、参照先は効果から見て納得できるものにする。計算式は詳細欄で見せる（`docs/STATS_AND_SCALING.md`）
12. **共鳴は源と糧**: 同じ語を起こす出どころ（源）と、その語を条件に強くなる出どころ（糧）がそろうと、その語に段が立つ。数えるのは装備だけでなくスキル石・祝福・流儀・型・改鋳・誓約。色は分類で、共鳴には関わらない（実装済み。`docs/LOOT_DESIGN.md`）

## ラン

13. **山場を作る**: 部屋ロック → 全滅 → 解放、ボス階、Reaper による「進め」の圧力
14. **毎ラン違う**: フロア種別・部屋種類・祝福・刻印符で同じ装備でも違う遊びになる
15. **決定的**: 同じ seed + 同じ入力で同じ結果。リプレイ・デイリーシード・QA の土台

## 見た目と音

16. **ドット絵はコード内ピクセルマップ**。外部素材なしで足せる。後でスプライトシートに差し替え可能
17. **効果音は合成**。外部素材なし。ロジックは名前を積むだけ
18. **気持ちよさの演出**: ヒットストップ・画面揺れ・ラストキル・スロー・見切りのスロー。演出はロジックに影響させない
19. **文字は日本語が主**。表記は `docs/GLOSSARY.md` に揃える

# ハクスラ装備システム 設計メモ（響き・揺らぎ・来歴）

目的: ローグライク（ランごとのランダムフロア・パーマデス）に、**永続する装備ドロップ** を融合する。
「同じアイテムが 2 つ出る方が珍しい」レベルの無限バリエーションを目指す。
PoE 由来の骨格（prefix / suffix・tier・rarity・Chaos / Exalt 型の通貨）は 2026-09 に撤去し、
docs/ideas/loot-identity.md の推奨案「響き・揺らぎ・来歴」に置き換えた。

## 設計哲学: 「ゴール装備」を作らない

ハクスラやモンハンにある「これを作れば最強」というテンプレ（BiS）を潰す。各プレイヤーが自分だけの最強を追い、しかもそれらに優劣が付かない状態を目指す。そのための仕組み:

1. **トレードオフ**: 強い性質ほど代償を持つ（例: +melee damage / -attack speed、+projectiles / -damage per projectile）。純粋な上位互換を作らない
2. **逓減（ソフトキャップ）**: 同じ数値を積むほど伸びが鈍る（`computeStats` で +100% を超えた分は sqrt 圧縮など）。1 種類を盛るより組み合わせる方が強い
3. **誓約（旧キーストーン）**: 遊び方そのものを変える大型改造（例: 硝子の砲 = ダメージ 2 倍 / 最大生命 1/4、狂戦士 = 失った生命に比例して攻撃力、瞬歩 = ダッシュがテレポート化して着地で爆発するが無敵なし、不殺 = 近接不可 / 射撃 3 倍）。相互排他グループがあり、同時に成立しない組み合わせがある
4. **トリガー文法**: `trigger × condition × effect` の組み合わせで性質を生成する（例: "見切り時 → 次の 3 ヒットが燃える"、"コンボ 10 以上のとき → 5 ヒットごとに衝撃波"）。固定リストではなく文法なので組み合わせは事実上無限
5. **シナジーの網**: 元素・コンボ・ダッシュ・射撃・近接がタグで相互作用し（burn は attack speed で伸びる、chill は shatter を可能にする、shock は弾数で連鎖が増える…）、局所最適が無数にある
6. **比較不能な多次元**: アイテムスコアや DPS 数値を UI に出さない。ツールチップは「何ができるか」を語る
7. **共鳴の排他**（追加）: 装備全体の色の配合で共鳴が同時に 1 つだけ発現する。どの共鳴を選ぶかで最適な遺物が入れ替わる
8. **揺らぎと反転**（追加）: 深層の遺物は「強い」のではなく「荒い」。最上振れを狙うと反転の危険を背負う
9. **来歴の分岐**（追加）: 性質が増えるのは使い込んだ末の芽吹きだけ。芽は 2 択で、捨てた枝は戻らない

## 原則

- アイテムは **ランを跨いで永続**。拾った瞬間に stash（localStorage）へ保存される。死んでも失わない
- 装備は次のランの開始時に `computeStats(equipment)` で `PlayerStats` に畳み込まれ、ゲームロジックはその数値だけを見る
- 生成は **純関数 + seedable RNG**。同じ seed / 深度なら同じアイテム。芽の候補も `item.seed + 節目` から決まり、`state.rng` を消費しない
- データ駆動: 性質とベースは `src/loot/affixes.ts` / `src/loot/bases.ts` に列挙し、追加が容易であること
- 型は `src/loot/types.ts` に集約。旧フィールド（`AffixRoll.kind` / `tier`）は旧セーブ互換のため optional で残す

## 用語

| 用語 | 内部名 | 意味 |
| --- | --- | --- |
| 遺物 | `Item` | 装備アイテム全般 |
| 性質 | `AffixRoll`（旧 affix） | アイテムに宿る 1 つの性質。表の性質 / トリガー文法 / 変換 / 誓約 |
| 色 | `TraitColor` | 紅 crimson / 蒼 azure / 翠 jade / 金 gold / 冥 umbra |
| 期待値 | `nominal` | 発見深度で決まる、その性質の標準的な強さ |
| 揺らぎ | `flux` | 期待値からの相対的なずれ。`value = nominal × (1 + flux)` |
| 反転 | `inverted` | flux < -1 で値が負になった性質。色は冥、共鳴への重み 2 倍 |
| 余白 | `margin` | まだ芽吹ける数 |
| 来歴 | `provenance` | 装備中に起きた出来事の記録 |
| 節目 | `MILESTONES` | 来歴の閾値。到達で芽が出る |
| 芽 | `budOffer` / `buds` | 節目で出る 2 択の成長。選ばなかった方は消える |
| 銘 | `inscription` | 余白を使い切ったアイテムに来歴から刻まれる名前 |
| 共鳴 | `Resonance` | 装備全体の色の配合で発現する効果。同時に 1 つ |
| 誓約 | `ks_`（旧 keystone） | 冥色の、遊び方を変える性質 |
| 名のある遺物 | `namedKey`（旧 unique） | 性質が固定の遺物（値は小さく揺らぐ） |
| 残響 | `EchoWallet` | 分解で得る色ごとの素材（紅響 / 蒼響 / 翠響 / 金響 / 冥響） |

## スロット（6）

| slot | ベース例 | 役割 |
| --- | --- | --- |
| weapon | dagger / shortsword / longsword / greatsword / spear | 近接の基礎ダメージ・速度・リーチ |
| gun | pistol / smg / rifle / shotgun | 射撃の基礎ダメージ・連射・弾数・貫通 |
| armor | cloth / leather / chain / plate | 生命・アーマー・被ダメ軽減 |
| boots | sandals / boots / greaves | 移動速度・ダッシュ |
| ring | ring 系 | 何でも（クリティカル、元素、吸血…） |
| amulet | amulet 系 | 何でも（ユーティリティ寄り） |

ベースは `implicit`（固定の暗黙補正 + ロール幅）と **色の傾き**（`colors.ts` の `BASE_LEAN`。生成時にその色の性質が 2 倍選ばれやすい）を持つ。implicit は色を持たず、配合にも減衰にも関わらない。

## 色と共鳴（`src/loot/colors.ts` / `src/loot/resonance.ts`）

### 5 色の意味

| 色 | 担う性質 |
| --- | --- |
| 紅 | 近接・与ダメージ・炎 |
| 蒼 | 射撃・機動・冷気・気力 |
| 翠 | 生存・回復 |
| 金 | 必殺・コンボ・会心・雷 |
| 冥 | 誓約・呪い（重い代償）・反転した性質 |

性質の色は定義の `color`、無ければ tags から決める（`colorFromTags`）。tag `mana` は他の tag より優先して蒼。トリガー文法は効果と起点から決める（`triggerColor`）。生成時に 10% で **異色**（既定と別の色）になる。

### 配合と判定

1. 装備中の全性質（implicit 除く）の色ごとに重みを足す。重み = `|value / nominal|`（0.25〜3。強く振れた性質ほど強く響く）、反転は 2 倍
2. 重みの合計が 3 未満なら共鳴しない（性質 1〜2 個で支配にならない）
3. 比率にして **冥の支配（虚極）→ 陰画 → 支配 → 二重 → 三和音 → 散光 → 拮抗 → なし** の順で最初に成立した 1 つを採用する

| 共鳴 | 条件 | 効果 |
| --- | --- | --- |
| 支配 | 1 色が 50% 以上 | 色ごとの極（下表）。他の色の性質は 75% に弱まる |
| 二重 | 上位 2 色がそれぞれ 30% 以上 | 組ごとの効果（下表） |
| 三和音 | ちょうど 3 色がそれぞれ 22% 以上（4 色目は 22% 未満） | 3 色の組ごとの効果（下表）。3 色それぞれのステータス +1 |
| 散光 | 全色が 30% 未満 | 虹: 主要倍率 +5%、必殺ゲージ獲得 +10% |
| 陰画 | 反転した性質の重みが全体の 35% 以上で、反転を除いた配合に冥以外の支配色がある（冥の支配は虚極のまま） | 支配の効果が裏返る（下表）。`kind` は dominant、`form` は negative |
| 拮抗 | 他のどれも成立せず、反対色の組（紅と蒼 / 翠と金）がそれぞれ 25% 以上で差 5% 以内 | 天秤 / 表裏（下表）。`kind` は dual、`form` は balance |
| なし | 上のどれでもない | 何も起きない |

陰画・拮抗は `Resonance.kind` を既存の値のまま `form` で見分ける（kind で分岐するスキル・状態異常の仕組みを壊さない）。

| 陰画 | 名前 | 効果 |
| --- | --- | --- |
| 紅 | 冷たい炎 | 燃焼の確率がすべて冷気の確率に変わる。射撃 +10% |
| 蒼 | 熱い氷 | 冷気の確率がすべて燃焼の確率に変わる。射撃時 25% で周囲を燃やす |
| 翠 | 枯れ森 | 命中・撃破・自然回復で戻る生命が半分。被弾時に衝撃波 |
| 金 | 暗雷 | 会心が出なくなる。感電しやすく、近接で 35% の連鎖雷 |

| 拮抗 | 名前 | 効果 |
| --- | --- | --- |
| 紅と蒼 | 天秤 | 近接と射撃を交互に当てるたび与ダメージ +8%（2 秒以内に交互に当て続ける間は重なる。上限 +32%） |
| 翠と金 | 表裏 | 生命が半分以上なら与ダメージ +10%、半分未満なら被ダメージ -15% |

### 星座（6 部位の主色の並び）

共鳴とは別の層で、同時に 1 つ（表の順で最初に成立したもの）。**すべて代償を持つ**（最強の並びを作らない）。主色 = 遺物 1 つの性質（implicit 除く）で重みが最も大きい色（同点は先に付いた性質の色。無色の性質は数えない）。部位の輪は 武器 - 銃 - 首飾り - 鎧 - 靴 - 指輪 - 武器。成立中の星座は `stats.resonance.constellation`、説明は `describeResonance` の末尾に「星座 〜」の行で出る。

| 星座 | 並び | 効果 | 代償 |
| --- | --- | --- | --- |
| 双子 | 武器と銃が同じ主色 | 近接と射撃の上乗せの 25% がもう片方にも効く | 攻撃速度・連射速度 -5% |
| 対岸 | 武器と銃が反対色 | 直前と違う攻撃手段で当てると怯み値 +40% | 同じ手段が続くと怯み値 -15% |
| 背骨 | 首飾り・鎧・靴が同じ主色 | 被ダメージ -10% | 移動速度 -6% |
| 環 | 6 部位の主色に 5 色すべて | 全ステータス +2 | 最大気力 -10 |
| 鏡像 | 向かい合う 3 組（武器と鎧・銃と靴・首飾りと指輪）が同じ主色 | 装備トリガーの内部クールダウン -25% | 最大生命 -15 |
| 虚空 | 主色が冥の遺物が 3 つ以上で隣り合わない | 反転した性質の負の値が 0 | 被ダメージ +8% |
| 鎖 | 6 部位すべてが隣と違う主色 | 持ち替えて当てるたび気力 +2 | 気力回収 -10% |

判定順は 冥の支配 → 陰画 → 支配 → 二重 → 三和音 → 散光 → 拮抗。判定の規則は誓約と一部の性質で変わる（`resonanceRules`）: 単色の誓い（支配だけ・35% で成立・効果 2 回・他色 50%）/ 無色の誓い（共鳴なし・性質 +20%）/ 鏡の誓い（色を反対色で数え、冥は数えない）/ 橋渡し・双頭の指輪（二重の条件を下げる。下限 20%）。

三和音（10）: 紅蒼翠 四季 / 紅蒼金 雷雨 / 紅蒼冥 煤 / 紅翠金 祭 / 紅翠冥 血肉 / 紅金冥 賭場 / 蒼翠金 凪 / 蒼翠冥 沼 / 蒼金冥 流星 / 翠金冥 輪廻（効果は `TRIAD_EFFECTS`）。

支配（5）:

| 色 | 名前 | 効果 |
| --- | --- | --- |
| 紅 | 灼極 | 3 回に 1 回の近接で周囲を燃やす。近接 +10% |
| 蒼 | 氷極 | 射撃時 25% で周囲を凍らせる。弾速 +15% |
| 翠 | 森極 | 被弾時 50% で生命 8 回復。生命自然回復 +0.5 |
| 金 | 雷極 | 10 コンボ以上の近接命中で 30% 連鎖雷。会心率 +5% |
| 冥 | 虚極 | 反転した性質の負の値を正として扱う。被ダメ +10% |

二重（10）: 紅蒼 蒸気 / 紅翠 血潮 / 紅金 閃火 / 紅冥 焦身 / 蒼翠 潮流 / 蒼金 霜雷 / 蒼冥 影弾 / 翠金 活脈 / 翠冥 澱 / 金冥 賭け（効果は `DUAL_EFFECTS`）。

## 揺らぎ（`src/loot/flux.ts`）

- **期待値**: 性質の期待値曲線（旧 tier 表を「深度 → 幅の中央」の点列として読んだもの）を深度で線形補間する
- **強さの係数**（2026-09-24、memo「序盤から装備が強すぎて 5 層くらいまでヌルゲー化する」）: 生成時の期待値に `FLUX.globalScale`（0.8）× `depthScale(深度)`（深度 1: 0.75 → 深度 5: 0.85 → 深度 10 以降: 1 を線形補間）を掛ける。深度 1 で 0.6、深度 5 で 0.68、深度 10 以降で 0.8。`affixes.ts` の点列は触らず、係数だけで全体を締める（`flux.ts` の `powerScaleAt` / `scaledNominalAt`、`generator.ts` の `rollTableTrait` / `rollTriggerTrait`）。変換の性質は割合なので掛けない。共鳴・三和音の効果値は深度に依らないので `globalScale` だけを掛ける（`resonance.ts` の `amt` / `frac`。代償・発動確率・回数は掛けない）。既に拾った遺物の値は変わらない
- **揺らぎ**: σ = min(0.12 + 0.05 × 深度, 1.0) ×（1 + 0.1 × boost）。flux は三角分布（-1.3σ, 0, +1.5σ）で、下限は -0.9
- **反転**: 発見深度 13 以降、表の性質（変換・トリガー以外）が 4% + 1%/深度（上限 15%）で反転する。|値| は期待値の 20〜90%、色は冥
- **性質の数**: 期待値 min(1 + 0.12 × 深度, 3.5) + 三角分布（半幅は 1 → 2 へ深度で広がる）を 0〜5 に収める
- **余白**: 5 - 性質の数（+ 揺らぎ -1..0）を 1〜4 に収める。性質が少ない遺物ほど育てる余地が大きい
- **中身**: 各性質は 25% でトリガー文法、外れたら 10% で変換（1 アイテム 1 つまで）、それ以外は表から。性質 3 以上なら 8% で 1 つを誓約に置き換える
- **見た目の分類**（旧 rarity のキーを流用。格付けではない）: 反転あり → `unique`「反転あり」、|flux| の最大が 0.45 以上 → `rare`「荒」、0.15 以上 → `magic`「揺」、それ未満 → `normal`「静」

## 来歴と芽（`src/loot/provenance.ts`）

- `recordProvenance(state, event)` を combat / floor から呼び、**装備中の全アイテム** の来歴を進める（撃破〔敵種別・ボス〕/ 見切り / 被弾 / 部屋制圧 / 階層踏破 / 最深）
- 節目（表の順に判定）: 撃破 50 / 見切り 20 / 被弾 40 / ボス 1 / 階層 10 / 部屋 25 / 撃破 200 / 見切り 60 / 被弾 150 / ボス 3 / 階層 30 / 撃破 500（以降は「2026-09 の拡張」の節）
- 余白が 1 以上で提示中の芽が無ければ、到達済み・未提示の最初の節目で **芽（2 択）** を出す。片方は節目の色、もう片方は反対色（紅↔蒼、翠↔金、冥→翠）。候補は `item.seed + 節目` から決まる純関数
- 過去に出た候補の key（選ばなかった方を含む）は二度と出ない
- 芽は `Item.budOffer` に保存され（ランを跨いで残る）、装備中のものは `state.pendingBud` に載る。UI が表示し、`chooseBud(state, index)`（`src/system/loot.ts`）で選ぶ。選ぶと性質が `origin: "bud"` で加わり、余白が 1 減り、stats を畳み込み直す
- 余白が 0 になると来歴から **銘** を刻む（`names.ts` の `engraveName`）。最も目立つ来歴が名詞、2 番目が修飾（例:「見切りのスライム喰らい」「王殺しの不屈」）

## クラフト（残響。`src/loot/crafting.ts`）

原則: **ランダムに性質を足す操作は無い**。性質が増える経路は芽だけ。

| 操作 | 素材 | 中身 |
| --- | --- | --- |
| 砕く | なし | 遺物を分解し、性質 1 つにつきその色の残響を 1 得る（性質が無ければベースの傾きの色を 1） |
| 染め | 目標色の残響 3 | 性質 1 つを、目標色の別の性質に置き換える。揺らぎは引き継ぐ |
| 鎮め | 性質の色の残響 2 | 揺らぎを半分にする（反転は解ける）。代償に余白 -1 |
| 煽り | 冥響 2 | 揺らぎを σ × 1.2 で引き直す。反転の危険がある（最低 10%） |
| 削ぎ | 性質の色の残響 1 | 性質 1 つを消し、余白を 1 戻す（器の容量 5 まで） |
| 移し | 冥響 3 | 銘か芽吹いた性質 1 つを、同じ部位の別の遺物へ移す。元の遺物は消え、受け手の余白を 1 使う |
| 転調 | 反対色の残響 3 | 性質 1 つの色だけを反対色へ変える（値・揺らぎはそのまま）。反転と誓約は変えられない |
| 脱色 | 翠響 2 | 性質 1 つを無色にする（`AffixRoll.colorless`）。共鳴の配合に数えず、支配の減衰も受けない。値と期待値は 9 割。反転・誓約・無色は不可 |
| 呼び戻し | 冥響 5 | 過去の芽で選ばなかった方を取り直し、選んでいた方を失う（`BudChoice.recalled`）。1 つの遺物に 1 回。選んだ芽を削いでいたら不可 |
| 注ぎ | なし | 遺物を捧げ、来歴の半分（切り捨て、最深は深い方）を同じ部位の別の遺物へ注ぐ。捧げた遺物は消える。届いた節目の芽はその場で出る |
| 鍛え直し | 性質の色の残響 4 | 性質 1 つの期待値を来歴の最深で取り直す（揺らぎ・張り・脱色の倍率は保つ）。余白の上限 -1（`Item.reforged` に回数）。期待値が上がらなければ不可 |
| 張り | 冥響 2 | 代償付きの性質 1 つの利得と代償を両方 1.3 倍（期待値ごと掛けるので鎮めでも戻らない。`AffixRoll.tensed`）。1 つの性質に 1 回 |

乱数は専用 RNG（`item.id + クラフト回数`）で決定的。通貨不足・成立しない操作は拒否し、何も消費しない。
残響とクラフト回数は `roguelike.craft.v1`（version 2）に保存する。

## 名前（`src/loot/names.ts`）

- 銘があれば銘
- 名のある遺物は固有名

## PlayerStats（派生値）

`types.ts` の `PlayerStats` と `DEFAULT_STATS` を参照。ゲームロジック側は **必ず** `state.stats` を通して読む。

## ドロップ（`src/system/loot.ts`）

- 方針（2026-09-24）: 「たくさん倒しても出ない、強敵を倒すと出る」。通常敵と部屋制圧を絞り、精鋭・ボス・巣窟の主・宝物庫・試練は据え置く
- 敵撃破: 敵ごとの `dropChance`（3〜30%）+ 深度 × 0.5% に、通常敵は深度別の倍率 `LOOT_DROP.mobDropMulByDepth`、徘徊・増援（`roomIndex = ROAMING_ROOM`）はさらに `roamingDropMul` ×0.5 を掛ける。エリートは `eliteDropMul` ×0.35（追加抽選にも効く）。ボス・巣窟の主（確定）は掛けない

| 深度 | 1 | 2 | 3 | 4 以降 |
| --- | --- | --- | --- | --- |
| 通常敵の倍率 | ×0.1 | ×0.12 | ×0.15 | ×0.2 |
| 部屋制圧で報酬が出る確率（`roomClearChanceByDepth`、旧: 必ず 1 個） | 10% | 12% | 15% | 20% |

- 階層到達の報酬は `depthArrivalChance` 35%（旧: 必ず 1 個）
- 経緯（QA 0.0.7α → 再調整）: 開放型フロアで塊の制圧と撃破の回数が増え、1 run の拾得数が前回（80b26cf）比 1.5〜2.6 倍になった。撃破あたりの落下は 4〜7%、徘徊・増援の撃破は全撃破の 1〜2 割で主因ではなく、通常敵・エリート・部屋制圧・階層到達を一律に絞って 6 装備合計で前回比 67% にした
- 特別な報酬（共鳴炉・増援の撃退・狂月）は `dropBonusReward` で必ず 1 個（呼び出し側の差し替えは統合待ち。差し替えるまでは部屋制圧と同じ確率）
- 宝物庫・試練・ボスは boost（揺らぎの増幅）が大きく、荒い遺物や名のある遺物が出やすい
- 生成深度 = depth + rng(0..2)
- 格付けの抽選は無い。深さが期待値・揺らぎ幅・性質の数を決める
- 床のアイテムは光柱 + 名前ラベル。触れると即 stash へ（ログとフローティングテキストは最も多い色）

## 旧セーブの移行

アイテムとクラフト通貨はそれぞれ別キーで、別の場所で移行する。どちらも冪等（新形式ならフィールドを補うだけ）。

**アイテム**（`src/loot/migrate.ts`）: `loadProfile`（`src/loot/profile.ts`）がアイテム単位で旧形式（`provenance` を持たない）を検出し、`migrateItem` で変換する。プロフィールのキー `roguelike.profile.v1` と version 1 は据え置き。

- tier → 揺らぎ: T1 +0.4 / T2 +0.2 / T3 0 / T4 -0.1 / T5 -0.2 / T6 -0.3。期待値は |value| / (1 + flux) で逆算（値は変えない）
- 負の値（旧 Corrupt）→ 反転（冥）。腐敗の印は捨てる
- 旧 rarity → 余白: normal 4 / magic 3 / rare 2 / unique 1
- 旧 rare の 2 語名は銘として残す。旧 unique は固有名から名のある遺物の key を引く
- `lifeOnHit`（旧: 命中ごとの固定回復）は与ダメの % に換算する（×1.5、`LEGACY_LIFE_ON_HIT_PCT_PER_FLAT`）。新形式で固定値だった頃のアイテムは印が無く見分けられないため、値をそのまま % として読む（旧曲線 1〜5 と新曲線 2〜8% の幅はほぼ重なる）

**クラフト通貨**（`src/loot/crafting.ts` の `convertLegacyWallet` / `src/loot/craftingStore.ts`）: `roguelike.craft.v1` の version 1（旧通貨 dust / shard / essence / relic）を読み込み時に残響へ換算する。1 / 2 / 4 / 8 点として合計し、5 色へ均等に配る（余りは色の並び順に 1 ずつ）。旧クラフト API（`craft` / `CRAFT_OPS` / `Wallet`）は撤去済みで、この換算だけが移行のために残る。version を 2 に上げて保存し直すと旧 wallet は消える

- 残響タブ（`ui/echoTab.ts` / `render/echoTabUi.ts`）: 状態機械（対象を倉庫から選ぶ → 操作を選ぶ → 性質〔・色 / 移し先〕を選ぶ → 実行ボタン）。装備中の遺物は対象にできない。実行を押すまで何も消費しない。クラフト本体は `craftEcho` / `applyEchoResult` / `ECHO_OPS` / `ECHO_LABEL` / `ECHO_OP_LABEL`
- 3 タブの共通部品は `render/lootUiParts.ts`（色の配合バー・性質の行・枠の色定数）に集約

## core
- `createGame(seed, seedText, profile, skillProfile)` → `GameState`。`step(state, input: FrameInput, dt)` が 1 固定ステップ
- 固定 60Hz（`core/loop.ts` の `FIXED_DT`）。ロジックは `FrameInput` と `dt` だけを見る
- 乱数は `state.rng`（mulberry32、`core/rng.ts`）だけ。`Math.random` は `audio/synth.ts` の音の揺らぎ以外で禁止
- `Date.now()` はアイテム / スキル石の `id` と `foundAt` を作る `now` 引数にだけ使う（ゲーム進行に影響させない）。`main.ts` の計時は別
- `core/replay.ts`: seed + FrameInput 列 + 装備スナップショット + 装備変更イベントで再現。`core/input.ts` / `gamepad.ts` が入力（パッドのボタン設定は `padBinds.ts`）、`view.ts` が 480x270 と `RENDER_SCALE`（描画バックバッファの固定倍率、既定 4 = 1920x1080）
- `core/status.ts`: 状態異常の型（`StatusKind` / `StatusEffect` / `StatusBag` / `StatusApply` / `StatusProc`）と一覧。ロジックは持たない（`system/statusEffects.ts` が読む）
- `core/damage.ts`: 与ダメの増・倍の型と純関数（`DamageTag` / `IncreasedTable` / `MoreMul` / `DamageContext` / `sumIncreased` / `productMore`）
- `core/scale.ts`: 深度の曲線 `curveAt`・三角分布 `triangular`・平均に掛ける揺らぎ `rollSpread`（敵の曲線・陣の生命の揺らぎ・装備の揺らぎの共通の器。純関数）
- `core/rules.ts` 統一ルール文法の `Rule` 型 / `core/events.ts` ゲームイベント（各 system は `pushEvent` で積むだけ。`system/rules.ts` が照合）/ `core/keywords.ts` 共通語彙「語」の型（推論・集計は `system/keywords.ts`。共鳴の段 `ResonanceStep`）/ `core/build.ts` 祝福・名のある遺物が共有するビルドの語（`BuildChange` = 柱 7 の審査・`BoonAction` = 加護の宿る行動。`system/boonDefs.ts` が re-export）/ `core/element.ts` 属性とジャンル / `core/terrain.ts` 地形の層の型 / `core/vec.ts` ベクトル / `core/units.ts` 表示単位（`formatMeters` / 大きな数の `formatAmount`）
- `core/hurt.ts` 被弾の記録の型（`HurtKind`〔敵・余波・流れ弾・落下物…〕/ `HurtRecord` / `HurtLog`、`createHurtLog`）

# ステータスと係数（共通の決まり）

武器種・銃・必殺・スキル・状態異常・祝福など、**ステータスの効き方に触れる要素を足す・直すときに必ず従う決まり**。
設計の経緯は `docs/COMBAT_DESIGN.md` A-10、数値の置き場所は `docs/BALANCE.md`、表記は `docs/GLOSSARY.md`。

---

## 1. 原則

1. **ステータスは行動に縛られない**。「筋力 = 近接」「霊力 = 状態異常」のように、ステータスが決まった行動を伸ばす固定の効果は作らない
2. **行動ごとに係数を持つ**（LoL のレシオと同じ考え方）。どのステータスをどれだけ参照するかは行動が決める
   - 参照する数は 0 種（基礎値だけ）・1 種・複数・5 種全部のどれでもよい
   - 同じ近接でも武器種ごとに、同じ武器種でも段ごとに違ってよい。通常攻撃が複数を参照してもよい
3. **参照先は効果から見て納得できるもの**にする（2 章）。ばらけさせること自体を目的にしない
4. **計算式はプレイヤーに見せる**。どのステータスがどれだけ効くかを装備画面の詳細欄に出す（5 章）
5. **ステータスが基礎値（各 5）のときの値がバランスの基準点**。係数を変えるときは基準点を動かさない（4 章）

## 2. 各ステータスが表すもの

参照先を選ぶときの基準。行動の中身を言葉にして、当てはまるステータスを選ぶ。

| ステータス | 表すもの | 参照が似合う行動の例 | ステータスそのものの効果（体の性能） |
| --- | --- | --- | --- |
| 筋力 `str` | 力・重さ・押し込み | 大剣・槌・叩きつけ・投げ・重い弾 | なし（係数でだけ効く） |
| 技巧 `dex` | 速さ・精度・刃の鋭さ・手数 | 双剣・細剣・突き・連射・先端判定・出血 | 移動速度・ダッシュの再使用時間 |
| 体力 `vit` | 体を張る・受け止める・耐える | 盾・拳・体当たり・自傷を伴う技・反動を体で受ける射撃 | 最大生命・受ける状態異常の持続 |
| 精神 `mnd` | 集中・溜め・気力を練る・狙い澄ます | 溜め技・居合・杖の術理・会心寄りの一撃・必殺 | 最大気力・気力の自然回復 |
| 霊力 `spi` | 魔法・呪い・霊的な属性 | 闇・炎・雷の術、呪い、状態異常の源 | なし（係数でだけ効く） |

- 属性とも整合させる（炎の術 = 霊力、雷を体に引き寄せる = 体力 + 霊力 など、説明できる組み合わせ）
- 状態異常の効果量も同じ基準で選ぶ（出血 = 技巧、燃焼 = 霊力、毒 = 霊力 / 精神 など）
- **「体の性能」以外の固定の効果をステータスに足さない**。新しい効果を伸ばしたいときは、その効果を持つ行動の係数として足す

### 例外の扱い

| 形 | 使ってよい場面 | 今ある例 |
| --- | --- | --- |
| 0 種（基礎値だけ） | 使い手の素質に依らないと納得できる道具・仕掛け・固定の爆発 | 地雷・爆薬樽・砲台・銃の設置弾 |
| 3 種以上 | 体全体を使う・奥義の締めなど「なぜ全部か」を説明できるもの | 突進斬り・地裂き・墜星・砲身化・奥義（瞬閃・天墜） |
| 5 種全部 | 5 ステータスすべてに理由があるもの | 五彩の礫（5 色 = 5 ステータス）・極意（どの武器種でも出る奥義） |

## 3. 計算式

| 量 | 書き方 | 最終値 |
| --- | --- | --- |
| 威力 | `Scaling` = `{ base, str?, dex?, vit?, mnd?, spi? }`。**base はステータス 0 のときの値** | base + Σ(係数 × 実効値) |
| 怯み値 | `poise`（**ステータス基礎値のときの値**）+ `poiseRatio?` | poise + Σ(係数 × (実効値 − 5))、その後 × 装備の怯み値倍率 |
| 状態異常の効果量 | `StatusApply.potency`（基礎値のときの値）+ `ratio?` | 同上、その後 × 装備の効果量倍率（プレイヤーが付けるときだけ） |
| 強化系スキルの効果量 | `buffScaling`（基礎値で 1 になる Scaling） | 効果量の倍率として掛ける |

- 実効値 = 逓減後のステータス（20 まで等倍、40 まで 0.5、以降 0.25）。1 つに盛るより分けた方が合計が伸びる
- 係数は非負。ステータスを下げても最終値は負にしない
- 最終の与ダメは、この「係数による基礎の値」に装備・祝福・コンボ・会心・敵の防御などの倍率が掛かったもの
- 実装: `src/system/attributes.ts`（`scaled` / `withRatio` / `ratioToScaling` / `buffMul`）

## 4. 数値の決め方

- **基準点を守る**: 威力の base は「基礎値（各 5）で狙いの威力」から逆算する（base = 狙いの威力 − 5 × Σ係数）。係数の配り先だけを変えるときは Σ係数を保てば base は変わらない
- **成長の速さ（Σ係数）**: 同じ役割の行動と同程度にする。威力の目安は既存の近い行動に合わせる
- **怯み値の係数**: 合計で「怯み値 × 3% / 点」前後を、行動らしいステータスへ配る（`src/data/scalingVariety.test.ts` が 2〜4% に収まることを検査する）。怯み値の小さい段（5 未満）には付けなくてよい
- **状態異常の効果量の係数**: potency が意味を持つもの（燃焼・毒・出血・感電など）にだけ付ける。目安は potency × 3% / 点
- 数値はすべて `src/data/balance/**/*.json` に置く（TS に直書きしない）

## 5. 表示

- 装備画面の詳細欄の 3 頁目「計算式」（拾うキー G で 要点 → 詳しく → 計算式）に、行動ごとの式と今の値を出す。例「威力 14 = 8+筋力×0.7+体力×0.5」
- 要点の頁には「主に参照: 筋力・体力」の 1 行。何も乗せていないときは、ステータスごとに参照している行動の一覧
- 式は `src/ui/scalingText.ts` が組み立てる。スキルの数値ブロックに **新しい Scaling のキー**（damage / tickDamage 以外）を足したら、`SKILL_SCALING_LABEL` に日本語の見出しを足す（無いとテストが落ちる）
- ステータス名は 5 色（紅 / 蒼 / 翠 / 金 / 冥）で色分けする。単一指標（DPS など）は出さない

## 6. 足すときのチェックリスト

- [ ] 行動の中身を言葉にし、2 章の表から参照先を選んだ（理由を `_note` か報告に 1 文で書ける）
- [ ] 威力の `scaling`、怯み値の `poiseRatio`、状態異常を付けるなら効果量の `ratio` を決めた
- [ ] 基礎値（各 5）での値が狙いどおり（`scaledAtBase` で確認）
- [ ] 0 種・3 種以上・5 種全部にしたなら、例外の表に当てはまる理由がある
- [ ] ステータスそのものに新しい固定の効果を足していない
- [ ] 詳細欄の計算式の頁に出ることを確かめた（新しい Scaling のキーなら見出しを足した）
- [ ] `npm run check` が通る

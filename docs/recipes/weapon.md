# レシピ: 武器種 / 銃の弾

- `src/data/weapons.ts`: `MOVESET_KEYS` に key を足し `MOVESETS` に `MovesetDef`（左の連撃 `steps` 各段の `MeleeStepDef`: windup / active / recover / `Scaling` / 怯み値と `poiseRatio` / 当たり判定の形 `HitShape` / 手触りの任意項目、右の連撃 `steps2`、派生 `branches`）。武器の群（近接・銃・投擲物）は `WEAPON_GROUP_OF` に 1 行足す（`GUN_MOVESETS` / `THROWING_MOVESETS` はそこから作る。`isGun` = 群が銃、`isRangedWeapon` = 近接でない、`shootsPrimary` = 左で撃つ）。左で撃つなら `primary: "shot"`。数値は tuning の `WEAPON`
- **近接の当たり判定の外縁は振った武器の先端まで**（`data/meleeReach.test.ts`）: 形の外縁（box / circle は `reach + size / 2`、arc は半径、thrust は長さ）を「握り 7px + 手に持つ絵の握りから刃先（`src/data/actor/` の武器の生成一覧）+ 1px」以内にする（突きと、腕ごと打つ拳・爪・盾は +5px、鎖で振る連接棍・鎖鎌は +8px）。敵の半径は当たりの計算が足すので、刃が敵の体に触れたら当たる。刃の外まで届くのが個性の段（鞭・扇子の風・鎖投げ・鎌鼬・杖の渦巻き・刀の居合）はテストの `BEYOND_BLADE` に理由と一緒に足す。溜めの段は `reachMul` を 1 にする（溜めは威力と怯み値で伸ばす）。数値を変えたらエフェクトを `ppnpm run fx:gen --atlas <武器種>` で描き直す（絵が当たり判定の大きさに揃う）
- **武器種を足したら**: `loot/colors.ts` の `BASE_LEAN` にも 1 行（`Record<MovesetKey>` の漏れは型エラーで分かる）。絵が無いうちは `render/actorSprites.test.ts` の `UNDRAWN_WEAPONS` と `render/fxSprites.test.ts` の `UNDRAWN_MOVESETS` に
- **武器の型（必須）**: `data/weapons.ts` の各武器種の spec に `form: FormKey`（`data/weaponForms.ts`）。放出の段は `FORMS.<型>.morale.release`（右レーンの段の key を `keys` に）。新しい型の足し方は `docs/ideas/weapon-forms-impl.md` 3-10。型の定義（`defineForm` に渡す `FormSpec`）には共鳴の数えに使う `keywords`（`kw(源, 糧, 強め)`）が必須。型を足したら改鋳 2 つを `data/reforges.ts` と `src/data/balance/weapons/REFORGE/<型>.json` に足し、改鋳の語は `data/reforges.ts` の `REFORGE_KEYWORDS`（`Record<ReforgeKey, KeywordProfile>` なので漏れは型エラー）に書く
- **段数の幅**: 左の段数は型の `FORM.<型>.stepsMin / stepsMax`（`weapons.test.ts` が検査）。連刃は 6〜8 段。右レーンも同じ段数。連続する段で式が同じなら計算式の頁で畳まれる（`ui/scalingText.ts` の `mergeSameActions`）。段を足したら fx の絵が要る（無いうちは `render/fxSprites.test.ts` の `UNDRAWN_MOTIONS` に）
- **武器の重さ（必須）**: `movesets/<key>.json` の先頭に `"weight": "light" | "medium" | "heavy"`（`reviveWeight` が照合）。重さ別の係数は `src/data/balance/weapons/WEAPON/weightClass.json`（攻撃中の移動の帯 `moveMulMin/Max`・終撃の移動 `finisherMoveMul`・ダッシュで取り消せない相 `lockActive` / `lockRecoverRatio`・硬直 `recoverMul`・通常命中のヒットストップ・重さの補償 `damageMul` / `poiseMul`）。決め方は `docs/ideas/core-synthesis.md` 3-2: 動き続けて避ける武器は軽、終撃だけ足が遅くなるのは中、振る時機を読む武器は重。攻撃中の移動の倍率は遅くしても **0（足が完全に止まる）にしない**（ユーザーの決定 2026-10-02。`weapons.test.ts` が検査）。`attackMoveMul` が帯から外れる武器種は `weapons.test.ts` の `EXPECTED_CLAMP` に理由付きで足す
- **振りの速さの段（必須）**: 近接の武器種は `docs/ideas/weapon-tempo.md` の 5 段（最速・速・中・重・最重）のどれかに入れ、1 段目の予備動作をその段の目安（0.06 / 0.08 / 0.12 / 0.2 / 0.36 秒）にする。速い段ほど 1 撃は軽く、遅い段ほど 1 撃が重く終撃が跳ね上がる（連撃の秒間威力の目安も同じ文書）。`data/weapons.test.ts` の `TEMPO_TIERS` に key を足す
- **射撃の型（共有の弾の表）は無い。弾は銃のベースごとに持つ**: 数値は `src/data/balance/weapons/WEAPON/bullets.json` の `<ベースの key>`（`BulletDef` の数値。sway / homing / bounce / charge / mine / burst / boomerang / lob の挙動ブロックを持てばその挙動になる）、語と素性は `src/loot/bullets.ts` の `BULLET_PROFILES`。銃のベースを足したら両方に 1 件ずつ足す（`balance.test.ts` がキー集合を検査）。右レーンの弾の段は `steps2[n].throw.bullet` に自分の弾を持つ（弾の key は `art.<段の key>`）
- **右レーン（アクション 2）の段の足し方**（`docs/ideas/ougi-and-dual-actions.md` 4 章）: `src/data/balance/weapons/WEAPON/movesets/<key>.json` の `steps2` に段を並べる（近接は `steps` と同じ段数、銃の家系は 3 段。段カウンタは左右で共有）。段は `{"_id":"secondary<段>.<key>","kind":"swing","key":…,"step":{…}}`（`_id` は左の段にも `primary<段>.<技>` で置く。形は `docs/BALANCE.md`「書式と行の名札」）（振り。`cooldown` / `selfKnock` / `detonateMines` / `knockToward`〔"ownMine" = 一番近い自分の設置弾の方へ飛ばす〕は任意）/ `hold`（`hold.parry` か `hold.guard`、`release` で離した振り）/ `volley`（`throw` に弾と威力）/ `charge`（居合）。`kind` は union 文字列なので `reviveActionStep` が照合する。key ごとに `STEP2_NAMES`（表示名）、1 段目だけ `STEP2_DESC`（説明）、弾の段は `STEP2_VOLLEY`（素性・絵。無ければ射撃・物理）に 1 行。数値の目安は「左の同じ段番号と同じ秒間威力、右は重い・広い寄りで recover ×1.2」。振り以外の段の挙動を足すなら `system/weaponArts.ts` の `startLaneArt` 振り以外の段に `chainWindow`（秒）を書くと、その段の後に次の段を受け付ける猶予だけ上書きできる（`laneChainWindow`。再使用の間が猶予を食う杖の氷など）
- **派生の足し方**: `movesets.<key>.branches.<派生の key>` に `sequence`（3 入力以上。左右を混ぜる）・`step`・任意の `next`（続きの段）/ `shots`（弾。`from: "lane"` で右レーンの弾）/ `selfKnock` / `detonateMines`。表示名は `BRANCH_NAMES`。派生の `sequence` は「実際に出た段」（振り・右レーンの技・銃の射撃）の列と照合する（予備動作中の押下は数えない。`player.ts` の `plannedInputs`）。武器種ごとに名前付き 4 本以上（`data/weapons.test.ts`）。名前は `docs/GLOSSARY.md`・祝福・スキル・奥義と重ねない
- **奥義（F）の足し方**（`docs/ideas/ougi-and-dual-actions.md` 3 章）: 武器種ごとに 3 本（一撃と持続を両方含む）。`src/data/ultimates.ts` の `<武器種>Set`（例 `swordSet`）に 1 行。一撃は `instantDef(m, "<名前の key>", "表示名", "説明", 素性, (n) => [行為…])`（行為は `nova` / `swing` / `lunge` / `volley` / `pull` / `buff` / `detonate` / `packedShot`〔弾倉の残りを全部詰めて撃ち出す。砲〕。`swing` / `lunge` は列の最後だけ）、持続は `sustainDef(m, "<名前の key>", …, (n, key) => ({ ...sustainCore(n), patch: patchOf(n), rules: [sustainRule(key, …)] }))`。数値は `src/data/balance/ultimates/ULTIMATE/defs/<武器種>.json` の `<名前の key>`（行為ごとのブロック、持続は `drainPerSec` / `minSec` / 倍率）に足す（`data/ultimates.test.ts` が JSON と定義の集合を照合）。新しい武器種は `SET_BUILDERS` にも 1 行。行為・差し替えの挙動を足すなら `system/ultimates.ts`（`runAct` / `ultimateMoveset` / `ultimateShot`）。名前は `docs/GLOSSARY.md` の「奥義の名前の一覧」に足し、派生・右の段・祝福・スキルと重ねない
- 祝福・統一ルール・性質が「設置弾を撃つとき」のように弾で絞るときは、弾の性質（`BulletFeature`。数値から `bulletFeatures` が読む）で書く（`BoonLoadout.bullets` / 条件 `{ kind: "bullet", has }` / `statsBulletHas`）。ベースの key で分岐しない
- 各段・弾の参照ステータスは `docs/STATS_AND_SCALING.md` に従う（効果から見て納得できるもの。怯み値の `poiseRatio` も付ける）
- ベースへの紐付け: `src/loot/bases.ts` の `BASES` で右手のベースに `moveset` を指定（`PlayerStats.moveset` へ流れる）。銃の家系のベースは `PlayerStats.bullet` に自分の key が入る
- 呼び出し側: `system/player.ts` が `stats.moveset` で `MOVESETS` を、`stats.bullet` で `loot/bullets.ts` の `BULLETS` を引いて発動処理を分岐
- **武器指南書**（`docs/ideas/weapon-manual.md`）: 武器種・段・派生・奥義は定義から自動で載る。特色の一文だけは手書きで `data/weaponFeatures.ts` の `MOVESET_FEATURE` に 1 行（押し方は書かない。`meta/weaponText.test.ts` が検査）。`meta/weaponManual.test.ts` が全技の実演（木人に当たる / 戦意を放つ）を回して確かめる。落ちたら台本（`meta/weaponManual.ts`）か段の届きを見直す。反動で下がる振りのように当たらないのが仕様の技は `expect: "none"` にし、テストの許す列に足す
- テスト: `data/weapons.test.ts` / `loot/bullets.test.ts` / `system/weaponArts.test.ts`（右レーンの段）/ `system/player.test.ts`（左右の共有の段カウンタ・派生）/ `data/ultimates.test.ts`・`system/ultimates.test.ts`（奥義）。計算式の欄が書付 1 枚に収まるかは `render/sheetUi.test.ts`（行動が増えて溢れたら `ui/scalingText.ts` の畳み方を見直す）。右レーンと派生の係数表は `data/scalingVariety.test.ts` の `LANE_TABLE` が受ける

最後に `pnpm run check`。関係するファイルの役割は `docs/CODE_MAP.md`、数値は `docs/BALANCE.md`、表示文字列は `docs/GLOSSARY.md`。
- **近接の威力の係数**: 近接の段の `scaling` は復元時に `WEAPON.meleeDamageScale`（0.6）を掛ける（`data/weapons.ts` の `meleeScaling`）。JSON は掛ける前の値。弾（`throw.scaling`・銃の弾）・スキル・奥義には掛けない。右手が空なら拳の型で `stats.unarmed`（表示名「素手」、威力 × `WEAPON.unarmed.damageMul`）
- **武器 Wave 4 の共通の仕組み**（`docs/ideas/weapons-wave4.md` 1 章。テストは `system/weaponMechanics.test.ts`）: 振りが弾を出す `cast`（弾の key `cast.<key>`、名前は `CAST_NAMES`、素性は `CAST_VOLLEY`）、弾の状態異常 `throw.applies`、弾の見た目 `bullet.look`、消えた位置に地形を残す `bullet.leaves`、周回 `bullet.orbit`、振りで敵弾を消す段の `cutsBullets`、溜め中の周期ヒット `charge.spinning`、墨印を記す弾が読まない目印 `HitOptions.inscribes` / `OnHitContext.inscribes`
- 説明に「投げる」とある弾・技を足したら `render/thrownLook.ts` の表に載せる（飛ぶ武器の絵）。載せないなら `render/thrownLook.test.ts` の `EXCLUDED` に理由を書く（テストが検出する）
- **弾と資源・派生の弾**（`docs/ideas/gun-bases-review.md` 0 章）: プレイヤーの弾（Projectile）の命中・炸裂では気力も奥義ゲージも溜まらない（銃・投擲物・杖や書の魔法の弾も同じ。近接の振りの命中だけが溜める）。派生の弾の `shots.count` は「普段の 1 回の射撃（1 + 弾数 + 散弾の粒、三点）を何回撃つか」（A 案）
- **型の放出の形**（`data/weaponForms.ts` の `MoraleRelease`）: 銃の型には `nextMagazine`（満ちたその込めの弾倉が強装填。短銃）/ `nextShot{keys}`（左の次の 1 発か keys の段。装薬）/ `nextPrimary` の `gate: "rifle"`（溜めの器は最大段、溜めでない器はリロード後の 1 発目だけ。長銃）/ `bothHands`（左右同時押しの撃ち尽くし。二丁）がある。弾倉の数値は `bullets.json` の器の `magazine`、リロード中の足は `movesets/<key>.json` の `reloadMoveMul`
- **戦意あり用のアクション**（放出だけを別に調整する口。最初は普段と同じ中身を写す）: 放出になる振りの段に `releaseStep`（段を丸ごと。長柄の突き・居合の溜め・構えの離しも）、右レーンの振りの付随効果は `releaseExtras`、振りの cast は `releaseThrow`（戦輪の大輪）、左の放出の 1 発は武器種の `releaseShot`（器の弾に浅く重ねる。苦無・長銃）、二丁の撃ち尽くしは `hands.releaseUnload`。型の倍率 `perUnit` はこの上に掛かる。新しい放出の段を足したら `releaseStep` も置く（`system/releaseActions.test.ts` が検査）
- **銃の弾倉の足し方**（`system/magazine.ts`。`Player.magazine` は戦意とは別。手を 2 本持つ〔二丁拳銃だけ左右、他は 0 番〕）: 弾倉は引き金の回数で数える（散弾の粒・三点は 1 回。派生の弾は射撃の回数ぶん減り、足りなければ残りの分だけ撃つ）。容量・リロード秒は `bullets.json` の器の `magazine`（`perRoundSec` があれば 1 発ずつ込める砲の形）。リロード中の足は `movesets/<key>.json` の `reloadMoveMul`。撃ち切ると自動で込め、キー（既定 T。`FrameInput.reloadPressed` / `reloadHeld`）でも込める。短銃の早込めは `quickReload`（`from` / `sec` / `missSec`。窓で押すと即込め終わりで戦意）、砲の詰めは `pack`（`levelSec` / `max`。満ちた後も込め続けると段が上がる）、二丁拳銃の左右の手は `hands`（`system/dualPistols.ts`）。銃の武器種を足すなら、型の戦意の出来事に弾倉の語（`quickReload` / `pack` / `alternateShot` / `blastHit`）を使えるか先に見る。遠距離の命中で気力・奥義ゲージが溜まらない代わりに、銃には資源を戻す近接（右レーン）を持たせる
- **投擲物（刺さる・食い込む・弧で飛ぶ）の足し方**（`docs/ideas/gun-bases-review.md` 0-5・2-9。群は `throwing`。器は武器種に直接ぶら下がるクナイ・手裏剣と、器を選ぶ戦輪）。弾（`bullets.json` の `<ベースの key>`）の挙動ブロックで飛び方が決まる: `pin`〔`PinDef`: 敵に刺さって `Enemy.pins` に残る。`max` 本まで・`sec` 秒で抜ける・`driveMul` = 叩き込みの追撃の倍率・`staggerAt` = 刺さり崩し（同じ種類がこの本数刺さると怯ませて消す）。種類は `PIN_KINDS`、処理は `system/pins.ts`〕/ `grind`〔食い込み: 当てた最初の敵に `sec` 秒とどまって `hits` 回当たる。牙輪〕/ `arc`〔弧で飛ぶ: `bulge` のふくらみで行き、折り返して反対側の弧で手元へ戻る。`catchRadius` で収まる。`range` があればカーソルでなく固定の射程（連撃の近投げ）〕/ `pair`〔2 枚投げ: 口元から直交する両側へ `offset` ずらして 2 枚〕。行きと帰りの両方で当てた敵を数える投げの組は `ShotRuntime.trip`（戦意の `roundTrip`）。弾の挙動は `BULLET_FEATURES` の語（`pin` / `arc`）に出る
- **投擲物の技の仕組み**（段の任意項目。数値は `movesets/<key>.json`）: `MeleeStepDef.drivePins`（`true` = 刺さっているものを全部叩き込む / 数 = 古い順にその本数だけ。クナイの逆手斬り・返し斬りは 1 本、叩き込みは全部。叩き込みの追撃は素性なしで、起点と気力は振りの命中が持つ）/ `passThrough`（踏み込みの道筋で重なった敵も斬り、前へ押さず脇へ払う抜け斬り）と `manaPerTarget`（斬った敵 1 体ごとに気力を戻し `MANA.meleeTargetCap` を外す。遠距離で溜まらない気力の戻し口。手裏剣のダッシュ攻撃）/ 振りの cast・弾の段の弾の `burst`（器の三点と同じ形の連射。1 本ずつ間を置いて同じ向きへ続けて投げる。手裏剣の左の 3 連射。`system/player.ts` の `queueArtBurst`）/ `BranchShots.lifeMul`（弾の寿命の倍率。足元へ投げる影留め）と `BranchShots.applies`（命中に付ける状態異常。影留めの足止め）/ `MovesetDef.chainAdvance: "alternate"`（左右を替えるときだけ連撃の段が進む。同じ手を続けても段はそのまま。最後の段は同じ手で続かない。手裏剣）/ `MovesetDef.dashCooldownMul`（その武器種を持つ間のダッシュの再使用時間の倍率。手裏剣は 2 倍で、代わりに武器種の Rule「撃破でダッシュの回数をすべて戻す」`refillDash` を持つ）/ `MovesetDef.waitForReturn`（投げた輪が戻るまで左の射撃も連撃も進まない。`system/projectiles.ts` の `ringsInFlight`。投げている間は手ぶらに見せる。戦輪）
- **投擲物の型の戦意**（`data/weaponForms.ts`）: 出来事は `pinDriven`（叩き込んだ本数。苦無）/ `pinStagger`（刺さり崩しで怯ませた回数。手裏剣）/ `roundTrip`（行きと帰りで当てた敵。戦輪）。放出は苦無 = `nextPrimary`（次の左が千本）、手裏剣 = `timed { sec, attackSpeedMul }`（満ちた後の次の投げで始まる連ね投げ。`system/morale.ts` の `timedAttackSpeedMul`）、戦輪 = 強化投げの段（`laneStep`。満ちていれば大輪になり貫いて戻る）
- **奥義の行為（投擲物・砲）**: `pinNova`（周りの敵すべてに `pins` 本ずつ刺す。当たった敵へ 1 回の傷を与え、その威力を刺さりの威力にする。苦無の影縫いの陣）/ `detonatePins`（刺さっているものを全部炸裂させ、1 本ごとに刺さったときの威力 × `damageMul`。爆ぜクナイ）/ `packedShot`（弾倉の残りを全部詰めて 3 段の詰めの 1 発を撃ち出し、反動 `selfKnock` で下がる。砲の全弾発射。値は `src/data/balance/weapons/FORM/powder.json` の詰め 3 段に揃える）。持続は `SustainDef.lanes { moveset }`（持続中、連撃を別の武器種の振りに差し替える。手裏剣の龍刃が刀を抜く。型・戦意・ダッシュ攻撃は装備のまま）と `SustainDef.pinDriveMul`（叩き込みの追撃の倍率。苦無の暗器）。戦輪の奥義の輪は輪刃の弧の弾を借りて数と大きさを差し替える（`ultimates.ts` の戦輪の volley）
- **派生の弾（A 案）**: 派生の弾の `shots.count` は「普段の 1 回の射撃を何回撃つか」（1 回の射撃の形 = 1 + 装備の弾数 + 散弾の粒・三点は捨てない）。派生の弾は弾倉を射撃の回数ぶん減らし、残りが足りなければ残りの分だけ撃つ。散弾・三点の器の派生は強くなるので `damageMul` は引き直す。三点の 2・3 本目も同じ射撃として放出と持続の奥義の補正を受ける（終撃は 1 本目だけ）。放出の弾に揺れは掛けない
- **新しい群・述語**: 武器の群は `MovesetDef.group`（`WEAPON_GROUP_OF`）。`isGun`（銃。弾倉・銃の決まり）/ `isThrowingWeapon`（投擲物）/ `isRangedWeapon`（近接でない。器が弾を持つ・武器掛けの器の段）/ `shootsPrimary`（左の押しっぱなしで器の弾を撃つ）。「銃だけ」「投擲物にも」の分岐は群の述語で書き、武器種の key で分けない。武器掛けの 3 段（群 → 武器種 → 器）は `ui/rackScreen.ts`

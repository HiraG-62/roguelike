# レシピ: 武器種 / 銃の弾

- `src/data/weapons.ts`: `MOVESET_KEYS` に key を足し `MOVESETS` に `MovesetDef`（左の連撃 `steps` 各段の `MeleeStepDef`: windup / active / recover / `Scaling` / 怯み値と `poiseRatio` / 当たり判定の形 `HitShape` / 手触りの任意項目、右の連撃 `steps2`、派生 `branches`）。左で撃つ銃の家系は `primary: "shot"` にして `GUN_MOVESETS` に足す。数値は tuning の `WEAPON`
- **近接の当たり判定の外縁は振った武器の先端まで**（`data/meleeReach.test.ts`）: 形の外縁（box / circle は `reach + size / 2`、arc は半径、thrust は長さ）を「握り 7px + 手に持つ絵の握りから刃先（`src/data/actor/` の武器の生成一覧）+ 1px」以内にする（突きと、腕ごと打つ拳・爪・盾は +5px、鎖で振る連接棍・鎖鎌は +8px）。敵の半径は当たりの計算が足すので、刃が敵の体に触れたら当たる。刃の外まで届くのが個性の段（鞭・扇子の風・鎖投げ・鎌鼬・杖の渦巻き・刀の居合）はテストの `BEYOND_BLADE` に理由と一緒に足す。溜めの段は `reachMul` を 1 にする（溜めは威力と怯み値で伸ばす）。数値を変えたらエフェクトを `npm run fx:gen -- --atlas <武器種>` で描き直す（絵が当たり判定の大きさに揃う）
- **武器種を足したら**: `loot/colors.ts` の `BASE_LEAN` にも 1 行（`Record<MovesetKey>` の漏れは型エラーで分かる）。絵が無いうちは `render/actorSprites.test.ts` の `UNDRAWN_WEAPONS` と `render/fxSprites.test.ts` の `UNDRAWN_MOVESETS` に
- **武器の型（必須）**: `data/weapons.ts` の各武器種の spec に `form: FormKey`（`data/weaponForms.ts`）。放出の段は `FORMS.<型>.morale.release`（右レーンの段の key を `keys` に）。新しい型の足し方は `docs/ideas/weapon-forms-impl.md` 3-10。型の定義（`defineForm` に渡す `FormSpec`）には共鳴の数えに使う `keywords`（`kw(源, 糧, 強め)`）が必須。型を足したら改鋳 2 つを `data/reforges.ts` と `src/data/balance/weapons/REFORGE/<型>.json` に足し、改鋳の語は `data/reforges.ts` の `REFORGE_KEYWORDS`（`Record<ReforgeKey, KeywordProfile>` なので漏れは型エラー）に書く
- **段数の幅**: 左の段数は型の `FORM.<型>.stepsMin / stepsMax`（`weapons.test.ts` が検査）。連刃は 6〜8 段。右レーンも同じ段数。連続する段で式が同じなら計算式の頁で畳まれる（`ui/scalingText.ts` の `mergeSameActions`）。段を足したら fx の絵が要る（無いうちは `render/fxSprites.test.ts` の `UNDRAWN_MOTIONS` に）
- **武器の重さ（必須）**: `movesets/<key>.json` の先頭に `"weight": "light" | "medium" | "heavy"`（`reviveWeight` が照合）。重さ別の係数は `src/data/balance/weapons/WEAPON/weightClass.json`（攻撃中の移動の帯 `moveMulMin/Max`・終撃の移動 `finisherMoveMul`・ダッシュで取り消せない相 `lockActive` / `lockRecoverRatio`・硬直 `recoverMul`・通常命中のヒットストップ・重さの補償 `damageMul` / `poiseMul`）。決め方は `docs/ideas/core-synthesis.md` 3-2: 動き続けて避ける武器は軽、終撃だけ足を止めるのは中、振る時機を読む武器は重。`attackMoveMul` が帯から外れる武器種は `weapons.test.ts` の `EXPECTED_CLAMP` に理由付きで足す
- **振りの速さの段（必須）**: 近接の武器種は `docs/ideas/weapon-tempo.md` の 5 段（最速・速・中・重・最重）のどれかに入れ、1 段目の予備動作をその段の目安（0.06 / 0.08 / 0.12 / 0.2 / 0.36 秒）にする。速い段ほど 1 撃は軽く、遅い段ほど 1 撃が重く終撃が跳ね上がる（連撃の秒間威力の目安も同じ文書）。`data/weapons.test.ts` の `TEMPO_TIERS` に key を足す
- **射撃の型（共有の弾の表）は無い。弾は銃のベースごとに持つ**: 数値は `src/data/balance/weapons/WEAPON/bullets.json` の `<ベースの key>`（`BulletDef` の数値。sway / homing / bounce / charge / mine / burst / boomerang / lob の挙動ブロックを持てばその挙動になる）、語と素性は `src/loot/bullets.ts` の `BULLET_PROFILES`。銃のベースを足したら両方に 1 件ずつ足す（`balance.test.ts` がキー集合を検査）。右レーンの弾の段は `steps2[n].throw.bullet` に自分の弾を持つ（弾の key は `art.<段の key>`）
- **右レーン（アクション 2）の段の足し方**（`docs/ideas/ougi-and-dual-actions.md` 4 章）: `src/data/balance/weapons/WEAPON/movesets/<key>.json` の `steps2` に段を並べる（近接は `steps` と同じ段数、銃の家系は 3 段。段カウンタは左右で共有）。段は `{"kind":"swing","key":…,"step":{…}}`（振り。`cooldown` / `selfKnock` / `detonateMines` は任意）/ `hold`（`hold.parry` か `hold.guard`、`release` で離した振り）/ `volley`（`throw` に弾と威力）/ `charge`（居合）/ `aim`（狙い撃ち）/ `recall`（手元返し）。`kind` は union 文字列なので `reviveActionStep` が照合する。key ごとに `STEP2_NAMES`（表示名）、1 段目だけ `STEP2_DESC`（説明）、弾の段は `STEP2_VOLLEY`（素性・絵。無ければ射撃・物理）に 1 行。数値の目安は「左の同じ段番号と同じ秒間威力、右は重い・広い寄りで recover ×1.2」。振り以外の段の挙動を足すなら `system/weaponArts.ts` の `startLaneArt` 振り以外の段に `chainWindow`（秒）を書くと、その段の後に次の段を受け付ける猶予だけ上書きできる（`laneChainWindow`。再使用の間が猶予を食う杖の氷など）
- **派生の足し方**: `movesets.<key>.branches.<派生の key>` に `sequence`（3 入力以上。左右を混ぜる）・`step`・任意の `next`（続きの段）/ `shots`（弾。`from: "lane"` で右レーンの弾）/ `selfKnock` / `detonateMines`。表示名は `BRANCH_NAMES`。派生の `sequence` は「実際に出た段」（振り・右レーンの技・銃の射撃）の列と照合する（予備動作中の押下は数えない。`player.ts` の `plannedInputs`）。右レーンの手元返し `recall.homing` で戻りの弾が近くの敵を追う。武器種ごとに名前付き 4 本以上（`data/weapons.test.ts`）。名前は `docs/GLOSSARY.md`・祝福・スキル・奥義と重ねない
- **奥義（F）の足し方**（`docs/ideas/ougi-and-dual-actions.md` 3 章）: 武器種ごとに 3 本（一撃と持続を両方含む）。`src/data/ultimates.ts` の `<武器種>Set`（例 `swordSet`）に 1 行。一撃は `instantDef(m, "<名前の key>", "表示名", "説明", 素性, (n) => [行為…])`（行為は `nova` / `swing` / `lunge` / `volley` / `pull` / `buff` / `detonate`。`swing` / `lunge` は列の最後だけ）、持続は `sustainDef(m, "<名前の key>", …, (n, key) => ({ ...sustainCore(n), patch: patchOf(n), rules: [sustainRule(key, …)] }))`。数値は `src/data/balance/ultimates/ULTIMATE/defs/<武器種>.json` の `<名前の key>`（行為ごとのブロック、持続は `drainPerSec` / `minSec` / 倍率）に足す（`data/ultimates.test.ts` が JSON と定義の集合を照合）。新しい武器種は `SET_BUILDERS` にも 1 行。行為・差し替えの挙動を足すなら `system/ultimates.ts`（`runAct` / `ultimateMoveset` / `ultimateShot`）。名前は `docs/GLOSSARY.md` の「奥義の名前の一覧」に足し、派生・右の段・祝福・スキルと重ねない
- 祝福・統一ルール・性質が「設置弾を撃つとき」のように弾で絞るときは、弾の性質（`BulletFeature`。数値から `bulletFeatures` が読む）で書く（`BoonLoadout.bullets` / 条件 `{ kind: "bullet", has }` / `statsBulletHas`）。ベースの key で分岐しない
- 各段・弾の参照ステータスは `docs/STATS_AND_SCALING.md` に従う（効果から見て納得できるもの。怯み値の `poiseRatio` も付ける）
- ベースへの紐付け: `src/loot/bases.ts` の `BASES` で右手のベースに `moveset` を指定（`PlayerStats.moveset` へ流れる）。銃の家系のベースは `PlayerStats.bullet` に自分の key が入る
- 呼び出し側: `system/player.ts` が `stats.moveset` で `MOVESETS` を、`stats.bullet` で `loot/bullets.ts` の `BULLETS` を引いて発動処理を分岐
- **武器指南書**（`docs/ideas/weapon-manual.md`）: 武器種・段・派生・奥義は定義から自動で載る。特色の一文だけは手書きで `data/weaponFeatures.ts` の `MOVESET_FEATURE` に 1 行（押し方は書かない。`meta/weaponText.test.ts` が検査）。`meta/weaponManual.test.ts` が全技の実演（木人に当たる / 戦意を放つ）を回して確かめる。落ちたら台本（`meta/weaponManual.ts`）か段の届きを見直す。反動で下がる振りのように当たらないのが仕様の技は `expect: "none"` にし、テストの許す列に足す
- テスト: `data/weapons.test.ts` / `loot/bullets.test.ts` / `system/weaponArts.test.ts`（右レーンの段）/ `system/player.test.ts`（左右の共有の段カウンタ・派生）/ `data/ultimates.test.ts`・`system/ultimates.test.ts`（奥義）。計算式の欄が書付 1 枚に収まるかは `render/sheetUi.test.ts`（行動が増えて溢れたら `ui/scalingText.ts` の畳み方を見直す）。右レーンと派生の係数表は `data/scalingVariety.test.ts` の `LANE_TABLE` が受ける

最後に `npm run check`。関係するファイルの役割は `docs/CODE_MAP.md`、数値は `docs/BALANCE.md`、表示文字列は `docs/GLOSSARY.md`。
- **近接の威力の係数**: 近接の段の `scaling` は復元時に `WEAPON.meleeDamageScale`（0.6）を掛ける（`data/weapons.ts` の `meleeScaling`）。JSON は掛ける前の値。弾（`throw.scaling`・銃の弾）・スキル・奥義には掛けない。右手が空なら拳の型で `stats.unarmed`（表示名「素手」、威力 × `WEAPON.unarmed.damageMul`）
- **武器 Wave 4 の共通の仕組み**（`docs/ideas/weapons-wave4.md` 1 章。テストは `system/weaponMechanics.test.ts`）: 振りが弾を出す `cast`（弾の key `cast.<key>`、名前は `CAST_NAMES`、素性は `CAST_VOLLEY`）、弾の状態異常 `throw.applies`、弾の見た目 `bullet.look`、消えた位置に地形を残す `bullet.leaves`、周回 `bullet.orbit`、振りで敵弾を消す段の `cutsBullets`、溜め中の周期ヒット `charge.spinning`、弾の命中ごとの気力の上書き `throw.mana`（`ThrowArtDef.mana` → `Projectile.shotMana`。省略は `MANA.onShot`）、墨印を記す弾が読まない目印 `HitOptions.inscribes` / `OnHitContext.inscribes`
- 説明に「投げる」とある弾・技を足したら `render/thrownLook.ts` の表に載せる（飛ぶ武器の絵）。載せないなら `render/thrownLook.test.ts` の `EXCLUDED` に理由を書く（テストが検出する）

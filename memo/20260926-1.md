# アイデア案
## アイテム
- 武器種「投擲」変更
  - 右クリックする前の通常の射撃時も弾速を遅くしたい。

- 武器種「杖」修正
  - 右クリックの氷技について、クールタイムが存在するのにコンボ入力待ち時間が短く、コンボをつなげにくいため、待ち時間を延ばす。

- 装備欄「頭」を追加
  - また、「鎧」を「体」「靴」を「足」に名称を変更する。

- 各種装備にて、ステータス上昇効果はデフォルトでほしい。
  - 武器なら、全ステータスの中からランダムで、武器種の主に参照するステータスが少し出やすくなるように。
  - 防具なら、防御力はデフォルトで付き、それ以外のステータスはランダムで、その部位ごとにそれぞれ少し出やすくなるように。
    - 頭: 筋力、技巧
    - 体: 体力 (防御が高くなりやすい)
    - 足: 技巧、体力
    - 指輪: 精神 (防御が低くなりやすい)
    - 首飾り: 霊力 (防御が低くなりやすい)
  - 属性耐性もランダムで付いたり付かなかったり。
  - 数値や何種類付くかはランダム。
    - 階層が深くなったり、レア度の高いアイテムは高く/多くなりやすい。
      - 割り振れる総リソースがランダムで決まり、階層が深くなったりすることでその総リソース量が高くなりやすくなる。
      - そこから数値が高くなったり項目数が増えたりするためにリソースが使われ、レア度が高いからといって数値も項目数もどちらも多くなるというようなことがあまりなくなるように。
    - ベースをかなり低い数値とし、急激なインフレを防ぐ。

  - ただし、これによりステータスが盛りやすくなり、強い装備が揃うことで序盤の階層がかなり簡単に突破可能になってしまう。ハクスラ要素としてはよいがローグライク要素が弱くなってしまうので一考の余地あり。


## スキル

## 戦闘システム
- 防御をステータスに追加。
  - 体の性能にある「防御力」とは別で、ステータスの防御が上がると防御力にも反映される。(ステータスの値そのままではなく係数で)
  - 防御を参照した攻撃を追加・既存技への反映を行う。ただし、防御力は装備で上げやすいことと、攻防兼ね備えられてしまうため、火力に関する係数値は低めが望ましい。

- 属性耐性は今は「魔防」というステータスでひとまとめにされているが、それぞれの属性ごとに個別で耐性値を設ける。

- 刻印符はランごとにリセットされるようにしてもいいかも？(ローグライク要素を強くするため。要検討)


## マップ
- 全階層にボスを用意し、ボスを倒すことで次の階層への道が出るように。
  - 5の倍数か10の倍数で強力なボスが出現。
  - 稀に隠し部屋が生成され、ボスと戦闘せずともお宝と次の階へ行けるように。(ただし上記の強力なボスが出る階層では生成されないものとする。)

- 次の階層に入ったときに減少体力の一部を回復する。

- 沸く敵の量を増やす。
  - マップの広さに対して湧く敵の量が少なすぎる。
  - 敵がまったくいない空間が広すぎる。
  - 今は通路と部屋の概念が分かれてるが、それを撤廃し、どこでも敵が湧くように。
  - 全体的にもっと敵に溢れていてわちゃわちゃしていてほしい。(ほどほどに)

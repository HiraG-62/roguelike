## 提案

1. depth 1 前後の敵密度・HPスケーリング（enemiesPerDepth / depthHpScale）を見直し、難度の急上昇を緩和する。
2. 死因トップの敵（reaper）の windup 時間や被弾判定の猶予を見直し、回避余地を増やす。
3. rare / unique 装備の有無で到達depthに大きな差が出ていない場合、レアアフィックスの倍率調整でビルドの手応えを強める。

## 問題（重大度順）

### 1（重大）1 対 1 被弾が 6.54→15.26 回/60秒に急増（目標 5〜6 回から大きく後退）

- **再現手順**: QA 標準ビルド（旋風斬り・撃ち抜き・突進斬り・グレネード固定、`buildQaSkillProfile`）で
  どの seed / 装備パターンでも良い（例: seed=1000, profileKind=dominantLoadout）。`npx vitest run
  src/qa/simulation.test.ts` の 1 対 1 被弾計測（`activeSkillMetrics.oneVOneHits`）で再現する。
- **原因の推測（根拠付き）**: 本コミットの bot 修正（`src/qa/bot.ts:257-296` の `skillEngageRange`）で、
  旋風斬り（whirl）等の自分中心近接スキルの有効射程が、修正前の一律 `SKILL_ENGAGE_RANGE`（150px）から
  `radius + MELEE_SKILL_RANGE_MARGIN`（whirl は 28+20=48px）に変わった。これは
  「遠距離から撃って素通りする空振り」を無くす狙い通りの修正で、スキル由来与ダメ比率の改善（33.4%→44.6%）
  にはつながっている。しかし 48px は `DANGER_RANGE`（55px、`src/qa/bot.ts:35`）の内側であり、bot の被弾回避
  ロジック（`combatInput`, `src/qa/bot.ts:505`）は敵が `windup`/`strike` フェーズのときしかダッシュ離脱を
  試みない（`isThreatening`, `src/qa/bot.ts:239-241`）。結果として、敵が windup/strike 以外のフェーズで
  近づいてくる間、bot は回避せずに 48px まで詰めてスキルを撃ち続けるようになり、敵の攻撃フェーズへの
  遷移に対して逃げ遅れる頻度が増えたとみられる。つまり「スキルが当たるようになった」ことと「被弾が
  増えた」ことは同じ射程変更が原因の表裏一体の結果。
- **担当**: `src/qa/bot.ts`（QA bot 側の問題。`combatInput` の危険判定を「windup/strike のときだけ」
  から「近接スキルの有効射程に入っている間は常時、一定確率で離脱を試みる」に広げるか、`DANGER_RANGE` と
  `MELEE_SKILL_RANGE_MARGIN` の関係を見直す）。ゲーム本体側の問題ではなく bot の意思決定ロジックの
  副作用である可能性が高い点に注意。人間プレイヤーなら windup 前でも危険を察知して距離を取れるため、
  実プレイでの被弾率がこの数値通りに悪化しているとは限らない。

### 2（中）depth 3 の到達率低下が目標範囲をわずかに超過（−21.7%、目標 −10〜−20%）

  強すぎる可能性がある。深刻度は高くないが、次回調整で depth 3 前後の敵密度/HPスケーリングを少し戻す
  余地がある。

### 3（軽微）状態異常の内訳が偏った（脆弱 +215%・堅守 +146%・毒 −95%）

- 毒（poison, 撃ち抜きの付与）が 127→6 回に激減している一方、脆弱・堅守は急増。撃ち抜き（railshot）の
  毒付与条件かヒット数が今回の調整（マナコスト/威力変更）で変わった可能性がある。バランス上の優先度は
  低いが、撃ち抜きの状態異常付与ロジック（`src/skills/data.ts` の railshot 定義）に変更が無いか確認する
  価値はある。

## 調整提案（次回向け、3 件まで）

1. **1 対 1 被弾の急増（問題1）への対処は bot 側が本命**。`src/qa/bot.ts` の危険判定（`combatInput`）を
   windup/strike 限定ではなく、近接スキルの `skillEngageRange` 圏内にいる間は常時一定確率で評価するように
   広げる。ゲーム側の定数（`src/data/tuning.ts`）をこれ以上動かす前に、まず計測方法（bot の回避行動）を
   実プレイに近づけて、被弾急増が「ゲームが厳しくなった」のか「bot が下手になった」のかを切り分けたい。
2. depth 3 の到達率超過分（−21.7%、目標 −20% 以内）を緩和するため、`src/data/tuning.ts` の
   `enemiesPerDepth` をわずかに下げる（現在 1.0 → 0.9 目安）か、depth 3 だけの HP スケーリング係数を
   据え置きにする。d2 は範囲内なので depth 全体ではなく depth 3 前後にピンポイントで効かせたい。
3. スキル比率は改善傾向（33.4%→44.6%）なので、`src/data/tuning.ts` のスキル威力を追加で強めるより先に、
   上記 1 の bot 行動修正後に再計測し、被弾が落ち着いた状態でスキル比率がどこに収まるかを見てから
   威力/コストを再調整する（同時に複数の変数を動かすと問題1の切り分けができなくなる）。

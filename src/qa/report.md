## バランス所見

- depth 2 での死亡が最多（54 件 / 144 件中）。この階の難度がボトルネックになっている可能性がある。
- 死因として最も多く推測されたのは "bat"（22 件）。
- 平均到達depth: 素手 1.43 / rare装備 3.67 / unique装備 3.17。
- キーストーン所持時の平均到達depthは非所持時より 0.40 高い（正なら強化、負ならリスクが上回っている）。
- 1 ステップの平均処理時間は 0.340ms（60fps 予算 16.6ms に対し余裕あり）。
- 平均到達depth（色配合）: 単色寄せ 2.80 / 2色 3.20 / 5色散光 2.87。

## 提案

1. depth 2 前後の敵密度・HPスケーリング（enemiesPerDepth / depthHpScale）を見直し、難度の急上昇を緩和する。
2. 死因トップの敵（bat）の windup 時間や被弾判定の猶予を見直し、回避余地を増やす。
3. rare / unique 装備の有無で到達depthに大きな差が出ていない場合、レアアフィックスの倍率調整でビルドの手応えを強める。
4. キーストーンつき装備が事故死を増やしている場合は、リスクに見合ったリターン（回復・被ダメ軽減の代替経路）を補強する。
5. Reaper 出現後に倒しきれず時間切れで死ぬケースが目立つ場合は、warnAfter / appearAfter の猶予時間を調整する。

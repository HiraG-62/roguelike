## バランス所見

- depth 2 での死亡が最多（43 件 / 161 件中）。この階の難度がボトルネックになっている可能性がある。
- 死因として最も多く推測されたのは "reaper"（73 件）。
- 平均到達depth: 素手 1.73 / rare装備 5.00 / unique装備 4.40。
- キーストーン所持時の平均到達depthは非所持時より 1.30 高い（正なら強化、負ならリスクが上回っている）。
- 1 ステップの平均処理時間は 0.038ms（60fps 予算 16.6ms に対し余裕あり）。
- 平均到達depth（色配合）: 単色寄せ 3.07 / 2色 3.43 / 5色散光 4.80。

## 提案

1. depth 2 前後の敵密度・HPスケーリング（enemiesPerDepth / depthHpScale）を見直し、難度の急上昇を緩和する。
2. 死因トップの敵（reaper）の windup 時間や被弾判定の猶予を見直し、回避余地を増やす。
3. rare / unique 装備の有無で到達depthに大きな差が出ていない場合、レアアフィックスの倍率調整でビルドの手応えを強める。
4. キーストーンつき装備が事故死を増やしている場合は、リスクに見合ったリターン（回復・被ダメ軽減の代替経路）を補強する。
5. Reaper 出現後に倒しきれず時間切れで死ぬケースが目立つ場合は、warnAfter / appearAfter の猶予時間を調整する。

### ドアタイル上でロックされた敵が「壁の中」判定になる（未解消、今回も非検出。継続監視）

- **状況**: `overlapsWall`（lockedTiles 込み、`src/system/physics.ts`）判定による壁めり込み検出は、
  前々回のフル版（戦闘再設計 段階 1 コミット後）で 3 件（1.7%）検出されたあと、前回（L6: bot の
  4 スロット・マナ対応後）・今回（バランス調整＝通常攻撃 −20%・マナ回収/回復増・スキル+10%・敵間隔
  ×0.9・ノックバック 0.45・湧き+1、および振り分け bot を `allocateAttribute` 直呼びへ変更した後）
  と **2 回連続で 0 件**。`anyEnemyInWall` の判定ロジック自体（`src/qa/simulation.test.ts`）は
  据え置きで変更していない。
- **推測**: bot がマナ/スキル主体で戦うようになった段階から、敵の突破経路・戦闘の滞在時間・死亡
  深度の分布が変わり、問題の起きやすい経路（ドアタイル上でロックされた敵が壁扱いになる状況）に
  bot が到達しにくくなったとみられる。今回の到達depthは前回よりやや低下（rare 5.73→5.00、
  unique 4.60→4.40）し、死因トップも depth 分布が浅め寄りに変化しており、この傾向と整合する。
  **根本原因（`src/system/floor.ts` の `lockRoom` / `src/system/physics.ts` の `isSolidTile` の
  非対称）は未修正のまま**なので、発生頻度が下がっただけで直ったとは断定できない。ただし 2 回連続
  0 件であり、経路依存で低頻度化している可能性が前回より高まった。
- **担当**: `src/system/floor.ts`（`lockRoom` 時にドアタイル上の敵へ猶予を与える／室内側へ押し出す）
  または `src/system/physics.ts`（`isSolidTile` の壁とロックの扱いを分ける）。固定 seed の再現手順
  は今回も得られていない（0 件のため）。次回以降も 0 件が続けば監視の優先度を下げてよい。
